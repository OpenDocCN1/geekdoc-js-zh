(1) The center of the road
If you want to control the cam robot to the center of the road, you will control so that the slope of the straight line connecting the left and right sensor values is horizontal (that is so that the difference between the left and right sensor values to 0).
Even if there is a difference in the sensor values on the left and right in the same black area, there should be somewhere where the inclination is almost horizontal. Control it with the goal.
To respond to the intersection of road lines, the second edition of this book only deals with running along the center of the road.
What explained here is only an example.
Besides this, your readers may find innovative ways.
There is no right answer for control. Failure is natural.
The most important thing is to think of various ways for yourself and try hard.
(2) Operation procedure
After turning on the power,
1) Place the cam robot on the white part of the paper on which the course is drawn and press the B button to read the white sensor value.
To confirm that you have pressed it, it will display the number 1 on the micro:bit LED screen.
2) Place the left and right sensors on the black part of the paper and press the B button to read the black sensor value.
Similarly, the number 2 is displayed on the LED screen of mcro:bit.
The order of 1) and 2) can be reversed. At the end of this operation, the white and black representative values and the median value are determined. If this operation is omitted, the default value will be used.
3) Place the two central sensors on the line and press the A button to start.
4) Press the B button to stop at any time. Since the typical values of black and white are remembered, the operation can be restarted simply by pressing the A button.

(4) Fuzzy calculation
The above fuzzy calculation is described in detail in "Fuzzy & PID2" of the same "Discover How" series as this document but uses its own fuzzy calculation.
This is determined as the following diagram shows.
The meaning of "fuzzyList []" below is as follows.
fuzzyList[0]​ Maximum deviation value (horizontal axis)
fuzzyList[1]​ Maximum deviation change (vertical axis)
fuzzyList[2]​ Output maximum value
The fuzzy calculation program is as follows.
===========================
//Fuzzy
//fuzzyList[2] is multiplied by 10, so the result should be 1/10
let fuzzyList = [200, 40, 200]
let oldDiff = 0
let fuzResult = 0
let target = 0
//Fuzzy  Calculate the amount to suppress
function Fuzzy(val: number) {
let x0 = target - val  //Deviation from median
let y0 = x0 - oldDiff   //Deviation change amount
oldDiff = x0
let dv = fuzzyList[0]     //Maximum deviation
let ddv = fuzzyList[1]    //Maximum difference in deviation change
let lout = -fuzzyList[2]    //Output maximum value
let a = ddv / dv //Slope = deviation change amount / deviation
let d = x0 + a * y0 //numerator
let x1 = d / (a * a + 1)    //X coordinate of intersection = numerator / denominator
let lx = dv   //Deviation
let result = (x1 * lout) / lx
//Limit output
let limit = fuzzyList[2]
if (result < -limit)
result = -limit
else if (result > limit)
result = limit
return result / 10
}

//micro: bit analog input resolution is 10 bits
//fuzzyList[0] : Fuzzy The Maximum deviation
//fuzzyList[1] : Fuzzy The maximum difference in deviation change
//fuzzyList[2] : Fuzzy Maximum output
//fuzzyList[2] is multiplied by 10, so the result should be 1/10
let fuzResult = 0
let target = 0
//Fuzzy  Calculate the amount to suppress
let fuzzyList = [200, 40, 200]
let oldDiff = 0
let dZone = 20  //dead zone
function Fuzzy(val: number) {
let x0 = target - val  //Deviation from median
if (-dZone < x0 && x0 < dZone) {   //Dead zone
oldDiff = 0
return 0
}
let y0 = x0 - oldDiff   //Deviation change amount
oldDiff = x0
let dv = fuzzyList[0]     //Maximum deviation
let ddv = fuzzyList[1]    //Maximum difference in deviation change
let lout = -fuzzyList[2]    //Output maximum value
let a = ddv / dv //Slope = deviation change amount / deviation
let d = x0 + a * y0 //numerator
let x1 = d / (a * a + 1)    //X coordinate of intersection = numerator / denominator 
let lx = dv   //Deviation
let result = (x1 * lout) / lx
//Limit output
let limit = fuzzyList[2]
if (result < -limit)
result = -limit
else if (result > limit)
result = limit
return result / 10
}

function CalcMedian(a: number, b: number, c: number) {

else if (c > b)
center = b
else
center = c
}
else {

center = b
else if (c > a)
center = a
else
center = c
}
