变量就像存储数据的占位符。要使用变量，你需要声明并给它赋值。

例如：

```javascript
var x = 98;
```

如果你想打印变量，使用：

```javascript
document.write(x);
```

如果你想使用字符串，必须用引号括起来：

```javascript
var name = "gilad";
document.write(name);
```

记住，JavaScript 是区分大小写的。这意味着 `name` 和 `Name` 被认为是不同的变量。

# 第 14 章
**返回语句 (Return Statement)**

在之前的课程中，我们讨论了函数，而我们的函数只是执行了某些操作，对吧？
我们在屏幕上打印内容，点击一个按钮弹出一个消息，诸此类……
但在某些情况下，你希望函数返回某个值，以便以后使用。
这就是为什么我们有 `return` 语句。

来看这个例子：

写一个名为 `BasicAddition` 的函数，请求两个参数 `num1` 和 `num2`。它将返回两者的和。

```
function BasicAddition(num1,num2){
  return num1 + num2;
}
```

现在我们将调用该函数并传入参数 1 和 2。我们预期得到数字 3，对吧？

`BasicAddition(1, 2);`

如果我们现在运行它，什么都不会显示。
这是因为我们没有告诉函数对结果进行什么处理。它既没有打印，也没有存储在任何地方。

创建一个新变量名为 `result`。从 `BasicAddition` 函数中获取结果。然后将 `result` 打印到页面上。

```
var result = BasicAddition(1, 2);
document.write(result);
```

保存并刷新……砰！搞定了！

我们返回了相加数字的结果，将其存储在名为 `result` 的变量中，然后使用该变量将其打印在页面上。

让我们试一下，创建一个 `GoodNight` 函数，以及另一个名为 `GoodMorning` 的函数。它们都不接受任何参数。

在 `GoodNight` 函数内部我们将使用 `document.write` 并说“Good night！”；在 `GoodMorning` 函数中，你猜得没错，我们将输入“Good morning！”。

```
function GoodNight(){

}
```

```
function GoodMorning(){

}
```

现在我们有了另一个名为 `Start` 的函数，我们从 `Start` 函数中调用这两个函数。

```javascript
function Start(){
    GoodMorning();
    GoodNight();
}
```

现在如果我们刷新页面，什么都不会发生，因为虽然我们调用了 `GoodMorning` 和 `GoodNight`，但我们还没有启动 `Start` 函数。只有当我们调用 `Start` 函数时，才会看到发生发生。

让我们这样做！

# 第 17 章
Else & if

假设你有一个条件，例如……单词“banana”等于单词“banana”：

当条件成立时，你将有一个名为“ChoppingBanana”的函数。

```javascript
if("banana" == "banana"){

```

到目前为止，没什么新奇的，对吧？

如果我把其中一个香蕉换成菠萝（Pineapple）……ChoppingBanana 函数就不会被触发……对吧？

但如果我想在条件不成立时触发另一个函数呢？我该怎么做？
在这种情况下，我们需要在花括号之后输入一个 `else` 语句，以及另一组大括号，在这些大括号内部，我们可以编写我们的代码。

```javascript
if("banana" == "pineapple"){
  ChoppingBanana();
} else {
  ChoppingPineapple();
}
```

如果我们愿意，我们也可以写另一个条件，我们会写 `else if` 和另一个条件，比如“banana”等于“cherry”（樱桃），然后是另一组大括号。

```javascript
if("banana" == "pineapple"){
  ChoppingBanana();
} else if("banana" == "cherry"){
  ChoppingCherry();
} else {
  ChoppingPineapple();
}
```

在这个示例中，浏览器会首先进入第一个 `if`，并询问条件：香蕉是否是菠萝。如果不成立，它将进入下一个即 `else if`，并询问……“香蕉看起来像樱桃吗？”嗯，它看起来不像……噢！还有一件事……你可以拥有你想要数量的 `else`！！！我们可以有像……无数个 `else if`……如果某个条件成立，它将执行其内部的代码，并让这一所有的 `ifs`、`else` 和 `else ifs` 不管……但如果不成立，它将继续询问，直到到达最后一个 `else`。

`else` 是我们器的最后尝试，如果没有 `if` 语句和 `else if` 被触发，那么我们的浏览器就会满意并进入其中。

如果你的浏览器访问了任何条件，`else` 语句就不会被触发。
