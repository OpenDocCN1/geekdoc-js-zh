Data Types in Python

Data types are known as the values that you place in Python, and the value’s data type is going to be what determines how that value will be used by the program. It is the best way to look at data types as objects, and the object will, in turn, be identified with a type that belongs to that value so that you as the user know where to place it.

Python, like many programming languages, offers multiple data types that you can use to do what you want with the program’s code. Python even offers extension modules that are written in other languages if you are more familiar with those and need it to accomplish your goal. The language that your data type is written in is ultimately going to be what defines that data type.

While you are working with data types, you are going to use the type() function so that you can figure out the variable’s type. There are going to be a few data types that have the ability to change their value, and those are going to be known as mutable data types. The other ones that are not able to be changed are known as immutables.

**Numbers**

Typically, a number will be created by numeric literals. Sadly, you are not going to be able to change numbers once you put it into Python. With numbers, there are three different types that you are going to be able to use. The number types are integers, complex numbers, and floating point numbers.

Integers are going to be numbers that are both negative and positive and lack fractional parts. A floating point number can also be positive or negative, but they are going to have the fractional parts that an integer does not have. You also have things such as Booleans, which are subtypes that you can use with integers.

Complex numbers are going to be used more with engineering more than anything. A complex number will come in the form of a + bi. The I next to the b is going to represent imaginary numbers because complex numbers not only contain real numbers but imaginary ones as well. Python is going to allow for you to use complex numbers as long as you remember that there are going to be both types of numbers. You can use functions such as real + imagJ or real + imagj. Python also has a method built into it that is going to allow you to use x,y for complex numbers.

**Strings**

A string is a combination of objects that are going to be read left to right just like everything else. When writing a series, you are either going to start and end it with a single set of quotes or a double set. Just like numbers, strings are immutable.

The quotes strings whether single or double can be exchanged with each other because they are going to be the same. Quotes can also be used inside of a string that has double quotes outside of it and vice versa.

That may seem a wee bit intricate, but essentially, it means you can type something like this:

“this is your ‘name’ and birthday” or ‘this is your “name” and birthday.”

Python is going to print the same thing for both strings the exact same way despite where the quotes are or what they are. But, you need to ensure that you are not placing a single quote at the start of the string and a double quote at the end of the string or you will wind up receiving an error code from Python.

Strings use special characters such as a backslash. A backslash is going to mean that you are introducing a unique character into the string.

Individual strings are as follows:

\n which means newline

\t horizontal tab

\\ backslash

\’ single quote

\” double quote

You will be able to access the characters and elements of the string through indexing. An index is going to start with a 0 on the left and a –1 on the other.

Type in Python Tutorial, and you will be able to place the items in your string. From the left, you are going to have all even numbers, but from the right, you are going to have all negative numbers. Unlike with the numbers going left to the right, you are going to start with a larger negative number on the right.

After you have created your string, you should double check that it is exactly how you want it to be because you cannot change any of the characters that expressed within the string once it has been created.

The operator “in” is going to check to determine whether or not a character or substring is located within a string or not. In this case, you are going to get a Boolean value returned to you.

In order to cut a substring out of a string, you are going to separate the two indices with a colon. When you slice a 2:6 that means that all the characters in the second, third, fourth, and fifth positions are going to be sliced. The six is not going to be added in the cutting. You can also splice with the negative indices if you want to.

**Tuples**

Values that you have separated by commas and contained inside of a set of parentheses are going to be tuples. Tuples cannot be changed after you have created them, but they do have the option to have different data types inside of them.

Empty tuples can be created by putting the code (empty_tupl) into your Python code. Any elements that you put in a tuple has to be indexed much like any sequence that you use with Python. However, like strings, the indexes for a tuple is going to start at zero. The index for a tuple also can be sliced. Tuples that have been sliced create new tuples while leaving the original tuple alone.

If you want to create a new tuple, you are going to use a plus sign, and in order to repeat a tuple, you will use an asterisk.

**Lists**

Lists are going to be like tuples except that they use square brackets instead of parentheses. The items that you place on a list does not have to be the same type. As you create a list, you are going to use the same function that is used when you are putting a value into Python; however, the difference is going to be that the element has to be a set of parentheses. The function print(my_list) is going to create new lists from scratch.

Much like the other data types we have talked about, the index for a list is going to start at zero and has the ability to be sliced. The biggest difference for the index on a list is that they are given names that are related to colors such as black, green, red, and blue. If you place a value in the index that is not in the range that the index is working with, then you are going to receive and error message.

As mentioned, list indexes can be sliced and the syntax is going to be as follows:

sliced_list =List_Name[startIndex:endIndex]

The great thing about a list is that it is mutable, so if you want to change values in it, you have the option to do this. Plus signs will create new lists, but that list is going to be connected to at least two other lists. The asterisk will once again repeat your list so that you do not have to copy and paste it.

**Sets**

When creating a set, you are going to be creating an unordered but unique collection of elements. You will mainly be using sets for when you use set theory. Set theory is a supported mathematical operation like a difference, union, symmetric difference, or even an intersection. You will also use a set when eliminating any duplicate entries that have occurred in your coding.

**Dictionaries**

A dictionary in Python is a container that holds an unordered set of items much like a list. However, the objects in a dictionary are surrounded by the curly braces ({}). A dictionary separates the different essential items and valued pairs with commas. The values and keys are going to be the Python data type.

Every value or object that you access with a key is going to be unique in your dictionary. The keys that are used for indexing will be immutable. You can, however, create an empty dictionary through the use of empty curly braces.

**None**

The last data value that you need to know when using Python is the data value of none. This value is a single value type because there is a single object within this value. Objects will be accessed with a built-in name on Python. The name is quite obviously, None.

The absence of any value in certain situations is going to return it from the functions that you use so that you do explicitly get a return of anything. The truth for this value will always be false.

List comprehensions may be familiar to you, but for dict/set comprehensions, this is something you may not be aware of. They are simple, as well as effective, to use. Take this example below:

*my_dict = {i: i * i for i in xrange (100)}*

*my_set = {i * 15 for i in xrange (100)}*

# The only difference in both is ‘:’.

**Forcing Float Division**

Back to the mathematics, you can divide numbers using the backslash key (/). Generally, division will always give out whole number answers. Normally for Python 2, you have to do something like this:

*result = 1.0/2*

But there’s a handy trick you can do instead to forgo the .0 right here:

*from __future__ import division
result = 1/2
# print(result)
# 0.5*

Of course, you don’t have to fret about this if using Python 3 as it is handled by default.
