Note about the keyword let
 
 
The let keyword in TypeScript is used to declare variables. It is similar to the var keyword in JavaScript, but with a few important differences.
 
Block scope: Unlike the var keyword, variables declared with let are scoped to the nearest enclosing block, instead of being function-scoped. This means that a let variable is only accessible within the block in which it is declared, and is not accessible outside of that block.
Re-declaration: Variables declared with let cannot be re-declared within the same scope, unlike var variables, which can be re-declared within the same scope.
