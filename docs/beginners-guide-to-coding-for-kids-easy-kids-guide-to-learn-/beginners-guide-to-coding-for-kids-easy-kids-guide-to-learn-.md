# 少儿编程入门指南：轻松从零开始学习JavaScript、HTML等编程语言：分步指南







## 引言

儿童编程正迅速流行起来，越来越多的家长和教育工作者认识到这是一项重要的21世纪技能，越早、越频繁地教授越好。然而，高质量的编程教育资源在许多城镇、城市甚至国家都相对匮乏。许多家长和教育工作者看到了这一需求，并希望能够为此做些什么。儿童编程（也称为计算机程序设计）正迅速受到欢迎。虽然美国仅有少数传统学校开设编程课程，但盖洛普民意调查显示，90%的家长希望在学校日常教学中教授计算机编程。让孩子在年幼时学习编程，确实能为他们的终身成功奠定基础。即使他们未来不从事与计算机科学直接相关的工作，这也能让他们在几乎每一个现代行业中占据优势。

## 什么是儿童编程？

儿童编程是指为儿童参与编程提供的各种机会。这些机会旨在通过趣味性和游戏化的方式保持孩子们的兴趣。虽然很难想象年幼的大脑学习看似复杂的知识，但儿童编程已成为现实——得益于众多编程夏令营、网站、编程辅导老师、课后项目以及益智玩具，编程知识已变得相当易于消化。

## 为什么"每个"孩子都应该学编程

多年前，当关于儿童和编程的讨论刚开始时，你可能会将其视为炒作，因为这对整个教育系统来说是一个全新而新颖的概念。虽然这股"学编程"的热潮并非毫无根据，但只有时间能告诉我们这一切是否只是昙花一现。好了，现在时间已经证明了。我们仍然看到STEM教育统计数据，比如到2018年，将有240万个STEM工作岗位空缺。还有其他的数据，如STEM领域71%的新增工作岗位在计算机领域，但仅有8%的STEM毕业生来自计算机科学专业。人们还在疑惑编程是否难学。我们已经正式超越了单纯说"编程很酷，去学吧"的阶段。现在，我们要说的是："编程确实很酷，去学吧，但你也应该因为能够获得回报而去学。"换句话说，有工作机会，很多工作机会——而且薪水非常可观。

更妙的是，这不仅仅关乎工作或酷劲（如果是那样的话，这篇文章会短得多）。还有……还在于创造力、问题解决能力、协作能力、沟通能力以及**其他**技能的提升，这些都是孩子学习编程的副产品。

因此，孩子应该学习编程，因为：

- 程序员需求旺盛
- 编程提供竞争优势
- 编程知识帮助学生更好地理解世界
- 编程有趣且令人满足
- 编程提升创造力
- 编程提升问题解决能力
- 编程提升毅力
- 编程提升协作能力
- 编程提升沟通能力

### 什么是儿童编程？几岁学编程合适？

编程，或者说计算机程序设计，是程序员发挥创造力，告诉计算机如何执行任务的过程。从根本上说，它涉及使用编程语言编写计算机程序。儿童编程通常通过高趣味性的内容来教授，同时创建涉及创意投入的项目。简而言之，儿童编程通常是游戏化的，让孩子学习起来充满乐趣！由于编程可以进行游戏化处理，最早5岁的孩子就可以开始学习编程，使用可视化积木界面或适合年龄的文本编程课程。利用游戏、应用程序和其他以儿童为中心的项目进行儿童计算机编程课程，是一种基于研究的方法，已被证明能够以吸引学生参与的方式教授真实世界的技能。

#### 为什么我的孩子要学编程？K-12年级学校教育够吗？

简而言之，在年幼时学习编程能让孩子和青少年拥有更多的未来机会。正如你将在下面了解到的，数据非常有说服力。根据美国劳工统计局的数据，软件开发者的年薪中位数为103,560美元，预计从2016年到2026年，需求将以每年24%的速度增长。这远快于其他职业的平均水平。

不幸的是，即使您的K-12学校是少数积极提供编程课程的学校之一，它们通常也无法充分培养学生。要么它们未能纳入能够启动您孩子职业生涯的合适语言，要么就是没有补习项目那样丰富的工具和资源。大多数学校使用Scratch、Code.org或Tynker等程序。Scratch是一种不错的免费方式，让孩子无需使用真正的编程语言就能学习编程概念。Code.org有一些不错的练习，介绍类Scratch的可视化积木语言，甚至在后期模块中引入了一些基础文本编程。Tynker也采用可视化积木方法，同时在后期模块中引入文本编程。这些程序是学校偏爱的工具，因为课程可以由编程经验有限或没有工程背景的教师来监督。它们是让孩子入门编程的有趣方式，但在短时间内，许多孩子会渴望更高级的内容。更高级的内容让学生能够使用真正的文本语言创建自己的游戏、应用程序和网页。而且，这不会将他们限制在封闭平台中。

您应该考虑尽早让孩子接触编程的其他一些原因：

- 计算机科学在多个相关领域培养技能，包括数学、科学、问题解决、团队合作、项目式学习、创意艺术等。正如史蒂夫·乔布斯的名言所说："编程教会你如何思考。"
- 学习计算机程序设计就像学习一门外语。越早开始，越容易。
- 2020年，由于合格工程师的短缺，美国将有近100万个技术岗位空缺。
- 在STEM（科学、技术、工程和数学）领域，计算机相关职业占预计新增职位的60%以上。
- 计算机编程教授的技能在当今就业市场中即时相关。
- 计算能力几乎为每个行业提供动力，从教育到农业，从法律到商业，从建筑业到医疗业。
- 计算机工程工作在新毕业生就业中薪资排名最高。



##### 编程的好处

以下是关于编程为何如此重要的不同原因的说明。

###### 程序员供不应求

- 如前所述，根据 Code.org 的数据，所有新的 STEM 职位中有 **71%** 在计算领域，然而只有 **8%** 的 STEM 毕业生来自计算机科学专业。这是计算机科学专业人才的严重短缺。

在申请大学、实习和工作时，编程提供竞争优势。

- 如果你掌握了一项许多同龄人都不具备的热门技能——比如编程能力——你在潜在的大学招生官和雇主眼中会立刻显得更加有吸引力。就这么简单明了。

####### 掌握编程知识后，学生能更好地理解周围的世界

- 我们大多数人对于智能手机、笔记本电脑、社交媒体网络和视频游戏的运行原理一无所知。基础的编程知识可以改变我们与日常使用的技术（以及我们认为理所当然的技术）的互动方式，并能让我们看到编程的无限可能。

######## 编程有趣且令人满足

- 虽然编程基于逻辑，但它也是一项极具创造性的活动。如果你懂得编程，你就可以开发前面提到的应用程序、视频游戏、网站等等！

######### 编程提升创造力

- 当你学习一门语言时，你用它来*表达自己*。编程也是如此。计算机编程让孩子们不仅能消费数字媒体和技术，还能**创造**它。孩子们不再只是玩视频游戏或使用应用程序，他们可以想象制作自己的视频游戏，或者设想自己的网站或应用程序会是什么样子——而且他们将拥有表达的途径。

############ 编程提升解决问题的能力

- 当孩子们编程时，他们将复杂的问题分解成更小的部分。孩子们学习如何像软件工程师那样处理问题，用逻辑的、计算的思维。
- 计算思维教会你如何*通过将问题分解为一系列更小、更易管理的问题来应对大型问题*。
- 这种逻辑思维是在学校、工作和生活中都非常有力的工具。

################ 编程提升毅力

- 学习编程，就像任何新学科一样，是一项挑战。因此，处理复杂问题——并在过程中犯错误——可能会非常令人沮丧。
- 编程教会了面对此类挑战时坚持不懈的宝贵技能。学会如何通过研究和协作来解决问题，可以培养这种非常受欢迎的能力。

#################################### 编程提升协作能力

- 每个学生都能学习，每个学生都能学会编程。孩子们可以与各种种族、性别或背景的同伴一起学习。孩子们能够结识并与各种各样的同伴协作，所有这些都因对技术的共同兴趣而凝聚在一起。
- 教室和其他面对面的环境，如 iD Tech，让孩子们聚在一起进行面对面协作。在线学习的孩子也能共同成长，互相提问，并合作解决问题和创造事物。
- 许多游戏，如《我的世界》，也提供了丰富的教育益处，因为它们同样涉及编程、协作和参与——与世界各地的同伴一起。

########################################## 编程提升沟通能力

- 沟通是在学校、工作和生活中都绝对必要的技能。能够用简单的术语清楚表达复杂想法的人，往往在不同的行业和人生道路中都能取得成功。
- 当孩子们学习编程时，他们学习如何与可以想象到的最简单的受众沟通：**计算机**。如前所述，计算机编程教会孩子们如何分解复杂的想法，并以计算机能够理解的方式组织它们。

################################################### 向幼儿介绍编程和计算机编程的方法

让你的孩子接触编程世界可能有些挑战，尤其是对于那些自己都不知道代码如何工作的父母而言。在当今这个数字世界已经很大程度上接管了我们的任务和日常的时代，学习编程基础知识至关重要。这不仅是一项让你的孩子参与的有趣且富有成效的活动，编程还有助于培养解决问题的能力，提升创造力和逻辑，并增强技术能力。

############################################################# 为 budding coders 提供的动手游戏

编程艺术不仅限于计算机和软件。向你的年幼孩子介绍能让他们测试创造力和逻辑思考的技术玩具。他们甚至不会知道自己在编程！例如，LittleBits 提供了一系列创新玩具，教孩子们了解电路、电子、磁铁和气泡！他们有一款名为 Crawly Creatures 的有趣学习工具，甚至会让你这个极客也着迷。适合 8 岁以上的孩子，这款玩具有许多小部件，包括调光器、脉冲器和电源，鼓励孩子学习电路的工作原理。我遇到的另一款精巧玩具非常适合学龄前儿童。费雪牌的 Think & Learn Code-a-Pillar 玩具是最简单的机器人，外形是时髦的毛毛虫，向幼儿传授命令、序列和编程模块的知识。

########################################################################################## 适合孩子的编程语言

############################################ Python

Python 是一种功能强大的、基于文本的计算机编程语言，即使是8岁的孩子也能轻松地用它来表达自己。这种特定类型的代码既可以作为掌握其他语言的跳板，也足以成为孩子进行严肃的游戏/网站/应用程序开发和编程的强大工具。网上有许多基于游戏和自主学习的课程，使学习Python（尤其是Python 3）成为孩子们一次独特、有趣且高度参与的体验。

Python 是向孩子介绍编程的绝佳选择，因为这种编程语言强调使用良好的代码布局。它也鼓励用户使用在线支持和丰富的Python库。随着你的孩子越来越多地接触Python，他们将学会如何正确使用列表、元组和映射等基本数据结构。掌握Python中的变量、循环和其他函数，将为他们未来处理更高级的编程打下坚实的基础。他们还将克服在Python中控制不同结构带来的复杂性。使用Python的turtle模块绘制形状和图案，将帮助你的孩子克服动画和游戏设计上的第一道障碍。很快，他们就能为Mac、PC或Linux编写自己的应用程序了。

############################ Ruby

Ruby 拥有最适合初学者程序员的可读语法。与其花很多时间解释学生输入机器的代码，不如让代码本身对他们来说是不言而喻的。对于仍在学习编程概念的孩子来说，这是一个非常重要的因素。归根结底，孩子们需要学习这些概念才能写出好的脚本。Ruby 是一种非常强大的语言，最初用于创建Twitter，因此你可以立即向学生展示，这个应用程序是流行平台上使用的工具。

################ Java (Minecraft)

Java 并不是我们最喜欢的儿童编程语言，坦白说，它之所以出现在这个列表上，唯一的理由是因为它是Minecraft的语言。因此，Minecraft的魅力为学生创造了一种非常有效的“胡萝卜加大棒”体验，使其成为教孩子编程的一种非常流行的方式。自2011年发布以来，Minecraft已成为全球许多孩子关注的焦点。即使许多成年人仍然认为这只是另一款游戏，但Minecraft已经证明它远不止于此。它是教孩子如何运用逻辑、解决问题以及加强多项核心学术技能的强大工具。而这还只是在他们的基础用户阶段。一旦你的孩子开始真正超越基础操作，他们就会清楚地看到Minecraft是一个高度适应性的、可供自定义的游乐场。当孩子开始真正喜欢这个游戏时，你可以向他们介绍“模组”。“Mod”是“modification”的缩写，模组基本上是孩子们可以引入游戏的所有改变。他们可以改变一切——角色、物品、景观、特定属性等等。可能性是无穷无尽的。为了在游戏中引入特定的模组，玩家需要编写一些代码。这就是事情变得有趣的地方。Minecraft基于Java运行，游戏的开放架构允许用户访问Minecraft的Java源代码并进行修改。在用Java制作模组的过程中，孩子们将开始学习如何创造简单和复杂的东西，这无疑会让他们保持专注并更深入地学习这种编程语言。

################## C++

许多计算机科学专家和开发者对于学生是否应该从C++开始学习有不同意见。这种编程语言看起来有点像数学，可能会让学生对学习编程的想法望而却步。然而，一旦理解了编程的基本原理，C++就能为编程世界打开许多大门。今天许多最成功的程序员都是从学习C或C++开始编程的。

######################## Scratch

Scratch 主要为8至16岁的儿童开发，是一种免费的教育编程语言，由米奇·雷斯尼克（Mitch Resnick）开发，并由麻省理工学院（MIT）的终身幼儿园组获得专利。用Scratch教孩子编程很容易，因为该平台提供了一个直观、易用的可视化积木界面，消除了年轻学习者打字的挫败感。这是孩子编程的一个绝佳起点。Scratch是所有儿童编程语言中最具视觉吸引力的语言之一，但它真正脱颖而出的真正原因在于它赋予学生的表达自由。其背后的核心理念是简化创建动画、设计游戏和构建互动故事的过程，让任何人都可以从根本上做到这一点。孩子们使用Scratch时感觉像是真正的游戏设计师，即使是完全的新手也能在几分钟内创建简单的、完全自定义的游戏。Scratch还拥有一个庞大的在线社区，拥有来自世界各地的超过1500万注册用户。任何人都可以成为会员，只要他们遵守麻省理工学院Scratch团队制定的友好且受尊重的规则。Scratch平台及其社区的另一个好处是，你需要将你的项目及其代码存储在Scratch服务器上，这使得年轻的学习者可以研究更高级的用户是如何创建复杂游戏的。

如果Scratch听起来适合你，你可以通过这份分步指南向你的孩子介绍它。这些卡片将为你的孩子提供一种有趣的新方式，来学习使用地球上最好的儿童编程语言之一进行编程。

############################################################################ Blockly

Blockly 是一种面向儿童的可视化积木编程语言，普遍被视为谷歌对Scratch的回应。打个比方，它使用相同的积木来帮助孩子们掌握代码。唯一真正的区别在于：Blockly 实际上是一种由几种现有编程语言组成的编程语言。在Apache 2.0许可下开发，Blockly通常被描述为用于创建可视化编程积木编辑器的客户端JavaScript库。也就是说，它主要是为8岁以上、想在家或学校在自己的浏览器中学习编程的孩子创建的。Blockly 附带一个“JavaScript库”，它基本上充当一个集中位置，可以轻松找到和访问预编写的语言（如JavaScript、Python、PHP、Lua和Dark）。Blockly 有一个特定的用户界面。

它就像是一个装有多形状、多颜色积木的儿童盒子。除此之外，还有一个放置积木的工具箱、一个回收站以及实际编写代码的空间。操作非常简单。用户从工具箱中取出积木（一次一块），按顺序排列，直到解决问题。完成后，程序会运行检查，查看已完成的操作，如果解决方案不正确——它会返回并再次分析代码，直到找到错误。轻而易举。Blockly 让任何人都能开发真正可运行的 Android 应用。这使得这门语言不仅仅是一个儿童玩具，甚至不仅仅是一个帮助孩子编程的简单工具。孩子们可以在屏幕一侧通过连接不同的积木来编写代码。他们还可以轻松切换语言，从而随时查看同一基本程序的不同代码类型。尽管这是一个很棒的程序，但与 Scratch 相比——Blockly 还有所欠缺。它不如其最大的竞争对手成熟，也没有那么多优质的教程，这使得孩子们更难自学 Blockly。Blockly 已被 Sphero 的一些优秀设计师使用，我们也看到越来越多的其他公司正在利用这项技术。

################################################################ Go (Golang)

Go 编程语言是一种静态类型、编译型语言，是最新获得广泛流行的语言之一。事实上，它非常新，仅仅诞生 10 年多（2009 年发明）。这种 promising 的增长使其成为一门值得掌握的语言，因此应该被添加到任何围绕儿童编程的课程中。就在 Go 首次实现后的短短几年内，它已经传播到各种不同的行业。此外，越来越多的财富 500 强公司和大型企业正在强调其重要性和前景。Uber、Netflix 甚至美国运通都是已知的 Go 用户。从结构上看，Go 与 C 语言相当相似。主要区别在于内存安全、垃圾回收、结构类型和 CSP 风格的并发性。然而，就儿童编程语言而言，它很可能可以采用 C 语言相同的整体教学策略并取得成功。Go 是一门值得了解的语言的原因有很多，尤其是在现代。也就是说，最主要的原因是它确实在人气方面呈现爆炸式增长，而且丝毫没有减缓的迹象。预计在未来几年，开发团队的持续更新将只会促使其人气不断增长，并在各行业中不断扩展。

################################################################## Swift (Swift Playgrounds)

Apple 的 Swift Playgrounds 于 2016 年首次推出，作为教孩子 coding 的工具。Swift Playgrounds 包含许多基础 coding 课程和游戏化挑战，并配有界面紧凑、图形背景赏心悦目的界面。作为一款 iPad 应用，Swift Playground 适合在课堂中使用 iPad 的学校。Swift Playgrounds 的问题不在于语言本身，而在于其过于限制性的课程，与许多其他普通的儿童 coding 资源一样，它没有给学生任何自由表达的空间，例如 Scratch 平台所提供的那种。学生被迫按照课程设计师设定的固定路径逐级推进。我们发现这种"轨道式"体验对于富有创造力的孩子来说很快就会变得乏味。鉴于最近有消息称 Apple 计划通过 Swift Playgrounds 教年轻一代 iOS 开发者如何构建支持 AR 的应用，我们的看法可能会有所改变。一旦我们深入研究 Swift Playgrounds AR 项目，我们将更新这篇文章。

############################################################# Lua (Roblox)

Lua 是一种非常适合向孩子介绍基于文本的 coding 的脚本语言。它易于学习、使用，并且可以轻松嵌入到应用程序中。Lua 是一种免费、优雅、强大、可移植、可嵌入且适合初学者的 coding 语言。这种类型的语言引入了简单的概念，这些概念有潜力成为成熟的产品，同时仍然保持其简洁性、可读性和效率。Lua 最好的特点之一是它为用户处理内存管理等底层事务。Lua 与 Python 相似，消除了许多使 coding 对孩子来说变得困难的语法问题。但与 JavaScript 不同，它不需要在每行代码末尾使用分号。

########################################################################### 为什么培养孩子 coding 很重要

信不信由你，我们正生活在 STEM（科学、技术、工程和数学）时代。越来越多的家长和老师意识到引导孩子理解 21 世纪趋势、信息和概念所蕴含的潜力。最新出现的方法之一是专注于教孩子如何 coding。已经开展了多种关于这一主题的研究，最近的研究已达成共识：coding 正 poised 成为有志于在科学、技术、工程和数学领域建立职业生涯的孩子的重要推动因素。

#################################################################################### 为什么每个孩子都应该学习 coding

Coding 是一种计算语言，应该教孩子学习新语言。当孩子被教导如何 coding 时，整个学习过程会起到触发作用，激发他们的逻辑思维能力。在孩子的 formative years 教他们 coding 是有利的，因为吸收速度更快，孩子也能 early 培养应用意识。就像 ABC 为英语提供方向一样，coding 使用 0 和 1 的不同组合来指导计算机执行特定功能。如果孩子在年幼时就接触到这种技术性知识，他们将能够与周围的技术和应用建立更好的兼容性。

######################################################################################### 学习 coding 的好处

Coding 不仅对职业有好处，而且具有终身前景。这简单地意味着，一旦孩子学会了如何 coding，他们可以继续投入其中，追求爱好或职业。Coding 是有益的，因为它能培养孩子的创造力。当他们尝试不同的 coding 组合时，孩子们 inherently 变得更加有创造力；他们的脑力被成倍激发。当然，孩子们会犯错，但这是为创造力付出的代价。最终，过程很重要，最终产品是次要的——至少对孩子来说是这样。

###### 为什么学习 coding 很重要？

2019 年，coding 在建立全球数字素养现象方面发挥着重要作用。因此，支持儿童 coding 倡议的夏令营、研讨会、网站和项目数量急剧增加。原因是，当孩子 early 学会如何 coding 时，这为他铺设了道路，去发现和识别自己的兴趣所在——科学、技术、工程和数学（STEM）学科。随着岁月的推移，程序员的重要性只会 poised 激增。随着越来越多的 STEM 工作岗位出现，世界各地的公司都需要优秀的人才来运行 IT、计算机科学和工程项目。因此，如果你鼓励孩子学习 coding，很有可能他长大后 will 从事 STEM 职业并 excell 其中！

##### 你的孩子应该学习 coding 的原因

除了是提升学业表现的巨大 trigger 之外，还有许多原因促使儿童需要学习 coding。这里有一个有趣的事实：去年未能填补的 STEM 工作岗数量为 240 万。虽然 71% 的 STEM 工作源于计算领域，但 2018 年计算机科学毕业生的数量仅为 8%。简而言之，我们正生活在技术驱动的时代。鉴于技术以这样的 pace 主导着我们工作、社交和私人生活的 every sphere，说学习如何 coding 已不再……这样的话并不为过

属于“为了娱乐而做”类别的一部分。相反，现在学习编程已成为创新的前提条件之一。

#### 为什么编程对未来发展至关重要

正如前文所述，编程是一种技能，将决定全球 STEM（科学、技术、工程和数学）职业的未来发展。考虑到技术及其在各平台上的应用正以惊人的速度在世界各地制造有序混乱，可以合理推断，正如克利夫·休比（Clive Humby）所说，“数据是新石油”，那么在未来不久的公司中，“程序员”将成为新的必备专业人才。机器学习、物联网、人工智能和数据科学等新兴行业的崛起，预示着未来的趋势。因此，尽早让编程少年做好准备，以便在时机来临时能实现飞跃，这最终会是个好主意！

## 教孩子编程的提示

对年幼的孩子使用 Scratch，对年长的孩子使用 Python。MIT 的 Scratch 是一款专为儿童设计的免费编程工具，可在任何现代网络浏览器上运行。其视觉风格受到 Logo 程序的影响，该程序是 20 世纪 80 和 90 年代儿童编程课程的经典内容。但 Scratch 远不止是又一个 Logo 仿制品。8 到 13 岁的孩子将从 Scratch 的简单图形界面中受益。Scratch 的拖放代码块会自动对齐连接。逻辑不通的代码片段无法拼接，从而使语法错误变得“不可能”。Scratch 非常适合尚未掌握打字技能的年幼孩子。当然，试图制作更复杂程序的孩子们最终会发现 Scratch 存在局限。对于青少年和儿童，像 Python 这样的现实编程语言更适合。Python 是极佳的入门编程语言，因为它语法简单（不像 Java 或 C#），生成的代码可读性强（不像 Perl 或 JavaScript），并且背后拥有一个庞大友好的开发者社区。如果您的孩子已经超越 Scratch 的水平，Python 是最佳的下一步选择。

### 展示真实程序的源代码，不要只跟他们谈论概念

尽管编程享有智力声誉，但它是一项需要动手实践的技能，不仅仅是阅读书籍。Python 的交互式 Shell 鼓励实验，以了解指令的作用。如果您亲自辅导孩子，编写代码的效果远胜于只跟他们谈论概念。即使学习了变量、循环和函数，坐在空白编辑器前开始新项目仍令人望而生畏。坐下来陪他们，逐行描述他们应编写的代码。或者，如果您使用在线资源与孩子分享，请寻找小型游戏的源代码。代码行数不到几百行的程序效果最好。Scratch 网站自动共享其网站上所有项目的源代码。鼓励你的孩子对代码进行修改，观察这些修改如何改变最终程序。

### 游戏是有趣的编程项目

制作视频游戏是许多年轻程序员常见的起点。《愤怒的小鸟》、《我的世界》、《小鸟快飞》（Flappy Bird）、《玩具熊的五夜后宫》（Five Nights at Freddy's）和其他游戏是主要的灵感来源。我写了一本免费的书籍，《用 Python 发明你自己的计算机游戏》，该书通过几个简单游戏项目的完整源代码展示了编程概念。请注意，孩子们喜欢的游戏在他们刚开始时可能不是很好的编程项目。许多游戏需要开发团队、艺术家和设计师共同努力完成。需要大量关卡设计和艺术作品的游戏可能会让初学者感到不堪重负。完成一个简单游戏比开始但从未完成庞大项目更令人满意。

### 请管住手，不要随意触碰键盘和鼠标

分享知识令人兴奋。向别人展示你掌握的编程知识很棒。但编程是一项通过动手实践习得的技能，所以要让孩子主导。即使暂时也要避免在孩子学习时跳进去敲击键盘。如果他们必须点击菜单或按钮，请用手指指向屏幕，而不是拿走鼠标自己点击。只要有代码需要输入，就让他们输入。虽然你自己做可能更快，但你的学生需要的练习比你更多。如果你在教一群人，尽量让每个学生拥有自己的电脑。就像演奏乐器一样，编程是一项通过动手实践而非观看他人而习得的技能。树莓派（Raspberry Pi）是一款廉价、简易的 PC，入门套件售价约为 70 美元。虽然增加键盘、鼠标和显示器后总价会相当于一台廉价笔记本电脑。避免使用 Chromebook、iPad 和平板电脑，因为让它们运行 Python 很困难。如果你需要在预算有限的情况下为课后俱乐部设置计算机实验室，树莓派将允许你利用闲置的键盘和显示器。

## 是否所有学生都应该学习编程

支持者通常会提出一个或多个论点来支持教育编程倡议：

编程教育将帮助学生获得与当前就业市场直接相关的职业技能。

- 倡导者们说，看看世界上所有可用的 IT 相关工作... 我们的学校不应该专门准备我们的学生去竞争这些工作吗？批评者回应称，许多相关努力在实际上是浪费时间，原因如下：它们侧重于开发主要在外部场所即可轻松学习的大机械过程；它们主要关注“今日工作相关的”技能，而非明日；此类倡议主要由商业部门推动（对此持高度怀疑态度的群体）；并且许多努力本身就几乎没有教育价值。（常被人轻蔑提及的是那些号称关于编程但实际上仅仅教如何学习使用基本办公工具（如文字处理软件和演示软件）的项目。）

### 编程有助于培养重要的逻辑和问题解决技能

- 很少有人会反对这样一个观点，即当教得好时，编程教育有助于培养重要的逻辑思维和问题解决技能。对此，批评者争辩说，编程课程并非发展此类技能的唯一途径，而且事实上这些技能应融入整个课程体系，而不是单一学校科目的焦点。

##### 理解编程有助于学生更好地理解周围世界的本质，以及它各部分运作的方式和原因

- 我发现，在这方面分歧较小，尽管值得注意的许多教育编程努力的批评者可能并未完全掌握这一论点的重要性。那些认识到这一点的人仍然可能会争辩说，这里存在机会成本：如果将编程加入所有学生的必修课程，会产出什么？

**教会学生编程可以成为后续学习 STEM（科学、技术、工程和数学）主题的门户，并希望通往相关领域的职业工作。**

- 这可能属实，一些批评者说，但这真的是“最佳”的门户吗？如果编程没有教好，它是否实际上会劝退一些学生不再深入研究 STEM 主题，从而降低他们从事 STEM 相关职业的可能性？学校的编程教育真的是通往编程的门户，还是在实践中仅仅是一种“寓教于乐”，只是处理学校购买但尚未想出产如何用产的电脑？

####### 能够编程为创造力和创造性表达开启新路径

- 通过像 Scratch 这样的工具向小学生教授编程技能，或者作为机器人课程或推广“创客”倡议的一部分，这些努力常被引为（好）的编程教育举措可能包含的内容的有力例子。在此再次，许多批评者可能赞扬此类努力，但仍争辩说，即使你承认编程是我们日益技术饱和世界的新识字能力，在推进新的、大规模、强制性的教育编程倡议之前，仍值得问两个相当基本的问题。我们对于阅读、写作和算术这些旧的基础识字能力做得如何？我们不应该在将新内容添加到已经臃肿的课程之前，确保这些基础“识字技能”到位吗？



- 当一位优秀的教师与一位热切、积极的学生一起学习编程时，很难反对推广更多此类活动。教育的“成功”，在很大程度上在于激发学习者内在的好奇心（而不是扼杀它！）。如果我们谈论的是一个不感兴趣或兴趣不大的学习者被迫死记硬背地学习与“如何让计算机做某事”相关的大量相当基础的命令和操作的情况，尤其是由一位自己对学科了解不深的教师来教授，而那个“某事”主要涉及如何在 PowerPoint 中更改字体大小等事情——那么，这可能是没有人应该在学校作为正式课程的一部分来学习的东西。当然，在这两个极端之间存在一个更有趣也更复杂的中间地带。

- 当考虑到这个广泛的中间地带时，我想我倾向于像人工智能先驱罗杰·尚克那样看待事物，他说：“任何称职的认知科学家都知道，重要的不是代数或化学这样的科目。重要的是认知能力。”我认为，在编程方面，情况也是如此。

- 在已经很好地促进基本读写技能发展的教育体系中，将编程引入学校作为课外或拓展活动似乎是相当合理的，尤其是当这些努力能够帮助吸引或激励那些原本不感兴趣的读者时——特别是当这些学生可能由于偏见、歧视或刻板印象，而不被认为（或甚至不自认为）是学习此类事物的候选人时。然而，在那些仍然在努力帮助学生发展基本读写技能的地方，特别是在许多中低收入国家，如果许多政策制定者认为教育编程努力是，正如一位这样的官员最近对我说的那样，一个他们“目前负担不起”的“奢侈品”，也就不足为奇了。

# 编程教育的利弊

## 优点

我们将在此介绍编程教育的好处。

#### 推动社会发展

- 对于完全不懂编程的人来说，也许他们不知道编程有多重要，我们的日常生活充满了编程。
- 此外，日常物品的互联网化正因物联网化而迅速推进。农业等第一产业通过使用编程可能会变得更高效、更高产。

#### 开阔儿童视野

- 从小接触编程有助于儿童拥有更多未来的可能性。
- 二十年前，谁能想到程序员会如此抢手？再过二十年，可能会出现新的职业。
- 因此，毫无疑问地说，学习与各种事物相关的编程将对儿童的未来大有裨益。

### 缺点

接下来，我将介绍编程教育的缺点。

###### 师资缺乏

- 从明年起，它将在小学成为必修课，三年后，日本所有学校都将强制开设。
- 有多少教师能教授编程？有足够的教师来教数百名儿童吗？
- 此能教授编程的教师中，又有多少人能教授实际上可以使用的、高质量的编程？即使编程成为必修课，如果无法保证教育质量，那也没有意义。也许，低质量的编程学习会导致孩子们讨厌编程。

######### 越来越多的孩子现在更喜欢待在室内

- 最大的缺点可能是孩子们变得更加“室内型”。小学生和初中生正处于成长发育期。而且，户外活动和社团活动有助于孩子们以健康的方式成长。
- 如果他们因为对编程过于热衷而在室内花费更多时间，也可能对他们的健康产生不良影响。此外，实际的亲身经历可能会减少。实际与人接触的机会可能会被面对电脑的时间所取代。编程教育有利有弊。
- 然而，如果我们不真正开始，我们永远不知道会发生什么。未来很有可能会变得光明。所以，没有必要只担心缺点。这是一个你不想错过的话题。
