

# 少儿编程入门指南：轻松从零开始学习JavaScript、HTML等编程语言：分步指南

## 引言

儿童编程正迅速流行起来，越来越多的家长和教育工作者认识到这是一项重要的21世纪技能，越早、越频繁地教授越好。然而，高质量的编程教育资源在许多城镇、城市甚至国家都相对匮乏。许多家长和教育工作者看到了这一需求，并希望能够为此做些什么。儿童编程（也称为计算机程序设计）正迅速受到欢迎。虽然美国仅有少数传统学校开设编程课程，但盖洛普民意调查显示，90%的家长希望在学校日常教学中教授计算机编程。让孩子在年幼时学习编程，确实能为他们的终身成功奠定基础。即使他们未来不从事与计算机科学直接相关的工作，这也能让他们在几乎每一个现代行业中占据优势。

## 什么是儿童编程？

儿童编程是指为儿童参与编程提供的各种机会。这些机会旨在通过趣味性和游戏化的方式保持孩子们的兴趣。虽然很难想象年幼的大脑学习看似复杂的知识，但儿童编程已成为现实——得益于众多编程夏令营、网站、编程辅导老师、课后项目以及益智玩具，编程知识已变得相当易于消化。

## 为什么“每个”孩子都应该学编程

多年前，当关于儿童和编程的讨论刚开始时，你可能会将其视为炒作，因为这对整个教育系统来说是一个全新而新颖的概念。虽然这股“学编程”的热潮并非毫无根据，但只有时间能告诉我们这一切是否只是昙花一现。好了，现在时间已经证明了。我们仍然看到STEM教育统计数据，比如到2018年，将有240万个STEM工作岗位空缺。还有其他的数据，如STEM领域71%的新增工作岗位在计算机领域，但仅有8%的STEM毕业生来自计算机科学专业。人们还在疑惑编程是否难学。我们已经正式超越了单纯说“编程很酷，去学吧”的阶段。现在，我们要说的是：“`编程`确实很酷，去学吧，但你也应该因为能够获得回报而去学。”换句话说，有工作机会，很多工作机会——而且薪水非常可观。

更妙的是，这不仅仅关乎工作或酷劲（如果是那样的话，这篇文章会短得多）。还有……还在于创造力、问题解决能力、协作能力、沟通能力以及其他技能的提升，这些都是孩子学习编程的副产品。

因此，孩子应该学习编程，因为：

- 程序员需求旺盛
- 编程提供竞争优势
- 编程知识帮助学生更好地理解世界
- 编程有趣且令人满足
- 编程提升创造力
- 编程提升问题解决能力
- 编程提升毅力
- 编程提升协作能力
- 编程提升沟通能力

### 什么是儿童编程？几岁学编程合适？

编程，或者说计算机程序设计，是程序员发挥创造力，告诉计算机如何执行任务的过程。从根本上说，它涉及使用编程语言编写计算机程序。儿童编程通常通过高趣味性的内容来教授，同时创建涉及创意投入的项目。简而言之，儿童编程通常是游戏化的，让孩子学习起来充满乐趣！由于编程可以进行游戏化处理，最早5岁的孩子就可以开始学习编程，使用可视化积木界面或适合年龄的文本编程课程。利用游戏、应用程序和其他以儿童为中心的项目进行儿童计算机编程课程，是一种基于研究的方法，已被证明能够以吸引学生参与的方式教授真实世界的技能。

#### 为什么我的孩子要学编程？K-12年级学校教育够吗？

简而言之，在年幼时学习编程能让孩子和青少年拥有更多的未来机会。正如你将在下面了解到的，数据非常有说服力。根据美国劳工统计局的数据，软件开发者的年薪中位数为103,560美元，预计从2016年到2026年，需求将以每年24%的速度增长。这远快于其他职业的平均水平。

不幸的是，即使您的K-12学校是少数积极提供编程课程的学校之一，它们通常也无法充分培养学生。要么它们未能纳入能够启动您孩子职业生涯的合适语言，要么就是没有补习项目那样丰富的工具和资源。大多数学校使用`Scratch`、`Code.org`或`Tynker`等程序。`Scratch`是一种不错的免费方式，让孩子无需使用真正的编程语言就能学习编程概念。`Code.org`有一些不错的练习，介绍类`Scratch`的可视化积木语言，甚至在后期模块中引入了一些基础文本编程。`Tynker`也采用可视化积木方法，同时在后期模块中引入文本编程。这些程序是学校偏爱的工具，因为课程可以由编程经验有限或没有工程背景的教师来监督。它们是让孩子入门编程的有趣方式，但在短时间内，许多孩子会渴望更高级的内容。更高级的内容让学生能够使用真正的文本语言创建自己的游戏、应用程序、网页。而且，这不会将他们限制在封闭平台中。

您应该考虑尽早让孩子接触编程的其他一些原因：

- 计算机科学在多个相关领域培养技能，包括数学、科学、问题解决、团队合作、项目式学习、创意艺术等。正如史蒂夫·乔布斯的名言所说：“编程教会你如何思考。”
- 学习计算机程序设计就像学习一门外语。越早开始，越容易。
- 2020年，由于合格工程师的短缺，美国将有近100万个技术岗位空缺。
- 在STEM（科学、技术、工程和数学）领域，计算机相关职业占预计新增职位的60%以上。
- 计算机编程教授的技能在当今就业市场中即时相关。
- 计算能力几乎为每个行业提供动力，从教育到农业，从法律到商业，从建筑业到医疗业。
- 计算机工程工作在新毕业生就业中薪资排名最高。

##### 编程的好处

以下是关于编程为何如此重要的不同原因的说明。

###### 程序员供不应求

- 如前所述，根据`Code.org`的数据，所有新的 STEM职位中有`71%`在计算领域，然而只有`8%`的STEM毕业生来自计算机科学专业。这是计算机科学专业人才的严重短缺。

在申请大学、实习和工作时，编程提供竞争优势。

- 如果你掌握了一项许多同龄人都不具备的热门技能——比如编程能力——你在潜在的大学招生官和雇主眼中会立刻显得更加有吸引力。就这么简单明了。

####### 掌握编程知识后，学生能更好地理解周围的世界

- 我们大多数人对于智能手机、笔记本电脑、社交媒体网络和视频游戏的运行原理一无所知。基础的编程知识可以改变我们与日常使用的技术（以及我们认为理所当然的技术）的互动方式，并能让我们看到编程的无限可能。

#### 编程有趣且令人满足

- 虽然编程基于逻辑，但它也是一项极具创造性的活动。如果你懂得编程，你就可以开发前面提到的应用程序、视频游戏、网站等等！

##### 编程提升创造力

- 当你学习一门语言时，你用它来表达自己。编程也是如此。计算机编程让孩子们不仅能消费数字媒体和技术，还能创造它。孩子们不再只是玩视频游戏或使用应用程序，他们可以想象制作自己的视频游戏，或者设想自己的网站或应用程序会是什么样子——而且他们将拥有表达的途径。

###### 编程提升解决问题的能力

- 当孩子们编程时，他们将复杂的问题分解成更小的部分。孩子们学习如何像软件工程师那样处理问题，用逻辑的、计算的思维。
- 计算思维教会你如何通过将问题分解为一系列更小、更易管理的问题来应对大型问题。
- 这种逻辑思维是在学校、工作和生活中都非常有力的工具。

######### 编程提升毅力

- 学习编程，就像任何新学科一样，是一项挑战。因此，处理复杂问题——并在过程中犯错误——可能会非常令人沮丧。
- 编程教会了面对此类挑战时坚持不懈的宝贵技能。学会如何通过研究和协作解决问题。

######## 编程提升协作能力

- 每个学生都能学习，每个学生都能编程。孩子们可以与各种种族、性别或背景的同伴一起。
- 教室和其他面对面的环境，如`iD Tech`，让孩子们聚在一起。在线学习的孩子也能成长，互相提问，合作解决问题并创造事物。
- 许多游戏，如《我的世界》，提供了丰富的教育益处，因为它们同样涉及编程、协作——与世界各地的同伴一起。

##### 编程提升沟通能力

- 沟通是在学校、工作和生活中绝对必要的技能。能够用简单的术语清楚表达复杂想法的人，往往在不同的行业和人生道路中都能取得成功。
- 当孩子们学习编程时，他们学习如何与想象到的受众沟通。如前所述，计算机编程教会孩子们以简单的方式组织复杂的想法。

### 向幼儿介绍编程和计算机的方法

让你的孩子接触编程世界可能有些挑战，尤其是那些自己不知道代码如何工作的父母而言。在当今数字世界很大程度上接管了任务，学习编程基础知识至关重要。这不仅一项让你的孩子参与的有趣且富有成效的活动，还有助于解决问题的能力，提升创造力和逻辑技术能力。

### 适合孩子的编程语言

#### Python

`Python`是一种功能强大的、基于文本的计算机语言，即使是8岁的孩子也能轻松地用它表达自己。这种特定类型的代码既可以掌握其他语言的跳板，也足以成为孩子进行严肃的游戏/网站/应用程序开发的强大工具。网上有许多基于游戏和自主学习的课程，使学习`Python`（尤其是`Python 3`）成为孩子们一次独特、有趣且高度参与的体验。`Python`是向孩子介绍编程的绝佳选择，因为这种语言强调良好的代码布局。它也鼓励用户使用在线支持和丰富的`Python`库。随着你的孩子越来越多接触`Python`，他们会学会正确使用列表、元组和映射等基本数据结构。掌握`Python`中的`变量`、循环和其他`函数`，将为他们未来处理更高级的编程打下坚实的基础。他们还将克服`Python`中控制不同结构带来的复杂性。使用`turtle`模块绘制形状和图案，将帮助你的孩子克服动画和游戏设计上的第一障碍。很快，他们就能为Mac、PC或Linux编写自己的应用程序了。

#### Ruby

`Ruby`拥有最适合初学者程序员的可读语法。与其花很多时间解释学生输入机器的代码，不如让代码本身对他们来说是不言而喻的。对于仍在学习编程概念的孩子，这是一个非常重要的因素。归结底，孩子们需要学习这些概念才能写出好的脚本。是一种非常强大的语言，最初用于创建`Twitter`，因此你可以立即向学生展示这个应用程序是流行平台上使用的工具。

#### Java (Minecraft)

`Java`并不是我们喜欢的儿童编程语言，坦白说，它之所以出现在这个列表上，唯一的理由是因为它是`Minecraft`的语言。因此，`Minecraft`的魅力为学生创造了一种非常有效的“胡萝卜加大棒”体验，使其成为教孩子编程的一种非常流行的方式。自2011年发布以来，`Minecraft`已成为全球许多孩子关注的焦点。即使许多成年人仍然认为这只是另一款游戏，但`Minecraft`已经证明它远不止于此。它是教孩子如何运用逻辑、解决问题以及加强多项核心学术技能的强大工具。这只是他们的基础用户阶段。一旦你的孩子开始真正超越基础操作，他们就会清楚地看到`Minecraft`是一个高度适应性的、可供自定义的游乐场。当孩子开始真正喜欢这个游戏时，你可以向他们介绍“模组”。`Mod`是`modification`的缩写。



# Blockly

`Blockly` 是一种面向儿童的可视化积木编程语言，普遍被视为谷歌对`Scratch`的回应。打个比方，它使用相同的积木来帮助孩子们掌握代码。唯一真正的区别在于：`Blockly` 实际上是一种由几种现有编程语言组成的编程语言。在`Apache 2.0`许可下开发，`Blockly`通常被描述为用于创建可视化编程积木编辑器的客户端`JavaScript`库。也就是说，它主要是为8岁以上、想在家或学校在自己的浏览器中学习编程的孩子创建的。`Blockly` 附带一个“JavaScript库”，它基本上充当一个集中位置，可以轻松找到和访问预编写的语言（如`JavaScript`、`Python`、`PHP`、`Lua`和`Dark`）。`Blockly` 有特定的用户界面。

它就像是一个装有多形状、多颜色积木的儿童盒子。除此之外，还有一个放置积木的工具箱、一个回收站以及实际编写代码的空间。操作非常简单。用户从工具箱中取出积木（一次一块），按顺序排列，直到解决问题。完成后，程序会运行检查，查看已完成的操作，如果解决方案不正确——它会返回并再次分析代码，直到找到错误。轻而易举。`Blockly` 让任何人都能开发真正运行的 `Android` 应用。这使得这门语言不仅仅是一个儿童玩具，甚至不仅仅是一个帮助孩子编程的简单工具。孩子们可以在屏幕一侧通过连接不同的积木来编写代码。他们还可以轻松切换语言，从而查看同一基本程序的不同代码类型。尽管这是一个很棒的程序，但与 `Scratch` 相比——`Blockly` 还有所欠缺。它不如其最大的竞争对手成熟，也没有那么多优质的教程，这使得孩子们更难自学 `Blockly`。`Blockly` 已被 `Sphero`的一些优秀设计师使用，我们也看到越来越多的其他公司正在利用这项技术。

# Go (Golang)

`Go` 编程语言是一种静态类型、编译型语言，是最新获得广泛流行的语言之一。事实上，它非常新，仅仅诞生 10 年多（2009 年发明）。这种 promising 的增长使其成为一门值得掌握的语言，因此应该被添加到任何围绕儿童编程的课程中。就在 `Go` 首次实现后的短短几年内，它已经传播到各种不同的行业。此外，越来越多的财富 500 强公司和大型企业正在强调其重要性和前景。`Uber`、`Netflix` 甚至美国运通都是已知的 `Go` 用户。从结构上看，`Go` 与 `C` 语言相当相似。主要区别在于内存安全、垃圾回收、结构类型和 `CSP`风格的并发性。然而，对于儿童编程语言而言，它很可能可以采用 `C` 语言相同的整体教学策略并取得成功。`Go` 是一门值得了解的语言的原因有很多，尤其在现代。也就是说，最主要的原因是它确实在人气方面呈现爆炸式增长，而且丝毫没有减缓的迹象。预计在未来几年，开发团队的持续更新将只会促使其人气不断增长，并在各行业中不断扩展。

# Swift (Swift Playgrounds)

Apple 的 `Swift Playgrounds` 于 2016 年首次推出，作为教孩子 coding 的工具。`Swift Playgrounds` 包含许多基础 coding 课程和游戏化挑战，并配有界面紧凑、图形背景赏心悦目的界面。作为一款 `iPad` 应用，`Swift Playground` 适合在课堂中使用 `iPad` 的学校。`Swift Playgrounds` 的问题不在于语言本身，而在于其过于限制性的课程，与许多其他普通的儿童 coding 资源一样，它没有给学生任何自由表达的空间，例如 `Scratch` 平台所提供的那种。学生被迫按照课程设计师设定的固定路径逐级推进。我们发现这种"轨道式"体验对于富有创造力的孩子来说很快就会变得乏味。鉴于最近有消息称 Apple 计划通过 `Swift Playgrounds` 教年轻一代 iOS 开发者如何构建支持 AR 的应用，我们的看法可能会有所改变。一旦我们深入研究 `Swift Playgrounds AR` 项目，我们将更新这篇文章。

# Lua (Roblox)

`Lua` 是一种非常适合向孩子介绍基于文本的 coding 的脚本语言。它易于学习、使用，并且可以轻松嵌入到应用程序中。`Lua` 是一种免费、优雅、强大、可移植、可嵌入且适合初学者的 coding 语言。这种类型的语言引入了简单的概念，这些概念有潜力成为成熟的产品，同时仍然保持其简洁性、可读性和效率。`Lua` 最好的特点之一是它为用户处理内存管理等底层事务。`Lua` 与 `Python` 相似，消除了许多使 coding 对孩子变得困难的语法问题。但与 `JavaScript` 不同，它不需要在每行代码末尾使用分号。

# 为什么培养孩子 coding 很重要

信不信由你，我们正生活在 `STEM`（科学、技术、工程和数学）时代。越来越多的家长和老师意识到引导孩子理解 21 世纪趋势、信息和概念所蕴含的潜力。最新出现的方法之一是专注于教孩子如何 coding。已经开展了多种关于这个主题的研究，最近的研究已达成共识：coding 正 poised 成为有志于在科学、技术、工程和数学领域建立职业生涯的重要推动因素。

# 为什么每个孩子都应该学习 coding

`Coding` 是一种计算语言，应该教孩子学习新语言。当孩子被教导如何 coding 时，整个学习过程会起到触发作用，激发他们的逻辑思维能力。在孩子的 formative years 教他们 coding 是有利的，因为吸收速度更快，孩子也能 early 培养应用意识。就像 `ABC` 为英语提供方向一样，`coding` 使用 `0` 和 `1` 的不同组合来指导计算机执行特定功能。如果孩子在年幼时就接触到这种技术性知识，他们将能够与周围的技术和应用建立更好的兼容性。

# 学习 coding 的好处

`Coding` 不仅对职业有好处，而且具有终身前景。简单意味着，一旦孩子学会了 `coding`，他们可以继续投入其中，追求爱好或职业。`Coding` 有益的，因为它能培养孩子的创造力。当他们尝试不同的 `coding` 组合时，脑力被成倍激发。当然，孩子们会犯错，但这是创造力付出的代价。最终，过程很重要，产品是次要的——对孩子来说这样。

# 教孩子编程的提示

对年幼的孩子使用 `Scratch`，对年长的孩子使用 `Python`。

### 使用 `Scratch`

`Scratch` 是一款为儿童设计的免费编程工具，可在任何现代浏览器上运行。其视觉风格受到 `Logo` 程序的影响。`Scratch` 的拖放代码块会自动对齐连接，逻辑上无法拼接，从而使语法错误变得“不可能”。`Scratch` 非常适合尚未掌握打字技能的幼儿孩子。8 到 13 岁的孩子从其简单图形界面受益。

### 使用 `Python`

对于青少年和儿童，现实编程语言更适合。`Python` 是极佳的入门编程语言，因为它语法简单（不像 `Java` 或 `C#`），生成的代码可读性强（不像 `Perl` 或 `JavaScript`），并且背后拥有庞大的开发者社区。如果您的孩子已经超越 `Scratch` 的水平，`Python` 是最佳的下一步选择。

### 展示真实程序的源代码，不要只跟他们谈论概念

尽管编程享有智力声誉，但它是一项需要动手实践的技能，不仅仅是阅读书籍。`Python` 的交互式 `Shell` 鼓励实验以了解指令的作用。如果您亲自辅导孩子，编写代码的效果远胜于只跟他们谈论概念。坐下来陪他们，逐行描述他们编写的代码。`Scratch` 网站自动共享其网站上所有项目的源代码。鼓励你的孩子对代码进行修改，观察这些修改如何改变最终程序。

### 游戏是有趣的编程项目

制作视频游戏是许多年轻程序员常见的起点。《愤怒的小鸟》、《我的世界》、《小鸟快飞》（`Flappy Bird`）和《玩具熊的五夜后宫》（`Five Nights at Freddy's`）等游戏是主要的灵感来源。写了一本免费的书，《用 `Python` 发明你自己的计算机游戏》，通过几个简单游戏项目的完整源代码展示了编程概念。请注意，孩子们喜欢的游戏在他们刚开始时可能不是很好的编程项目。许多游戏需要开发团队、艺术家和设计师共同努力完成。需要大量关卡设计和艺术作品的游戏可能会让初学者不堪重负。完成一个简单游戏比开始但从未完成庞大项目更满意。

### 请管住手，不要随意触碰键盘和鼠标

分享知识令人兴奋的。向别人展示你掌握的编程知识很棒。但编程是一项通过动手实践习得的技能，要让孩子主导。即使暂时也要避免在孩子学习时跳进去敲击键盘。如果他们必须点击菜单或按钮，请用手指指向屏幕，而不是拿走鼠标自己点击。只要有代码需要输入，就让他们输入。虽然你自己做可能更快，但你的学生需要的练习比你更多。如果你在教一群人，尽量让每个学生拥有自己的电脑。就像演奏乐器一样，编程是一项通过动手实践而非观看他人而习得的技能。

# 编程教育的利弊

## 优点

#### 推动社会发展
- 对于完全不懂编程的人来说，可能不知道编程有多重要，日常生活充满了编程。
- 此外，日常物品的互联网化正因物联网化而迅速推进。农业等第一产业通过使用编程可能会变得更高效、更高产。

#### 开阔儿童视野
- 从小接触编程有助于儿童拥有更多未来的可能性。
- 二十年前，谁能想到程序员如此抢手？再过二十年，可能会出现新的职业。
- 因此，毫无疑问地说，学习相关编程对儿童的未来大有裨益。

## 缺点

#### 师资缺乏
- 从明年起，将在小学成为必修课，三年后，日本所有学校都将强制开设。
- 有多少教师能教授编程？有足够的教师来教数百名儿童吗？
- 此能教授编程的教师中，又有多少人能教授实际上可以使用的、高质量编程？

# 是否所有孩子都应该学习编程

支持者通常提出一个或多个论点：编程教育将帮助学生获得当前就业市场直接相关的职业。批评者回应称，许多相关努力实际上是浪费时间，原因如下：
- 侧重于开发今日相关的技能，而非明日工作；
- 许多努力由商业部门推动（对此高度怀疑的群体）；
- 许多努力仅仅教如何使用基本办公工具（如文字处理和演示软件）。

### 编程有助于培养重要的逻辑和解决技能

很少有人会反对这种观点：教得好，编程有助于培养重要的逻辑思维和解决技能。批评者辩说，编程课程并非发展此类技能的唯一途径，事实上这些技能应融入整个课程，而不是单一学科。

### 理解编程有助于更好地理解世界

编程有助于学生更好地理解世界的本质，以及部分运作的方式。我发现在这方面分歧小，尽管值得注意，许多教育努力者并未完全掌握这一点的重要性。

### 能够编程为创造力和创造性开启新路径

- 通过像 `Scratch` 这样的工具向小学生教授技能，作为机器人课程或推广“创客”倡议的一部分，这些努力常被引为（好）。
- 许多批评者可能赞扬此类努力，但仍辩说，即使承认编程是我们日益技术世界的新识字能力，仍值得问两个基本问题：我们的阅读、写作和算术这些旧的基础识字能力做得如何？我们不应该将新内容添加到已经臃肿的课程之前，确保这些基础“识字技能”到位？
- 当一位优秀的教师与热切、积极的学生一起学习编程时，很难反对更多此类活动。教育的“成功”，在很大程度上在于学习者的内在好奇心（而不是扼杀它！）。
