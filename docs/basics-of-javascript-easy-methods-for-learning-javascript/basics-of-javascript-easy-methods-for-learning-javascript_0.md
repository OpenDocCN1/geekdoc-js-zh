# JavaScript基础：简单学习方法

# 引言

本书教你如何使用经过验证的方法编写 JavaScript 代码。书中提供了循序渐进的 JavaScript 编程技巧，帮助你高效掌握。JavaScript 是一种脚本语言。你会注意到 HTML 标签中嵌入了大量脚本。由于 JavaScript 无法独立运行，我决定将其嵌入 HTML 中，以便在网页浏览器中使用。

如果你想将所学付诸实践，可以打开代码编辑器，复制代码并粘贴进去，看看会发生什么。你也可以直接将网页加载到电脑浏览器中，在页面上立即看到结果。嵌入的脚本完整且可直接使用。最佳策略是记住这些脚本，并对它们进行修改以使其更个性化，从而学得更快、更有趣。

无论你是开发网站，还是立志成为网页开发者的学生，或是为自己的业务搭建网站，本书都是市场上能找到的最佳读物。一旦你完成了前几章，你将拥有正确的心态，继续学习更具挑战性的主题。从轻松开始，随着对概念理解的加深，逐步提高速度。

本书提供了从零开始学习编程的经过验证的流程和策略。更棒的是，书中还提供了中级系统和课程，让已经熟悉 JavaScript 的人能够提升水平，并将其用于更高级的工具和系统。

别担心，你无需为学习 JavaScript 支付任何额外的第三方软件或工具费用。如果你使用的是 Mac，只需要记事本或 TextEdit。不过，当你进入中级阶段时，你会希望使用支持 HTML 和 CSS 的源代码编辑器，例如 Notepad++。
