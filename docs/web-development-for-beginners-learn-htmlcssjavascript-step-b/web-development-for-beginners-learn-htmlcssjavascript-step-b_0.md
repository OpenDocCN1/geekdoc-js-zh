## 第 1 章：网站
今天，互联网在世界上几乎每个角落都可以访问。在过去的二十十年里，互联网和网页得到了飞猛发展，网站也是如此。如果你回到二十年前，网站的样子与现在完全不同。当然，它们一点也不吸引人，而且最重要的是，它们是静态的。我所说的静态，是指网页上的所有内容都是固定的。但现在，网站是动态的，由 Web 应用生成。

### 静态网站与动态网站
在静态网站中，在有人从后台手动更改它之前，所有内容都是固定的。这类网站使用 `HTML` 创建，是网站开发中最简单的部分。所有访问静态网站的用户看到的视图都是完全相同的。但动态网站的内容对于每个用户来说可能是不同的。例如，`亚马逊的首页`对于已登录用户和未登录用户来说略有不同。如果你没有登录，你就无法看到账户信息、订单历史和其他内容。只有当你使用凭据登录时，这些内容才会出现。

动态网站与至少一个数据库关联，所有的动态信息都存储在其中。静态网站没有这样的数据库。用户交互是动态网站的另一个重要部分。

本书的重点是开发部分。它们之间有很多区别。正如我之前提到的，`HTML` 用于创建静态网站。`HTML` 是万维网（WWW）的核心技术之一。另外两种技术是 `CSS` 和 `JavaScript`。你也可以在静态网站中使用 `CSS` 和 `JavaScript` 来使其更具吸引力和交互性。但核心概念是，即数据是固定的，不会改变。通过更有效地使用这三种技术，特别是 `JavaScript`，可以创建美观且高性能的动态网站。

别担心；我们将在章之后深入讨论这三种技术。在继续之前，让我们简要介绍一下 `HTML`、`CSS` 和 `JavaScript`，让你对将要学习的内容有一个大致的了解。

### HTML
`HTML` 代表 `超文本标记语言`。无论你的网站变得多大或多复杂，你总是从 `HTML` 开始。它是创建网页结构的标准语言。虽然 `CSS` 和 `Javascript` 在多年年来发生了巨大变化，但 1990 年代和 2010 年代的 `HTML` 与现在没有多少。

网页的基本结构是使用 `HTML` 创建的。有几个 `HTML` 元素，它们是这些页面的构建块。`HTML` 元素以标签的形式出现。标签是带有带有 `HTML` 名称的角括号。例如，用于图片的 `HTML` 标签是 `<img/>`。大多数标签都有闭合标签，如 `<p>` 和 `</p>`。然而，某些标签如 `<img/>` 不需要闭合标签。`CSS` 和 `JavaScript` 被应用于 `HTML`，分别改变其外观并使其动态化。

### CSS
`级联样式表`或简称 `CSS` 是网页的呈现部分。`HTML` 创建结构，而 `CSS` 将其转换为更吸引人、更易读的版本。今天，没有 `CSS` 的网站是不完整的。用户期望网站具有吸引力、参与性，最重要的是要易于阅读。

通过 `CSS`，你可以更改字体、颜色、大小、位置、布局等许多内容。在 `HTML` 文件中使用 `CSS` 有多种方法，每种方法都有其自己的优势。

### JavaScript
`JavaScript` 被认为是网站最重要的部分。根据 StackOverflow 的洞察，它是 2019 年最流行的语言。事实上，你访问的大多数网站都是使用 `javascript` 创建的。

它是一种既用于客户端也用于服务器端的脚本语言。早期，`javascript` 只能在浏览器中运行，但随着 `node.js` 的引入，它也可以在外部运行。如 `Angular`、`React`、`Vue` 等 Web 框架和库都是使用 `javascript` 构建的。作为 `node.js`，它也被用于创建后端服务。

#### 总结
- 网站有两种：静态和动态。
- 静态网站的内容固定不变。
- 动态网站的内容可以更改，可以通过用户更改，也可以为不同的用户自动更改。
- `HTML`、`CSS` 和 `JavaScript` 是万维网（WWW）的三大核心技术。
- `HTML` 元素通过角括号（通常称为标签）访问。这些标签用于创建网页的结构。
- `CSS` 用于增强网页的外观。
- `JavaScript` 是一种脚本语言，在开发动态网站中起着至关重要的作用。它用于用户交互、内容管理、操作数据库等。

## 第二章：理解 HTML 元素、标签和属性
如上一章所述，`HTML` 元素是网页的构建块。这些元素包含在角括号中。许多 `HTML` 标签都有相应的闭合标签。还有一些标签不需要闭合标签。我们将在下一章讨论所有这些标签，但首先，你需要理解 `HTML` 标签是如何工作的。

### 基础 HTML 标签
让我们从最基本的标签开始，即 `<html>` 标签。每个 HTML 文档都以 `<html>` 标签开始，并以相应的闭合标签 `</html>` 结束。其他的 HTML 标签都嵌套在这个标签里面。另外两个基础 HTML 标签是 `<head>` 和 `<body>` 标签。`HTML` 文件可以在浏览器中渲染。浏览器中可见的部分写在 `<body>` 标签内。它可以包含段落、标题、视频等多个元素。另一个基础标签是 `<head>` 标签。所有关于文档的信息都列在 `<head>` 标签中，包括`<link>`、`<style>` 等标签。在早期版本中，`<head>` 标签是强制性的，但在 HTML5 中可以省略。

### HTML 属性
所有的 HTML 标签都是为了特定目的而构建的。HTML 标签具有属性。例如，`<p>` 用于段落，`<img>` 用于图片。大多数 HTML 标签都有由属性定义的额外属性或特征。标签可能没有强制属性。`<img>` 标签必须包含 `src` 和 `alt` 属性。此外，你可以放置 `height` 和 `width` 属性，但它们不是强制性的。

### 闭合标签和开启标签
如上所述，许多标签都有闭合标签。开启标签和闭合标签的区别在于闭合标签有斜杠。某些标签如 `<img/>` 带有斜杠。

### <!DOCTYPE html
你可以在浏览器中运行 HTML 文档。`<!DOCTYPE html>` 标签定义这是一个 HTML 文档。`<!DOCTYPE html>` 是一个声明。你必须在每个 HTML 文档的顶部声明它。

#### 总结
- 网站有两种类型——静态和动态。
- 静态网站具有固定且不变的内容。
- 动态网站的内容可以根据用户更改，或为不同的用户自动更改。
- `HTML`、`CSS` 和 `JavaScript` 是万维网（WWW）的三大核心技术。
- `HTML` 元素通过角括号（通常称为标签）访问。这些标签用于创建网页的结构。
- `CSS` 用于增强网页的外观。
- `JavaScript` 是一种脚本语言，在开发动态网站中起着至关重要的作用。它用于用户交互、内容管理、操作数据库等。

## 第三章：段落和标题
我们可以在 HTML 文档中添加各种内容。在网页上最常见的内容是简单文本。文本可以是任何形式或样式。我们可以创建不同长度的段落、标题，并可以更改颜色、字体大小、背景颜色。

HTML 中的段落使用 `<p>` 标签添加。对于标题，我们有多个标签，包括 `<h1>`、`<h2>`、`<h3>`、`<h4>`、`<h5>` 和 `<h6>`，它们的大小不同。

### <p> 标签
段落是使用 `<p>` 标签创建的文本块。标签之间是内容。假设我们有以下文本：我的名字是 Tommy。我 25 岁。我来自伦敦。我来美国深造。我于 2016 年毕业于哈佛大学。第 6、7、8 行有换行。你认为它们会在浏览器中正确显示吗？！它们不会以在 `<p>` 标签中编写的格式显示。为什么？原因很简单。无论我们如何格式化 `<p>` 标签中的文本，它总是将整个 `<p>` 标签的内容视为单个段落。

### 换行
每个段落从新的一行开始。但如果你要在特定段落内部添加换行呢？HTML 提供了 `<br>` 标签。只需将标签放在你想开始新行的行尾。你可以看到，`<br>` 标签没有闭合标签。它是一个空标签，不需要闭合标签。看看它在浏览器中的显示。这就是我想要的效果。

### <h1> 和其他标题标签
为了提供标题和副标题，HTML 提供了标题标签。它们包括 `<h1>`、`<h2>`、`<h3>`、`<h4>`、`<h5>` 和 `<h6>`。这些标签之间的唯一区别是大小。5 到 10 行包含不同类型的标题。`<h1>` 尺寸最大，而 `<h6>` 最小。这些标签旨在网页提供标题。标题与段落不同，它们加粗且大。但这并不意味着我们应该在段落之间使用它们来使文本加粗或放大。高效地使用这些标签。

#### 总结
- `<p>` 标签用于编写段落。
- 每个段落从新的一行开始。
- 要在段落内添加换行，使用 `<br>` 标签。该标签没有闭合标签。
- 有六个标题标签，每个的大小都不同。
- 永远不要在段落之间使用标题标签。

## 第章：文本格式
在 HTML 文档中添加文本时，你可能需要为某些部分定义特殊含义。我说的特殊含义是指文本中看起来不同的部分。HTML 提供了几个标签来格式化文本。

### <b> 和 <strong>
`<b>` 标签定义加粗文本。在段落中，单词 'name' 被包含在 `<b>` 标签内。`<b>` 标签内的文本现在是加粗的。同样，还有一个标签 `<strong>`。

### <i> 和 <em>
`<i>` 标签定义斜体文本。在段落中，单词 'name' 被包含在 `<i>` 标签内。同样，还有一个标签 `<em>`。

### <small>
有时你可能需要使用 `<small>` 来定义一个文本。

### <del>
表示删除的文本。

### <mark>
高亮文本通过 `<mark>` 标签实现。

### <sub> 和 <sup>
`<sub>` 标签定义下标，`<sup>` 标签定义上标。

#### 总结
- `<b>` 和 `<strong>` 定义加粗文本。
- `<i>` 和 `<em>` 定义斜体。
- `<small>` 定义较小文本。
- `<del>` 定义删除的文本。
- `<mark>` 定义高亮文本。
- `<sub>` 和 `<sup>` 定义下标和上标。

## 第五章：超链接
网站上有多个页面。我们可以从一个页面导航到另一个页面。HTML 中的这些链接被称为超链接。`<a>` 标签用于创建超链接。在本章中，我们将讨论如何使用 `<a>` 标签从一个页面导航到另一个页面。

### <a> 标签
`<a>` 标签有几个属性。其中 `href` 是强制性属性，它持有文档或网页的 URL。URL 应该写在引号内，例如 `<a href="https://google.com">这里</a>`。点击链接将打开 Google 首页。

### target 属性
`target` 属性是 `<a>` 标签的一个可选属性。它指定在哪里打开文档或网页。它可以具有以下值：
- `_self`：在同一个标签页/窗口中打开文档或网页。默认设置为 `_self`。
- `_blank`：在新的标签页/窗口打开文档或网页。
- `_top`：在窗口的全主体中打开文档或网页。
- `_parent`：在父框架中打开文档或网页。
你也可以提供一个 `framename` 作为 `target` 属性的值，在特定框架中打开文档。上面的超链接将在新标签页/窗口打开。

### title 属性
`title` 属性为超链接提供标题。当鼠标悬停在链接上时，它会显示名为 `title` 的文本。默认情况下，它不显示任何内容。标题通常是关于链接的简短信息。

### 更多 <a> 标签
`<a>` 标签不仅限于文本。你还可以使用图像和按钮作为超链接。甚至可以使用图片的一部分作为超链接。

#### 总结
- HTML 中的 `<a>` 标签用于创建超链接。
- `href` 属性是强制性的，因为它持有文档或网页的 URL。
- `target` 属性指定文档或网页在哪里打开。使用 `_blank` 打开新标签页。
- `title` 属性提供悬停时显示的额外信息。
- 图像和按钮也可以作为超链接。

## 第六章：图片
图片是文本之后常见的网站部分。今天，你访问的几乎每个网站都有图片。图片提高了网站的外观并吸引更多观众。只需使用 `<img>` 标签添加图片。

### <img> 标签
`<img>` 标签具有以下语法。`<img>` 标签没有闭合。

### <source> 标签
`<source>` 标签用于定义视频源。它有一个 `src` 属性持有视频的 URL。我们还需要使用 `type` 属性说明视频类型。观察视频在浏览器中的样子。视频出现在屏幕上，但它不会播放，因为没有播放或暂停选项。

### controls 属性
`<video>` 标签有一个布尔属性叫做 `controls`。该属性为视频提供了控制选项。你现在可以看到播放/暂停按钮和视频长度。

### autoplay 属性
`autoplay` 属性是 `<video>` 标签的另一个布尔属性。当指定它时，视频会在页面加载后立即开始播放。

### <audio> 标签
`<audio>` 标签用于定义网页上的音频。与 `<video>` 标签类似，这里也使用了 `<source>` 标签。此外，`<audio>` 也有 `controls` 和 `autoplay` 属性。

#### 总结

- `<source>` 标签通过 `src` 和 `type` 定义媒体源。
- `controls` 提供播放/暂停选项。
- `autoplay` 让媒体自动开始播放。

网页上的数据应该以适当的方式表示。我们已经讨论了表示数据的各种方法。有时我们可能需要表格来准确清晰地显示数据。表格按行列排列数据。

## 第八章：列表
另一种表示数据的方法是使用列表。列表在网页上很常用。它们主要用于表示相关数据。HTML 有三种列表：有序、无序和描述列表。

### 有序列表
有序列表总是有顺序的。默认情况下，有序列表是数字的。使用 `<ol>` 标签创建有序列表。要插入值必须使用 `<li>` 标签。`start` 属性允许我们控制起点。

### 无序列表
无序列表没有顺序，它是项目列表。使用 `<ul>` 标签定义无序列表，`<li>` 用于选项。无序列表的 `type` 属性有值：`disc`、`square` 和 `none`。

### 描述列表
描述列表用于创建一个每个选项都有描述的列表。`<dl>` 标签定义描述列表。有两个额外的标签——`<dt>` 和 `<dd>`。`<dt>` 定义术语，`<dd>` 描述它。

#### 总结
- 列表有三种类型：有序（`<ol>`）、无序（`<<ul>>`）和描述性（`<dl>`）。
- `<li>` 用于用于列表项。
- `start` 属性适用于有序列表。
- `<dt>` 和 `<dd>` 用于描述列表中的术语和描述。

## 第十章：DOM
DOM 代表文档对象模型（Document Object Model）。它是成为开发者道路上的一个非常重要的概念。在本章中，我们将讨论什么是 DOM 以及如何使用。

### 什么是 DOM？
当 HTML 文件加载到浏览器中时，会创建一个树形结构。该结构包含各种节点，这些节点代表 HTML 文档的元素。结构从 `<html>` 标签开始，它是根元素。然后，`<head>` 和 `<body>` 是不同的节点。在 body 中，有一个 `<p>` 标签，它是 `<body>` 标签的节点。随着 HTML 文档中添加更多标签，结构会增长。

#### 总结
- DOM 是树形结构。
- 节点代表元素。

#### 总结

## 第十三章：CSS 选择器
在上一章中，我们讨论了 CSS 的语法。选择器是规则集的两个部分之一。我们讨论了如何通过标签选择 HTML 元素。

### ID 选择器
现在，无论 HTML 文件中只有一个 `<p>` 标签还是几百个，这个 CSS 都会应用于所有元素。但我们不想对所有段落应用相同的 CSS，对吧？可能我们想要一个段落是红色，另一个是蓝色。同样，对于这些场景会有各种选择器。`Id` 选择器用于选择特定元素。每个元素都有 `id` 属性。赋予元素的 id 应该是唯一的。要使用 id 选择元素，使用井号 (`#`) 后跟 id 名称。

### 类选择器
id 通常用于单个元素。但如果我们想为一组元素使用相同的 CSS 呢？同样，对于这些场景会有选择器。类选择器使用点 (`.`) 后跟类名。

### 分组选择器
你可以使用逗号来选择多个元素。例如，`h1, h2`。

### 通用选择器
使用星号 (`*`) 匹配所有元素。

#### 总结
- ID 选择器使用 `#`。
- 类选择器使用 `.`。
- 分组选择器使用逗号。
- 通用选择器使用 `*`。

## 第十五章 - CSS 边框、外边距和内边
每个 HTML 元素都有边框（border）、外边距（margin）和内边（padding）。这三个术语很重要，因为呈现通常泛程度上取决于它们。在移动它们之前，你需要理解盒模型。

### CSS 盒模型
HTML 元素封装在盒子内部。这个盒子被称为 CSS 盒模型。该模型有四个部分：边框、外边距、内边和内容。默认情况下，只有内容可见的，而边框不可见，外边距和内边为零。

## 第十六章：HTML 事件
HTML 事件是触发 JavaScript 的方式。它们分为不同的类别：
- 鼠标事件：`onclick`、`dblclick`、`onmouseover`、`onwheel`。
- 键盘事件：`keydown`、`onkeypress`、`onkeyup`。
- 窗口事件：`onload`、`onresize`。
- 表单事件：`onchange`、`onsubmit`、`onreset`。
- 拖放事件：`ondrag`、`ondrop`。

## 第十七章：什么是 JavaScript？
到目前，我们讨论了 HTML 和 CSS，现在我们知道如何创建网页并赋予它样式。但仍然，一切仅仅是呈现。例如，我们可以使用 `<button>` 标签创建一个按钮，但点击按钮时什么也不会发生。这是静态的，而今天网站是动态的。在不重新加载页面的情况下更改网站内容。JavaScript 是一个庞大的编程语言。它有许多概念。从初学者水平到高级水平，JavaScript 中有很多内容。

### 什么是 JavaScript？
根据定义，JavaScript 是一种高级、多范式的编程语言。它是万维网（WWW）的核心技术之一，另外两种是 HTML 和 CSS。JavaScript 是 Web 开发中至关重要且缺的一部分。HTML 创建基本结构，而 CSS 将其转换为吸引人的版本。一个只有 HTML 的网站是静态的，没有用的。假设页面上有一个漂亮的按钮，但点击时什么也不会发生。JavaScript 被用于让按钮工作。

### JavaScript 的历史
在 90 年代早期中期，Web 是年轻的，一切都是静态的。人们很快意识到 Web 不能是静态的，需要动态性，并且应该是动画和交互。为了让 Web 动态化，需要 DOM 操作，因此需要脚本语言。Brendan Eich 在 1996 年创建了 JavaScript。

## 第八章：JavaScript 基础
JavaScript 是一个庞大的编程语言，涵盖了许多概念。我们将从基础开始。

### 变量、数据类型和运算符
使用 `var`、`let` 或 `const` 声明变量。使用 `=` 进行初始化。

### 数据类型
JavaScript 中的数据类型分为两类：
- 原型（Primitive）：Number（数字）、String（字符串）、Boolean（布尔）、Undefined（未定义）。
- 非原型（Non-primitive）：Object（对象）、Array（数组）、Date（日期）。

## 第十三章：DOM
DOM 代表文档对象模型（Document Object Model）。它是成为开发者道路上的一个非常重要的概念。在本章中，我们将讨论什么是 DOM 以及如何使用。

### 什么是 DOM？
当 HTML 文件加载到浏览器中时，会创建一个树形结构。该结构包含各种节点，这些节点代表 HTML 文档的元素。结构从 `<html>` 标签开始，它是根元素。然后，`<head>` 和 `<body>` 是不同的节点。在 body 中，有一个 `<p>` 标签，它是 `<body>` 标签的节点。随着 HTML 文档中添加更多标签，结构会增长。
