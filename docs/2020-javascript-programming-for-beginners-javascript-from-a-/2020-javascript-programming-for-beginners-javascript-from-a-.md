## JavaScript简介

JavaScript是一种强大的客户端脚本语言。JavaScript主要用于提升用户与网站的互动性。换句话说，在JavaScript的帮助下，你可以让你的网站更生动、信息更丰富。JavaScript也常用于图形渲染和移动设备开发。

JavaScript也有更复杂的服务器端变体，例如Node.js，它使你能够为网站添加更多功能，而不仅仅是上传文件（例如多台计算机之间的实时通信）。在客户端环境（例如Web浏览器）中，JavaScript可以连接到环境对象，以提供对它们的编程控制。

它因网页创建而广为人知，一些非浏览器应用程序也使用它。JavaScript可用于客户端和服务器端开发。JavaScript包含一系列基本对象，如序列、日期和数学，以及一组核心语言结构，如运算符、控制结构和语句。

### 客户端

它为用户及其文档对象模型（DOM）的使用提供对象。客户端扩展使应用程序能够在HTML表单上放置元素，并响应用户事件，如鼠标点击、模板数据和页面导航。使用完整的客户端框架，如AngularJS、ReactJS、VueJS等等。

### 服务器端

它提供在服务器上运行JavaScript所需的重要对象。服务器端扩展允许应用程序与数据库交互，以提供从一次调用到另一次调用的细节连续性，或在服务器上执行文件操作。目前最流行的实用框架是node.js。

### JavaScript与Java

JavaScript和Java在某些方面相似，但在其他方面完全不同。JavaScript类似于Java，但没有Java的静态类型和强类型控制。这就是为什么JavaScript从LiveScript重构为Javascript，采用了大多数Java表达式语法、命名约定和基本控制流结构的原因。

JavaScript遵循基于有限数据类型的运行时框架，这些数据类型表示整数、布尔值和字符串值，这与Java的编译时类结构不同。JavaScript没有类模型，而是基于原型的对象模型。原型模型具有动态继承，可以为单个对象更改继承的内容。JavaScript通常提供没有唯一声明规范的函数。函数可以是对象资源，作为松散类型的方法使用。

与Java相比，JavaScript是一种非常开放的语言。所有变量、类和方法都不需要声明。你不必担心public、private或protected方法，也不需要实现接口。不需要显式声明变量、参数和返回函数类型。

Java是一种为快速输出和类型安全而构建的类编程语言。类型安全意味着，例如，Java整数不能通过修改Java字节码被抛入对象引用或私有内存。Java的基于类的范式意味着编程仅由类及其方法组成。Java类的继承和强类型通常包括紧密相关的对象层次结构。这些规范阻碍了Java的编程，使其不如JavaScript灵活。

相比之下，JavaScript在精神上源自一系列更小、更动态的语言，如HyperTalk和dBASE。它们简单的语法、高级的内置功能和构建结构的低要求，为更广泛的编程资源受众提供了便利。

## 条件语句

条件语句用于根据不同情况执行不同的操作。
条件语句控制JavaScript的行为，并决定代码片段是否运行。
在JavaScript中，有多种类型的条件，包括：

- 1) "If"语句：如果条件有效，则用于执行一系列代码。
- 2) "Else"语句：如果同一断言为假，则定义一个代码块的执行。
- 3) "Else if"：如果第一个条件不正确，则陈述一个新问题。现在你有了基本的JavaScript术语，让我们展示每个示例。

### IF语句示例

If语句仅在括号()中的条件为真时运行。因此，这是最常见的条件形式。

#### ELSE 语句示例

```javascript
if (10 > 5) {
    var outcome = "if block";
}

outcome;

OUTPUT

"if block"
```

对于上述情况，发生的过程如下：
关键字 `if` 表示 JavaScript 应开始一个条件语句。`(10 > 5)` 是一个为真的统计条件——在此情况下，10 大于 5。因此，将要运行的代码块是花括号 `{}` 包围的部分。由于条件通过，变量 `outcome` 被赋值为 `"if block"`。

#### ELSE 语句示例

带有 `else` 语句的 `if` 语句可以扩展，以便在条件不通过时运行另一个代码块。

```javascript
if ("cat" === "dog") {
    var outcome = "if block";
} else {
    var outcome = "else block";
}
outcome;

OUTPUT

"else block"
```

在上述情况下，`"cat"` 和 `"dog"` 不相同，因此运行另一个代码块，变量的结果为 `"else block"`。

#### ELSE IF 语句示例

你还可以用另一个 `else if` 声明来扩展 `if` 声明，为其代码块添加另一个条件。

```javascript
if (false) {
    var outcome = "if block";
} else if (true) {
    var outcome = "else if block";
} else {
    var outcome = "else block";
}

outcome;

OUTPUT

"else if block"
```

你可以使用多个 `if else` 条件语句，但请注意，第一个通过的 `else if` 代码块将被执行。在运行第一个通过的条件后，JavaScript 会跳过所有剩余的条件。

- 函数的标题。
- 一个函数参数列表，用括号括起来并用逗号分隔。
- 定义函数的 JavaScript 语句，包含在花括号 `{...}` 中。

JavaScript 中可以使用一个或多个内部函数。这些嵌套函数位于外部函数内部。内部函数将控制外部函数的变量和参数。外部函数无法访问内部函数指定的变量。

### 要记住的要点

- 1) JavaScript 函数允许你指定一个代码块，为其命名，并根据需要运行任意多次。
- 2) 函数可以使用关键字 `function` 定义，并可以使用运算符执行。
- 3) 函数可以包含一个或多个参数。函数参数值可以在执行期间可选地指定。
- 4) JavaScript 是一种动态类型语言。函数参数可以包含任何类型的数据。
- 5) 调用函数时，你可以指定更少或更多的参数。
- 6) 所有函数都可以默认访问 `arguments` 对象，而不是参数名称。
- 7) 函数可以返回特定值或另一个函数。
- 8) 函数可以赋给不同名称的变量。
- 9) JavaScript 允许你使用匿名函数创建变量。

### 作用域

变量的可访问性（可见性）由作用域决定。

在代码的某些特定部分，作用域是执行期间变量、函数和对象的可访问性。也就是说，代码区域中变量和其他资源的可见性由作用域决定。

在 JavaScript 中，有两种选择。
1) 全局作用域
2) 局部作用域

#### 全局作用域

当你在文档中开始编写 JavaScript 时，你已经处于全局框架中。整个 JavaScript 文本只有一个全局作用域。如果在函数外部指定变量，则该变量处于全局作用域。

![](img/c8bda18d83895f80a2442fa61b57b147_14_0.png)

#### 局部作用域

在 JavaScript 函数中声明的变量将对该函数是局部的。

函数作用域的局部变量：它们只能从函数内部获取。
在任何 `var` 参数函数内声明的变量称为局部变量。局部变量无法在声明函数外部访问或更改。

在函数内指定的变量在作用域上是局部的。但是，对于该函数的每次调用，它们具有不同的作用域。这意味着可以在不同函数中使用同名变量。由于这些变量绑定到各自的函数，每个函数都有多个作用域，并且其他函数无法访问。由于局部变量仅在其函数中定义，因此同名变量可以用于不同的函数。局部变量在函数开始时生成，在函数完成时移除。

```html
<!DOCTYPE html>
<html>
<body>

<p>在 myFunction() 外部，carName 是未定义的。</p>

<p id="demo1"></p>

<p id="demo2"></p>

<script>
myFunction();

  var carName = "Volvo";
  document.getElementById("demo1").innerHTML = typeof carName + " " + carName;

</script>

```

#### 要记住的关键点

- 1) JavaScript 具有全局作用域和局部作用域。
- 2) 在任何函数外部声明和初始化的变量成为全局变量。
- 3) 在函数内部声明和初始化的变量成为该函数的局部变量。
- 4) 在任何函数内不使用 `var` 关键字声明的变量将自动成为全局变量。
- 5) 全局变量可以在软件中的任何地方访问和更新。
- 6) 局部变量无法在声明函数外部访问。
- 7) 全局变量和局部变量可以同名而不相互影响。
- 8) JavaScript 不要求在 `{}` 括号内使用块级宽度。

## 数组

### 描述：

数组是类列表对象，其原型具有执行遍历和变异操作的机制。JavaScript 数组的长度及其组件的类型都不是固定的。由于数组长度经常被修改，并且数据可以存储在数组的不连续位置，因此 JavaScript 数组是否密集并不重要。通常，这些是有用的特性；但如果你的特定用途不适合这些特性，你应该考虑使用类型化数组。数组不会使用字符串作为索引元素（如在关联数组中），而必须使用整数。设置或访问非整数符号不会从数组列表本身设置或检索元素，而是设置或访问与数组对象的首选项相关的变量。数组对象的属性和数组元素的列表是不同的，数组的遍历和变异操作不能应用于这些命名属性。

数组是一种特殊类型的变量，可以使用不同的语法存储多个值。每个值都与从 0 开始的数字索引相关联。

#### 访问数组元素

JavaScript 数组是零索引的：数组的第一个元素索引为 0，因此最后一个元素的索引等于数组的 `length` 属性值减 1。使用不正确的索引号将返回 `undefined`。

```javascript
let arr = ['this is the first element', 'this is the second element', 'this is the last element']
console.log(arr[0])           // 输出 'this is the first element'
console.log(arr[1])           // 输出 'this is the second element'
console.log(arr[arr.length - 1]) // 输出 'this is the last element'
```

JavaScript 数组及其属性没有什么特别之处。以数字开头的 JavaScript 属性不能用点表示法引用，必须使用方括号表示法访问。

例如，如果你有一个名为 `3d` 的对象，它只能使用方括号表示法引用。
注意，在 `3d` 示例中必须提及 '3d'。也可以引用 JavaScript 列表的索引（例如 `years['2']` 而不是 `years[2]`），尽管这不是必需的。

## 循环

JavaScript 中使用循环来基于条件执行重复任务。条件在求值时通常返回 `true` 或 `false`。循环将持续运行，直到指定的条件返回 `false`。

### 不同类型的循环

JavaScript 包含多种循环类型：

1.  For-循环 通过代码块执行多次。
2.  For/in-循环 遍历对象的属性。
3.  For/of-循环 遍历可迭代对象的值。
4.  While-循环 当指定条件为真时，遍历代码块。
5.  Do/while-循环 当指定条件为真时，也遍历代码块。

### While 循环

JavaScript 循环被反复用于运行代码块，直到满足某些条件。当开发者考虑迭代或遍历，比如一个数组时，这与循环相同。JavaScript 提供了多种选项来重复运行代码块，如 `while`、`do while`、`for` 和 `for-in`。

#### 示例

```javascript
var sum = 0;
var number = 1;
while (number <= 50) {  // -- 条件
  sum += number;        // -- 循环体
  number++;             // -- 更新器
}
alert("Sum = " + sum);  // => Sum = 1275
```

首先评估条件。如果有效，将执行 `while` 语句后面的语句块。这将重复，直到条件不正确。由于它在执行代码块之前测试条件，因此被称为前测试循环。

`number++` 语句将被称为更新器。移除它将导致无限循环。你必须始终在循环中提供一个语句，以确保循环终止，否则你将遇到这个问题。

### Do While 循环

```javascript
var sum = 0;
var number = 1;
do {
  sum += number;        // -- 循环体
  number++;             // -- 更新器
} while (number <= 50); // -- 条件
alert("Sum = " + sum);  // => Sum = 1275
```

首先执行 `do` 块，然后评估状态。如果 `while` 条件有效，将再次执行该块并重复，直到条件为假。由于条件在代码块执行后测试，因此被称为后测试循环。

```javascript
do {
    // 在循环体中从键盘读取一个字符
} while (if ch === '0');    // => 如果输入 '0' 则终止循环
```

### For 循环

```javascript
var sum = 0;
for (var i = 1; i <= 50; i++) {
    sum = sum + i;
}
alert("Sum = " + sum);    // => Sum = 1275
```

它由三个部分组成，用分号分隔。第一个是初始化器 (`var i = 1`)，它初始化循环，并且只在循环开始时执行一次。第二个是测试状态 (`i <= 50`)。当条件表达式求值为 `true` 时，执行循环体。当条件为真时，循环停止。第三个元素是更新器 (`i++`)，它在每次迭代后调用。通常，更新器会增加或减少循环计数器。

在 `for` 循环中，所有三个阶段，即初始化器、测试条件和更新器，都写在这样的一行中（称为迭代语句），而在 `while` 中它们是分散的，位于不同的位置。

### For In 循环

```javascript
var student = { name:"Bill", age: 25, degree: "Masters" };
for (var item in student) {
    alert(student[item]);    // => "Bill", 然后 25, 然后 "Masters"
}
```

在每次迭代中，JavaScript 将属性的名称（字符串值）应用于变量对象。在上面的示例中，这些是：`name`、`age` 和 `degree`。

## BREAK 语句

当 JavaScript 在循环中遇到 break 语句时，它会立即退出循环，不再执行任何其他循环语句。控制权会立即传递给循环结构之后的语句。下面是一个示例：

```
var sum = 0;
for (var i = 1; i <= 10000; i++) {
    sum += i;
    if (i === 50) {
        break;    // 立即将控制权转移到 for 代码块之外
    }
}
alert("Sum = " + sum);        // => Sum = 1275
```

当故意创建一个无限循环时，你可以使用 break 语句来控制循环的结束，如下所示：

```
var number = 1;
var sum = 0;
while (true)   // 等同于 for ( ; ; )，称为“永久”循环
{
    sum += number;
    if (number === 50) {
        break;  // 立即将控制权转移到 while 代码块之外
    }
    number++;
}
alert("Sum = " + sum);      // => Sum = 1275
```

当循环第 50 次进入时，`number++;` 断言将不会被执行。

## CONTINUE 语句

如果在 JavaScript 的循环中发现一个 continue 语句，它会完成当前迭代的运行，然后返回到循环的开头，开始下一次迭代。下面的示例仅显示偶数。

```
for (var i = 1; i <= 10; i++)
{
    if ((i % 2) != 0) {
        continue;
    }
    alert(i);          // => 2, 4, 6, 8, 10
}
```

在其他循环中，也会发现 continue 语句。然而，在 for 循环中，它的行为与在 while 循环中不同。在上面的示例中，for 循环首先测试 `i++`，然后检查 `i <= 50` 条件。现在注意 while 循环：

```
var number = 0;
while (number <= 10) {
    number++;
    if ((number % 2) != 0) {
        continue;
    }
    alert(number);    // => 2, 4, 6, 8, 10
}
```

当执行 continue 语句时，控制权将直接恢复到测试条件（`number <= 50`），而 `number++` 不会被求值，从而避免了无限循环。这里的教训是，你不能简单地将 for 循环替换为 while 循环；你必须小心，特别是当涉及 continue 语句时。

#### 迭代器

迭代器是一种从一次性数据结构中提取数据的方式，它需要引入一个迭代器接口。

它是一个帮助我们遍历列表或集合的对象或模式。迭代器定义了序列并强制执行迭代器协议，该协议返回一个使用 `next()` 方法的对象，该方法持有值和完成状态。值表示迭代器序列的下一个值，完成值是一个布尔值（true 或 false），如果序列的最后一个值已被消耗，则完成值为 false。我们可以检查一个实体是否默认可迭代。

### 迭代协议

可以有两种迭代协议可用：可迭代协议和迭代器协议。

#### 迭代器协议

当一个对象实现了一个接口（或 API）来解决以下两个问题时，它就是一个迭代器：
1. 是否还有元素？
2. 如果有，元素是什么？

当一个对象具有 `next()` 方法时，它就被认为是一个合格的迭代器，该方法返回一个具有两个属性的对象：

- Done：一个布尔值，表示是否还有其他元素可以迭代。
- Value：这是当前的值。

每次调用 `next()` 都会返回序列中的下一个值：

```
{ value: 'next value', done: false }
```

当返回最后一个值时，如果你调用 `next()` 方法，将返回以下结果对象：

```
{done: true, value: undefined}
```

完成属性的值意味着没有更多值需要返回，并且该属性的值被设置为 undefined。

#### 可迭代协议

如果一个对象包含一个名为 `[Symbol.iterator]` 的方法，该方法不使用参数并返回一个符合迭代器协议的对象，那么这个对象就是可迭代的。`[Symbol.iterator]` 是 ES6 中众所周知的符号之一。

#### 迭代器

由于 ES6 为 Array、Set 和 Map 集合形式提供了内置迭代器，因此你不需要为这些对象创建迭代器。

当你有一个自定义形式并希望使其可迭代以便可以使用循环构造时，你需要强制执行迭代协议。
以下代码生成一个序列对象，该对象返回一个在范围（start, end）内的数字列表，相邻数字之间有间隔。

```
class Sequence {
    constructor( start = 0, end = Infinity, interval = 1 ) {
        this.start = start;
        this.end = end;
        this.interval = interval;
    }

    [Symbol.iterator]() {
        let counter = 0;
        let nextIndex = this.start;

        return  {
            next: () => {
                if ( nextIndex <= this.end ) {
                    let result = { value: nextIndex,  done: false }
                    nextIndex += this.interval;
                    counter++;
                    return result;
                }
                return { value: counter, done: true };
            }
        }
    }
};
```

## 清理

除了 `next()` 方法，`[Symbol.iterator]()` 还可以选择性地返回 `return()` 方法。
当迭代提前停止时，`return()` 方法会被自动调用。这是你可以设置应用程序来清理资源的地方。

以下示例在 Sequence 对象中使用了 `return()` 方法：

```

    constructor( start = 0, end = Infinity, interval = 1 ) {
        this.start = start;
        this.end = end;
        this.interval = interval;
    }

    [Symbol.iterator]() {
        let counter = 0;
        let nextIndex = this.start;
        return {
            next: () => {
                if ( nextIndex <= this.end ) {
                    let result = { value: nextIndex, done: false }
                    nextIndex += this.interval;
                    counter++;
                    return result;
                }
                return { value: counter, done: true };
            },
            return: () => {
                console.log('cleaning up...');
                return { value: undefined, done: true };
            }
        }
    }
}
```

## 模块

随着应用程序的增长，我们希望将其拆分为多个文件。

更大。针对特定用途，一个模块可能包含一个类或一个功能库。
长期以来，JavaScript没有语言级别的模块语法。这并非问题，因为脚本最初都很小且简单，所以没有必要。

然而，脚本变得越来越复杂，以至于开发者们发现了多种将代码组织成模块的方法，并从特殊库中按需加载模块。

### 什么是模块？

一个文件就是一个模块。一个单独的模块就是一个脚本。就这么简单。
模块可以相互加载，并通过特殊的指令导出和导入，从一个模块调用另一个模块的函数，以实现功能互换：

- 导出（Export）使用关键字标签导出变量和函数，使其可从当前模块外部访问。
- 导入（Import）则允许导入其他模块的功能。

让我们运行一个浏览器内的示例。

由于模块支持关键字和特殊功能，用户需要被告知，一个脚本需要通过 `<script type="module">` 属性被当作模块来处理。

#### 示例：匿名闭包

```javascript
(function () {
    // 我们将这些变量保持为闭包作用域内的私有变量

    var myGrades = [93, 95, 88, 0, 55, 91];

        var total = myGrades.reduce(function(accumulator, item) {
```

我们的匿名函数拥有一个自执行环境或“闭包”，具有这种结构，然后我们立即执行它。这允许我们隐藏父级（全局）命名空间变量。

这种方法的优点在于，你可以在不意外覆盖现有全局变量的情况下，仍然在此函数中访问全局变量：

```javascript

}());

// 'Hello, I am a global variable :)'
```

请注意，匿名函数需要括号，因为以关键字 `function` 开头的声明通常被称为函数语句（注意在JavaScript中不能有未命名的函数语句）。

#### 示例：对象接口

```javascript
var myGradesCalculate = (function () {

    var myGrades = [93, 95, 88, 0, 55, 91];

```

如你所见，这种方法允许我们决定哪些部分/方法我们希望保持私有（例如 `myGrades`），哪些通过将它们添加到 `return` 语句中来公开（例如 `average` / `failing`）。

### COMMONJS 和 AMD

一个特别重要的特点是，首要地，使用一个全局变量将代码打包到一个函数中，该函数通过闭包作用域为自己创建一个私有命名空间。

尽管每种解决方案在其自身方式上都很成功，但它们确实有其缺点。

首先，作为开发者，你必须知道如何以正确的依赖关系加载文件。例如，假设在你的项目中使用了Backbone，那么你在文件中包含了Backsource源代码的脚本标签。

然而，由于Backbone对Underscore.js有很强的依赖，Backbone的脚本标签不能设置在underscore.js之前。
作为开发者，管理依赖关系并修正这些事情有时会令人头疼。

另一个缺点是它们可能导致命名空间冲突。例如，如果你的两个模块同名怎么办？或者如果你有两个模块版本，而两者都需要呢？

所以你可能想知道：我们能否设计一种方法来请求模块的接口，而不跨越全局作用域？
幸运的是，答案是肯定的。CommonJS和AMD方法是两种突出且实现良好的方案。

#### COMMONJS

CommonJS是一个社区工作组，致力于开发和实现JavaScript的模块声明API。

CommonJS模块本质上是一个可重用的JavaScript元素，它导出特定对象并使其在程序中对其他模块可用。如果你在Node.js中编程，你会非常熟悉这种格式。

每个使用CommonJS的JavaScript文件在其唯一的模块上下文中存储模块（就像将它们闭包起来）。我们在这个领域使用 `exports` 对象模块来暴露和导入模块。

当你定义CommonJS模块时，它可能看起来像这样：

```javascript
function myModule() {
  this.hello = function() {
    return 'hello!';
  }

  this.goodbye = function() {
    return 'goodbye!';
  }
}

module.exports = myModule;
```

我们使用特殊的 `module` 对象，并将一个链接放在 `module.exports` 中以实现我们的目的。这允许CommonJS模块系统知道我们想要暴露给其他文件的内容。

然后，如果有人想使用它，你可以在你的文件中 `require` myModule：

```javascript
var myModule = require('myModule');

var myModuleInstance = new myModule();
myModuleInstance.hello(); // 'hello!'
myModuleInstance.goodbye(); // 'goodbye!'
```

这种方法相对于我们之前讨论的开发模块有两个显著优势：
1. 避免命名空间中的全局污染
2. 明确地声明我们的依赖关系

我个人非常喜欢的语法也非常紧凑。

另一个值得注意的是，CommonJS采用服务器优先的方法，并同步加载模块。这很重要，因为如果我们有三个其他模块，我们需要一个接一个地加载。
现在，它在服务器上运行得非常好，但不幸的是，这使得JavaScript在你的浏览器会变得更难使用。可以说，从互联网加载模块比从磁盘读取要复杂得多。只要模块加载屏幕在运行，浏览器就会被阻塞，直到加载完成。这相当于JavaScript线程在代码加载完成前停止运行。

#### AMD

CommonJS虽然很好，但如果我们想异步加载模块呢？答案就是异步模块定义，简称AMD。
使用AMD加载模块看起来像这样：

```
define(['myModule', 'myOtherModule'], function(myModule, myOtherModule) {
    console.log(myModule.hello());
});
```

这里发生的是，定义的函数将每个模块的依赖项作为其第一个参数。这些依赖项在后台加载（非阻塞），并在加载完成后指定提供的回调函数。

接下来，对于myModule和MyOtherModule，回调函数以参数形式接收已加载的依赖项，以便应用程序可以使用这些依赖项。依赖项也必须使用给定的关键字指定。

示例：MyModule可能看起来像这样

```
define([], function() {

    return {
        hello: function() {
            console.log('hello');
        },
        goodbye: function() {
            console.log('goodbye');
        }
    };
});
```

同样，与CommonJS不同，AMD使用第一种浏览器方法来完成任务，并具有异步行为。（请注意，在开始运行代码时动态加载文件并不是很有益，我们将在下一节开始创建模块时探讨这一点）。除了异步性，你的模块可以是对象、函数、构造函数、字符串、JSON等等，而CommonJS仅支持对象作为模块。

### 为什么使用模块？

在广泛、相互依赖的代码库中使用模块有几个优势。

- 1) 维护性：模块在定义上是自包含的。一个构建良好的模块旨在尽可能减少对代码库其他部分的依赖，以便它可以自主发展和演进。如果模块与其他代码部分分离，单个模块可以更容易地更新。
- 2) 命名空间：在顶级功能范围之外的变量在JavaScript中是全局的（这意味着任何人都可以访问它们）。这就是为什么“命名空间污染”很普遍，完全不相关的代码共享全局变量。

在不相关的代码之间分配全局变量是一个主要的开发禁忌。
正如我们稍后将看到的，模块通过为我们的变量提供私有空间来避免命名空间污染。

### 如何整合模块？- 模块模式

模块模式用于模拟类定义（因为JavaScript不原生支持类），以便能够在单个对象中存储公共和私有方法及变量——就像其他编程语言（如Java或Python）中的模块一样。它帮助我们创建一个公共API，同时维护一组私有的变量和方法。

## JavaScript Promises

JavaScript中的异步操作是通过Promise完成的。多个异步操作可以轻松处理，而调用可能产生难以管理的代码。回调地狱。

在Promise之前，使用事件和回调函数，但功能有限，代码创建也受限。
在处理异步操作时，事件效果不佳。

Promise是管理异步操作最简单的方式。你可以轻松处理多个异步活动，并比调用和事件更好地管理错误。

### Promise的好处

- 增强代码可读性
- 更好地管理异步操作
- 最佳的异步逻辑控制描述流
- 有效处理错误

Promise是一个承诺时未知值的符号。它使你能够将处理程序与异步操作的最终成功值或失败原因结合起来。这允许异步方法像同步方法一样返回值：异步方法返回一个承诺，承诺在未来提供值，而不是立即返回最终值。

### Promise有三种状态

**Fulfilled:** Promise操作成功
**Rejected:** Promise失败被拒绝
**Pending:** Promise仍在等待中，尚未被履行或拒绝。如果Promise不是pending状态（它已被接受或拒绝），则Promise已履行。
通常人们是果断和坚决的：他们不必犹豫。

一旦Promise被履行，就不能重新部署。同样，调用resolve()或reject()不会产生任何效果。一个重要特性是已履行Promise的不可变性。

原生JavaScript的Promise不显示Promise状态。你应该将承诺视为一个黑盒。只有创建Promise的任务才能理解承诺状态或有权克服或拒绝。

### 可以使用Promise构造函数创建Promise

- Promise构造函数只接受一个请求，一个函数回调。
- 两个点，解析和拒绝函数回调。
- 在回调函数中执行操作，如果一切顺利则调用resolve。
- 如果执行不顺利，则调用reject。

```
var promise = new Promise(function(resolve, reject) {
  const x = "geeksforgeeks";
  const y = "geeksforgeeks"
  if(x === y) {
    resolve();
  } else {
    reject();
  }
});

promise.
    then(function () {
        console.log('Success, You are a GEEK');
    }).
    catch(function () {
        console.log('Some error has occured');
    });
```

输出：Success you are a Geek

### 1. Then( )

如果Promise被接受或拒绝，则调用Then()。

#### 参数

- 如果Promise被履行并获得测试，则执行第一个任务。
- 如果Promise被忽略并发生错误，则执行第二个任务。它是可选的，最好使用.catch()方法来查找错误。

#### 示例：Promise已解决

```
var promise = new Promise(function(resolve, reject) {
    resolve('Geeks For Geeks');
})

promise
    .then(function(successMessage) {
        //成功处理函数被调用
        console.log(successMessage);
    }, function(errorMessage) {
        console.log(errorMessage);
    })
```

输出：Geeks for Geeks

#### 示例：Promise被拒绝

```
var promise = new Promise(function(resolve, reject) {
    reject('Promise Rejected')
})

promise
    .then(function(successMessage) {
        console.log(successMessage);
    }, function(errorMessage) {
        //错误处理函数被调用
        console.log(errorMessage);
    })
```

输出：Promise Rejected

### 2. CATCH()

当Promise被拒绝或执行过程中发生错误时，调用catch()。

#### 示例：Promise被拒绝

```
var promise = new Promise(function(resolve, reject) {
    reject('Promise Rejected')
})

promise
    .then(function(successMessage) {
        console.log(successMessage);
    })
    .catch(function(errorMessage) {
        //错误处理函数被调用
        console.log(errorMessage);
    });
```

输出：PROMISE REJECTED

#### 示例：Promise被拒绝

```
var promise = new Promise(function(resolve, reject) {
    throw new Error('Some error has occured')
})

promise
    .then(function(successMessage) {
        console.log(successMessage);
    })
    .catch(function(errorMessage) {
        //错误处理函数被调用

    });
```

输出：SOME ERROR HAS OCCURRED

### 3. FINALLY()

通常，无论Promise是履行还是拒绝，你都想执行相同的代码。
例如：

```
function createApp() {
    // ...
}

learnJS
    .then(
        (success) => {
            console.log(success);
            createApp();
        }
    ).catch(
        (reason) => {
            console.log(reason);
            createApp();
        }
    );
```

如你所见，对于then()和catch()方法，对createApp()的调用是重复的。
你使用finally()方法来删除这种重复，并在Promise被履行或拒绝时执行createApp()：

```
learnJS
    .then(success => console.log(success))
    .catch(reason => console.log(reason))
    .finally(() => createApp());
```

### 应用：

- 1. Promise用于异步处理错误
- 2. Promise用于处理异步HTTP请求。

### 总结

1.  一个在未来返回值的对象是一个 Promise。
2.  一个 Promise 开始于待定状态，最终会变为已兑现或已拒绝状态。
3.  使用 `then()` 方法为兑现安排回调，使用 `catch()` 方法为拒绝安排回调。
4.  在 `finally()` 过程中，放置无论 Promise 是兑现还是拒绝都希望执行的代码。

### 结论

Promise 已经成为许多 JavaScript 惯用模式不可或缺的组成部分，包括 WHATWG Fetch 标准（用于同步大多数现代 Ajax 请求）和 Async Functions 标准。在撰写本文时，Async functions 处于第 3 阶段，但我预测它们很快将成为异步 JavaScript 编程的一种可行方法，这意味着在未来几年，JavaScript 开发者将需要学会欣赏他们的 Promise。

## ASYNC-AWAIT

我们都认识到 Javascript 是同步的，这意味着它有一个事件循环来排队一个操作，该操作在代码结束该操作后一段时间才会完成。但在我们的软件中，有许多功能使我们的代码异步。其中之一就是 Async / Await 接口。

Async / Await 扩展了我们在语言中提供的保证作为支持。有关更多信息，请参阅 Javascript promises。

除了 JavaScript Promise，Async / await 语句是语法糖。它们允许我们编写基于 Promise 的代码，但无需主线程，就像它是同步的一样。

### ASYNC:

它只是帮助我们编写同步代码的 Promise，并确保我们不会中断运行的线程。它通过事件循环异步操作。Async 函数永远返回一个值。你做出一个承诺，Javascript 会立即将其打包成一个合约，如果它没有返回值，则用其值解决。

Async 函数允许我们不阻塞执行线程，而是像编写同步代码一样编写 Promise 代码。它通过事件循环异步操作。Async 函数将始终返回一个值。使用 Async 只是意味着将返回 Promise，如果 Promise 没有返回，JavaScript 会自动用其值包装 Promise。

```javascript
const getData = async() => {
    var data = "Hello World";
    return data;
}

getData().then(data => console.log(data));
```

输出：Hello World

### AWAIT:

Await 函数用于等待一个 Promise。它只能在 async 块中使用。它导致代码等待 Promise 的结果。它只是等待 async 块。

Await 运算符用于等待一个 Promise。它只能在 Async 块内使用。关键字 Await 导致 JavaScript 等待，直到 Promise 返回结果。需要注意的是，这只会导致异步函数块等待，而不是整个程序运行。

```javascript
const getData = async() => {
    var y = await "Hello World";
    console.log(y);
}

console.log(1);
getData();
console.log(2);
```

**输出：Hello World**

注意，控制台在 "Hello World" 之前打印了 2。这是由于使用了等待关键字。

在这里你可以——async / await 提供了一种良好、更易于阅读和维护的异步代码。即使在撰写本文时，浏览器支持比其他异步代码机制更有限，但它非常值得学习和考虑使用，无论是在现在还是未来几年。

-   `Send()` 请求（用于 GET）到服务器
-   `Send(string)` 将数据发送到服务器程序（用于 POST）

### GET 还是 POST？

在大多数情况下，GET 比 POST 更简单、更快。但是，在以下情况下使用 POST 请求：

-   打开没有缓存的文件（更新文件或服务器数据库）。
-   向服务器发送大量数据（POST 没有任何大小限制）。
-   当发送用户输入（可能包含未知字符）时，POST 比 GET 更健壮、更可靠。

## AJAX

AJAX 不是一种编程语言。

AJAX 是一种从网页访问 Web 服务器的技术。

AJAX 代表异步 JavaScript 和 XML。

### 同步请求

将 `open()` 方法的第三个参数改为 false 以执行同步请求：
xhttp.open("GET", "ajax_info.txt", false);

Async = false 通常用于快速检查。在较旧的 JavaScript 代码中，你也会发现同步请求。

由于代码需要完成应用程序，因此不需要 onreadystatechange 函数。

不建议使用 XMLHttpRequest (async = false) 同步方式，因为一旦服务器响应就绪，JavaScript 将停止运行。当服务器繁忙或响应较慢时，程序会挂起或停止。

同步 XMLHttpRequest 正在从 Web 标准中删除，但这可能需要很多年。
现代开发工具支持同步应用程序的使用，如果确实发生，将提供 InvalidAccessError 异常。
