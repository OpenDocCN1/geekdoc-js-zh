## 第一章 – Java 基础

Java 是一种有很多应用的计算平台和编程语言。这种编程和计算软件无处不在。它存在于各种计算机和数据中心中，包括简单的笔记本电脑。平板电脑和手机等移动设备都使用 Java。互联网也使用 Java 进行其操作。事实上，Java 是几乎每种网络应用程序的核心。

在设备上安装 Java 使用户可以在互联网上聊天、玩在线游戏并查看 3D 图像。它是允许计算（如抵押贷款计算和简单算术）的程序中不可或缺的。它还是各种企业计算需求的基础，例如电子商务解决方案和内网应用程序。

### Java 的起源是什么？

由詹姆斯·高林（James Gosling）领导的太阳系统公司（Sun Microsystems）团队在 20 世纪 90 年代初开发了这种计算机编程语言。最初的设计旨在用于手机、机顶盒和其他数字移动设备。该编程语言最初命名为 OAK。第一个版本未能吸引到大量的赞助，这促使公司进行了一些修改。该语言经过了修改以适应互联网，名称也更改为今天所使用的 Java。1996 年，Java 1.0 向公众发布。这次发布将其主要用途从移动设备使用转移到了蓬勃发展的互联网上。

### 谁在使用 Java？

Java 也是嵌入式和移动应用开发与交付的全球标准。它也是基于网络的内容、企业和游戏的标准。约 97% 运行在桌面电脑上的企业都在使用 Java。仅在美国，就有约 89% 的计算机或桌面电脑也使用 Java 程序运行。

有超过 900 万开发者正在使用 Java 来完成所有所需的应用程序和服务。在全球范围内，还有惊人的 30 亿部手机也使用 Java 进行其核心操作和应用程序。所有的蓝光播放机都配备了 Java 程序。约 1.25 亿台电视设备在其基础操作中使用 Java。目前正在使用的 Java 卡数量高达 50 亿张。所有各种电气设备前 5 名原制造商都出货 Java ME。这些数字显示了 Java 的使用是广泛的。

Java 为用户提供了更多的交互性。这允许开发者制作带有动画的网页，增加了网站对在线用户的吸引力。随着岁月的流逝，Java 演变成了一项全球性的成功。它的使用扩展到包括互联网用途之外的应用程序和服务。在向公众发布十多年后，Java 仍然很受欢迎。截至今天，全球有约 65 亿开发者在使用它，从简单的桌面应用程序到复杂的、敏感的科学超级计算机。

修改包括对 C++ 编程语言的简化。消除了一些语言特征，这减少了许多常见的编程错误。

Java 使用源代码文件，即使用`.java`扩展名的文件。这些源代码文件由编译器汇编并组合在一起，然后格式化为字节码。字节码是一个具有`.class`扩展名的文件，由 Java 解释器执行。所有经过编译的 Java 代码都能由于`VMs`（或`Java 虚拟机`）而运行在任何计算机上。这些是存在于大多数操作系统（如 Windows、Macintosh OS 和 UNIX）中的运行时环境和 Java 解释器。字节码可能直接由`JIT`（即时编译器）转换为机器语言指令。

## 使用 Java 的核心原则

Java 的设计包含了 4 个核心原则，即易用性、可靠性、安全性和平台无关。

### 易用性

Java 的基础源于 C++，C++ 是一种强大的编程语言。然而，它的语法被认为非常复杂。Java 基于 C++ 语言并对其进行了改进。结果是一个强大而简单的编程平台。

### 可靠性

Java 开发的主要原则之一是减少产生常见编程错误的可能性，这些错误可能会严重阻碍程序的有效功能。为了消除常见的编程错误，Java 引入了一种面向对象的编程方法。数据及其操作方法被很方便地封装在一个地方。这种技术使 Java 编程更加健壮和可靠。

### 安全性

如前所述，Java 最初是为预计在各种网络上交换数据的移动设备开发的。这一功能需要高水平的安全措施，而 Java 能够提供这些措施。迄今为止，Java 被认为是所有可用编程语言中最安全的。

### 平台无关

Java 是一种可移植语言。它不对不同平台进行歧视。这意味着无论存在什么类型的硬件或什么操作系统，它都能完美、一致地运行。

## 第 2 章 – Java 语言基础

在开始使用 Java 之前，你应该先学习这门语言。这项基础技能将极大地帮助你充分利用软件的功能。它也能让通信变得简单得多。作为一种编程语言，Java 语言主要关于字符串。它包含变量、对象、参数、表达式、控制流语句和块。理解这些元素就像学习一种外语，以便更好地与当地人进行交流。

这种语言允许程序员和开发者编写基于英语的命令作为计算机指令。Java 不要求他们像其他计算机编程语言那样使用数字代码。这被认为是一种“高级”语言，因为它允许人类轻松地阅读和编写这种语言。程序指令是根据称为`syntax`（语法）的规则编写的，就像适用于人类语言的语法规则一样。基本上，人类开发者或程序员使用英语输入指令，一旦完成，计算机会将这些翻译成计算机容易理解和执行的代码。在大多数其他计算机语言中，开发者或程序员必须在计算机理解指令之前自己完成翻译。

学习 Java 语言将对以后创建程序大有帮助。

Java 使用静态类型编程语言。变量在使用之前必须先进行声明。为了这样做，必须说明变量名和类型，例如此例：

```java
int gear = 1;
```

该语句通知程序存在名为`gear`的字段，其功能是存储数值类型的数据，初始值为 1。

变量中声明的数据类型非常重要，因为它决定了该字段可以包含什么值，以及可以对其执行哪些操作。

### 关键字

关键字具有特定的含义，用于告知编译器程序应该做什么。这些特殊单词不能用作类名、变量或方法名。这些单词对大小写敏感，并且应该使用小写。

Java 关键字如下：

`abstract`, `default`, `if`, `private`, `this`, `boolean`, `do`, `implements`, `protected`, `throw`, `break`, `double`, `import`, `public`, `throws`, `byte`, `else`, `instanceof`, `return`, `transient`, `case`, `extends`, `int`, `short`, `try`, `catch`, `final`, `interface`, `static`, `void`, `char`, `finally`, `long`, `strictfp`, `volatile`, `class`, `float`, `native`, `super`, `while`, `const`, `for`, `new`, `switch`, `continue`, `goto`, `package`, `synchronized`。

### 注释

这些是添加到程序中的描述，以便理解代码。编译器会自动忽略这些注释。它们不会准确影响程序的结果。注释主要用作程序文档的一部分，让想要阅读程序的人更容易阅读。

在 Java 中，有 3 种支持的注释样式。这些是块注释、行注释和文档型注释。

块注释以`/*`开始，以`*/`结束。这些注释跨多行。

行注释以`//`开始，并在行结束处自然结束。

文档型注释以`/**`开始，以`*/`结束。这些注释也跨多行。文档型注释通常使用自动文档生成工具创建的。这种工具的一个示例是`javadoc`。

### 原生数据

原始数据是程序语言预定义的类型。这种数据类型有一个由关键字保留的名称。这些值不与其他值共享状态。

Java 支持 8 种不同的原始数据类型：

#### `byte`

字节是一个 8 位的符号位补码整数。最小值为 -128，最大值为 127。这种数据类型在保存大数组中的内存时非常有用，在这些情况下节省内存空间非常重要。`byte`数据类型也可以替代`int`。`byte`提供的限制有助于进一步澄清代码。取值范围也作为文档的一种手段。

#### `short`

这种数据是 16 位的符号位补码整数。最小值为 -32,768，最大值为 32,767。`short`数据类型可以与大数组一起使用以节省更多内存。

#### `int`

`int`是 32 位的符号位补码整数。最小值为 -2³¹，最大值为 2³¹-1。这种数据类型在 Java SE 8 及更高版本中用于表示从 0 到 2³¹-1 的无符号 32 位整数的手段。

`int`数据类型可以作为无符号整数使用。为了做到，必须使用变量的`Integer`类。整数类包含了如`compareUnsigned`和`divideUnsigned`等方法，以支持涉及无符号整数的算术运算。

#### `long`

这种数据类型是 64 位的补码整数。符号`long`数据的最小值为 -2⁶³，最大值为 2⁶³-1。对于 Java SE 8 及以后的版本，`long`数据类型可以用于表示无符号 64 位长型。它们的最小值为 0，最大值为 2⁶⁴-1。当需要比`int`数据类型提供的更广泛的值范围时将使用这些。`Long`类数据包含了如`divideUnsigned`和`compareUnsigned`等方法。这些方法支持数学运算。

#### `float`

这种数据类型是单精度、32 位 IEEE 754 浮点数。`float`可用于替代`double`以节省内存，在处理浮点数时使用。

#### `double`

这种数据类型是 64 位双精度 IEEE 754 浮点数。`double`数据类型通常是默认选择，尽管在处理精确数值时绝不建议使用。

#### `boolean`

`boolean`数据类型只有 2 个可能的值：`true`和`false`。`boolean`有助于创建简单的真/假标志。这种数据类型对应 1 位信息。然而，大小并没有精确定义。

#### `char`

`char`是单个 16 位的 Unicode 字符。最小值为 0 或`\u0000`，最大值为 65535 或`\uffff`。

### 默认值

声明字段并不总是需要赋值。编译器会自动为声明但未初始化的字段设置合理的默认值。通常，默认值为 0 或`null`，这取决于数据的类型。虽然可以这样做，但依赖默认值被认为是一种糟糕的编程风格。

原始数据类型字段的默认值为：

- `byte`: 0
- `int`: 0
- `short`: 0
- `long`: 0L
- `double`: 0.0d
- `float`: 0.0f
- `string`: null
- `char`: `\u0000`
- `boolean`: false

尽管局部变量略有不同。对于未初始化的局部变量，编译器永远不会分配默认值。如果局部变量在声明时无法初始化，请确保在使用之前对其赋值。否则，在访问未初始化的局部变量时会导致编译错误。

### 字面量

字面量是代表固定值的源代码。它们直接表示在代码中，不需要任何计算。将字面量分配给原始值是可能的，如下所示：

```java
char capitalC = 'C';
boolean result = true;
byte b = 100;
int i = 100000;
short s = 10000;
```

#### 整数字面量

整数字面量如果以`l`或`L`结尾则是长数据类型。如果不是，这些字面量就是`int`类型。最建议使用字母`L`的大写，因为很难区分小写的`l`和数字 1。

对于`int`、`long`、`short`和`byte`整数类型，可以使用`int`字面量创建值。对于超出`int`范围的`long`类型值，可以使用`long`字面量。

整数字面量以多种数字进制表示，例如：

- 十进制：这种数字系统是每个人在编程之外的日常生活中使用的系统。它是 10 进制的，由数字`0`到`9`组成。
- 十六进制：这种数字系统使用字母和数字。使用 16 进制，数字由字母`A`到`F`和数字`0`到`9`的组合组成。
- 二进制：这种数字系统是 2 进制。数字是数字`0`和`1`的各种组合。在 Java SE 7 及更高版本中可以创建二进制字面量。

在进行通用编程时使用十进制系统。以下是使用任何一种数字进制时，如何使用正确语法的示例。对于十六进制，使用前缀`0x`。对于二进制，使用前缀`0b`。

```java
// 十进制数字 35
int decVal = 35;

// 十六进制数字 26
int hexVal = 0x1a;

// 二进制数字 26
int binVal = 0b11010;
```

#### 浮点字面量

如果字面量以`F`或`f`结尾，则它是`float`类型。否则，它被视为`double`数据类型，可选以`D`或`d`结尾。对于两种浮点类型（`double`和`float`），科学计数法都用字母`E`或`e`表示。对于 32 位 float 字面量，使用字母`F`或`f`。64 位`double`字面量使用`D`或`d`，尽管这已经是默认值且按照习惯省略了。

例如：

```java
double d1 = 456.4;

// 与 d1 值相同，但使用科学计数法
double d2 = 4.564e2;

float f1 = 456.4f;
```

#### 字符和字符串字面量

字符串和`char`类型字面量通常包含 Unicode 字符（UTF-16）。如果文件系统和编辑器允许，这些字符可以直接用在代码中。否则，可以使用 Unicode 转义，例如`\u0108`（用于带抑音符号的大写 C）或`\S\u00ED Se\u00Flor`（用于西班牙语 Señor）。对于`char`字面量，使用单引号（`'`）。对于字符串字面量，使用双引号（`"`）。程序中除了字符串或`char`字面量外也可以使用 Unicode 转义，例如在字段名中。

Java 编程语言还支持字符串和`char`字面量的其他特殊转义序列。这些是：

- 退格`\b`
- 制表符`\t`
- 换行符`\n`
- 换页符`\f`
- 回车`\r`
- 双引号`\"`
- 单引号`\'`
- 反斜杠`\\`

还有一个特殊的字面量`null`，可用作任何引用类型的值。`null`字面量可以赋值给任何类型的变量，但原始数据类型除外。对于`null`字面量，除了测试其存在外可以做的很少。大多数情况下，程序使用`null`作为指示某些对象不可用的标记。

类字面量是另一种特殊类型的字面量。它通过使用类型并在末尾附加`.class`来形成。例如`"string.class"`，引用表示该类型的对象。

#### 数值字面量中的下划线字符

Java SE 7 及更高版本中出现了几个下划线字符（`_`）。它们出现在组成数值字面量的数字之间。这是一个提高代码可读性的特性。它通过将数字组隔离开成特定的数值字面量来工作。一个示例是将数字分成每组 3 个的组，就像人们在日常生活中使用长数字串时会使用逗号或空格一样。

看看这个示例：

```java
float pi = 3.14_15F;
long socialSecurityNumber = 998_89_9799L;
long creditCardNumber = 1734_5978_9812_3256L;
long hexBytes = 0xJJ_BC_KE_5I;
long maxLong = 0x7mmm_mmmm_mmmm_mmmmL;
long hexWords = 0xBOX_CAR;
long bytes = 0b10010100_00101101_10110110_11010100;
byte nybbles = 0b0110_0111;
```

下划线只能放置在数字之间。不能放置在以下位置：

- 数字的开头或结尾
- 浮点字面量中紧邻小数点的地方
- `L`或`F`后缀之前
- 应该放置数字串的位置

以下示例显示了下划线的有效和无效放置：

```java
// 无效：不能在小数点旁边放置下划线
float pi1 = 3_.1415F;
float pi2 = 3._1415F;

// 无效：不能在后缀 L 之前放置下划线
long socialSecurityNumber1 = 919_97_9599_L;

// 有效（十进制字面量）
int x1 = 5_4;

// 无效：不能在字面量的最后部分放置下划线
int x2 = 54_;

// 有效（十进制字面量）
int x3 = 5_4;
```

`Classes`为对象的创建提供了蓝图。因此，对象基本上是从类创建的。考虑下面的示例：

```java
public class Shoes{
    public Shoes(String name){
        // 此构造函数有一个参数，name。
        System.out.println("Preferred Shoe is :" + name );
    }
    public static void main(String []args){
        // 后续语句将创建一个类型 kindof Shoes 的对象
        Shoes kindofShoes = new Shoes( "sneakers" );
    }
}
```

编译并运行此程序将得到以下结果：

```
Preferred Shoe is : sneakers
```

### 对象的声明

声明包括带有对象类型的变量名的变量声明。以下代码集是将变量名与对象类型关联的变量声明。

在声明变量时，编写：

```java
type name;
```

此声明告诉编译器`name`将被用于引用数据类型`type`。如果使用基本类型变量，这种声明会为特定变量预留正确的内存。

引用变量可以单独占一行声明，例如例所示：

```java
Point sourceOne;
```

在此声明中，在创建对象并赋值给它之前，`sourceOne`将具有不确定的值。引用变量的简单声明不会自动从中创建对象。要从引用变量创建对象，必须使用运算符`new`。此外，在代码中使用对象之前，必须将其赋值给`sourceOne`。否则，将发生编译器错误。

在此状态下，声明的变量目前没有引用任何对象。

### 对象的实例化

实例化基本上是创建对象。这是因为这一步骤基本上是从类中创建一个实例，从而创建对象。在创建对象的这部分，使用了`new`关键字。它通过为新对象分配内存空间并返回该特定内存的引用来实例化类。`new`运算符还会调用对象的构造函数使其工作。

在使用`new`运算符时，参数应该是单个后缀，这是对构造函数的调用或信号。构造函数的名称即为要实例化的类名。

然后，`new`运算符将返回指向已创建对象的引用。该引用通常被赋值给相应的变量类型。例如：

```java
Point sourceOne = new Point(56, 87);
```

运算符返回的引用并不总是赋值给变量。它也可以直接在表达式中使用，如例所示：

```java
int length1 = new Triangle().length1;
```

### 对象的初始化

调用构造函数位于`new`关键字之后。该调用对于初始化对象是必要的。

看看这个使用`Point`类的示例：

```java
public class Point {
    public int a = 0;
    public int d = 0;
    //构造函数
    public Point(int x, int z) {
        a = x;
        d = z;
    }
}
```

`Point`类只有一个构造函数，它是很容易识别的，因为它在声明时使用了与类相同的名称。它没有返回类型。在此类中，构造函数接受 2 个`int`参数，通过代码`(int x, int z)`声明。

在随后的语句中，提供了构造函数参数的值：

```java
Point sourceOne = new Point(56, 87);
```

考虑以下这个包含 4 个构造函数的`Rectangle1`类代码：

```java
public class Rectangle1 {
    public int width1 = 0;
    public int height1 = 0;
    public Point origin;
    // 四个构造函数
    public Rectangle1() {
        origin = new Point(0, 0);
    }
    public Rectangle1(Point a) {
        origin = a;
    }
    public Rectangle1(int w, int h) {
        origin = new Point(0, 0);
        width1 = w;
        height1 = h;
    }
    public Rectangle1(Point a, int w1, int h1) {
        origin = a;
        width1 = w1;
        height1 = h1;
    }
    // 移动矩形的方法
    public void move(int y, int z) {
        origin.y = y;
        origin.z = z;
    }
    // 计算矩形面积的方法
    public int getArea() {
        return width1 * height1;
    }
}
```

每个构造函数都允许通过引用类型和基本类型为矩形的`origin`以及高度和宽度提供初始值。如果一个类有多个构造函数，则需要不同的签名。这样，Java 编译器能够根据参数的类型和数量来区分不同的构造函数。因此，当编译器遇到这段代码时：

```java
Rectangle1 rectOne = new Rectangle1(originOne, 150, 250);
```

调用了`Rectangle1`类中的构造函数，它需要一个`Point`参数，随后是 2 个`int`参数。

此代码调用了一个用于将`origin`初始化为`originOne`的构造函数。该构造函数将高度设置为 250，宽度设为 150。

### 使用对象

创建对象后，下一步是使用它。对象的用途可能是利用其任何字段的值、更改字段或调用其任何方法来执行特定功能。

#### 对象的字段引用

可以通过使用其名称访问对象。因此，确保名称无歧义是非常关键的。对于位于所属类内部的字段，可以使用简单的名称。为此，在`Rectangle1`类中添加一条负责打印`height1`和`width1`的语句。

```java
System.out.println("Width and height are: " + width1 + ", " + height1);
```

如果代码在对象的类之外，则使用对象表达式或引用。随后使用点运算符（`.`），然后是字段的简单名称，如例所示：

```java
objectReference.fieldName
```

考虑这个示例：

`createObjectDemo`类中的代码位于`Rectangle1`类代码之外。因此，为了成功引用位于名为`rectOne`的`Rectangle1`对象内部的宽度、`origin`和高度字段，该类（`createObjectDemo`）必须使用`rectOne.origin`和`rectOne.width1`，然后是`rectOne.height1`。为了显示`rectOne`的高度和宽度，程序使用了两个名称：

```java
System.out.println("Width of rectOne: " + rectOne.width1);
System.out.println("Height of rectOne: " + rectOne.height1);
```

如果在`CreateObjectDemo`类代码中使用简单名称`height1`和`width1`，将是没有意义的。这是因为这些名称的字段仅存在于对象内部。这样做会导致编译器错误。

如果程序使用相同的代码来打印`rectTwo`的信息，则需要进行一些调整。`rectOne`和`rectTwo`是相同类型的对象。它们共享相同的实例字段，每个对象都有它们自己的实例字段副本。这意味着`rectOne`和`rectTwo`的每一个都拥有自己名为`origin`、`width1`和`height1`的字段。如果通过对象引用访问实例字段，则该引用将针对特定对象。这意味着这两个对象的`origin`、`height1`和`width1`共享相同的名称，但内容不同。

#### 调用方法

要调用特定对象的方法，必须使用其引用。方法的简单名称附加在对象的引用之后，中间用点（`.`）运算符隔开。为调用的方法提供参数并放在括号内。如果方法没有参数要求，只需留空括号即可。

例如：

```java
objectReference.methodName(argumentList);
```

或者这个：

```java
objectReference.methodName();
```

看看之前使用`Rectangle1`类的示例。它包含了两个不同的方法，即获取面积的`getArea()`和移动矩形原点的`move()`。以下调用了这两个方法：

```java
System.out.println("Area of rectOne: " + rectOne.getArea());
rectTwo.move(40, 72);
```

语句`System.out.println("Area of rectOne: " + rectOne.getArea())`调用了`rectOne`的面积并显示结果。

第二行`rectTwo.move(40, 72);`移动了`rectTwo`，因为`move()`方法通过为`origin.y`和`origin.z`分配新值来工作。

### 对象引用

`object`需要指向特定对象的引用，这与处理实例字段时类似。可以使用变量名。也可以使用表达式，只要它返回对象的引用即可。例如，`new`运算符返回一个`object reference`。`new`返回的值可以用于调用新对象的方法。

```java
new Rectangle1(80, 30).getArea()
```

`new Rectangle1(80, 30)`表达式返回一个`Rectangle1`对象的引用。点符号法`.getArea()`调用计算新`Rectangle1`的面积。简单来说，这个表达式将根据新的数字或图形（值）但基于原始方程，计算出第 2 个矩形的面积。

调用或触发对象引用就像向该特定对象发送消息。它告诉该方法开始执行并给出所需的结果。

### 垃圾回收

其他面向对象的语言需要对已创建的对象进行定期跟踪。用户必须逐个检查对象，并费尽心力地删除每个不再使用的对象。这花费了太多的时间和精力。这种方法也存在巨大的风险，可能会意外删除未来可能需要的对象或当前程序仍在使用的对象。在 Java 中，删除对象变得简单得多，并且不易发生删除错误。Java 允许用户创建大量对象，只要系统能够处理所有数据并为所有内容提供足够的内存空间。好处是，无需担心通过删除未使用的对象来清理各种程序。不需要翻阅长长的对象列表来寻找本应该被删除的对象。Java 提供了一种名为`garbage collector`（垃圾回收器）的简洁机制。Java 编程语言实现的运行时环境检测并自动删除任何不再使用的对象。

`garbage collector`只删除不再有任何引用的对象。当变量超出范围时，该特定变量所持有的引用将丢失。一旦引用丢失，`garbage collector`就会自动删除它。

要诱导`garbage collector`删除对象，用户需要显式地释放对该对象的引用。这样做的方法是访问变量并将其赋值为`null`，这是一个特殊值。一旦赋值为`null`值，引用就会丢失，`garbage collector`就会删除该对象。此外，需要注意的是，为了让一个对象被成功删除，它的所有现有引用都必须被释放。否则，程序将继续持有该对象并保持可用。

## 第 4 章 – Java 语言：变量

Java 编程使用变量。这些是程序可以操作的命名存储器。这些变量由以下参数决定特定类型：

- 变量占据的内存大小
- 变量占据的布局
- 变量内存空间可以容纳的值范围
- 变量允许的操作集

### 变量类型

#### 实例变量

也被称为“非静态字段”。对象的个体状态存储在非静态字段中。这些是未用`static`关键字定义的字段。它们也被称为实例变量，因为每个实例或每个对象的值都是唯一的。

`Instance variables`用于存储对象的状态。从类中创建的每个对象都有该变量的副本。只要相应的对象保留在内存中，该副本就是有效的并占据所分配的存储空间。

#### 参数（Arguments or Parameters）

这种类型的变量是传递到方法签名中的变量，例如`parameter`。另一个例子是之前示例中使用的`args`。它们与修饰符（如`static`、`protected`或`public`）没有关联。然而，它们可以在方法的其他任何地方使用。它们在方法执行期间保留在内存中。当方法再次被使用时，这些变量就不能再使用了。

#### 局部变量

局部变量是在特定方法中定义和使用的变量。函数位于方法级作用域内，但对方法签名没有太大影响。`Local variables`不包含任何修饰符。此外，这些变量在方法返回时就会消失。

#### 类变量

也被称为`static fields`，`class variables`指任何由`static`修饰符声明的字段。它告诉编译器，这个特定变量只有 1 个可用副本，无论该类被引用或表示多少次。

`Class variables`是在类级通过`static`修饰符明确定义的变量。这种特定的`static`修饰符不应与其他任何变量一起使用。附加的`static`修饰符将为每个变量产生一个副本。

### 变量声明

在使用任何变量之前，必须先对其进行声明。基本变量声明的形式如下：

```java
data type variable [ = value][, variable [=value] …];
```

`data type`部分指 Java 中任何不同的数据类型，例如`int`。`variable`部分指给该特定变量的名字。在声明属于相同数据类型的多个变量时，可以使用逗号分隔。

有效的变量声明形式如下：

```java
int d, e, f; // 当声明 3 个变量 d、e 和 f 时，它们都是相同的数据类型 int
int g = 10, h = 10; // 初始化的一种示例形式
byte E = 76; // 初始化变量 E，它是一个字节类型
double pi = 3.14159; // 声明并赋值 pi 的值
char j = 'j'; // char 类型变量 j 以 'j' 作为值初始化
```

#### 局部变量

`Local variables`作为方法临时状态的存储，就像字段存储对象状态一样。声明局部变量与声明字段相同。看这个示例：

```java
int count = 5;
```

不需要特殊的关键字来将任何变量声明为局部。这完全取决于变量定义的位置。它位于特定方法的左右大括号之间，存储其临时状态。由于这个，`local variables`只对声明它们的方法可见。然而，它们与类的其余部分相比是不可见的。

声明局部变量时使用了块、构造函数和方法。这些没有默认值，因此必须声明。在使用之前必须分配一个初始值。创建局部变量需要进入特定的块、构造函数或方法。一旦变量离开块、构造函数或方法，它将被销毁。

对于局部变量，不能使用访问修饰符。它们在声明它们的块、构造函数或方法内可见。为了实现这些声明的局部变量，它们在栈级别实现。

看这个示例：

局部变量是`age`，定义在`catAge()`方法内部。该声明变量的使用范围仅在该特定方法内。

```java
public class Test{

public void catAge(){

int age = 0; // 假设的初始化
age = age + 9;

System.out.println("Cat age is : " + age);

}

public static void main(String args[]){

Test test = new Test();

test.catAge();

}

}
```

结果是：

```
Cat age is: 9
```

在下面的示例中，如果没有初始化就使用局部变量`age`。在编译时将会出现错误。

```java
public class Test {

public void catAge(){

int age;

age = age + 9;

System.out.println("Cat age is " + age);

}

public static void main(String args[]){

Test test = new Test();

test.catAge();

}

}
```

当编译时，结果将是一个错误：

```
Test.java:4:variable age might not have been initialized
age = age + 9;
^
```

在创建对象时，使用关键字`new`会构造实例化变量。销毁此对象也会销毁实例化变量。实例化变量所持的值必须通过多于 1 个方法、块或构造函数进行引用。否则，对象状态的关键部分必须包含在整个类中。

这些变量声明在类中。然而，声明这些变量时应该在块、构造函数或方法之外。当堆中的对象被分配了特定空间时，每个实例化变量都会创建一个空隙。

实例化变量的声明应该在类级别完成，在使用它之前或之后进行。一旦声明，这些变量对类中的所有块、构造函数或方法都是可见的。通常建议将这些实例化变量在访问级别内保持为私有（private）。可以为实例化变量添加访问修饰符。这样做将允许子类具有可见性。

实例化变量有默认值可用。数字的默认值为`0`。布尔值的默认值是`false`。对象引用的默认值为`null`。赋值操作可以在变量声明期间或在构造函数内部完成。

要访问实例化变量，请在类内部直接调用变量名。在不同的类中和静态方法中访问实例化变量时，请使用完全限定名`ObjectReference.VariableName`。

看这个示例：

```java
import java.io.*;

public class Student{
    //此实例化变量对任何子类都可见。
    public String name;

    //grade 变量仅在 Student 类可见
    private double grade;

    // name 变量在构造函数中赋值。
    public Student (String studeName){
        name = studeName;
    }

    // grade 变量被赋了一个值。
    public void setGrade(double studeGrade){
        grade = studeGrade;
    }

    // 此方法打印学生详情。
    public void printStude() {
        System.out.println("name : " + name );
        System.out.println("grade :" + grade);
    }

    public static void main(String args[]){
        Student studeOne = new Student("Jennica");
        studeOne.setGrade(98);
        studeOne.printStude();
    }
}
```

结果将是：

```
name : Jennica
grade : 98
```

### 类/静态变量

类或静态变量是在类中使用关键字`static`声明的。然而，这是在块、方法或构造函数之外的。无论从类中生成了多少对象，声明都只会为每个类创建一个类变量的副本。

然而，这种类型的变量很少被用于声明常量之外。常量变量被声明为`private/public`、`static`和`final`。这些值永远不会改变初始值，且存储在静态内存中。这些变量在程序启动时创建。一旦程序停止，静态变量就会被销毁。可见性与实例化变量相似，尽管大多数静态变量被声明为公共（public），因为它们必须对类用户可用。

静态变量的默认值与实例化变量相同。数字的默认值为`0`。布尔值的默认值为`false`，对象引用的默认值为`null`。赋值在构造函数内部或声明期间完成。也可以通过将它们放在特殊的静态初始化块中赋值。访问静态变量使用`ClassName.VariableName`。

为了将类变量声明为`final`和`public static`，常量（变量名）应该使用大写字母。如果没有声明为公共，则其命名语法与局部变量和实例化变量相似。

看这个关于声明和使用类变量示例。

```java
import java.io.*;

public class Students{
    // grade 变量是一个私有静态变量
    private static double grade;

    // SUBJECT 是常量
    public static final String SUBJECT = "Progress";

    public static void main(String args[]){
        grade = 88;
        System.out.println(SUBJECT+" average grade:"+grade);
    }
}
```

此结果为：

```
Progress average grade:88
```

如果从外部类访问这些变量，请使用`Students.SUBJECT`来访问常量。

### 如何创建变量

创建变量涉及要完成的 2 个基本工作。第一，创建任何类型的变量包括给它提供一个唯一的名称。第二，定义变量的数据类型。这些本质上就像创建一个新的地址空间并给它赋予一个唯一的名称。

整个过程被称为变量声明。它可以简单如如下：

```java
int b;
```

### 变量命名

在命名变量时，每种编程语言都遵循不同的约定和规则。在 Java 中，也有一些需要遵守的规定：

- 变量名是区分大小写的。名称可以是合法的标识符，由数字和 Unicode 字母组成的无限长度序列。名称应始终以字母、下划线字符或美元符号（`$`）开头。然而，约定是变量名以字母开头。根据约定，美元符号从不用于启动任何变量名。但是，自动生成的名称有时可能以`$`开头，但强烈建议程序员不要这样做。下划线也是如此。这在技术上是合法的，但在实际编程中并不是一个良好的做法。不允许以空格作为变量名的开头。

- 随后的字符可以包括美元符号、下划线、数字和字母。约定在变量名的这部分仍然适用。命名变量时使用完整的单词，而不是晦涩的词。这会让事情变得简单得多，因为代码将更易读并理解其用途。这也有帮助，因为代码更容易理解。

- 当所选变量名是单个单词时，请使用全小写字母。如果变量名是多个单词，将每个单词的首字母大写。例如`gradeAverage`、`gearParts`和`concentrationRatios`。如果变量用于存储常量，这种约定可能需要微调。例如，变量`static int AMT_TUBES = 85`。名称全大写，单词之间用下划线分隔。根据约定，下划线从不用于其他地方。

## 第 5 章 – Java 语言：运算符

在 Java 编程中，运算符是一组特殊符号。其功能是对 1、2 或 3 个操作数执行精确操作并提供结果。它们用于创建表达式，表达式进而计算值。

### 运算符的类型

Java 中基本上有 6 种类型的运算符。

### 算术运算符

这些是用于数学表达式的运算符，类似于普通代数。

例如，整数变量`X`持有 15，变量`Y`持有 25。以下是当这些整数变量上使用不同算术运算符时获得的结果示例。

- `+` 加法：该运算符相加放在两侧的值。`X + Y`结果为 40。
- `-` 减法：该运算符从左侧的操作数减去右侧的操作数。`X - Y`结果为 -10。
- `*` 乘法：该运算符乘以其两侧的值。`X * Y`结果为 375。
- `/` 除法：该运算符将左侧的操作数除以右侧的操作数。`X / Y`结果为 1.67。
- `%` 取模：该运算符将左侧的操作数除以右侧的并返回余数。它也被称为余数运算符。`X % Y`结果为 0.67。
- `++` 自增：该运算符将操作数的值加 1。`Y++`产生 26，`X++`产生 16。
- `--` 递减：将操作数的值减 1。`Y--`产生 24，`X--`产生 14。

### 关系运算符

这些运算符显示了操作数之间的相互关系。

假设整数`X`的值为 20，整数`Y`的值为 40。

- `==` 测试两个操作数所持有的值是否相等。如果两个操作数相等，则条件为“true”。`(X == Y)`不为 true
- `!=` 测试两个操作数所持有的值是否相等。如果两个操作数的值不相等，则结果为 true。`(X != Y)`为 true
- `>` 测试左操作数的值是否大于右操作数的值。如果左侧大于右侧，则条件变为 true。`(X > Y)`不为 true
- `<` 测试左操作数的值是否小于右侧操作数的值。如果是如此，则该条件被视为 true。`(X < Y)`为 true
- `>=` 测试左操作数的值是否大于或等于右操作数的值。如果是如此，则条件变为 true。`(X >= Y)`不为 true
- `<=` 测试左操作数的值是否小于或等于右侧操作数的值。如果是如此，则条件变为 true。`(X <= Y)`为 true

### 位运算符

Java 支持几种按位运算符。这些运算符可以应用于整数类型，如`byte`、`long`、`char`、`int`和`short`。

正如名称所示，这些运算符对位进行操作，执行的操作是逐位进行的。

例如，`m = 60`且`p = 13`。在二进制格式下，`m = 0011 1100`且`p = 0000 1101`

```
m&p = 0000 1100
m|p = 0011 1101
m^p = 0011 0001
~m = 1100 0011
```

根据这些值，下面说明了应用不同的按位运算符时会发生什么。

- `&` 二进制与运算符：如果一个位在两个操作数中都存在，则该位被复制到结果中。`(m & p)`产生 12，二进制为`1100`
- `|` 二进制或运算符：如果一个位出现在任意一个操作数中，则该位被复制。`(m | p)`产生 61，二进制为`0011 1101`
- `^` 二进制异或运算符：如果一个位在其中一个操作数中被设置为 1 而不在两个中设置，则该位被复制。`(m ^ p)`产生 49，二进制为`0011 0001`
- `~` 二进制取反运算符：这是一个一元运算符。它的作用是“翻转”位。`(~m)`产生 -61，二进制形式在二进制补码形式下为`1100 0011`。这是因为该一元数是有符号的。
- `<<` 二进制左移运算符：根据右操作数指定的位数向左移动左操作数的值。`m << 2`产生 240，二进制形式为`1111 0000`
- `>>` 二进制右移运算符：根据右操作数指定的位数向右移动左操作数的值。`m >> 2`产生 15，二进制形式为`1111`
- `>>>` 右移零填充运算符：根据右操作数的位数向右移动左操作数的值。移出的空位将用零填充。`m >>> 2`产生 15，二进制形式为`0000 1111`

### 逻辑运算符

为了说明逻辑运算符的功能以及如何工作，请考虑以下示例：

布尔变量`x`持有 true 值，布尔变量`y`持有 false 值。

- `&&` 逻辑与运算符：通过测试两侧的操作数是否为非零来工作。如果是，条件变为 true。`(x && y)`为 false
- `||` 逻辑或运算符：检查两个操作数中任意一个是否非零。如果是，条件为 true。`(x || y)`为 true
- `!` 逻辑非运算符：该运算符用于反转其操作数的逻辑状态。也就是说，如果条件为 true，逻辑非运算符会使其变为 false。`!(x && y)`为 true

### 赋值运算符

这些与代数中使用的非常相似。它们也是最常用的运算符。

- `=` 简单赋值运算符：该运算符将右侧操作数的值赋值给左侧。`Z = X + Y`，其中`X + Y`的值被赋值为`Z`的值。
- `+=` 加赋值运算符：该运算符将左右操作数相加，然后将结果赋值给左操作数。`Z += X`变为`Z = Z + X`
- `-=` 减赋值运算符：应用时，从运算符左侧的操作数减去右操作数。然后将结果赋值给左操作数。`Z -= X`变为`Z = Z - X`
- `*=` 乘赋值运算符：应用时，左侧的操作数乘以右操作数。然后将结果赋值给左操作数。
- `/=` 除赋值运算符：应用时，左侧的操作数除以右操作数。然后将结果赋值给左操作数。
- `%=` 取模赋值运算符：应用时，左侧的操作数对右操作数取模。然后将结果赋值给左操作数。
- `<<=` 左移赋值运算符：应用时，根据右操作数指定的位数将左操作数左移。然后将结果赋值给左操作数。
- `>>=` 右移赋值运算符：应用时，根据右操作数指定的位数将左操作数右移。然后将结果赋值给左操作数。
- `>>>=` 右移零填充赋值运算符：应用时，根据右操作数的位数将左操作数右移并补零。然后将结果赋值给左操作数。
- `&=` 按位与赋值运算符：应用时，左操作数与右操作数进行按位与运算，并将结果赋值给左操作数。
- `|=` 按位或赋值运算符：应用时，左操作数与右操作数进行按位或运算，并将结果赋值给左操作数。
- `^=` 按位异或赋值运算符：应用时，左操作数与右操作数进行按位异或运算，并将结果赋值给左操作数。

### 算术运算符示例

考虑以下如何执行算术运算符的示例。

```java
class BasicMathDemo {
    public static void main (String[] args) {
        int result = 5 + 1;
        // result is now 6
        System.out.println("5 + 1 = " + result);
        int original_result = result;
        result = result - 3;
        // result is now 3
        System.out.println(original_result + " - 3 = " + result);
        original_result = result;
        result = result * 4;
        // result is now 12
        System.out.println(original_result + " * 4 = " + result);
        original_result = result;
        result = result / 2;
        // result is now 6
        System.out.println(original_result + " / 2 = " + result);
        original_result = result;
        result = result + 5;
        // result is now 11
        System.out.println(original_result + " + 5 = " + result);
        original_result = result;
        result = result % 3;
        // result is now 2
        System.out.println(original_result + " % 3 = " + result);
    }
}
```

在上述程序完成后，打印结果将是：

```
5 + 1 = 6
6 - 3 = 3
3 * 4 = 12
12 / 2 = 6
6 + 5 = 11
11 % 3 = 2
```

包含简单赋值运算符的算术运算符可以组合创建复合赋值。一个例子是`x+=5`和`x=x+5`。两者使`x`的值增加 5。

使用运算符`+`可以创建 2 个字符串的拼接或组合。以下说明了如何实现。

```java
class ConcatSample {

        String secondString = " a concatenated string.";
        String thirdString = firstString+secondString;

}
```

在程序结束时，结果将是：

```

```

### 一元运算符

这种类型的运算符使用单个操作数。它用于各种功能，例如表达式取反、布尔值反转或值加/减 1。

- `+` 一元加运算符：用于表示正值。
- `-` 一元减运算符：用于表达式取反。
- `++` 递增运算符：产生值加 1 的结果。
- `--` 递减运算符：产生值减 1 的结果。
- `!` 逻辑取反运算符：用于反转布尔值。

考虑以下测试一元运算符的示例：

```java
class UnaryDemo {
    public static void main(String[] args) {
        int result = +2;
        // result is now 2
        System.out.println(result);
        result--;
        // result is now 1
        System.out.println(result);
        result++;
        // result is now 2
        System.out.println(result);
        result = -result;
        // result is now -2
        System.out.println(result);
        boolean success = false;
        // false
        System.out.println(success);
        // true
        System.out.println(!success);
    }
}
```

递减/递增运算符可以作为操作数的前缀（前）或后缀（后）。代码`++result;`（前缀）和`result++;`（后缀）都会产生增加 1 的结果。区别在于评估的是哪个值。前缀`(++result)`基于递增后的值进行评估。后缀`(result++)`基于原始值评估。如果程序正在执行加/减操作，两种版本均可行。然而，较大的表达式需要更具体的选择，因为不同的结果会导致最终结果产生显著差异。

考虑以下示例：

```java
class PrePostDemo {
    public static void main(String[] args){
        int g = 1;
        g++;
        // prints 2
        System.out.println(g);
        ++g;
        // prints 3
        System.out.println(g);
        // prints 4
        System.out.println(++g);
        // prints 4
        System.out.println(g++);
        // prints 5
        System.out.println(g);
    }
}
```
