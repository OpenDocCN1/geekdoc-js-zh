Chapter 1 – Java Basics

 

Java is a computing platform and a programming language that has lots of applications. This programming and computing software is present everywhere. It is in all kinds of computers and data centers, including the simple laptop. Mobile devices like tablets and cell phones all use Java. The Internet, too, uses Java for its operations. In fact, Java is at the core of nearly every kind of networked application.

Installing Java in a device allows the user to chat on the Internet, play games online, and view 3D images. It is integral in programs that allow computations such as mortgage interest computations and simple arithmetic. It is also the foundation of various corporate computing needs such as e-business solutions and intranet applications.

What is the origin of Java?

A team from Sun Microsystems led by a man named James Gosling developed this computer programming language in the early 1990s. The original design was intended to be used on cellular phones, set-top boxes, and other digital mobile devices. The programming language was originally named OAK. The first version failed to attract a substantial patronage, which prompted the company to make some modifications. The language was modified to cater to the Internet and the name was changed into Java as it is called today. In 1996, Java 1.0 was made available to the public. This public release shifted its main use from use on mobile devices to use on the burgeoning Internet.

Who uses Java?

Java is also the global standard in embedded and mobile applications development and delivery. It is also the standard in web-based contents, enterprise and games. About 97% of enterprises operated in desktops run on Java. In the US alone, about 89% of computers or desktops also operate using the Java program.

More than 9 million developers are using Java for all applications and services needed. Worldwide, an astounding 3 billion mobile phones also use Java for its core operations and applications. All Blu-ray disc players are equipped with the Java program. About 125 million TV devices use Java in their fundamental operations. Java cards reaching a whopping 5 billion are currently in use. All of the Top 5 original manufacturers of various electrical equipment ship the Java ME. These figures show just how widespread Java use is.

Java provided users with more interactivity. This allowed developers to produce webpages that are animated, which increased websites’ appeal to online users. With the passing of the years, Java evolved into a worldwide success. Its use expanded to included applications and services that went beyond Internet use. Even after more than a decade since it was released to the public, Java remains popular. As of today, about 6.5 billion developers worldwide are using it, from simple desktop applications to complex, sensitive scientific supercomputers.

The modifications include a simplification of the C++ programming language. A few language features were eliminated, which reduced a lot of common programming errors.

Java uses source code files, which are files that use a .java extension name. These source code files are assembled and grouped together by a compiler and formatted into a bytecode. A bytecode is a file that has a .class extension, which a Java interpreter executes. All Java codes that were compiled are able to run on any computer because of VMs or Java Virtual Machines. These are runtime environments and Java interpreters present in most operating systems such as Windows, Macintosh OS and UNIX. Bytecodes may be directly converted by JIT (just-in-time compiler) into machine language instructions.

Key Principles of using Java

The Java design incorporated 4 key principles, namely, ease of use, reliability, security, and platform independent.

Ease of Use

The basics of Java originated from C++, which is a powerful programming language. However, its syntax is considered as very complex. Java built on the C++ language and improved on it. The result is a powerful yet simple programming platform.

Reliability

One of the main principles in the development of Java was to reduce the possibility of making common programming errors that may seriously hinder efficient program function. To eliminate common programming mistakes, Java introduced a programming method that is object oriented. Data and its methods of manipulation were conveniently packaged in one place. This technique made Java programming more robust and reliable.

Security

Java, as previously mentioned, was originally developed for mobile devices expected to exchange data over various networks. This function required high level security measures, which Java was able to provide. To date, Java is highly considered as the most secure of all programming languages available.

Platform independent

Java is a portable language. It does not discriminate across various platforms. This means that it works perfectly fine and consistent regardless of whatever type of hardware or what operating system is present.

Advantages of Using Java for Software Development

Java is a computer programming language that has been honed, improved, refined, tested, extended and proven through the years. A dedicated community involving enthusiasts, as well as Java developers and architects all work together to help the language able to meet the various and changing needs of software developers and users. It is able to perform the widest range of functions, across numerous platforms, and provide the highest performance. These key characteristics enable users such as businesses to provide better and wider ranges of services. These boost the productivity of end-users, as well as collaboration and communication (mainly from its platform independent characteristic). These also immensely reduce the costs involved in owning consumer and enterprise applications.

Chapter 2 – Basic Java Language

 

Before you start using Java, you should learn the language first. This basic skill will immensely help in getting the most out of the software. It makes communicating much easier, too. As a programming language, Java language is mainly about strings of characters. There are variables and objects, parameters, expressions, control flow statements and blocks. Understanding these elements is like learning a foreign language in order to better communicate with the locals.

This language allows programmers and developers to write English-based commands as computer instructions. Java does not require them to use numeric codes like other computer programming languages do. This is considered as “high level” language because it allows humans to easily read and write the language. The program instructions are written based on rules called syntax, much like Grammar rules applying to human languages. Basically, the human developer or programmer input instructions using the English language and once done, the computer translates these into a code that the computer can easily understand and execute. In most other computer languages, the developer or programmer would have to do the translation himself before the computer understands the instructions.

Learn the Java language will immensely help when creating programs later.

Java uses a statically-typed programming language. Variables must be declared first before these can be used. To do so, the variable name and type must be stated, such as in this example:

int gear – 1;

This statement informs the program that there exists a field called “gear”, which functions to hold numerical type of data and the initial value is 1.

The data type stated in the variable is very important because it determines what values the field can contain and what operations can be done on it.

COMMENTS

These are descriptions added to programs, for easy understanding of the codes. Compilers automatically ignore these comments. They do not exactly affect the outcome of the program. Comments are mainly used as part of program documentation, making it easier for those who want to read the program.

In Java, there are 3 supported comment styles. These are block style, line style and documentation style.

Block style starts with /* and end with */. These comments span multiple lines.

Line style starts with // and ends naturally where the line ends.

Documentation style start with /** and ends with */. These comments also span multiple lines. Document style comments are often created with the use of an automatic documentation generation tool. An example of this kind of tool is javadoc.

PRIMITIVE DATA

Primitive data is a type of data that comes predefined by the program language. This data type has a name reserved by a keyword. The values do not share states with other values.

Java supports 8 different types of primitive data:

byte

A byte is 8-bit signed two’s complement integer. The minimum value is -128 and the maximum value is 127. This type of data is useful when saving memory that comes in large arrays, where saving memory space matters a lot. byte data type may also be used to replace int. Limits provided by byte help in further clarifying the code. The value range also serves as a means of documentation.

short

This data is a 16-bit signed two’s complement integer. The minimum value is -32, 768 and the maximum value is 32, 767. The short data type can be used with large arrays in order to save more memory space.

int

The int is 32-bit signed two’s complement integer. The minimum value is -231 and the maximum value is 231-1. This data type is used in Java SE 8 and later versions as a means to represent unsigned 32-bit integers from 0 to 231-1.

The int data type can be used as an unsigned integer. To do this, the Integer Class of variables has to be used. The integer class incorporates methods such as compareUnsigned and divideUnsigned in order to support arithmetic operations that involve unsigned integers.

long

This type of data is 64-bit two’s complement integer. The minimum value of a signed long data is -263 and with a maximum value of 263-1. For Java versions SE 8 and later, long data types can be used for representing unsigned 64-bit long. These have minimum value of 0 and maximum value of 264-1. These are used when there is a need for wider range of values than those offered by the data type int. Long class data incorporates methods such as divideUnsigned and compareUnsigned. These methods support mathematical (arithmetic) operations that can be used for unsigned long.

Float

This type of data is single-precision, 32-bit IEEE 754 floating point. float is used instead of using double to save some memory when working with large arrays that involve floating point numbers. However, this data type is not recommended for use with precise values, such as currency.

double

This data type is 64-bit double-precision IEEE 754 floating point. The double data type is most often the default choice when working with decimal values. However, this must never be used when working with precise values like currencies.

boolean

There are only 2 possible values for the boolean data type: true and false. boolean is useful in creating simple flags for tracking true/false conditions. This type of data corresponds to 1 bit of information. However, the size isn’t precisely defined.

char

The char is a single 16-it Unicode character. The minimum value is 0 or ‘\u0000’ and the maximum value is 65, 535 inclusive or ‘\uffff’.

There is a slight difference with local variables, though. For uninitialized local variables, the compiler will never assign a default value. If the local variable cannot be initialized where it was declared, then ensure to assign a value before using it. Otherwise, compile-time error would occur when accessing uninitialized local variables.

LITERALS

Literals are source codes that represent a fixed value. These are directly represented into the code without requiring any computation. Assigning literals to primitive values is possible, as see in the following examples:

char capitalC = 'C';

boolean result = true;

byte b = 100;

int i = 100000;

short s = 10000;

Integer Literals

Integer literals are long data types if these end with l or L. If not, then these literals are of type int. The upper case form of the letter L is most recommended to use because it is difficult to distinguish the lower case l from the numeral 1.

For the integral types of int, long, short and byte data, the values can be made from int literals. For type long values that are more than the range provided by int, long literals can be used instead.

Integer literals are expressed in various number systems such as these:

•Decimal: This number system is the one everyone uses in real life on a daily basis, outside of programming. The numbers are in base 10, composed of digits from number 0 to 9.

•Hexadecimal: This number system uses letters and numbers. Using base 16, the digits are composed of a combination of the letters A to Z and the numbers 0 to 9.

•Binary: this number system is at base 2. The digits are various combinations of number 0 and 1. Binary literals can be created in Java SE 7 and later versions.

The decimal system is used when creating general purpose programming. The following are examples on how to use the correct syntax when using any of these number systems. For hexadecimals, the prefix 0x is used. For binary, the prefix 0b is used.

// The number 35, in decimal

int decVal = 35;

// The number 26, in hexadecimal

int hexVal = 0x1a;

// The number 26, in binary

int binVal = 0b11010;

Floating point literals

This is a type of float if the literal ends with F or f. If not, then it is considered a double data type, optionally ending in D or d. For both floating types (double and float), the scientific notation is expressed with the letter E or e. For 32-bit float literal, the letter F or f is used. A D or d is used for 64-bit double literal, although this is already a default and omitted by convention.

For example:

double d1 = 456.4;

// same value as d1, but in scientific notation

double d2 = 4.564e2;

float f1 = 456.4f;

Underscore characters in Numeric Literals

Several underscore characters (_) appear in Java SE 7 and later versions. These are found between digits that compose a numeric literal. This is a feature that improves the readability of the code. It works by separating groups of digits into specific numeric literals. One example is by separating digits into groups consisting f 3 digits each, much like one would use a comma or space in regular, daily use of long threads of numbers.

Underscores can only be placed between digits. It cannot be placed in the following instances:

•At the start or end of numbers

•Next to decimal points in floating point literals

•Before an L or F suffix

•Positions where string of digits is supposed to be placed

These following examples show valid and invalid placements of underscores:

 

// Invalid: cannot place underscore

// next to a decimal point

// OK (decimal literal)

// Invalid: cannot put underscores

// Invalid: cannot put underscores

// Invalid: cannot put underscores

// at the start of a number

Chapter 3 – Java Language: Objects

 

Aside from the 8 primitive types of data, Java programming language also gives a special kind of support for character strings. This is achieved through java.lang.Stringclass.

When a character string is enclosed within double quotes, a new string object is automatically created. For example,

String s= “make a new string”;

When string objects are created, these are considered as immutable. This means that the values can no longer be changed.

Essentially, objects use fields or variables to store their states. The behavior of objects is exposed through methods or functions. Methods work on the internal state of an object and function as the main method of object-to-object communication.

Methods are also the core of data encapsulation, a fundamental principle used by object-oriented programming such as in Java. This process essentially hides the object’s internal state and requires all interactions be conducted through that particular object’s method. The benefits for data encapsulation include the following:

•Modularity

This allows for independent writing and maintenance of an object’s source. Once the source code is created, the object easily passes around within the system.

•Information-hiding

Details of the object’s internal implementation are hidden from others because they only get to interact with the methods.

•Code re-use

Objects from other software developers or those that are already within the system can be used for one’s own program. This is a very beneficial characteristic because specialists can use objects from another software developer to test, implement or debug task-specific and complex objects. These objects can then be trusted to run within one’s own code because it will be certified safe.

•Pluggability and ease of debugging

Anytime an object becomes problematic, it can easily be removed from the application. Another object can be used to take its place. This is much like how things work in the real world, when fixing mechanical problems. The entire machine is not replaced. Instead, the broken part is identified, removed and replaced with a new one.

Instantiating objects

Instantiating is basically creating the object. This is because this step basically creates an instance of a class from which the object is created. In this part of creating an object, the keyword new is used. It instantiates a class by allotting memory space for the new object and returns a reference for that specific memory. The operator new also calls upon an object constructor and puts it to work.

In using new operator, the argument should be a single postfix, which is a call or signal to a constructor. The constructor’s name gives the class’ name that will be instantiated.

Then, the operator new will return a reference to the created object. The reference is often assigned to the appropriate variable type. For example:

The reference that the operator returns does not always get to be assigned to a variable. It may also be directly used in an expression such as in this example:

Garbage Collection

Other object-oriented languages require regular tracking of the objects created. Users have to check objects one-by-one and painstakingly delete each object that is no longer being used. This takes too much time and effort. This method also is a huge risk on accidentally deleting an object that may be needed in the future or objects that are still being used by current programs. With Java, deleting objects is much easier and less prone to deletion errors. Java allows users to create a vast number of objects, as long as the system can handle all the data and has adequate memory space for everything. The part is that there is no need to worry about having to clean up the various programs by deleting unused objects. There is no need to scroll through a long list of objects just to find the ones that should already be deleted. Java provides a neat process called the garbage collector. The runtime environment implemented by the Java programming language detects and automatically deletes any object that is no longer in use.

The garbage collector only deletes objects that no longer have any references. When a variable goes out of range, the references that this particular variable holds will be dropped. Once the references are dropped, the garbage collector will automatically delete it.

To induce the garbage collector to delete an object, the user explicitly drops the reference to that object. To do so, access the variable and assign it with null, which is a special value. Once assigned with the null value, the reference is dropped and the garbage collector deletes the object. Also, it is important to remember that for an object to be successfully deleted, all of its existing references must be dropped. Otherwise, the program will continue to hold on to the object and make it available.

 

 

Chapter 4 – Java Language: Variables

 

Java programming uses variables. These are named storage that can be manipulated by the program. These have specific types determined by the following parameters:

•Memory size occupied by the variable

•Layout of the memory occupied by the variable

•Range of values that the variable’s memory space can accommodate

•Set of operations that the variable allows

TYPES OF VARIABLES

Instance variables

These are also referred to as “non static fields”. The individual states of objects are stored in non static fields. These are fields that have not been defined by the keyword static. These are also called instance variables because the values are unique for each instance or each object.

Instance variables are used in storing the state of an object. A copy of the variable is available for each of the objects formed from a class. This copy is valid and occupies the assigned storage provided that its corresponding object remains within the memory.

Arguments or Parameters

Variables of this type are ones that were passed into method signatures such as parameter. Another example is the use of args in the previous examples. These are not connected to modifiers, such as static, protected or public. These can be used, however, everywhere else in the method. These remain within the memory during the method execution. When the method is used again, these can no longer be used.

Local Variables

Local variables are ones that were defined and used for a specific method. The function is within method level scope but do not play much function to method signature. Local variables do not contain any modifiers. Also, these variables cease to exist when the method returns.

Class variables

Also known as static fields, class variables refer to any field declared by the modifier static. It informs the compiler that this particular variable has exactly only 1 copy available, no matter how many times that the class is referred to or represented.

Class variables are variables that are clearly defined at the class level of a static modifier. This specific static modifier should not be used with any other variables. The attached static modifier would produce a single copy for each of the variables.

Naming Variables

There are different sets of conventions and rules that every programming language follows when it comes to giving names. In Java, there are also things to follow:

•Names of variables are case sensitive. The name can be a legal identifier, with an unlimited length of a sequence of digits and Unicode letters. The name should always begin with a letter, the underscore character or a dollar sign ($). The convention is to start the variable name with a letter, though. By convention, the dollar sign is never used to start any variable name. However, auto-generated names may sometimes start with “$” but programmers are highly advised against it. The same goes for underscore. It is technically legal but not a good thing to follow in actual programming. White space to start a variable name is also not allowed.

•The succeeding characters may include dollar sign, underscore, digits and letters. Conventions still apply in this part of a variable name. Use full words when naming variables instead of cryptic words. This will make things much easier because the codes will be easier to read and understand what they are for. For instance, fields that are named as gears, grades, speed and closet are much easier to understand what they are and what they are for rather than those named with xx6g or z. Keep in mind, too, that variable names should not be any of the reserved words or keywords.

• When the chosen variable name is a single word, spell it with all the letters in lowercase. If the variable name is more than a single word, capitalize the 1st letter of each word, except the 1st word. For example, gradeAverage, gearParts and concentrationRatios. If the variable is meant for storage of constant values, this convention may have to be slightly altered. For instance, the variable static final int AMT_TUBES = 85. The name is fully capitalized and the words of the variable name are separated with an underscore. The underscore, by convention, is never used in a different place.

 

 

 

 

Chapter 5 – Java Language: Operators

 

In Java programming, operators are a set of special symbols. Their function is to perform precise operations on 1, 2, or 3 operands and then provide a result. These are used in creating expressions, which in turn, compute values.

TYPES OF OPERATORS

There are basically 6 different types of operators in Java.

Arithmetic operators

These are operators used in mathematical expressions much like in regular algebra.

For instance, the integer variable X holds 15 and variable Y holds 25. The following are examples of what results will be obtained if the different arithmetic operators are used on these 2 integer variables.

+ Addition: This operator adds the values placed on both its sides.

X + Y yields 40

- Subtraction: This operator subtracts the operand on the right from that on the left.

X – Y yields -10

* Multiplication: This operator multiplies the values on both its sides.

X * Y yields 375

/ Division: This operator divides the operand on the left by the operand on the right

X / Y yields 1.67

% Modulus: This operator divides the operand on the left by the one on the right and returns the remainder. It is also called the remainder operator.

X % Y yields 0.67

++ Increment: This operator increase the operand’s value by 1

Y++ yields 26

X++ yields 16

-- Decrement: Decreases the operand value by -1

Y-- yields 24

X-- yields 14

Relational operators

These operators show how the operands are related to each other.

Consider X integer value holds 20 and Y integer value holds 40.

== tests if the values held by the 2 operands are equal to each other or not. The condition yields “true” if the 2 operands are equal.

(X == Y) is not true

!= tests if the values held by the 2 operands are equal to each other or not. The result is true if the values of the operands are not equal.

(X != Y) is true

> tests if the left operand’s value is more (greater) than the right operand’s value. The condition becomes true if the left is greater than the right.

(X > Y) is not true

< tests if the left operand’s value is less than that of the right. This condition is regarded as true if this is the case.

(X < Y) is true

>= tests if the left operand’s value is greater than or equal to the right operand’s value. This condition becomes true if this is the case.

(X >= Y) is not true

<= tests the left operand’s value if it is less than or equal to that of the right operand. This condition becomes true if this is the case.

(X <= Y) is true

Bitwise operators

Several bitwise operators are supported in Java. These can be applied on integer types such as byte, long, char, int, and short.

AS the name implies, these operators work on bits and the operation these perform is bit-by-bit.

For instance, m = 60 and p =13. In binary format, m = 0011 1100 and p = 0000 1101

m&p = 000 1100

m|p = 0011 1101

m^p = 0011 0001

~m = 1100 0011

From these values, the following illustrates what happens if the different bitwise operators are applied.

& Binary AND operator: This operator copies a bit to the result if it is present in both of the operands.

(m & p) yields 12, in binary, 1100

| Binary OR operator: This operator copies a bit if it is present in either of the operands.

(m | p) yields 61, in binary, 0011 1101

^ Binary XOR operator: This operator copies the bit if it the bit is set in 1 of the operands but not in both.

(m ^ p) yields 49, in binary, 0011 0001

~ Binary Ones Complement Operator: This is a unary. Its effect is to “flip” bits.

(~m) yields -61, in binary form, 1100 0011 in a 2s complement form. This is because the unary number is signed.

<< Binary Left Shift Operator: This moves the value of the left operand based on the number of bits that were specified by the operand on the right.

m << 2 yields 240, in binary form, 1111 0000

>> Binary Right Shift Operator: The value of the left operand is moved to the right based on the number of bits that were specified by the operand on the right.

m >> 2 yields 15, in binary form, 1111

>>> Shift right zero fill operator: This moves the value of the left operand to the right, as specified by the number of bits of the right operand. The shifted values are then filled up with zeros.

m >>>2 yields 15, in binary form, 000 1111

Logical operators

To illustrate what and how logical operators function, consider the following examples:

Boolean variable x holds true values and the Boolean variable Y holds false values.

&& Logical AND operator: This functions by testing if operands on both sides are non-zero. If yes, the condition becomes true.

(x && y) is false

|| Logical OR Operator: This checks the 2 operands if any of them are non-zero. If yes, the condition is true.

(x || y) is true

! Logical NOT Operator: This operator is used in reversing its operands logical state. That is, if the condition is true, the Logical NOT operator makes it false.

!(x && y) is true

These are so much like the ones used in algebra. These are also the most commonly used operators.

Z = X + Y, wherein, the value of X + Y is assigned as the value of Z.

Z /= X becomes Z = Z / X

The different operators in Java come with different precedence. Higher precedence operators are evaluated first before those with relatively lower precedence. Those that occur on the same line are considered to have equal precedence. In case operators with equal precedence occur on the same line, rules have to be followed in which to evaluate first. For all binary operators, evaluation is from left to right. For assignment operators, the evaluation proceeds from right to left.
