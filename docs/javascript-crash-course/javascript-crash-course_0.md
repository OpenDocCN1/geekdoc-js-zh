## 第 1 节：Script 标签

`JavaScript` 代码可以放在 `HTML` 文档内部，也可以放在外部文件中。

### 在 HTML 文档内部使用 Script 标签

放在 `HTML` 文档内部的 `JavaScript` 代码必须放在 `<script></script>` 标签之间，以区别于 `HTML` 和 `CSS` 代码。`<script></script>` 标签可以放在 `HTML` 文档的 `<head>` 或 `<body>` 部分，或者两者都有。事实上，你可以创建任意数量的 `<script></script>` 标签。在 `<head>` 部分，`<script></script>` 标签位于 `<meta>` 标签之后。在 `<body>` 部分，只要在 `<body></body>` 标签之间，它们可以放在任何地方。然而，通常情况下，最好将大部分 `JavaScript` 代码放在 `<head>` 部分，因为文档的 `<head>` 在 `<body>` 之前渲染。

![带有 script 标签的 HTML 文档](img/00003.jpeg)





由于 JavaScript 是目前最流行的脚本语言，因此在 HTML5 中创建网页时，你不需要在起始 `<script>` 标签内部使用 `type` 属性。然而，在旧版本的 HTML 中，你必须通过值为 `"text/javascript"` 的 `type` 属性来指明你正在`<script></script>` 标签中放置 JavaScript 代码。本书假设你正在使用 HTML5，因此脚本标签将不会指定 `type` 属性。

## 使用外部 JavaScript 文件

向网页中添加 JavaScript 代码更高效的方法是使用外部 JavaScript 源文件。使用外部 JavaScript 文件让你的代码更易读，因为你的 JavaScript 代码与 HTML 代码分了来。另一个好处是，你可以通过这种方法轻松地将 JavaScript 代码应用到多个网页。

你可以通过在起始 `<script>` 标签中使用 `"src"` 属性来调用外部 JavaScript 文件，如下：`<script src="filename.js">`。外部 JavaScript 文件具有 `".js"` 扩展名，并且仅包含 JavaScript 语句。注意的是，外部 JavaScript 源文件不包含 `<script>` 元素。`<script>` 元素仅存在于调用 JavaScript 源文件的 HTML 文档中。

你可以在 HTML 文档的 `<head>` 部分或 `<body>` 部分中调用外部 JavaScript 源文件。然而，当你调用外部 JavaScript 文件时，`<script></script>` 标签之间的任何 JavaScript 语句都会被忽略。

### 什么是变量？

变量是代表值的名称。变量可以代表数字、字符、布尔值、内存位置等。使用变量允许程序处理不同的数据集。每个变量都有一个名称和一个数据类型。数据类型告诉计算机存储的是什么类型的值。例如，如果你想存储用户的姓名，你可以将变量命名为 `name`。常量是变量的相反面。常量是一个永远改变的值。

### 在 JavaScript 中命名变量

在 JavaScript 中，你的变量名必须仅由字母、数字、`$` 符号或下划线组成。变量名不能以数字开头，所以你不能将变量命名为 `1car`，但可以命名为 `car1`。变量对大小写敏感，所以变量 `car1` 与 `Car1`。最后，你不能使用保留字作为变量名。保留字是编程语言中具有特殊含义的单词。保留字也被称为关键字。保留字始终小写，并在 Notepad++ 中显示为蓝色的斜体文本。以下是 JavaScript 保留字列表：

### 基础数据类型

变量可以是几种数据类型，但最基础的数据类型是数值、字符串、布尔和空（null）。数值变量是值为数字的变量。该数字可以是整数或小数，也可以是正数或负数。字符串变量仅仅是键盘输入的一系列字符，包含在引号之间。布尔变量用于做出决策，其值位 `true` 或 `false`。null 变量是一个空变量，即该变量完全没有值。它与零不同，因为零本身也是一个值。

### 声明变量

在程序中使用变量之前，你必须先创建它。在编程术语中，创建变量的过程被称为**声明变量**（declaring a variable）。你可以通过变量名配合 `var` 关键字来声明变量。例如，如果你想创建一个名为 `fish` 的变量，你会使用语句 `var fish;`。





如果你愿意，可以在创建变量的同时给它赋一个初始值。这被称为**初始化变量**。你可以通过赋值运算符（`=`）给变量赋值。例如，语句 `var bull = true;` 创建了一个名为 `bull` 的变量，并给它赋了初为 `true` 的初始值。

![声明变量的示例](img/00012.jpeg)

## 第 4 ：在 JavaScript 中进行数学运算

### 运算符和操作数

计算机指令由两个基本部分组成：运算符和操作数。**运算符**是表示动作的字符。例如，加号（`+`）是一个表示加法的算术运算符。**操作数**是计算机指令中指定要进行操作或处理的数据部分。因此，在表达式 `x + 3` 中，`x` 和 `3` 就是操作数。

![运算符图片](img/00015.jpeg)

### 赋值运算符

**赋值运算符**（`=`）用于给变量赋值。

### 算术运算符

最常用的算术运算符是（`+` 用于加法，`-` 用于减法，`*` 用于乘法，`/` 用于除法，以及（`%` 用于取模运算（取余）。取模运算意味着你正在寻找整数除法的余数。例如，`7 % 3`（读作 "seven modulo three"）是 1，因为 7 除以 3 的余数是 1。所有这些运算符都可以用于数字和变量。

然而，加法运算符（`+`）也可以用于字符串。当你将两个字符串相加时，这被称为**拼接**。下面的代码展示了如何使用加法运算符处理数字、变量和字符串。

### 复合赋值运算符

复合赋值运算符通过将算术运算符与赋值运算符相结合使编码变得更容易。复合赋值运算符有 `+=`、`-=`、`*=` 和 `/=`。它们被用作基本算术语句的简写。例如，`sum += 10;` 是 `sum = sum + 10;` 的简写。同样，`num -= 2;` 是 `num = num - 2;` 的简写，`num *= 2;` 是 `num = num * 2;` 的简写。最后，正如你可能猜到的那样，`num /= 2;` 是 `num = num / 2;` 的简写。

### 递增运算符

**递增运算符**是符号（`++`）。它是数字变量值加 1 的简写。因此，语句 `num++;` 是 `num = num + 1;` 的简写。你可以在变量名之前或之后使用该运算符。例如，如果你有一个名为 `num` 的变量并想让它加 1，你可以写 `num++;` 或 `++num;`。这两个语句都会将变量 `num` 的值加 1。唯一的区别在于你何时想在计算中使用变量 `num` 的值或将其值打印到屏幕上。例如，语句 `document.write(num)`

### 递减运算符

**递减运算符**是符号（`--`）。它是数字变量值减 1 的简写。因此，语句 `num--;` 是 `num = num - 1;` 的简写。

## 第 5 ：函数

### 什么是函数？

你是否见过汽车工厂的工人是如何使用分工的？一个工人负责焊接框架，另一个人安装门，另一个人安装玻璃窗窗，依此类推，直到你得到一辆完工的汽车。制造汽车的巨大工程被拆分为更小的任务，每个工人专门负责一项任务。同样，我们使用函数将一个大程序拆分成更小的部分。创建一个复杂的程序类似于造汽车。如果你将想让程序执行的工作拆分为可以处理的小任务，就会变得更容易。**函数**是一个在调用时执行特定任务的命名代码块。

## 第 6 Lesson：决策与条件语句

很多时候，你会遇到这样的情况：当某个条件为真时运行一段代码，当另一个条件为真时运行另一段代码。我们可以使用 `conditional statements`（条件语句）根据各种条件执行不同的操作。我们可以从四种不同的条件语句中选择：

*   `if...else` 语句
*   `if...else if...else` 语句
*   以及 `switch` 语句

比较运算符用于比较两个操作数，它们通常用于条件语句。常用的比较运算符列如下：

![常用的比较运算符](img/00035.jpeg)

比较两个操作数后，会返回布尔值 `true` 或 `false`。例如，表达式 `5 == 5` 将返回 `true`，而表达式 `5 != 5` 将返回 `false`。

相等运算符 (==) 会检查两个操作数是否相等，然而，操作数可以是不同数据类型仍然相等。例如，表达式 `5=="5"` 将返回 `true`，因为 JavaScript 解释器会尝试将字符串值转换为数字。然而，如果字符串无法转换为数字，则返回 `false` 值。因此，表达式 `5 == "five"` 将返回 `false`，因为解释器无法将字符串 `"five"` 转换为数字。

严格相等运算符 (===) 与相等运算符略有不同。它检查两个操作数具有相同的值且数据类型相同。例如，表达式 `5==="5"` 将返回 `false`，因为一个操作数是数字类型，而另一个是字符串类型。

### Method 属性 (Method Attribute)

`method` 属性告诉浏览器如何发送表单数据。最常用的两种方法是 `get` 方法和 `post` 方法。`get` 方法以名称/值对的形式将表单数据附加到 URL 中。处理敏感数据时，绝不应该使用 `get` 方法，因为数据在 URL 中可见的。此外，如果你有很长的数据需要发送，不应该使用 `get` 方法，因为 URL 的长度被限制在 3000 个字符左右。在处理敏感或很长数据的情况下，你应该使用 `post` 方法，它对数据长度没有限制，而且由于数据不显示在 URL 中，因此是一种更安全的方法。不过，出于学习目的，`get` 方法是理想的，因为我们可以在 URL 中看到提交的表单数据。

### 访问表单数据 (Accessing Form Data)

在我们检查用户是否正确填写了表单之前，我们必须知道如何访问用户输入表单的数据。`document` 对象有一个 `forms[]` 数组，其中包含了网页上所有的表单。每个表单都包含在 `<form></form>` 标签中，你可以在一个网页上有多个表单。表单根据它们在网页上的位置进行引用。因此，网页上的第一个 `<form>` 元素被称为 `forms[0]`，第二个表单元素是 `forms[1]`，第三个表单元素是 `forms[2]`，依此类推。然而，大多数网页不包含多个 `<form>` 元素。如果网页上没有表单，`forms[]` 数组就是空的。因此，在我们的示例中，代码 `document.forms[0]` 将允许我们访问在本课程开始创建的表单。

`forms[]` 数组包含了表单内的元素，例如 `<input>` 元素、`<select>` 元素等，是可以访问的。我们可以通过使用元素的 `name` 属性值来访问表单中的元素。例如，在我们课程开始时创建的表单中，我们使用 `name` 属性将第一个 `<input>` 元素命名为 `"myemail"`。我们将 `<select>` 元素命名为 `"size"`，并将这组单选按钮命名为 `"payment"`。因此，如果我们想引用表单中创建的第一个 `<input>` 元素，我们将使用代码 `document.forms[0].myemail`。

表单中的每个元素都是具有属性和方法的对象。一个非常有用的属性是 `value` 属性。`value` 属性存储用户输入到 `<form>` 元素的数据。在电子邮件输入字段的情况下，`value` 属性存储一个字符串，其值是用户在电子邮件输入字段中输入的文本。因此，如果我们想访问用户在电子邮件地址输入字段中输入的地址，我们将使用代码 `document.forms[0].myemail.value`。

`<select>` 元素与电子邮件 `<input>` 元素略有不同。`<select>` 元素的值是预定义的。回想我们在课程开始时表单中的 `<select>` 元素：

![select element](img/00108.jpeg)

注意每个 `<option>` 标签内部都有一个 `value` 属性。当选择第一个 `<option>` 标签时，`value` 属性等于空字符串 (`""`)。这意味着用户没有从下拉列表中选择任何选项。第一个选项的文本通常留作为用户撰写说明，例如 `Select An Option`。当用户选择第二个选项时，`value` 属性等于 `"small"`，当用户选择第三个选项时，`value` 等于 `"med"`，依此类推。因此，如果我们想知道用户从下拉列表中选择了哪个选项，我们将使用代码 `document.forms[0].size.value`。

回想我们的表单包含一个单选按钮元素，允许用户选择其支付方式，我们使用 `name` 属性将这组单选按钮命名为 `payment`。单选按钮和复选框与其他 `<input>` 元素不同，因为相同的名称适用于一组按钮。为了区分这些按钮，我们需要将每个按钮的值存储在一个名为 `payment[]` 的数组中，其中第一个按钮的值存储在 `payment[0]` 中，第二个按钮的值存储在 `payment[1]` 中，第三个按钮的值存储在 `payment[2]` 中。每个按钮的值为 `true` 或 `false`。如果用户选择了按钮，则为 `true`；如果用户没有选择该按钮，则为 `false`。

![radio buttons](img/00109.jpeg)

`checked` 属性仅对复选框和单选按钮可用，它返回一个布尔值，告诉我们用户是否选中了单选按钮或复选框。因此，如果我们想检查用户是否选中了表单中 `Method Of Payment` 部分的 `Debit Card` 单选按钮，可以使用以下代码：`document.forms[0].payment[1].checked`。如果这段代码返回值为 `true`，则用户已选中 `Debit Card` 单选按钮。
