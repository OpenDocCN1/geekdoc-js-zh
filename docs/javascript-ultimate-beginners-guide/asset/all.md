Chapter 11: Creating a Loop Within Your Code

In most of this guidebook we have been talking about functions and codes that will just have one input and one output based on the condition. In these codes, the statement that is the first one in the sequence will be executed in the program first and then it will go on down the line until the whole code has been executed. But if you would like to be able to run the same code block many times on your program, it is a good idea to learn how to work with loops.

A loop has the ability to make a statement execute multiple times as long as the condition is true and then the loop will exit as soon as the condition becomes false. There are a few different types of loops that are supported in JavaScript including:

While loop

Do…while loop

For loop

For…in loop

Loop control statements

Let’s take a look at how most of these work and how you would be able to use these in your own coding.

While loop statements

The while loop is one of the most basic loop types that you can use and it is pretty popular because of how simple the program is. This piece of code is going to continue to execute as long as your expression is true. One the expression comes out false, the loop is going to stop working. An example of the syntax that uses the while loop statement is as follows:

<!DOCTYPE html>

<body>

<script type = “text/javascript”>

var counter = 0

document.write(Entering while Loop!”);

while (counter < 5){

document.write(“Current Counter is : “ + counter + “<br/>);

counter++

document.write(Exiting while Loop!”);

</script>

<p>We are inside body section…</p>

With this formula, the loop is going to execute the HMTL program through the counter five times as long as the condition is help to be true for these five times. You can change the counter to go up or down based on how many times you want to make the program do the work.

Do….while loop statements

This kind of loop statement is going to be similar to what you found with the loop statement except that with this one, the condition check is going to happen when you reach the end of the loop. This means that the code block will be executed a minimum of one time. If the code is found to have a false condition, then the statement is going to stop being run, but since it is not checking to see if the condition is false or not during execution, the program will run until the false condition is shown as the end.

For loop statement

This is one of the most used looping statements that you will find within JavaScript programming. There are three parts that are very important and should be present when you are trying to make one of the for loop statements. These parts include:

*   Loop initialization—this is where you will initialize the counter value to be the starting value. This statement will be executed before your looping process even begins.
*   Test statement—this is the condition that your compiler is going to evaluate to see if it is true or false. If this condition is true, the code inside your loop will be executed. If the condition ends up being false, then your control will make the program exit the loop.
*   Iteration statement—this is the place where you will be able to increase or else decrease the counter value that you initialized during the first statement.

In most cases, you will be able to put all three parts into one line that will be separated out with semicolons and you can use some of the syntaxes that we used before.

Loop control statements

You would use this kind of statement when you are looking to change out the execution of your statements from the normal sequence that it should use. When this execution is going to leave the scope, all of the automatic objects that you created inside of that scope will be destroyed and removed. There are a few types of loop control statements that are supported inside of this language including:

*   Break statement—this kind of statement is going to be used in order to stop the loop statement and to transfer the execution of this statement right to the end of the loop.
*   Continue statement—this kind of statement is going to force the loop to skip over the rest of the body and go right back to retesting to condition prior to restarting the looping body.
