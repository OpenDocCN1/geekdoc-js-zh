### 强类型检查

Java 是一种强类型语言。每个定义的变量都需要关联到一个数据类型。目前你不需要理解整个程序，但让我们快速看一眼 2 行代码。

```java
int i=5;
```

在这里我们定义了一个被称为变量的东西，用于存储值。可以存储的值取决于数据类型。在这个示例中，我们说`i`的类型是`int`或`Integer`，这是一种数值数据值。

### 数组边界检查

在运行时，Java 将检查数组是否定义了所需数量的值。如果尝试访问数组边界之外的值，将抛出异常。目前你不需要理解整个程序，但让我们快速看一眼以下代码行。

```java
int[] array1 = new int[2];
array1[0] = 1; array1[1] = 2; array1[2] = 3;
```

在这里我们声明了一个数组，它是一个整数值的集合。值`2`意味着只能在数组中存储两个值。通过这段代码，我们可以看到正在给数组分配 3 个值。当你运行此程序时，将得到一个错误，因为程序会发现数组超出了允许的两个的最大边界。你将在运行时得到下面的错误。

```
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: 2 at HelloWorld.main(HelloWorld.java:8)
```

### 为什么 Java 很重要？

接下来，Java 的语法和特征类似于 C 和 C++ 等其他编程语言。如果你有任何之前的编程经验，你会发现学习 Java 是轻而易举。即使你对编程完全是新手，你也可以放心，Java 设计成是一门相对容易学习的语言。大多数程序员发现学习 Java 比学习 C 或 C++ 更容易。

Java 还被设计为平台无关。如之前所述，Java 代码首先被编译成字节码，字节码可以在任何带有 Java 虚拟机的机器上运行。因此，通过 Java，你可以编写一次代码并在任何你想的地方运行它。

## 为什么选择 Java？

当然，使用 Java 的关键原因之一是它对面向对象编程的关注。面向对象编程（或`OOP`）是一种语言模型，它允许程序代码围绕数据组织，而不是函数和逻辑（后者被称为过程化编程）。这些“数据簇”被组织成被称为“对象”的东西，因此被称为“面向对象编程”。这些对象是由被称为“类”的东西创建的，这里的类从传统意义上理解，即：对象的类型，允许程序员根据两个标准对它们进行“分类”：属性和方法。

类的属性是创建对象的原始数据：这些是它的描述符，例如它所拥的值以及构成对象的其他数据。第二个标准是对象的“方法”。这个“方法”是行为，或类中包含的逻辑序列，描述了它如何交互或如何被交互。
