# 前言

这是一本关于广泛使用的编程语言 Perl 的书。它既包括对语言特性的描述，也包括如何利用这些特性编写有用的程序。正如编程书籍通常的情况一样，示例都很小，旨在说明一个或少数几个语言功能。更大、更复杂的程序往往会因其规模和结构而淹没本书试图展示的特性。

本书的目标是为那些在其他编程语言中有编程经验并想学习使用 Perl 的人提供清晰简洁的 Perl 描述。在许多方面，Perl 与其他编程语言相似；在其他一些方面，它又非常不同。我们会在相关之处指出 Perl 相对于其他语言的优势。

Perl 作为最广泛使用的 UNIX 系统管理语言已有相当的时间。现在，它也是编写通用网关接口（CGI）程序最流行的脚本语言。近年来，Perl 开始在许多较小的编程任务中取代 C，特别是当需要处理大量文本文件时。由于该语言这些多样化应用，现在有大量的 Perl 用户。由于万维网的普及度急剧上升，以及随之而来的涵盖其各个方面（包括 CGI 编程）的大学课程，Perl 书籍现在正出现一个新兴的学术市场。然而，大多数（如果不是全部）目前可用的 Perl 书籍都是为专业程序员编写的。本书试图面向有经验的程序员，无论这些经验是来自专业编程，还是来自计算机科学或密切相关领域的学位课程的前门课程。

Perl 既不小也不简单。它是先前语言（如 `sed`、`awk` 和 C）的特性和功能的复杂组合，再加上一些自己的新思想。尽管 Perl 功能强大，但学习足够的语言来编写描述重要处理的程序相对容易，尽管程序本身相当小。

本书既不是全面的参考书，也不是教程。关于语言的参考书包含语言的所有细节，但通常以难以阅读的形式呈现。从这样的书中学编程语言是困难的；这就像试图通过学习一本英语语法书来学习英语。另一方面，编程语言的教程书籍往往目标太低——它们假设读者对编程语言和编程知之甚少。经验丰富的程序员，无论是专业的还是来自大学经验的，都会觉得这样的书枯燥乏味，因为它们常常在显而易见的事情上浪费了好几段。

我们的意图是让这本书介于这两种模式之间。它不会涵盖 Perl 的每一个细节，也不会提供计算机、编程或编程语言的入门介绍。它不适合那些想成为 Perl 专家的人；他们仍然需要一本 Perl 参考书。另一方面，它也不适合那些只想了解一点 Perl 以编写（和阅读）一些相对较小和简单的程序的人。

## 本书内容

第一章概述了 Perl 的目的和起源，并介绍了 CGI 编程是什么。最重要的是，它包含了一个 Perl 程序示例，并对每个语句进行了简要描述。第二章描述了 Perl 的小规模特性，涵盖了足以编写小程序的语法结构。第三章描述了大多数控制语句。第四章介绍了 Perl 的数组，它们比其他流行编程语言的数组更灵活、更强大。第五章描述了哈希（用于存储键值表信息的数据结构）和引用（提供了指针的部分好处，而没有其固有的危险）。Perl 函数的剖析是第六章的主题，包括一些预定义函数。Perl 强大的模式匹配功能在第七章中描述，其中包含许多小代码片段，展示了其强大和灵活性。文件、文件测试和格式在第八章中描述。第九章提供了用 Perl 编写 CGI 程序所需的信息，包括使用便捷的 `CGI.pm` 模块。第九章还包含几个完整的 CGI 程序示例。最后，第十章简要介绍了六个适合放在前面章节的 Perl 高级主题。其中包括如何从 Perl 程序启动程序、Per 程序与其他计算机通信，以及如何使用 Tk 为程序添加图形界面。

Perl 是一种在软件开发领域日益重要的语言。许多专业人士应该学习它，以便他们正确识别它在应用程序中成为几乎不可少的语言：CGI 和系统管理。本书提供的一些指导会有帮助。

### 1.1 Perl 是什么

Perl 包含了来自前身编程语言的一些强大的构造，并引入了自己的新构造。结果是一种具有表达力和灵活性的语言。除了那些兴趣仅限于大型系统的程序员外，大多数程序员都应该对 Perl 兴趣。

Perl 最初是一种相对简单的编程语言，旨在扩展文本处理实用程序 `sed` 和 `awk`。它被设计用于处理文本文件的短程序，使用复杂而强大的模式技术。Perl 很快发展到包含 UNIX shell `sh` 和 `csh` 的许多特性。其中包括进程创建和销的能力，有助于 Perl 在系统管理中有用。然后添加了套接字的能力，允许 Perl 用作网络语言与其他计算机通信。最近，Perl 获得了模块和面向对象编程的支持。像其他语言一样，Perl 仍在发展和成长，正如 Perl 5 版本开发和测试（至少最低度的）。

Perl 是 `Practical Extraction and Reporting` 的缩写，尽管它也被指责是 `Pathologically eclectic rubbish list`。从 1987 年首次发布（版本 1.0）到 1994 年中期，Perl 的设计和实现都是由非常有抱负、有天赋和无私的人 Larry Wall 完成的。语言及其实现的持续演进由其他几个抱负、有天赋和无私的人继续。

Perl 的血统将其置于 shell 实用程序和高级语言之间的空白地带。最初，这个利基市场很小，但通过 Perl 的演进和发展，已经增长到相当大的规模。Perl 早已超越了仅仅是 UNIX 系统管理和文本处理的语言。它已成为大量小型应用程序任务的首选语言。正如第 1.3 节所讨论的，它是最流行的语言。像大多数其他流行的编程语言一样，Perl 有一套工具（分析器、调试器和语法导向编辑器），共同提供了一个现代的软件开发环境。Perl 已加入相对小的通用语言集合，这些语言既得到良好支持又广泛使用。

在某种意义上，Perl 是一种简单的语言——初学者在第一次接触后不久就可以用它编写小而有用的程序。但它也是一种复杂的语言，提供了用于创建执行复杂任务程序的丰富性和强大功能。Perl 通过从大多数程序员熟悉的语言中借鉴大部分语法而变得更容易。Perl 代码看起来有点像 C，有点像 `sh`，有点像 `awk`。如果你知道其中一种或多种语言，你不会觉得学习 Perl 很困难。如果你不知道，别担心。你仍然会发现 Perl 相对容易学习，本书不假设你了解任何特定的编程语言（尽管你期望熟悉某种高级语言）。

一些 Perl 的批评者认为 Perl 程序晦涩难懂，当然可以用它编写混淆的程序。然而，只要有一点编程纪律和一些简单的标准，Perl 程序可以像任何流行编程语言的程序一样可读。

尽管 Perl 最初是 UNIX 工具，但它已传播到许多非 UNIX 系统，并在 1990 年代由于几个原因其受欢迎程度急剧增加。它无疑是最移植的系统编程语言。一些以前在 UNIX 下进行的软件开发正在非 UNIX 系统下进行。进行这种转变的程序员发现，在非 UNIX 系统下使用 Perl 让他们感觉一些 UNIX 文化也随之而来。最后，Perl 易于获取、免费，并且适用于所有流行的计算平台。

许多 Perl 程序员认为它是一种不仅相对容易，而且有趣的语言。然而，编程语言理论家可能在 Perl 中找不到多少可爱之处。“该语言旨在实用（易于使用、高效、完整），而不是美观（小巧、优雅、极简）。”¹

许多 Perl 用户以及许多撰写 Perl 相关内容的作者，将 Perl 语句集合称为脚本。下一节将解释这样称呼以及为何将这些集合称为程序。

### 1.2 脚本与程序

早期的操作系统 包含一些小型的命令，这些命令可以在终端输入，由命令解释器逐条执行。这些命令许多与文件操作。为了避免繁琐的任务，将命令放入文件中，开发出一种方法。这些文件的内容并非程序，而是称为脚本。UNIX 中的第一个语言被称为 shell (`sh`)。shell 语言及其后来的变体如 `csh` 和 `ksh` 获得了一些特性，使其看起来像编程语言。然而，这些语言仍然由操作系统解释器执行。

Perl 部分是从 shell 语言演化而来的。因此，脚本程序在执行之前会先编译成中间语言。编译器会检查程序中各种潜在错误。这种使得 Perl 的执行过程与许多高级语言（例如 Java）相似。我们反对将 Perl 程序称为脚本。然而，我们更倾向于称它们为程序，并且本书中始终如此。

Perl 仅是一门成熟且灵活的语言。Perl 在互联网编程中的应用是其迅速普及的原因。

### 1.3 Perl 中的 CGI

到 1995 年，已有相当多的人为万维网创建页面。这些人经常希望在页面上显示一些 HTML 等标记的内容——必须使用强大的方法。显而易见的解决方案是转向通用语言编写程序。从数据库检索和显示信息以及浏览器交互。由于数据库通常存储在 Web 服务器上（而不是客户端），以及其他原因，执行这些操作应该留在服务器上，当客户端系统请求时，由解释器触发，然后结果（以 HTML 形式返回给用户。客户端与服务器之间的这种协议或接口被称为通用网关接口（CGI）。因此，此类软件开发被称为 CGI。最初，许多 CGI 编程是用各种 shell 语言完成的，UNIX 系统中至少有一种 shell语言。（Web 服务器，通常运行在 UNIX 系统上。）然而，shell 语言用于此目的三个问题变得明显。首先，由于存在几种不兼容的 shell 方言，使用特定 shell 语言难以移植到其他系统。其次，对于某些类型的编程任务，例如在 CGI 编程中常见的文本处理，shell 语言用起来笨拙。最后，shell 语言相对慢的执行速度使其在 CGI 应用中吸引力较低。由于这些原因，CGI 程序员开始使用高级语言。实际上，任何高级语言都可以用于 CGI 编程。这类编程常用的功能是文本处理、访问操作系统以及与系统实用程序和其他软件包的接口。考虑到这些，Perl 在 CGI 编程方面具有以下优势：

它易于在所有常见的 Web 服务器平台之间移植；学习足够的 Perl 来编写 CGI 应用相对容易；系统函数内置于 Perl 中，大大简化了它们的使用；Perl 提供对操作系统环境变量的直接访问；具有扩展，允许与非 Perl 系统（如数据库系统）进行简单接口。

由于这些原因，Perl 已成为 CGI 编程中使用最广泛的语言。由于这种流行，Lincoln Stein 开发了一个模块 `CGI.pm`，其中包含了最常见 CGI 编程任务的 Perl 函数。`CGI.pm` 是免费且易用的。Perl 中的 CGI 编程和 `CGI.pm` 的使用将在第 9 章中讨论。

Perl 围绕许多有趣且强大的语言设计理念演化而来。这些理念提供了一种快速介绍语言本质特征的方法。

### 1.4 Perl 的核心特性

了解 Perl 的基本特性为学习这门语言提供了一个框架，应该会使学习变得更容易。这种讨论的一个缺点是，我们必须使用一些术语和概念，这些术语和概念直到本书后面才会完全定义。请在此处等待，因为这很值得这点不便。

隐式变量。隐式变量是由语言实现的变量，而不是由用户定义的。大多数高级语言不提供用户访问的隐式变量。它们唯一的隐式变量是编译器为表达式求值创建的临时变量。汇编语言通常使用寄存器作为隐式变量。Perl 中有几个操作具有可选的操作数。当此类运算符的操作数被省略时，会使用一个隐式变量。使用隐式变量方便了程序员，并使程序稍微短一些。

函数和运算符的互换性。在大多数高级语言中，语言定义的运算符和函数是语言特性的不同类别。在 Perl 中，这种区别被模糊到在许多情况下差异无关紧要的程度。具体来说，Perl 包括列表运算符，其中运算符后跟一个操作数列表。在其他情况下，将此类运算符的操作数括在括号中很方便，使其看起来像函数调用。在其他情况下，省略函数调用参数周围的括号很方便，使其看起来像运算符及其操作数。在 Perl 中，程序员有这种选择权。

数字就是数字。大多数编程语言提供多种数值数据类型，并为这些类型的值提供多种支持。然而，Perl 只有一种数值类型，由硬件直接支持。变量是隐式声明的。

字符串和数字。一些 Perl 运算符加上文，这可能导致这些类型转换。一个常见的例子是数字作为字符串运算符的操作数出现，此时数字会隐式转换为字符串。同样，当字符串或变量作为算术运算符的操作数出现时，该值将隐式转换为数字。

标量和列表上下文。在 Perl 的某些情况下，数组变量可以作为期望标量运算符的操作数出现。在这些情况下，数组变量被解释为数组的长度。此外，标量变量可以出现在期望数组操作数的地方。这里，变量被视为一个包含元素的数组。这是语言灵活性的另一个例子。

### 2.1 标量字量

Perl 中最简单的数据形式是标量。标量量是三种类型之一的单个值：数字、字符字符串或引用。数字和字符字量将在接下来的小节中讨论。引用是内存地址，将在第 5 章讨论。

#### 2.1.1 数字字量

大多数计算机为多种数字数据类型提供硬件支持，大多数编程语言也提供与这些硬件支持类型对应的数据类型。Perl 对数字数据的看法与其他大多数常见编程语言大相同——默认情况下，Perl 程序中的大多数数字数据都以单一类型表示，即双精度浮点数。所有浮点值都以分数和指数的形式存储，类似于科学计数法。许多语言提供两种浮点数据类型：标准精度和双精度。双精度浮点类型存储的值范围比标准浮点类型大得多。Perl 中对数字值的大多数操作都是在其双精度类型中完成。

可以指示编译器使用整数算术运算，但由于这并不常见，我们不作讨论。然而，第 2.3.1、2.3.3 和 2.9 节分别描述的取模运算符、重复运算符和位运算符，在执行操作前总是会将其数字操作数转换为整数值。

数字量可以以三种形式中的任何一种出现：一串没有小数点和指数的数字、一串带有小数点的数字，或者这两种形式之一后跟一个指数。指数以 `E` 或 `e` 开头，后跟一个可能带符号的整数字量。以下所有内容都是合法的 Perl 数字量：

```
37    3.7    .37    37e1    37E1    37e-1    37E-1
```

数字量可以通过 `0x` 表示十六进制、`0o` 表示八进制或 `0b` 表示二进制。例如，`0xff` 表示 255，`0o377` 表示 255，`0b11111111` 表示 255。

数字量还可以使用下划线提高可读性，例如，`1_000_000` 等于 `1000000`。

### 2.2 标量变量

一个变量有两个组成部分：一个名称和一个与该变量关联的内存位置的地址。变量的值存储在其关联的内存位置中。标量变量是存储标量值的变量。所有标量变量的名称都具有相同的语法形式：一个美元符号 `$` 后跟一个字母，后面可能跟一串字母、数字和下划线。名称没有长度限制，名称中的所有字符都是有意义的。以下两个名称是不同的：

```
$supercalifragilisticexpialadocious
$supercalifragilisticexpialadoces
```

名称中的字母区分大小写，因此 `$Rose` 与 `$ROSE` 或 `$rose` 或 `$RoSe` 不同。按照 Perl 的惯例（与其他几种编程语言一样），用户定义的变量名不使用大写字母。仅使用大写字母的名称保留给值永不改变的变量（有时称为常量）。我们更喜欢使用下划线而不是嵌入的大写字母，因此我们更喜欢 `$sum_of_squares` 而不是 `$sumOfSquares`，尽管这取决于个人喜好。

标量变量没有被定义为具有特定类型。事实上，它们通常根本没有被显式定义。如前所述，所有标量变量都可以存储数字、字符串或对其他内存位置的引用。标量变量在程序中的仅仅出现就会导致编译器隐式地定义它。Perl 程序中所有隐式定义的变量都是全局的，或者具有全局作用域，这意味着它们在整个程序中都是可见的。Perl 中有标量变量声明，但我们只在它们变得相关时才讨论，即在第 6 章。

变量插值通过以下示例说明，我们假设 `$name` 的值为 "bob"：

```
"Apples are good for $name"
```

被解释为

```
"Apples are good for bob"
```

如果我们不想让 `$name` 被插值，我们会用反斜杠转义 `$`，如：

```
"Apples are good for \$name"
```

当然，我们也可以使用单引号来避免插值。

当双引号字符串字面量中嵌入单引号字符串字面量，或反之亦然时，外层引号决定字符串的性质。例如，在

```
"The boy sent the message, 'Help, send $money' "
```

`$money` 被插值，即使它在单引号字符串中。此外，在

```
'The boy sent the message, "Help, send $money" '
```

`$money` 没有被插值。

如果你想让一个字母数字字符紧跟在双引号字符串中插值的标量变量的值的右边，你必须用花括号 `{ }` 将变量名括起来。例如，如果 `$day` 存储字符串 "Mon"，那么

```
"Today is ${day}day";
```

的值是

```
"Today is Monday"
```

你可能认为美元符号看起来很傻，这些隐式声明是草率和/或危险的，但这种疯狂是有其道理的。首先，变量名是 Perl 名词（事物的名称）中最重要的类别，它们看起来与 Perl 动词（指定某些动作的词）不同。这不是一个新想法。在德语中，所有名词都以大写字母开头，以使它们看起来与非名词的词不同。其次，当标量变量的名称出现在双引号字符串字面量时，其独特的名称形式使其能够被识别为标量的名称，并且其值可以被插值到字符串中（如第 2.1.2 节所讨论）。最后，如果将来 Perl 添加新的保留字，它们不会与现有 Perl 程序中的变量名冲突。

Perl 包含大量隐式变量，其中许多是标量。隐式变量通常用作某些运算符的默认操作数和某些预定义函数的默认参数。隐式标量变量名当然以美元符号开头。我们将在第 2.3 节讨论最常用的隐式变量，即名为 `$\_` 的变量。其他类别的变量，如数组，也使用特殊字符作为名称的开头。现在我们准备看看标量运算符和表达式。

### 2.3 标量运算符

Perl 包含丰富的运算符集。本节描述最常用的标量数据运算符，以及一些对字符串值执行操作的函数。回顾第 1 章，运算符和函数在 Perl 中密切相关。

#### 2.3.1 算术运算符

Perl 包含用于加法（`+`）、减法（`-`）、乘法（`*`）、除法（`/`）、取幂（`**`）和取模（或除法后的余数，`%`）的二元算术运算符（具有两个操作数的运算符）。以下示例说明了取模运算符：

```
4 % 2    is 0  (i.e., the remainder of dividing 4 by 2 is 0)
7 % 2    is 1
18 % 4   is 2
```

如果取模运算符的任一操作数碰巧具有非整数值，例如 7.86，则该值在执行操作之前会通过截断隐式转换为整数。截断只是移除小数部分，因此 7.86 将被截断为 7。对于所有其他算术运算符，包括 `**`，具有整数值的操作数会被隐式转换为双精度浮点值。隐式转换称为“强制转换”。例如，在

```
5 / 2
```

中，尽管两个操作数都是整数字面量，但它们被强制转换为双精度数，并执行双精度除法操作，产生 2.5。

#### 2.3.2 数值表达式求值

每个允许包含多个运算符的表达式语言，也有规则规定这些运算符的求值顺序。在大多数常见语言中，控制求值顺序是相似的。这些规则中最基本的“优先级规则”。它们为运算符指定一个优先级或重要性。例如，加法比乘法具有更低的优先级。因此，在表达式

```
$a + b * 2
```

中，乘法在加法之前执行。注意，在大多数情况下，先执行加法会导致表达式的值不同。

当一个表达式中有两个相邻的运算符或具有相同优先级时，另一组“结合性规则”决定了求值顺序。这些规则为运算符指定左结合或右结合。左结合或简称左结合性，意味着左运算符的操作在右运算符的操作之前执行。同样，右结合或右结合性意味着右运算符的操作先执行。例如，在表达式

```
$a / b / 2
```

中，左侧的除法先执行。因此，如果 `$a` 和 `$b` 的值分别为8和2，此表达式的值为2。（如果除法是右结合。）Perl 还提供一元正负运算符，以及一元自增（`++`）和一元自减（`--`）。自增和自减运算符与其他运算符根本的不同，因为它们的操作数必须是变量，并且有副作用。

自增和自减可以是前缀（出现在操作数之前）或后缀（出现在操作数之后）。当与其他运算符一起出现在表达式中，含义取决于它们是前缀还是后缀。例如，在表达式

```
++total * 3
```

中，`total` 的值首先自增，然后新值用作乘法的操作数。因此，如果 `$total` 的值是3，表达式的值是12。另一方面，在表达式

```
$total++ * 3
```

中，`total` 的旧值用作乘法数。在这种情况下，假设 `$total` 的值是3，表达式的值是9。但 `$total` 仍然会被值自增。（回想一下，递增和递减运算符的优先级高于乘法。）显然，让任何表达式的值依赖于操作数的求值顺序并不是一个好主意。因此，应避免使用任何类似于上述表达式的表达式。

在 Perl 中，表达式中运算符的操作数的求值顺序是未指定的。编译器可以选择每个表达式中操作数的求值顺序。这导致表达式的值无法预先确定；也就是说，它们可能取决于求值表达式的特定实现。例如，在表达式

```
$a++ * $a--
```

中，假设在表达式求值之前 `$a` 的值为3。如果先求值左侧操作数，则整个表达式的值为12。如果先求值右侧操作数，则值为6。

| 二元 + - | 左 |

#### 2.3.3 字符串运算符

关于 Perl 字符串，首先必须理解的是，它们不是像许多其他编程语言中那样存储为字符数组。因此，不能通过下标将字符串中的单个字符作为数组元素访问。单个字符和子字符串只能通过预定义函数访问。字符串连接由点运算符（`.`）指定。在 Perl 表达式中，两个字符串字面量或具有字符串值的相邻出现是永远合法的。因此，连接运算符不是隐式的。例如，考虑 `$str` 的值为 "Happy"：

```
$str " World"
```

此代码无效。相反，我们可以使用

```
$str . " World"
```

这将产生单个字符串 "Happy World"。

重复运算符由字母 `x` 指定，它将其左侧字符串复制右侧数值数指定的次数。例如，

```
"Happy " x 3
```

创建字符串 "Happy Happy Happy "。

重复运算符的右侧操作数可以是算术表达式，但其值会被转换为整数。左侧操作数可以是任何字符串。重复运算符的优先级高于连接运算符。因此，表达式

```
"Happy " . "World" x 2
```

的值是 "Happy WorldWorld"，而不是

```
"Happy Happy World "
```

未被显式赋值的变量具有值 `undef`。当编译器隐式定义该变量时，会将此值赋给该变量，这发生在编译器在程序中首次发现该变量时。当 `undef` 被解释为数字时，其值为0。因此，在表达式中使用值为 `undef` 的变量既不是语法错误，也不是运行时错误。`undef` 也可能由某些运算符和函数返回。

### 2.3.4 字符串函数

本节描述最常用的定义函数，这些函数对字符串值执行操作。在讨论它们之前，要介绍一下 Perl 函数。我们经常需要从特定字符串中删除最后一个字符。`chop` 函数对其参数字符串执行此操作。例如，如果 `$fruit` 的值是 "apples"，

```
chop($fruit)
```

将 `$fruit` 的值更改为 "apple" 并返回删除的字符 "s"。此外，如果 `$fruit` 的值是 "apples"，

```
chop($fruit) x 2
```

求值为 "appleapple"。chop` 的主要操作通过改变参数值的副作用来体现。我们之前提到 Perl 函数与数学函数只是松相关的原因之一就是这种改变参数的情况，这在数学函数中从未发生。通常，`chop` 的返回值会被忽略，而对 `chop` 的调用是一个完整的表达式。用字面量调用 `chop`，如

```
chop("gumballs")
```

没有太大意义，因为没有地方放置修改后的字符串值。此外，为什么不直接写 "gumball"，而不是调用函数呢。

`chop` 的常见用途，尤其是在较旧的 Perl 程序中，是从键盘或文本文件输入的行中删除换行符。使用 `chop` 执行此操作有两个问题：(1) 如果字符串末尾没有换行符，无论最后一个字符是什么，都会被删除；(2) 尽管在 UNIX 系统中换行符由单个字符（回车符）表示，但在某些非 UNIX 系统中，换行符使用两个字符——回车符和换行符。由于换行符的表示方式不同，最好考虑输入记录分隔符——其中分隔符在某些系统上是一个字符，在其他系统上是两个字符。由于 `chop` 可能存在的问题，Perl 包含了一个函数 `chomp`，它删除系统用于输入记录分隔符的任何内容，无论它包含多少个字符。`chomp` 返回它删除的输入记录分隔的数量。如果 `chomp` 用于不以输入记录分隔符结尾的字符串，它不会对字符串做任何操作并返回零。因此，当你不确定字符串是否以输入记录分隔符结尾时，即使你知道输入记录分隔符是单个字符，也使用 `chomp`。在本书中，我们将始终使用 `chomp` 来删除输入记录分隔符，并建议你也这样做，因为它使代码更具平台独立性。

文本处理通常需要在字符串中搜索特定的子字符串。Perl 包含两个用于此任务的函数：`index`从左到右搜索字符串，`rindex`则从右到左执行相同操作。这两个函数都接受两个字符串参数：要搜索的字符串和要搜索的子字符串。两者都返回从左端零开始计数的、要搜索的子字符串第一个字符的位置。如果未找到子字符串，两个函数都返回 -1。考虑以下示例：

```
index("apples", "pp") returns 1
rindex("apples", "pp") returns 1
index("apples", "p") returns 1
rindex("apples", "p") returns 2
index("apples", "q") returns -1
```

有时需要提取给定字符串中特定位置的子字符串。这通常在 `index` 或 `rindex` 找到子字符串后进行。`substr` 函数接受一个字符串和两个数字作为参数来执行此类提取，如

```
substr($str, position, length)
```

`position` 参数指定要提取的第一个字符的位置。`length` 参数指定要提取的字符数。如果第二个参数的值为负数，则位置从右端而非左端开始计数。考虑以下示例，我们假设 `$str` 的值是 "fruit juice"：

```
substr($str, 0, 3) returns "fru"
substr($str, 3, 5) returns "it ju"
substr($str, -3, 3) returns "ice"
```

`substr` 的第三个参数是可选的。如果省略，`substr` 将返回从指定位置到字符串右端的所有字符。

Perl 有一个函数用于从两个或多个现有字符串构建新字符串，另一个函数用于拆分字符串，分别是 `join` 和 `split`。我们在这里讨论 `join` 函数，但将 `split` 函数的描述推迟到第 4 章，因为它通常与数组一起使用。`join` 函数调用的形式为

```
join Expression, List
```

其中 `Expression` 指定一个字符串（通常是一个字符），该字符串将作为新字符串各部分之间的分隔符。第二个参数指定要连接在一起的字符串列表——例如，

```
join ':', $month, $day, $year;
```

如果使用空字符串作为分隔符，`join` 只是将字符串连接在一起。事实上，这是进行字符串连接最快的方法。本节讨论的字符串函数总结在表 2.3 中。

### 2.4 混合模式表达式

当二元运算符的两个操作数具有不同的数据类型时，该表达式称为混合模式表达式。在本节中，我们讨论一种特定类型的混合模式表达式——即包含一个二元运算符，其中一个操作数是数字，另一个操作数是字符串的表达式。

在 Perl 中，当数字值操作数与字符串运算符一起使用时，它会被强制转换为如果打印其值时会出现的字符串。当字符串值作为数字运算符的操作数出现时，它会被强制转换为数字。在此转换过程中，前导空白和尾部非数字字符会被忽略。因此，" 2x" 被转换为 2，而 'x' 被忽略。如果字符串在这些规则下不包含数字，则使用值 0。

考虑以下示例，我们假设 `$str` 的值是 " 32abc"：

```
7 + $str $str 的值被转换为 32，结果为 39。
7 . $str 7 被转换为 "7"，结果为 "7 32abc"。
- $str $str 的值被转换为 32，结果为 -32。
```

如果 `$str` 是 "alpha32"，那么

```
7 + $str
```

的结果是 7，因为该字符串被转换为 0。

¹²在某些编程语言中，字符串长度操作根本不计算输入运算符。

### 2.5 赋值语句

赋值语句是大多数常见编程语言中进行计算的主要手段。因此，它们在包括 Perl 在内的任何此类语言中都具有核心重要性。

#### 2.5.1 简单赋值运算符

简单赋值运算符 `=` 接受两个操作数：左侧的目标变量和右侧的表达式，如代码所示：

```
$average = $sum / $total;
$last_name = "van Beethoven";
$name = "Ludwig " . $last_name;
```

请注意，这些语句以分号结尾。每个 Perl 语句都必须以分号结尾，除非它是块中的最后一条语句。（参见第 3 章。）

正如我们之前所述，变量有两个部分：地址和值。当变量作为操作数出现在表达式中，使用的是变量的值。当变量出现在赋值语句左侧时，使用的是地址。赋值语句左侧必须具有 l-value。字量不能作为赋值语句，因为它们没有 l-value。赋值运算符会产生一个结果，即被赋的值。因此，赋值语句可以用作表达式中的操作数。赋值运算符的优先级低于目前讨论的所有运算符，并且它是右结合。例如，考虑以下语句：

```
$sum_a = $sum_b = 0;
$result = 17 * ($sum = $total);
```

在第一条语句中，值 0 首先赋给 `$sum`，然后赋给 `$sum_b`，最后赋给 `$sum_a`。由于此类语句含义不太明显，不建议使用。

赋值的结果既可以作为值，也可以作为目标变量（l-value 或 r-value）使用。例如，尽管 `chomp` 需要一个 l-value，但我们可以有：

```
chomp($str = $str);
```

在这个例子中，`chomp` 处理的是 `$str` 的新值

标量变量中的值作为赋值的目标时，其现有类型（数字或字符串）是无关紧要的。我们可以有：

```
$a = 17;
```

以及：

```
$a = "Beethoven";
```

#### 2.5.2 表达式作为语句

到为止，我们只讨论了一种语句形式，即简单赋值。然而，表达式和语句之间存在密切的关系，引出了第二种相关语句：表达式。表达式可以语句出现的任何地方。例如，我们可以有：

```
$a * $b - 1;
```

因为计算这个表达式没有副作用（没有变量的值改变），它本身没有任何作用。另一方面，具有副作用的表达式，例如：

```
$a++;
```

作为完整的语句是有用的。我们将这样的表达式视为赋值语句。

#### 2.5.3 复合赋值运算符

某种赋值语句在程序中出现的频率，导致在 C 语言及其衍生语言（包括 Perl）中对其进行了缩写。这种常见的语句形式是：

```
$whatever operator operand
```

其中运算符适用于 `$whatever` 和操作数的任何二元运算符。这种语句形式的缩写在语句中使用了赋值运算符和其他运算符的组合，被称为复合赋值运算符。以下代码具有说明性：

```
$sum += $new_value;    # 等同于 $sum + $new_value;
$str .= "ing";        # 等同于 $str . "ing";
$result **= 4;         # 等同于 $result ** 4;
```

Perl 中所有的二元算术、字符串和布尔（参见第 3 章）运算符都可以这样使用。（回想一下，`#` 在任何行上开始一个注释，行尾结束注释。）

复合赋值运算符的优先级与简单赋值运算符相同，而不是其他运算符的优先级。例如，`**=` 与 `=`（以及 `+=`）具有相同的优先级，而不是 `**` 的优先级。因此，复合赋值运算符应仅在右侧操作数不包含运算符时使用。在其他情况下可能的问题由以下示例说明：

```
$a = 2;
$a *= 2 + 1;    # $a 的新值是 6（+优先计算）
```

接下来，我们讨论从键盘获取输入和将输出定向到屏幕的过程。

### 2.6 简单的键盘输入和屏幕输出

尽管 Perl 程序通常处理来自文件的数据并将其输出文件，但键盘输入和屏幕输出也是必不可少的。此外，对这些简单过程的简要讨论使我们能够编写小型但完整的程序，而无需涉及文件输入/输出的细节。因此，这里是简要的讨论。

文件，包括标准输入（键盘）和标准输出（屏幕），在程序中通过称为文件句柄的特殊变量来指定。Perl 中标准的预分配文件句柄是 `STDIN`。标准输出预分配文件句柄是 `STDOUT`。

#### 2.6.1 键盘输入

与其他编程语言相比，在 Perl 中将键盘（或文件）的一行读入程序中的变量是相当不同的。在 Perl 中，使用了一个外观相当奇特的运算符。该运算符称为行输入运算符，或尖括号运算符。输入文件的文件句柄被放置在尖括号中。尖括号是运算符，文件句柄是操作数。表达式`<STDIN>` 读取键盘输入，直到并包括输入记录分隔符，这个字符串值替换了 `<STDIN>` 的出现。如果在调用执行时没有输入任何内容，`perl` 解释器会等待。

通常，`<STDIN>` 是赋值给标量变量的右侧，例如在语句中：

```
$new_input = <STDIN>;
```

在许多输入将作字符串的情况下，不需要输入分隔符。因此，Perl 中常见的形式是：

```
chomp($new_input = <STDIN>);
```

在输入中找到结束符时，`<STDIN>` 返回 `undef`。在 UNIX 系统上，它是 `Control-D`；在 Windows 上，它是 `Control-Z`；在 Macintosh 上，它是 `Control-D`。

#### 2.6.2 屏幕输出

输出到屏幕与键盘输入一样简单。通过 `print` 指定，将其视为运算符或函数。它可以有任意数量的参数，所有参数都是屏幕的文件句柄是 `STDOUT`。然而，如果你想要的，无需指定 `STDOUT`。考虑以下示例：

```
print "Isn't this fun?";
print("That may be overstatement!");
print("The sum is: $sum", "\tThe average is: $average");
```

最后一个示例有效，因为标量变量在带引号字符串中会被插值。`print` 函数的形式和语义直接自 C 语言。关于 `printf` 的更多信息可以在任何该语言的教科书中。`sprintf` 函数与 `printf` 相同，只是 `sprintf` 返回其输出，而不是将其发送到标准输出。`sprintf` 最常用于内部数值转换为字符串。例如：

```
$sum = sprintf("%.2f", 427.56);
```

如果需要对输出进行控制，可以使用 `printf` 函数。此函数的第一个参数是输出字符串字面量，包括变量的值。第一个参数称为格式代码，或简称控制字符串。字符串值的格式代码是 `%s`；整数值的格式代码是 `%d`；浮点值的格式代码是 `%f`。在所有三种情况下，`n` 是一个数字面量，指定显示的小数点。考虑以下代码：

```
$a = "apples";
$b = 173;
$c = 3.55;
printf("%7s %5d %6f \n", $a, $b, $c);
```

此代码的输出是：

```
a, b, and c are: apples   173    3.550000
```

### 2.7 一个示例

我们终于可以来看简单但完整的程序了，它只用到了已经解释过的语言特性。当然，由于我们只介绍了 Perl 的小部分，这个示例是很简单的。它会提示用户输入一个数字，这个数字当作圆的半径。下面的程序计算并显示给定圆的面积和周长：

```perl
# circle
#     Input:    A number that is the radius of a circle
#     Output:   The area and circumference of the given circle
#     Formulas: Area of a circle = pi * radius * radius
#               Circumference of a circle = pi * 2 * radius

$pi = 3.14159265;
print "Please type the radius of a circle: ";
$radius = <STDIN>;
$area = $pi * $radius * $radius;
$circumference = $pi * 2 * $radius;
print "A circle of radius $radius has an area of $area \n",
      " and a circumference of $circumference \n";
```

既然我们已经展示了一个完整的示例，就必须解释如何运行它，或者更一般的，如何运行任何其他 Perl 程序。

### 2.8 运行 Perl 程序

Perl 程序可以通过几种不同的方式编译和运行，这些方式在不同的操作系统上略有不同。本章只讨论其中一种方式，但它很可能在所有运行 Perl 的操作系统上都适用。请注意，我们用 Perl 指代这门语言，用 `perl` 指代 Perl 编译器/解释器程序。

运行 Perl 程序的一种方式是将 `perl` 系统作为命令执行（在操作系统的命令行模式下），并将 Perl 程序文件作为参数包含进去。例如，对于文件 `circle.pl` 中的程序：

```bash
% perl circle.pl
```

这里的 `%` 代表操作系统的提示符。

单语句程序可以通过在 `perl` 命令行上输入 `-e` 标志和用单引号括起来的语句来运行，例如：

```bash
% perl -e 'print "Is this easy enough? \n";
```

请注意，一些非 UNIX 的实现要求 `-e` 标志后的语句用双引号括起来。如果你需要运行两三行的程序，又不想麻烦地使用编辑器，你可以在命令行上输入 `perl`，后面跟着任意多行 Perl 代码，最后以一个包含文件结束符的行结束。例如：

```bash
% perl
print "Well, ok! \n";
print "This is also easy! \n";
# end-of-file character (for example, Control-D for UNIX)
```

回顾第一章，Perl 程序不像大多数操作系统命令语言是纯粹解释执行的。Perl 程序首先被编译成一种中间形式，然后再被解释执行。`perl`编译阶段会在执行开始前找出程序中的语法错误。运行 `perl` 通常会导致翻译和执行。可以通过在命令行中包含 `-c` 标志来避免执行部分，例如：

```bash
% perl -c circle.pl
```

运行 Perl 时另一个常用的标志是 `-w`，它会使 Perl 编译器检查许多常见的编程错误，并在程序中发现可疑代码时产生警告消息。如果没有设置这个标志，`perl`会简单地忽略许多麻烦的错误。我们强烈建议你始终在启用警告标志的情况下运行 `perl`。

一个会导致警告但不会导致错误的代码示例是：

```perl
$str = "hello";
...
$sum = 3 + $str;
```


在这种情况下，字符串不是数字的表示，将使用零值（`undef`）。如果没有设置`-w`，就不会对此做任何提示。

`perl`系统还有许多其他可以设置的标志。其中一些将在本书后面讨论。所有标志的信息都可以在`perlrun`部分的Perl手册页中找到。

### 2.9 位运算符

本章的最后一项任务是介绍Perl的位运算符，它们很有趣且偶尔有用，但并不那么重要，因此没有在本章前面部分占有一席之地。

Perl有六个运算符，它们将操作数（是数字）视为位字符串，而不是数字。这些是按位逻辑与（`&`）、按位或（`|`）、按位异或（`^`）、按位取反（`~`）、左移（`<<`）和右移（`>>`）。所有这些运算符的操作数在运算发生前，如果需要，会被强制转换为整数值。当浮点值被强制转换为转换为整数值时，值会被截断，而不是四舍五入。例如，在表达式

```perl
3.9 << 2
```

中，左操作数被转换为3（二进制11），然后左移2位，产生值12（二进制1100）。移位操作在某种意义上是算术的，因为在大多数机器上，右移会将符号位的副本带入左操作数的左端。这使得快速的移位运算符可以在第二个操作数是2的幂时，替代相对较慢的乘法和除法运算符。例如，要将`x`中的值乘以8，我们可以使用

```perl
$x << 3
```

要将`x`中的值除以16，我们可以使用

```perl
$x >> 4
```

然而，由于整数表示的差异，移位操作可能是机器相关的。此外，除非操作要执行非常多次，否则使用移位获得的执行速度提升可以忽略不计。

按位逻辑和取反运算符对其操作数的所有位执行操作。每对相应的位独立地产生结果的一位。例如，如果`x`和`y`的值分别是00010011和00110010，那么

```perl
$x | $y
```

的值是00110011。

取反运算符（`~`）只接受一个操作数，它将其操作数中的所有零变为一，所有一变为零。

`&`、`|`和`^`运算符是少数几种你必须关注数字和字符串之间区别的场景之一。如果这些运算符的两个操作数都是字符串，并且自赋值以来未被用作数字，则运算符的行为会有所不同。由于这很少有用，我们在此不作描述。

Perl还包括非按位的AND和OR运算符，用于具有布尔值的操作数。这些将在第3章讨论。

### 2.10 总结

数字是Perl中三种标量类型之一。它们几乎总是以双精度浮点值存储。标量变量名总是以美元符号开头，这种约定允许它们被隐式定义。这种隐式定义的变量是全局的，意味着它们在出现的整个文件中都可见。

Perl包含用于乘法、除法、加法、减法和取模的常用数值运算符。它还有来自C的递增和递减运算符。Perl有典型的运算符优先级和结合规则。字符串字面量可以用单引号或双引号分隔。它们之间的区别在于，嵌入在双引号中的变量会被插值，并且双引号可以包含转义序列来指定特殊字符。有一些字符串函数，专门用于删除字符或尾部、获取字符串长度、将字符转换为大写或小写、将字符串中的十六进制和八进制转换为数字、将字符转换为ASCII代码、在字符串中搜索特定字符串以及提取子字符串。`join`运算符将字符串组合一个新的字符串。Perl包含简单的赋值运算符和复合赋值运算符，后者将其他二元运算符结合。可以通过尖括号指定标准输入句柄`STDIN`从键盘获取。屏幕输出通过简单的函数`print`或`printf`完成。Perl有六个位运算符，分别指定逻辑与、按位或、按位异或、取反、左移和右移。所有这些运算符的操作数在运算发生前都会转换为整数。

### 3.1 控制表达式

控制表达式必须求值为可以解释为真或假的值。Perl没有布尔类型（其值仅为真和假），而是允许使用标量表达式来指定控制表达式。因此，控制表达式总是作为字符串或数字进行求值，最终值被解释为真或假。控制语句的控制表达式可以是简单的、关系的或复合的。这三种控制表达式将在以下节中描述。

#### 3.1.1 简单控制表达式

简单控制表达式是算术表达式或字符串表达式。简单控制表达式的值根据以下规则进行解释：如果值是字符串，则其值为真，除非它是空字符串（``）或零字符串（"0"）。如果值是数字，则除非它是零，否则为真。如其他规则暗示的，任何未定义的值都是假的（因为未定义的数字被解释为零，未定义的字符串被解释为空字符串）。存在一些可能导致混淆的特殊情况。例如，字符串字面量"0.0"看起来像零，但由于它不是"0"，所以是真的。总而言，该系统简单而有效——几乎所有标量值都以最直观的方式求值为尔值。

#### 3.1.2 关系表达式

关系表达式是包含单个关系运算符（如`>`）的表达式。在Perl中，有两组六个关系运算符，一组用于数字操作数，一组用于字符串操作数。所有这些运算符如表3.1所示。

关系运算符对真产生`1`，对假产生空字符串（`""`）。回想一下，当空字符串被解释为数字时，其值为`0`。

关系运算符总是将其操作数强制转换为适当的类型。例如，在表达式`fruit" eq 7`中，数字`7`将被强制转换为"7"（因为`eq`运算符接受字符串）。

关系运算符是为了避免可能出现的奇怪结果。例如，假设有表达式`27" gt "3"`，在这个表达式中，关系运算符`gt`首先比较操作数的第一个字符（"2"和"3"）。由于"2"小于"3"，表达式求值为假。然而，如果使用`boy" == "girl"`总是为真，因为两个操作数都不是数字，都被转换为零。

表3.1 关系运算符

| 操作 | 数字 | 字符串 |
|---|---|---|
| 等于 | `==` | `eq` |
| 不等于 | `!=` | `ne` |
| 小于 | `<` | `lt` |
| 大于 | `>` | `gt` |
| 小于等于 | `<=` | `le` |
| 大于等于 | `>=` | `ge` |

关系运算符的优先级和结合性：这些运算符的优先级低于算术运算符。为了读性，建议使用括号。例如，在`0 * a < limit`中，比较是在乘法之后。我们更倾向于将表达式写成`(0 * a) < limit`。关系运算符是非结合。比较运算符`<=>`和`cmp`将在第6章讨论。

#### 3.1.3 复合表达式

复合表达式由标量变量、标量字量、关系表达式和布尔运算符组成。复合表达式可以包含任意数量的布尔运算符。Perl有两组语义相同但优先级不同的运算符。`&&`表示与，`||`表示或，`!`表示非。这些运算符的优先级低于关系运算符。`&&`和`||`是短路运算符，这意味着如果左操作数决定了表达式的值，则不对右操作数求值。如果布尔运算符是`&&`，如果左操作数值为假，则不对右操作数求值。例如，在`a && (b < limit)`中，如果`a`大于零，则不会进行第二次比较（在`b`和`limit`之间）。这仅在布尔运算符的第二个操作数是具有改变变量值的表达式时才重要。例如，考虑`(a > 0) && (++b < limit)`，如果`a`大于零，则`b`的值不会受到此表达式求值的影响。

对于布尔运算符`||`，如果左操作数为真，则不对右操作数求值。`&&`和`||`产生的值是最后求值的值，而不是真或假（`1`或""""）。例如，在`a && b`中，如果`a`是17，`b`是9，使得表达式的值为真，但表达式的实际值是9，而不是1。

`and`、`or`和`not`表示的运算符与`&&`、`||`和`!`运算符完全相同，只是它们更具读性且优先级更低。事实上，它们的优先级低于任何其他Perl运算符。这意味着无论使用何种表达式（除了其他布尔表达式）作为它们的操作数，这些布尔运算符总是最后求值。

所有二元布尔运算符（但不包括关系运算符）都可以与赋值运算符组合，例如`a ||= b;`。此语句在`a`和`b`之间执行或运算，并将结果放入`a`。

到目前为止讨论的所有运算符的优先级和结合性如表3.2所示。顶部的运算符具有最高优先级。由`and`和`or`形成的布尔表达式的值，与`&&`和`||`的情况一样，是最后求值的值，而不是1或""。

表3.2 运算符优先级和结合性

| 运算符 | 结合性 |
| :--- | :--- |
| ++ -- | 非结合 |
| ** | 右结合 |
| ~ ! 一元 + 和 - | 右结合 |
| * / % x | 左结合 |
| + - . | 左结合 |
| << >> | 左结合 |
| > < >= <= lt gt le ge | 非结合 |
| == != | 左结合 |
| & ^ | 左结合 |
| && || | 左结合 |
| |= &= *= << >>= 左结合 |
| = | 左结合 |
| xor | 右结合 |
| not | 右结合 |
| and | 右结合 |
| or | 右结合 |

（注：上表中由`and`和`or`形成的布尔表达式的值，与`&&`和`||`的情况一样，是最后求值的值，而不是1或""）

我们现在准备开始讨论Perl的控制语句。我们从选择语句（包括`if`和`unless`）和条件表达式开始。


`Boolean_expression ? then_expression : else_expression`

条件表达式通常用作赋值语句的右侧，例如：

> ¹这构建了一个结构，其中受控子句实际上通过 OR 运算符连接。将 `if` 语句嵌套在 then 子句中会构建一个结构，其中受控子句实际上通过 AND 运算符连接。

```
$average = ($number != 0)? $sum / $number : 0;
```

如果 `then` 和 `else` 表达式都具有左值，则条件表达式可以用作赋值语句的左侧，例如：

```
(($next > 0) ? $positives : $negatives) += $next;
```

下面的示例说明了 Perl 的 `if` 语句。它从键盘读取三个不同的数字，确定哪个数字在数值上居中，并显示该数字。策略是首先使用带有复合控制表达式的嵌套 `if` 语句来确定第一个数字是否具有中间值，然后对第二个数字进行同样的判断。如果这两个测试都失败，程序会正确地假设第三个数字具有中间值。

```
# middle
# Input: Three unique numbers, on separate lines, from the keyboard
# Output: The input number whose value is smaller than the largest and larger than the smallest
# Get the input numbers
$first = <STDIN>;
$second = <STDIN>;
$third = <STDIN>;

# Is the first number the middle one?
if ((($first < $second) and ($first > $third)) or
    (($first < $third) and ($first > $second))) {
    $middle = $first;

# Is the second number the middle one?
} elsif ((($second < $first) and ($second > $third)) or
         (($second < $third) and ($second > $first))) {
    $middle = $second;
}

# It must be the third one
else {
    $middle = $third
}

print "The middle input number is: $middle \n";
```

### 3.3 迭代语句——while、until 和 for

Perl 有几个用于指定迭代结构或循环的语句。控制语句集合重复执行的能力是计算机强大功能的基本来源。因此，迭代语句在所有编程语言中都是必不可少的。与其他编程语言一样，Perl 包含迭代语句，其中重复控制是一个布尔表达式（`while` 和 `until`）——以及一个基于计数器的控制（`for`）。Perl 还包含第三种循环语句 `foreach`，其中的迭代由给定数组中的元素数量控制。本节描述所有这些，除了 `foreach`，它将在第 4 章讨论数组时一并介绍。以下小节讨论最简单和最通用的迭代语句，即使用布尔表达式进行控制的语句。

#### 3.3.1 while 和 until 循环

`while` 语句的形式如下：

```
while (control expression) {
    # loop body
}
```

当执行 `while` 语句时，其控制表达式被求值，如果为真，则执行循环体。然后再次对控制表达式求值，如此反复，直到其求值为假。由于控制机制在循环体执行之前执行并影响语句执行流程，因此 `while` 循环被称为前测试循环。作为 `while` 循环的一个例子，考虑：

```
$sum = 0;

while ($sum <= 1000) {
    $sum += <STDIN>;
    ...
}
```

`until` 语句与 `while` 类似，只是控制表达式的值以相反的方式使用。例如，检查此代码：

```
$sum = 0;

until ($sum > 1000) {
    $sum += <STDIN>;
    ...
}
```

使用 `until` 形成的循环，与使用 `while` 形成的循环一样，都是前测试循环。

#### 3.3.2 for 语句

在许多情况下，由于循环的迭代次数在循环执行开始时已知，因此使用由计数器控制的循环会很方便。`for` 语句旨在构建控制依赖于计数器的循环。其一般形式为：

```
for (initial expression; control expression; increment expression) {
    # loop body
}
```

初始表达式和递增表达式通常是赋值语句或具有副作用的表达式，例如 `$count++`。`for` 的语义用 `while` 语句来解释最为简单。通用的 `for` 语句与以下代码具有相同的效果：

```
初始表达式;
while (控制表达式) {
    # 循环体
    递增表达式;
}
```

这段代码表明，`for` 与 `while` 一样，指定了一个前测试循环。以下代码从键盘获取 10 个数字并计算它们的总和：

```
$sum = 0;

for ($count = 0; $count < 10; $count++) {
    $value = <STDIN>;
    $sum += $value;
}
```

`for` 语句中的三个表达式都是可选的，但分号不是。如果省略控制表达式，它将被解释为真，使循环成为通常所说的无限循环。无限循环是一种迭代结构，其控制机制具有一个固定值，该值永远不会导致循环完成执行。此类循环通常在其循环体中包含一个提供跳出循环的语句。

`for` 语句中的三个表达式都可以是多个表达式或语句，用逗号分隔。在这种情况下，逗号是一个运算符。由逗号分隔的表达式和/或语句列表返回最后一个的值。例如，执行语句 `($a = 7, b = 10, c = -2)` 的值是 `-2`。请注意，`($a = 7, b = 10, c = -2)` 本身是有效的。`for` 语句中的逗号分隔表达式常用于 `for` 语句中初始化或递增变量。考虑以下代码：

```
for ($forward = 0, $backward = 10; $forward < 10; $forward--) {
    ...
```

如果我们想在初始表达式中包含两个语句，不能使用分号来分隔，因为它会被解释为初始表达式的结束。赋值语句有时用于 `for` 语句中的控制表达式。考虑以下循环：

```
for ($sum = 0; $value = <STDIN>; $sum += $value)
```

这个循环从输入读取数据。当 `<STDIN>` 获取到 EOF 时，它返回空字符串，表示假。经过 `chomp` 处理，循环会继续处理 EOF 之外的输入。我们可以在 `while` 语句中使用相同的表达式，如：

```
$sum = 0;

while ($value = <STDIN>) {
    $sum += $value;
}
```

对于 `for` 循环体中可以包含什么。特别是，`for` 表达式中出现的任何变量都可以在循环体中更改，尽管通常不是一个好意。并非所有循环都可以简单地用 `while`、`unless` 或 `for` 建模。下一节将描述构建更复杂循环的其他语句。

### 跳出代码块的方式——next、last 和 redo

Perl 提供了几个控制运算符 `last`、`next` 和 `redo`，它们可以出现在代码块中提供语句控制。最常见的是，这些运算符用于循环体，但它们可以用于任何代码块。当 `next` 运算符在代码块中带操作数出现时，其执行会将控制转移到代码块的末尾。如果 `next` 出现的代码块是 `while`、`until` 或 `for`，则控制会返回到循环的表达式。考虑以下代码：

```
while (substr($next_line = <STDIN>, 0, 1) ne "~") {
    if (length($next_line) < 5) {
        next;
    }
    $first4 = substr($next_line, 0, 4);
    if ($first4 eq "jack") {
        $count++;
    }
}
```

在这段代码中，每次迭代都会从键盘获取一个新字符串。当新字符串以 "~"开头时，循环终止。如果一行少于五个字符（意味着不能包含 "jack" 和换行符），则跳过该迭代的剩余部分。如果一行以 "jack" 开头，则 `$count` 递增。这是输入字符串不必进行 `chomp` 处理的少数之一。在循环体中出现被执行的 `last` 运算符会导致循环立即终止。控制被转移到循环体后的第一语句。在循环体中出现被执行的 `redo` 运算符会导致控制转移到循环体的顶部（而不是控制表达式）。迭代只是被重新执行，而不重新评估控制表达式。将循环中的 `next` 替换为 `redo` 将是一个坏意，因为它会导致无限循环`last`、`next` 和 `redo` 控制运算符通常与带标签的代码块结合。标签的形式是一个标识符，后跟一个冒号，如：

```
LOOP:
    while (...) {
    } ...
```

如果一个循环嵌套在另一个循环中，没有操作数的 `next`、`last` 和 `redo` 运算符只影响它们所在的循环（而不是任何外层循环）。有时让这些运算符影响某个外层循环会方便。这就是在循环上放置标签的目的。如果一个循环有一个标签，并且该标签出现在嵌套循环中的 `next`、`last` 或 `redo` 运算符的操作数，那么这些运算符会影响带标签的循环，而不是运算符所在的最小循环。例如，考虑以下代码：

```
OUTER:
    for ($out_index = 100; $out_index < 1000; $out_index += 100) {
        for ($in_index = 100; $in_index < 1000; $in_index += 100){
            $product = $in_index * $out_index;
            if ($product > 872e3) {
                last OUTER;
            } else {
                print "Next product is $product \n";
            }
        }
    }
```

当 `if` 控制表达式求值为真时，标记为 `OUTER` 的循环被终止。裸代码块（那些不是循环构造一部分的代码块）可以被标记，并且可以包含 `last`、`next` 或 `redo` 运算符。`last` 运算符可用于构建多选结构，如：

```
SWITCH: {
    if ($word eq "bob") {
        $bob++;
        last SWITCH;
    }
    if ($word eq "darcie") {
        $darcie++;
        last SWITCH;
    }
    if ($word eq "jake") {
        $jake++;
        last SWITCH;
    }
```

Perl 包含一个称为 `continue` 的特殊代码块，它可以跟任何代码块之后。`continue` 块与 `next` 运算符交互。由于它们相对少使用，我们将讨论 `continue` 块的目的和用法。

### 语句修饰符

在某些情况下，我们需要选择执行单个语句，而不是代码块。单个语句和 `do` 代码块后面可以跟修饰符。可能的修饰符有：

- `if` 表达式，
- `unless` 表达式，
- `while` 表达式，
- `until` 表达式，
以及 `foreach` 表达式。（参见第 5 章。）

注意，语句修饰符中的控制表达式不像相应的语句那样用括号起来。当修饰符跟在语句后面时，它们的语义几乎如所料。例如，考虑：

```
$bob++ if $word eq "bob";
$sum *= 2 until $sum > 1000;
```

修饰符有点惊讶的方面是，即使控制表达式在语句末尾，它也是首先求值的。`while` 和 `until` 修饰符构建后测试循环（每次迭代后执行）。`do` 代码块是一个前测试，如：

```
do {
    chomp($word = <STDIN>);
    $bob++ if $word eq "bob";
}
```

在这种形式中，`do` 不做任何事情。但是 `do` 代码块后面可以跟修饰符，如：

```
do {
    chomp($word = <STDIN>);
}
```

### 使用 `die` 终止执行

```perl
$bob++ if $word eq "bob";
chomp($word = <STDIN>);
} until $word eq "~";
```

当 `while` 或 `until` 作为 `do` 代码块修饰符时，该结构是一个后测试循环。控制表达式在块执行之后求值，而不是像普通的 `while` 和 `until` 结构以及单语句那样之前求值。因此，`while` 和 `until` 语句以及单语句修饰符是前测试的，但用于修饰 `do` 代码块时，它们是后测试的。考虑以下示例：

```perl
$sum = 1;
while ($sum < 1) {
    $sum *= 2;
}
$sum = 1;
$sum *= 2 until $sum < 1;
$sum = 1;
do {
    $sum *= 2;
} while $sum < 1;
```

前两个示例使 `$sum` 的值保持为 1。最后一个示例将其更改为 2，因为 `do` 块在控制表达式求值之前执行了一次。当你认为程序阅读者（包括你自己）会觉得该语句比控制表达式更重要时，才使用语句修饰符。

程序执行过程中可能会出现一些情况，你希望程序打印一条消息然后退出。在 Perl 中，使用 `die` 函数可以方便地完成此操作，该函数将在下一节中描述。`die` 函数接受参数列表。调用时，它会将参数连接在一起，打印到 `STDERR`，并终止程序执行。`STDERR` 是一个标准输出句句，其输出通常与 `STDOUT` 的输出位置相同。通常，`die` 有一个字符串字量参数，如：

```perl
die "The input file is empty!"
```

当执行 `die` 函数时，Perl 系统会将一些信息附加到其参数字符串的末尾。这通常包括程序名称、`die` 所在的行号和一个换行符。如果字符串中已包含换行符，则不会提供此信息。因此，`die` 的字符串参数通常不包含换行符。在许多情况下，当系统函数失败时会调用 `die`。系统错误号存储在 `$!` 中。因此，在许多情况下，$!` 会包含在 `die` 的字符串参数中。例如，考虑以下语句：

```perl
die "Input/output function error $!";
```

如果你希望程序在不提供任何信息的情况下终止，可以使用 `exit` 函数，该函数接受一个数字参数作为错误号。错误号 0 表示正常终止，如：

```perl
exit 0
```

### 关于输入的更多信息

既然我们已经讨论了 Perl 的大部分控制语句和语句修饰符，我们可以扩展第 2 章中介绍的输入操作的描述。在以下两个小节中，我们将讨论如何将行输入运算符用于控制表达式，以及如何通过命令行参数指定输入文件的名称。

#### 3.7.1 控制表达式中的行输入运算符

行输入运算符可用于 `while` 语句的控制表达式。当它是整个控制表达式时，从标准输入获取的值被赋给隐式变量 `$_`，该变量仅作为 `while` 语句、`for` 语句或 `while` 语句修饰符的控制表达式时，才是行输入运算符的目标。例如，考虑以下代码：

```perl
while (<STDIN>) {
    print;
    chomp;
    if ($_ eq "money") {
        print "I've finally found it!!! \n";
    }
}
```

在这段代码中，`$_` 的默认使用出现在三个地方：作为从 `<STDIN>` 输入行的隐式赋值目标、作为 `print` 运算符的操作数，以及作为 `chomp` 运算符的操作数。



`$_` 变量应仅用作临时变量。它绝不应被使用超过几行代码，因为它经常被不同的运算符和函数使用。隐式变量，尤其是 `$_` 的一个优点是，它们节省了在程序中发明和输入许多变量名的工作。Perl 新手有时认为 Perl 对 `$_` 的使用是神奇而神秘的，但它实际上只是一种实用设计。

### 3.7.2 命令行参数

在 UNIX 编程中，使用命令行参数为程序指定输入文件早已是一种常见做法。无论程序在何种计算机上运行，这种技术都可以在 Perl 程序中使用。命令行参数是出现在执行程序的命令其余部分之后的字符串，如：

```
% perl maximum.pl salaries.dat
```

在这种情况下，命令是在 Perl 程序文件 `maximum.pl` 上运行 `perl`，并指定参数 `salaries.dat`。虽然命令行参数通常是为程序指定的文件的文件，但它也可以指定程序的输出目标。因为输入文件和输出文件的指定在语法上没有区别，所以前面示例中的 `salaries.dat` 可以是两者中的任意一种。以这种方式指定数据输入文件的原因是为了允许程序用于不同的输入文件。如果没有这种机制，就需要在每次使用之间修改程序，或者从键盘读取输入文件的名称。

在 Perl 中，命令行参数被隐式重定向到一个特殊文件句柄，该句柄是行输入运算符的默认值。因此，输入行运算符 `<>` 从命令行指定的文件中读取行。以下循环从命令行指定的文件中读取输入行并打印它们：

```perl
while (<>) {
    print;
}
```

同样，特殊变量 `$_` 被用作控制表达式中隐式赋值的目标以及 `print` 的操作数。

如果指定了多个命令行参数，则文件将被逐一读取，直到读取最后一个文件的 EOF。如果未指定命令行参数，则空的 `<>` 从标准输入（键盘）获取行。

命令行参数在 Perl 中可以直接访问，因此它们可以用于远不止简单的提供输入文件名。这将在第 4 章中讨论。（当从 DOS 命令行运行 Perl 时，命令行文件指定也有效。）

### 3.8 一个示例

以下程序从命令行参数指定的文件中读取数字列表，找到并打印列表中第二小的数字及其在列表中的位置。当然，其真正目的是说明一些 Perl 控制语句。

```perl
# small
#     Input:  A text file containing one number per line, where
#             the file is taken from the command line
#     Output: The second smallest number in the file, along with
#             its position in the file, with 1 being the position
#             of the first number

# Get the first two numbers and initialize the smallest, its
# position, the second smallest, and its position
# If there are fewer than two numbers, print a message and die

if ($first = <>) {
    if ($second = <>) {
        if ($first < $second) {
            $min = $first;
            $pos_min = 1;
            $second_min = $second;
            $pos_2nd_min = 2;
        } else {
            $min = $second;
            $pos_min = 2;
            $second_min = $first;
            $pos_2nd_min = 1;
        }
    } else {
        "The file has only one line!";
    }
} else {
    die "The file is empty!";
}

$position = 2;

# Loop to read and process the rest of the file
while ($next = <>) {
    $position++;

    # If the new number is the new smallest, replace both the
    # smallest and the second smallest
    if ($next < $min) {
        $second_min = $min;
        $min = $next;
        $pos_2nd_min = $pos_min;
        $pos_min = $position;

    # If the new number is between the smallest and the second
    # smallest, replace the second smallest with the new number
    } elsif ($next > $min and $next < $second_min) {
        $second_min = $next;
        $pos_2nd_min = $position;
    }
}

print "The second smallest number is: $second_min \n";
print "The position of the second smallest is: $pos_2nd_min \n";
```

该程序的策略如下：首先，它从输入文件中获取前两个数字，并初始化存储文件中最小和第二小数字的变量的值，以及存储它们在文件中位置的变量。然后，它读取文件的其余部分，一次一个数字。任何新数字都可能是文件中的新最小数字或新第二小数字。因此，对于每个新数字，程序必须确定它是否必须成为存储文件中最小或第二小数字的变量的新值。每次更改存储最小或第二小数字的变量时，也必须更新存储被更改变量位置的变量。

### 3.9 调试器

程序员的重要工具之一是调试器。Perl 系统内置了一个调试器，它包含了大多数常见的调试器功能。当在执行 Perl 的命令行中设置 `-d` 开关时，程序将在调试器的控制下运行。例如，如果我们使用 `-d` 开关运行第 3.8 节的程序 `small`，Perl 会响应：

```

Emacs support available.

Enter h or `h h' for help.

  DB<1>
```

调试器已准备执行，但并未执行任何代码。示例中的倒数行表明，下一行要执行是程序 `small` 的第 12 行，这是程序的第一执行语句。最后一行（`DB<1>`）是调试器符，邀请用户调试器命令。`h` 会显示调试器帮助，每次显示屏。输入 `h` 后某个命令，会显示帮助信息。常用的调试器操作包括：控制执行、显示变量的值、显示源代码以及更改变量的值。使用 `s` 命令可以请求执行单行——例如：

```

```

在示例中，这将导致：

```

```

```

```

在第 17 行之前设置断点。例如：

```

DB<1)> b 39 [$pos_min == 2]

### 3.10 总结

Perl 拥有控制语句集合，但也包括一些常见的修饰和运算符。控制表达式的结果总是字符串或数字。空字符串代表假，其他字符串代表真。数值代表假，而其他数字代表真。Perl 有两组关系运算符，一组用于数字的比较运算符（数字用 `<=>`，字符串用 `cmp` 返回 1、0 或 -1）。Perl 包含了逻辑运算符 `&&`、`||` 和 `!`，以及一组低优先级运算符 `and`、`or` 和 `not`。所有复合语句用花括号分隔，都可以是块（这意味着它们可以定义局部变量）。控制语句都用花括号分隔，即使只有一条语句。反向逻辑形式 `if`（名为 `unless`）和一个反向逻辑形式 `while`（名为 `until`）。`while` 和 `until` 都形成循环。`for` 语句是一个强大而灵活的控制语句，用于计数循环。Perl 有三个在循环体中使用的运算符：是 `next`（控制到循环体的末尾）、`last`（强制跳出循环）和 `redo`（导致当前迭代重复）。这三个运算符可以包含一个标签作为操作数，以指定的目标循环。五个语句修饰符附加在单条语句末尾：`if`、`unless`、`while`、`until` 和 `foreach`。在所有这些情况下，修饰符都会执行。但是当附加到 `do` 块时，它们在 `do` 块之后执行。`die` 函数用于打印消息并终止执行。当不需要消息时，可以使用 `exit` 函数达到相同的目的。行运算符 `<>` 可以作为赋值的右侧出现，该赋值作为 `while` 和 `for` 语句中的控制表达式。当它出现时，只有当输入返回 EOF 字符时才假。行运算符是整个表达式时，使用隐式变量 `$_`。这个变量也是 `print` 和 `chomp`（以及许多其他函数，其中将在本书后面讨论）的默认操作数。行是从命令行中指定的文件获取。如果没有命令行参数，从 STDIN（键盘）获取行。

### 3.11 练习

Perl中有三种数据类型：标量、数组和关联数组（或哈希）。第2章讨论了标量；本章讨论数组；第5章讨论哈希。

几乎所有编程语言都支持数组。然而，Perl的数组比其他常见编程语言的数组灵活得多。这种增加的灵活性源于数组与其属性的后期绑定。简单来说，Perl数组更容易适应程序的需求。它们会根据需要隐式增长长度。它们也可以在程序执行期间缩小。其元素的类型也不是一成不变的。这些特性相当于放宽了对其使用的限制和约束，使其易于使用。此外，Perl提供了一系列函数和运算符，用于处理数组及其元素的许多最常见操作。

### 4.1 数组简介

数组是线性数据结构，其元素通过带下标的变量引用。Perl数组存储标量值的列表。回想一下，标量值可以是字符串、数字或引用。数组没有类型，除了数组本身。一个数组可以包含全部数字、全部字符串、全部引用，或这三种值的任意组合。

Perl数组没有定义任何特定的大小。它们可以是空的，也可以占用机器上所有可用内存。它们会根据需要隐式增长，并且可以随时缩小。缺乏特定的元素类型和大小限制，使得Perl数组比大多数编程语言的数组更灵活、更强大——这是Perl“无必要限制”设计哲学的又一个结果。

在进一步讨论数组之前，我们必须先研究列表和列表字面量，它们用作数组字面量。

### 4.2 列表字面量

`列表`是标量值的有序序列。`列表字面量`是程序中列表的规范表示。列表字面量通常用括号分隔。¹ 最简单的列表字面量是由标量字面量组成的列表，用逗号分隔并用括号括起来。列表字面量的元素也可以标量变量和表达式。例如，考虑以下内容：

| 列表字面量 | 描述 |
| :--- | :--- |
| (5) | 一个包含一个数字的列表。 |
| () | 空列表。 |
| ("apples", "pcs") | 一个包含两个字符串的列表。 |
| ("me", 100, "you", 50) | 一个包含两个字符串和两个数字的列表。 |
| ($sum, "Sum") | 一个包含一个由变量指定的元素的列表。 |
| (2 * $total, "!" x 20) | 一个包含由表达式指定的值的列表。 |
| (qw(bob carol tedf)) | 一个元素隐式引用的列表。 |

`范围运算符`（`..`）用于列表字量中指定标量。例如，考虑以下等价关系：

| 列表字面量 | 等价列表 |
| :--- | :--- |
| (0 .. 6) | (0, 1, 2, 3, 4, 5, 6) |
| (1.5 .. 7) | (1.5, 2.5, 3.5, 4.5, 5.5, 6.5) |
| (5 .. 3) | () |
| ('a' .. 'z') | 包含26个字符的列表 |
| ('aa' .. 'zz') | 包含676个元素的列表 |

### 4.3 数组

`数组`是其值的列表。数组变量以`@`开头，使它们处于不同的命名空间。`$list`和@list`之间没有关联。与标量变量一样，数组不需要声明。因为数组存储列表，所以其元素始终是标量；其长度是未初始化的数组的值为空。

如果赋值语句的左侧（目标）是一个数组变量（带下标），则无论右侧表达式如何（尽管常见的是数组或列表字量），数组都会作为一个整体赋值。如果右侧元素多于目标数组，则数组会扩展到右侧的大小。如果目标数组元素多于右侧，则多余的元素设置为`undef`。如果将标量值赋予数组，则数组设置为包含该值的单个元素。考虑以下数组示例：

```
@a = (2, 4, 6); # @a 有三个元素
@a = ('a', 'b', 'c', 'x'); # 现在 @a 有四个元素
@a = (4); # @a 仍然有四个元素，但最后三个是 undef
@a = undef; # @a 是 ()
```

如果将数组赋予标量变量，则数组的长度赋给目标。例如：

```
@names = ("mary", "jo", "ann");
$girls = @names;
```
中，`girls`被设置为3。数组赋值可以是表达式的一部分。一个简单的例子是：

```
@friends = @girl_friends = ("Peggy Sue", "Mary Lou", "Pompadou");
```

一个不包含表达式或字量（即只有变量）的列表字面量可以用数组赋值的目标。例如，考虑以下语句：

```
($a, $b) = (2, 4);
```
此语句将2赋给`a`，将4赋给`b`。如果目标列表中的变量少于右侧的元素，则多余的标量被忽略。例如，如果我们有：

```
($a, $b) = (2, 4, 6); # 6被忽略
```

如果目标列表中的变量多于右侧的标量，则多余的变量设置为`undef`。例如：

```
($a, $b, $c) = (2, 4); # $a被赋值为2，$b被赋值为4，$而$c被赋值为undef
```

贪婪行为：如果目标列表中的某个元素是数组名，它会“吞噬”右侧列表的剩余部分。例如，在：

```
($a, @list, $b) = ("broncos", "chargers", "raiders", "beatles");
```
中，`a`被赋值为"broncos"，@list`获取右侧列表的其余部分，而`b`被赋值为`undef`。由于这种贪婪行为，在赋值语句中，数组名应出现在目标列表的末尾位置。

通过在列表中同时使用标量和数组作为赋值目标，可以方便地移除数组的第一个元素并将其赋值给标量变量，例如：

```
($first, @list) = @list;
```
如果@list的值为("able", "baker", "charlene")，这会将`first`设置为"able"，并将@list设置为("baker", "charlene")。

如果数组名出现在列表字面量中，且不是赋值语句的目标，它会被展开为其标量值的列表。例如，如果@list的值为(2, 4, 6)，

```
(1, @list, 10) # 结果为 (1, 2, 4, 6, 10)
```

通过将空列表字面量`()`赋值给数组来将其设置为空，例如：

```
@list = ();
```

也可以使用`undef`操作符将数组设置为空：

```perl
undef @list;
```

如果你将`undef`赋予数组，例如：

```perl
@list = undef;
```
你得到的不是一个空数组；而是一个包含一个元素的数组，该元素是`undef`。尽管Perl没有多维数组，但可以通过存储引用列表的数组来模拟。

### 4.4 引用数组元素

可以通过数组名后附加下标来赋值和引用数组。下标由`[]`定。下标由标量值指定，必要时会被转换为整数。数组的第一个下标都是零，因此最高下标比长度小一。例如：

```perl
@list = (2, 4, 6);
$list[0] = 10; # 修改元素
```

考虑以下代码：

```perl
$list = "Darcie";
$list[5] = 17;
$sum += $list[5]; # 自动扩展
```

与大多数语言不同，使用负下标值引用元素是有效的，下标不会导致错误，而是用作从数组高端索引，将最后一个元素视为-1。例如，考虑以下代码的输出为：

```
Scalar: Darcie
Element: 10
List: 2
```

数组名可以出现在列表字面量中，既可以赋值的目标，也可以作为右侧。例如：

```perl
($list[0], $list[1]) = ($list[1], $list[0]); # 交换前两个元素
```

这种交换适用于任何标量，例如：

```perl
($my_salary, $your_salary) = ($your_salary, $my_salary);
```

访问超出最后一个元素的数组会返回`undef`。例如：

```perl
@highs = (92, 84, 79, 85);
$Saturday_hi = $highs[6]; # 返回undef
```

有时知道数组最后一个元素的索引很方便。隐式变量`#list`具有最后一个元素的索引。例如：

```perl
print "The last index of @list is $#list\n";
```

这个最后一个索引名称也可将数组设置为空：

```perl
$#list = -1;
```

如果数组在执行期间多次增长，在程序开始时将其扩展到预期的最大长度，运行会更快。例如，假设数组预期最终增长到1000个元素，可以将其最高索引设置为999：

```perl
$list[999] = 0;
$#list = 999;
```

### 4.5 一个示例

下面的示例程序说明了数组的特性。在此示例中，将新名称插入从文件读取的已排序数组中。

```perl
# merge
# 输入：从命令行指定的文件读取的按升序排列的名称列表。
#        同时，从键盘输入第二个无特定顺序的名称列表
# 输出：有序列表（来自文件），其中包含来自第二个列表（来自键盘）的所有名称，
#         这些名称已进行排序。

my $file = $ARGV[0] or die "Usage: $0 <file>\n";
open( $FH, '<', $file ) or die "Could not open $file: $!";
my @list;
while ($line = <$FH>) {
    chomp $line;
    push @list, $line;
}
close $FH;

print "Enter names (or 'done'):\n";
while ($line = <STDIN>) {
    chomp $line;
    last if $line eq 'done';
    my $inserted = 0;
    for (my $i = 0; $i < @list; $i++) {
        if ($line < $list[$i]) {
            splice(@list, $i, 0, $line);
            $inserted = 1;
            last;
        }
    }
    if (!$inserted) {
        push @list, $line;
    }
}

print "Sorted list:\n";
print join("\n", @list), "\n";
```

其计算结果为 `@list` 的长度。标量上下文也可以通过伪函数`scalar`显式强制，其目的正是如此。这对于打印数组的长度很方便，如

```
print "Length of \@list is: ", scalar(@list), "\n";
```

其中`print` 接受一个字符串列表作为其操作数，因此函数中分隔操作数三个元素的逗号只是起到分隔元素的作用；它们在任何意义上都不是运算符。我们在这个例子中使用了`print` 的这种列表形式参数，因为我们必须将对`scalar` 的调用放在字符串字面量之外。（否则它不会被调用。）

列表字面量不能被强制到标量上下文。如果在标量上下文中使用包含逗号的列表字面量，例如赋值给标量变量的右侧，那么列表字面量的值是列表的最后一个元素。这是因为由逗号分隔的表达式列表的最后一个元素是整个表达式的值。例如，在

```
$x = (7, 12, 27, 5);
```

中，`$x` 被设置为 5。但是，如果列表字面量是用引号运算符构建的，如

```
$x = qw(a b c d);
```

那么`$x` 的值是列表中的元素数量——在这种情况下是 4。

实际上，没有显式的方法可以强制任何东西进入列表上下文，因为任何需要列表的函数或运算符已经强制标量参数或操作数成为列表。

某些运算符在标量和列表上下文中都有效。例如，我们已经在标量上下文中使用了行输入运算符，如

```
$next = <STDIN>;
```

当它出现在标量上下文中时，此运算符返回键盘输入的下一行。我们可以通过将行输入运算符赋值给数组来将其置于列表上下文中，如

```
@input = <STDIN>;
```

在这种情况下，所有键盘输入行都被读取并分配给 `@input` 数组，每个元素一行。另一个可以在标量或列表上下文中使用的运算符示例是`chomp`，如第 4.9 节所述。

## 4.8 foreach 语句

在第 3 章中，我们提到 Perl 中有一个迭代语句，其控制基于数组或列表中的元素数量。`foreach` 语句实际上只是 `for` 语句的另一种形式。使用`foreach` 这个词是因为它稍微更具内涵。`foreach` 的一般形式是

```
foreach [scalar_variable] (list literal or array name) {
    ...
}
```

`scalar_variable` 周围的方括号表示它是可选的。如果省略，则使用`$_`。标量变量成为列表或数组元素的别名，一次一个，用于循环体的迭代（别名，我们指的是你所期望的：它是其别名的任何东西的第二个名称。）例如，

```
foreach $age (@ages) {
    $age++
}
```

会递增 `@ages` 的每个元素。`foreach` 中的标量变量是一个特殊变量，与任何碰巧同名的程序变量不同。它仅限于循环体内部。例如，考虑以下语句：

```
$count = 17;

foreach $count (1, 3, 5, 7, 9) {
    $sum += $salaries[$count];
}

print "\$count is: $count \n";
```

这里的`print` 语句显示 17，但循环中 `$count` 的值是 9。范围运算符通常用于指定 `foreach` 语句中的列表，如

```
$sum = 0;

foreach $index (0..99) {
    $sum += $list[$index];
}
```

`foreach` 语句可以被标记，拥有`continue` 块，并包含任何控制运算符`next`、`last` 或`redo`。`foreach` 循环通常比用 `for` 编写的等效循环快大约两倍。

`foreach` 可以用作语句修饰符。其一般语法是

Statement foreach expression,

其中 expression 是列表字面量或数组。隐式变量`$_` 被设置为表达式中的值，如

```
$sum = 0;
$sum += $list[$_] foreach (0..99);
```

我们现在完成了关于如何使用普通标量运算符操作单个数组元素的讨论。下一小节描述一些操作数组和列表及其元素的 Perl 函数（或运算符）。

### 4.9 列表运算符

Perl 包含一组操作列表和数组的运算符。因为数组的值是一个列表，我们通常将这些称为列表运算符。回想一下，运算符通常可以被视为函数。

### 4.9.1 reverse 运算符

`reverse` 运算符的作用如其名所示，反转其列表操作数的元素顺序。例如，

```
@names = ("Al", "Bob", "Jake", "Ezekiel");
@rnames = reverse @names;
print "@rnames \n";
```

显示

```
Ezekiel Jake Bob Al
```

`reverse` 运算符有时用于反转 `foreach` 访问的元素顺序，如

```
foreach $employee (reverse @employee_list) {
    print "$employee\n";
}
```

如果在标量上使用`reverse`，它会将标量强制转换为字符串（如果必要），反转其字符顺序，并返回结果。例如，如果 `$name` 是 "adam",执行

```
$rname = reverse $name;
```

后，`$rname` 的值是 "mada"。请注意，`reverse` 操作数的值（在我们的例子中是 `$name`）不受此反转的影响。

### 4.9.2 sort 运算符

`sort` 运算符对字符串列表进行排序。例如，

```
@names = ("eve", "adam", "devil", "worm");
@sorted_names = sort @names;
print "Sorted list of names is: @sorted_names \n";
```

显示

```
Sorted list of names is: adam devil eve worm
```

如果不慎对数字列表使用`sort`，它们会被强制转换为字符串并作为字符串排序，这可能不是你想要的。例如，

```
@list = (42, 68, 10, 5, 103);
@sorted_list = sort @list;
print "Sorted list is: @sorted_list \n";
```

显示

```
Sorted list is: 10 103 42 5 68
```

`sort` 运算符用于将各种列表按我们选择的顺序排序，但我们推迟讨论这种形式的`sort`直到第 6 章，因为它需要一些 Perl 函数。

## 9.3 重复操作符

第2章介绍的重复操作符（`x`）同样适用于列表。例如，

```
@valentine = ("I love you!") x 5;
```

这创建一个包含五个元素的数组，每个元素都是 "I love you!"可以使用重复操作符设置数组，如

```
@list = (0) x @list;
```

这里右侧 `@list` 表示其长度，因为`x` 操作数是一个标量。

## 9.4 chop 和 chomp 操作符

`chop` 和 `chomp` 操作符既接受标量，也可以接受列表作为操作数。当操作数是列表时，`chomp` 会移除列表中所有元素，返回移除的总数。当操作数是列表时，`chop` 会移除列表中最后一个元素，返回移除的字符。例如，

```
@list = ('little', 'green', 'apples');
chop(@list);
```

会将 ('little', 'green', 'apple') 放入 @list，并返回 's'。注意，当操作数是标量时，`chomp` 会移除行符。

## 9.5 splice 函数

`splice` 函数为修改数组提供了强大的工具。它可以用来从数组中移除一个切片，选择性地用不同数量的新元素替换移除的元素。在大多数语言中，从数组内部移除或添加元素是复杂的。`splice` 函数接受变数量的参数，其中只有前两个是必需的：一个数组和一个相对于数组基的偏移量。仅给定这两个参数时，`splice` 会移除从指定偏移量到末尾的所有元素。例如，

```
@list = (2, 4, 6, 8, 10);
splice (@list, 3);
print "@list is now: @list";
```

输出

```
@list is now: 2 4 6
```

`splice` 的可选可选参数（如果提供）是要从数组中移除元素数量。例如，

```
@list = (1, 2, 3, 4, 5);
@new = (7, 6);
splice (@list, 2, @new);
print "@list is now: @list";
```

输出

```
@list is now: 1 2 7 6 5
```

当调用`splice` 指定不移除元素时，这也适用，如

```
@list = (1, 2, 3, 4, 5);
@new = (7, 6);
splice (@list, 2, 0, @new);
print "@list is now: @list";
```

输出

```
@list is now: 1 2 7 6 3 4 5
```

最后，调用`splice` 可以指定任意数量的标量来代替第四个数组参数。在这种情况下，`splice` 的行为就像指定了一个内容为这些标量的数组一样。例如。

```
@list = (1, 2, 3, 4, 5);
splice (@list, 2, 9, 8, 7);
print "@list is now: @list";
```

输出

```
@list is now: 1 2 9 8 7 5
```

## 4.9.6 pop 和 push 函数

在 Perl 之外的世界，哈希有时被称为关联数组。它们有时也被称为哈希表，Perl 用户将其简称为哈希。哈希是一种数据结构，它以一种允许非常快速地存储和检索特定元素的方式来存储无序数据。它们通常用于存储动态数据列表（在使用过程中会增长和收缩的列表），这些列表必须允许快速访问列表中的任何特定元素。尽管哈希已经存在很长时间，但 Perl 是唯一广泛使用哈希的语言。

### 5.1 哈希的结构

哈希变量名称以百分号（`%`）开头，因此它们与标量一样，有自己的命名空间。与数组一样，哈希不需要声明，可以根据需要增长，并且随时缩小。哈希变量可以被赋予偶数长度的列表。

```
%hasharies = ("key1" => "value1", "key2" => "value2");
```

将 `undef` 赋值给哈希*不会*将其设置为空。相反，它将其设置为有一个元素，即 `undef`。除了可能不是你想要的之外，用任何奇数个元素构建哈希都会从 perl 生成警告。

```
%hash = ();
undef %hash;
```

哈希变量不会在引号字符串中进行插值。如果它们会，这将在 `printf` 的格式代码参数中使用 `%` 冲突。所以：

```
print "%hash \n";
```
显示 `%hash` 而不是该哈希中的值。

如果你碰巧使用裸（非引用）哈希变量作为 `print` 的参数，如：

```
print %hash;
```
哈希中的所有标量、键和值，将一起显示（没有分隔空格）。

哈希的切片通过花括号中的键列表指定。这样的切片是与指定键关联的值的数组。例如：

```
@some_salaries = @salaries ("Bill", "Billiam");
```

### 5.2 哈希运算符

哈希的各个值可以通过“下标”访问，使用花括号（不是方括号，如数组）中的键。例如：

```
$salaries{"Billy"}
```
是 `43000`。

同样，可以使用此机制插入新值和旧值，例如：

```
$salaries{"Willie"} = 51950;
```

如果引用哈希元素的下标是裸字符串，它会被隐式引用。例如：

```
$salaries{Billie} += 500;
```
等同于：

```
$salaries{"Billie"} += 500;
```

`=>` 符号在列表面量中代替逗号，用于指定哈希使其具可读性，如下：

```
%hash = ("bob" => 42, "carol" => 40);
```

如果 `=>` 的左操作数是裸字符串，它会被隐式引用。如果左操作数是列表，例如 `print`，如：

```
print @hash => "yes";
```
它将被计算简单的字符串。

`keys` 运算符返回哈希的键。例如：

```
@keys = keys %hash;
```

`values` 运算符返回哈希的值。例如：

```
@vals = values %hash;
```

`sort` 运算符对哈希的键进行排序。例如：

```
@sorted_keys = sort keys %hash;
```

`reverse` 运算符反转哈希的顺序。例如：

```
@reversed_keys = reverse keys %hash;
```

`splice` 函数可以删除并替换哈希。例如：

```
splice(@hash, 1, 1, "new_value");
```

`push` 运算符将操作数放在哈希的末尾。例如：

```
push %hash, "newkey" => "value";
```

`pop` 运算符移除哈希的最后一个元素。例如：

```
$last = pop %hash;
```

`unshift` 运算符类似于 `push`，但将操作数放在哈希的左端。例如：

```
unshift %hash, "key" => "value";
```

`shift` 运算符移除哈希的第一个元素。例如：

```
$first = shift %hash;
```

`split` 运算符根据指定分隔符将字符串分割成子字符串。例如：

```
@parts = split / /, $string;
```

### 5.4 引用

接下来我们讨论第三种标量值——引用，它与其他编程语言中的指针相关。许多应用程序需要比数组和哈希更复杂的数据结构。这些可以通过使用 Perl 提供的常量指针（通常称为引用来定义和操作。引用是值为地址的标量变量。这些地址可以是其他命名或匿名变量（字面量），甚至是子程序，我们将在第 6 章讨论。匿名变量没有名称，只能通过引用来使用。

#### 5.4.1 硬引用

用于存储引用的变量通过反斜杠运算符设置为命名变量的地址。例如，考虑以下代码：

```
$sum = 0;
$ref_sum = \$sum;
@list = (1, 3, 5, 7);
$ref_list = \@list;
```

变量 `$ref_sum` 和 `$ref_list` 现在分别具有变量 `$sum` 和 `@list` 的地址。这类引用称为硬引用。引用也可以指向字面量和函数。

当字面量的地址被赋值给一个标量变量时，该字面量就成为匿名变量的值。字面量列表的地址通过将元素括在方括号中获得，如

```
$ref_list = [1, 3, 5, 7];
```

`$ref_list` 现在具有编译器为存储右侧列表字面量而创建的存储空间的地址。该列表值是一个匿名变量。

字面量哈希值的地址通过将值括在花括号中获得，如

```
$ref_hash = {
    'Bob' => '42',
    'Jake' => '12',
    'Darcie' => '11',
};
```

标量字面量的地址通过在字面量前加上反斜杠获得，如

```
$ref_pi = \3.14159;
```

解引用是引用变量上一个基本且常用的操作。

#### 5.4.2 解引用

引用有两个关联的值：通常的值（即一个地址）和该地址的值。指定地址处值的过程称为解引用。未引用的变量使用的是其地址。解引用可以是隐式的（意味着处理器确定何时需要解引用）或显式的（意味着程序员使用额外的运算符来指定解引用）。在 Perl 中，所有解引用都是显式的，尽管有几种方式指定解引用。

指定解引用的一种方式是将引用变量放在名称中。因此，如果引用的名称是 `$ref_sum`，那么 `$$ref_sum` 指定了 `$ref_sum` 的值。例如：

```
$sum = 17;
$ref_sum = \$sum;
print "The sum is: $$ref_sum \n";
```

显示
```
The sum is 17
```

另一方面，

```
print "The sum is: $$ref_sum \n";
```

显示
```
The sum is: SCALAR(075dc)
```

这表示的值是一个标量，其十六进制地址为 `75dc`，这是在特定情况下的。指定数组和哈希引用的另一种方式是使用箭头运算符（`->`）。箭头运算符放置在数组或哈希引用之间。例如，以下两个赋值语句是等效的：

```
$$ref_list[3] = 17;
$ref_list -> [3] = 17;
```

同样，以下两个哈希赋值是等效的：

```
$$ref_hash{'Bob'} = '42';
$ref_hash -> {'Bob'} = '42';
```

除了硬引用，Perl 还允许对命名变量使用软引用。

#### 5.4.3 软引用

存储字符串（该字符串是已定义变量的名称）的标量变量可以用引用。例如，在

```
$sum_name = "sum";
$$sum_name = 17;
```

中，变量 `$sum` 被设置为 17。这种引用称为软引用，有点危险，因为很容易意外创建（例如只需引用名称，结果得到现有的标量）。为避免这种情况，可以告诉编译器禁止引用，这是通过向编译器发送 pragma 来完成的。Pragma 不是语句——它们只是向编译器传达指令。

```
use strict 'refs';
```

告诉编译器将封闭块中的所有引用标记为错误。正如我们在章开头所述，引用对于构建比数组和哈希更复杂的数据至关重要。

### 5.5 嵌套数据结构

在 Perl 中，二维数组可以实现为数组引用的数组。例如，可以构造一个指向匿名数组引用的数组，如下：

```
@mat = (
    [1, 3, 5],
    [7, 9, 11],
    [13, 15, 17],
);
```

注意，`@mat` 是一个数组引用的数组；它本身不是引用。围绕数字列表的方括号创建了这些引用。另一种方式是指引用数组的引用。指向引用数组和行本身都可以匿名的。在这两种情况下，方括号都创建了引用，如：

```
$ref_mat = [
    [1, 3, 5],
    [7, 9, 11],
    [13, 15, 17],
];
```

记住，列表是用圆括号创建的，就像 `@mat` 数组一样。引用是用方括号创建的，就像 `$ref_mat` 一样。因此，`$ref_mat` 是一个指向匿名数组的匿名数组的引用。它不是一个数组。

假设我们想要作为二维数组行的已经存在，例如：

```
@row1 = (1, 3, 5);
@row2 = (7, 9, 11);
@row3 = (13, 15, 17);
```

在这种情况下，可以使用以下方式定义指向这些行的引用的数组：

```
@mat = (\@row1, \@row2, \@row3);
```

数组的数组（例如 `@mat`，而不是指向数组引用的 `$mat_ref`）的元素可以通过使用下标和箭头运算符来引用，如下所示：

```
print "The (2,3) element is: $mat[2] -> [3] \n";
```

在方括号或花括号表达式之间，箭头运算符是可选的。因此，以下语句与前面的版本等效：

```
print "The (2,3) element is: $mat[2][3] \n";
```

对于指向引用数组的数组的引用，例如前面提到的 `$ref_mat`，赋值语句

```
$ref_mat -> [2][2] = 17;
$$ref_mat[2][2] = 17;
```

是等效的，尽管第一个更容易理解。第二个利用了 `$` 解引用运算符的优先级高于下标周围的方括号这一事实。这意味着 `$$ref_mat` 被解释为指向二维数组的引用，而不是将 `$ref_mat[2]` 解释为指向一维数组的引用。请记住，在这两个赋值语句中，下标对之间都有一个隐含的箭头运算符。

在 Perl 中，与某些其他编程语言不同，指向引用数组的数组与指向引用数组的数组的引用（换句话说，指向二维数组引用）是不可换的。Perl 二维数组的一个特点是它们在必要时会增长。考虑以下代码：

```
$num_rows = <STDIN>;

    @row = split /, $temp;
    $mat[$row] = [ @row ];

```
foreach $ref_row ( @mat ) {

### 5.6 另一个示例

矩阵是一个二维数组，其中所有行具有相同数量的元素。以下简单程序从文件中读取两个矩阵，将它们相加，然后显示和矩阵，说明了矩阵的使用，通过数组的数组实现：

```
# matadd
# 输入：两个数字，$num_rows 和 $num_cols，后跟两个具有这些维度的矩阵，
#        每行一个，从命令行指定的文件中读取。
# 输出：两个输入矩阵之和的矩阵

$num_rows = <>;
$num_cols = <>;

# 获取两个矩阵
foreach $row (0 .. $num_rows - 1) {
    @arow = split /, <>;
    $mat1[$row] = [ @arow ];
}

foreach $row (0 .. $num_rows - 1) {
    @arow = split /, <>;
    $mat2[$row] = [ @arow ];
}

# 计算和矩阵
foreach $row (0 .. $num_rows - 1) {
    foreach $col (0 .. $num_cols - 1) {
        $sum_mat[$row][$col] = $mat1[$row][$col] + $mat2[$row][$col];
    }
}

    print "@$ref_row \n";
}
```

此程序说明了嵌套数据结构的最简单用法。实际上，代码看起来非常像其他常见编程语言的代码。

### 5.7 总结

哈希，或关联数组，是一种线性数据结构，其中元素在逻辑上成对收集，每对的第一个分量是键，第二个是标量值。哈希与数组的不同之处在于，元素访问是通过键（始终是字符串）而不是数字下标，并且对元素不像数组那样有序。哈希变量的名称都以百分号开头，以区别于标量和数组变量。列表字面量用作引用。



子程序正如其名所示：它是一个代码单元，但不是一个完整的程序。子程序用于将程序设计和实现为处理单元的集合，通常是一个层次结构，每个单元定义程序整体处理的一部分。它们通过允许开发者一次专注于完整程序中相对较小的部分，而不是需要将整个程序作为一个整体来考虑，从而使大型复杂程序的开发成为可能。

虽然那些每次调用时总是执行完全相同操作的子程序有时很有用，但当子程序可以被参数化时，它们的价值会大大增加。在后一种情况下，子程序可以始终执行相同的过程，但每次执行时可能处理不同的数据。

在 Perl 中，所有子程序都以函数的形式存在。函数通过程序或另一个函数中的调用来执行其代码。该调用还可以向函数提供实际参数值，函数在其计算中使用这些值。大多数函数根据其计算返回值。

`函数定义`指定了函数的名称，以及其操作的完整描述，形式为一个代码块。在 Perl 中，函数的参数数量、参数类型以及返回值的类型并未明确说明。`函数声明`指明指定的名称是一个函数，但不包含定义其操作的代码。函数声明用于告知编译器某个名称是一个函数，并且其定义将在其他地方提供。

Perl 函数可以定义在程序中的任何位置，但不能在另一个函数的定义内部。一些程序员将所有函数定义放在程序的末尾；其他人，包括我们，则将它们放在开头。这对 Perl 编译器来说没有问题，因为它可以正常处理在函数定义出现之前就调用该函数的情况。

## 6.2 无参数函数

我们现在可以开始讨论 Perl 函数，从最简单的形式开始。本节描述无参数函数的定义、声明和直接调用的形式。所介绍的大部分内容也适用于有参数的函数。

### 6.2.1 定义与声明

Perl 函数定义的语法是：

```perl
sub 函数名 代码块
```

其中代码块包含函数被调用时执行的 Perl 语句。例如，考虑以下代码：

```
sub print_header {
    print "\n Program Output \n\n";
}
```

当被调用时，`print_header` 会跳过一行，显示 "Program Output"，然后再跳过一行。

`print_header` 的声明如下：

```perl
sub print_header;
```

### 6.2.2 直接函数调用

本小节解释直接函数调用和函数声明的目的。间接函数调用将在第 6.6 节讨论。函数调用是一个表达式，其值是被调用函数返回的值。在某些情况下，函数返回的值对调用者没有意义，此时函数调用可以作为一条独立的语句。这样的调用由函数名后跟空括号组成，如：

```
print_header();
```

编译器之前已经看到其定义或声明的函数可以被视为列表运算符。例如，在编译器看到 `print_header` 的定义或声明之后，可以用以下方式调用它：

```perl
print_header;
```

因此，如果对函数的调用出现在该函数的定义之前，在程序开头（或调用之前的任何位置）放置一个函数声明，就可以使用这种更简单的形式来调用它。在本书的所有示例中，我们将用户编写的函数作为函数（带括号）来调用，而不是将它们视为列表运算符。这使我们无需担心被调用的函数是否已预定义或声明。当然，如果函数返回的值对调用者有意义，则不能将其作为独立表达式调用（因为返回值将没有去处）。这样的调用必须是表达式的操作数，或作为赋值语句的右侧。例如，在以下语句中，`fun` 和 `sumer` 都返回值：

```perl
$result = 2 * fun() + 1;
$sum = sumer();
```

从技术上讲，函数名前需要加一个 `&` 符号，但在大多数情况下，`&` 符号是可选的，通常不写。第 6.6 节讨论了一种必须使用 `&` 符号的情况。

### 6.2.3 函数返回值

函数返回的值可以在函数中通过两种方式指定。最清晰和最灵活的方式是包含对预定义函数 `return` 的调用。`return` 函数接受一个表达式作为参数，并将该表达式的值返回给调用 `return` 的函数的调用者。第二种方式是，如果函数的执行没有以调用 `return` 结束——即如果执行到达了函数的末尾——则返回的值是最后计算的表达式的值。以下两个函数 `two_pi_1` 和 `two_pi_2` 是等价的：

```perl
$pi = 3.14159;
sub two_pi_1 {
    return(2 * $pi);
}

sub two_pi_2 {
    2 * $pi;
}
```

## 6.2.4 函数调用的上下文

函数调用（标量或列表）决定了返回值的求值，无论该值是否通过 `return` 返回。例如，考虑以下程序：

```perl
sub sub1 {
    (1, 3, 5);
}

$scalar = sub1(); # 标量上下文
print "Scalar value from sub1: $scalar";

@list = sub1(); # 列表上下文
print "List value from sub1: @list";
```

运行此程序的结果
```
Scalar value from sub1: 3
List value from sub1: 1 3 5
```

函数通过 `want` 来确定其调用的上下文。如果调用的上下文是列表，则返回 `true`；如果是标量，则返回 `false`。

## 6.3 变量的作用域和生命周期

在讨论带参数函数之前，我们必须描述局部变量。反过来介绍变量的作用域和生命期的概念。作用域是一个空间概念；生命周期是一个时间概念。

到为止，我们在示例中使用的所有变量都是隐式定义的，它们成为全局变量，其作用域是整个文件。全局变量的生命周期是整个程序。全局变量不适合在函数内部使用。全局变量的问题在于可能与函数外部变量发生冲突。根本办法是在编写函数时使用局部变量不同的变量名，尤其当程序的不同部分由不同的程序员编写时。

### 6.3.1 局部变量

Perl 提供了两种创建局部变量：`my` 和 `local`。我们首先讨论在函数中使用 `my` 定义变量。`my` 定义的变量具有函数的作用域。它的生命周期从执行 `my` 声明开始，到该块结束。为了可读性（和合理性），所有函数的 `my` 声明都应出现在函数的开头。这使它们易于找到，并确保它们的作用域是整个函数。

`my` 变量的另一个优点是访问它们比访问全局变量稍快。因为 `my` 是可执行的，所以它几乎不应该放在循环中。如果 `my` 确实出现在循环中，每次迭代都会创建它定义的变量的新版本，这很少有用。

定义非全局变量的第二种方式是使用 `local` 声明。使用 `local` 定义的变量与使用 `my` 定义的变量具有相同的生命周期，但它们的作用域不同。我们将使用 `local` 定义的变量称为半局部变量，因为它们的作用域更大。它们在定义它们的块中可见，也在从该块调用的任何函数中可见，以及从这些函数调用的任何函数中可见，依此类推。这被称为*动态作用域*。因为动态作用域使程序难理解，所以不建议使用。

任何块都可以包含 `my` 声明。当块是函数体时，使用 `my` 在非函数体中定义的变量的作用域是从定义到最小块的结束。它们的生命周期从执行 `my` 声明开始，直到离开定义它们的块。虽然 Perl 中不能嵌套函数定义，但任何不是函数体的块都可以嵌套。例如，我们可以有

```perl
$temp = 5;
{
    my $temp = 10;
    if ($temp > 5) {
        $temp = $temp;
    }
}
print "Global temp: $temp";
```

这段代码隐式定义了一个全局变量 `$temp`（通过顶部的赋值语句）和两个同名的局部变量（通过两个 `my` 声明）。在 `if` 块中，只有那里定义的 `$temp` 版本是可见的，尽管存在不同的名为 `$temp` 的变量。在更大的块中，只有在那里定义的版本是可见，尽管全局版本也是活动的。块中定义的变量的任何使用都不会影响全局或包含作用域（块）中定义的同名变量的值。作用域仅限于显式定义的块（所有 `my` 变量都是这种情况）的变量被称为静态或词法作用域。

Perl 程序可以包含一个编译指示，指示编译器禁止任何静态作用作用域变量。此编译指示是：

```perl
use strict;
```

包含此编译指示的程序中的全局变量，使用出现在任何函数定义或块之外的 `my` 声明来定义。这些变量的作用域是从 `my` 声明到文件结束。大多数特殊变量，如 `$_`，不受此要求的的限制。

强制所有程序变量都声明的优点是允许编译器检测变量名中的拼写错误。例如，假设我们输入了 `$sun` 而本意是 `$sum`，并且程序中没有名为 `$sun` 的变量。如果包含 `use strict`，这会导致错误，否则不会（因为编译器会隐式地将 `$sun` 定义为一个新的全局变量）。

## 6.4 参数传递

我们现在开始讨论 Perl 中的参数传递。实际参数是在函数调用中指定的；形式是函数名后的括号。一种方法是按值传递，这意味着实际参数的值被提供给调用的函数。实际参数也可以按引用传递，这意味着实际参数的地址被提供给调用的函数。

### 6.4.1 按值传递

在 Perl 中，参数也可以按值传递。为了实现按值传递的语义，实际参数的值通常从 `@ARG` 复制到函数中的 `my` 变量中。这可以防止实际参数。例如，考虑以下代码：

```perl
sub sub1 {
    my ($x, $y, $z) = @ARG;
    ...
}
sub1($a, $b, 7);
```

在此次调用 `sub1` 之后，在该执行期间 `sub1` 函数体内，`$x`、`$y` 和 `$z` 分别被初始化为 `$a`、`$b` 和 `7` 的值。无论 `$x` 和 `$y` 在 `sub1` 中如何使用，都不会影响调用者中 `$a` 和 `$b` 的值。

下面的示例函数说明了按值传递参数。它以数字倒序显示给定的整数参数。例如，如果传递 2376，它将显示 6732。我们使用取模运算符`%`从输入参数的右端提取各个数字，并在计算时显示这些数字。每次计算一个数字时，它都会通过除以 10 从剩余数字的右端移除。处理循环的终止条件是数字小于 1。因为此函数使用浮点运算，所以降到零需要长时间，因此零不是一个好的比较选择。

```
# reverse_digits (一个函数)
# 参数：
#     一个整数
# 返回值：
#     无
# 处理过程：
#     以数字倒序显示给定的数字

use English;
sub reverse_digits {
    my $number = @ARG[0];
    my $digit;
    print "The reverse of $number is: ";

    until ($number < 1) {
        $digit = $number % 10;
        print "$digit";
        $number /= 10;
    }

    print "\n";
}
```

### 6.4.2 按引用传递

调用 `interchange` 时，实际参数 `$a` 和 `$b` 的值被隐式地作为第一和第二个元素放入 `@ARG` 数组中。`interchange` 中唯一的语句使用列表赋值来交换 `@ARG` 前两个元素。由于 `@ARG[0]` 和 `@ARG[1]` 在函数返回时复制回 `$a` 和 `$b`，使得 `$a` 被设置为 3，`$b` 被设置为 7。

当然，试图更改字量实际参数是愚蠢的。例如：

```perl
sub add1 {
    ++$ARG[0];
}
add1(7);
```
什么也不会发生。（甚至不会产生错误消息。）



局部变量 `%my_people` 将被分配 `@ARG` 的所有元素。因此，如果传递给此函数的参数更多，它们的值最终都会进入 `%my_people`。Perl 提供了第二种实现按引用传递参数的方法，将在下一小节中描述。

### 6.4.3 传递引用作为参数

实现按引用传递参数的第二种方法（我们在大多数情况下更喜欢这种方法）是传递实际参数的引用。与传递实际参数变量的名称相比，传递引用的主要优势在传递数组时最为明显。数组的引用是一个标量，而传递数组的名称会导致其所有元素被移动到 `@ARG` 中。因此，如果数组规模较大，传递引用要快得多。以下示例说明了如何传递标量、数组和哈希表的引用：

对于标量参数：

```
sub add_1_scalar {
    my $param = $ARG[0];
    $$param++;
}
...
add_1_scalar(\$sum);
```

对于数组：

```
sub add_1_array {
    my $ref_list = $ARG[0];
    my $element;

    foreach $element (@$ref_list) {
        $element++;
    }
}
...
add_1_array(\@list);
```

对于哈希表：

```
sub add_1_hash {
    my $ref_hash = $ARG[0];
    my $key;

    foreach $key (keys %$ref_hash) {
        $ref_hash -> {$key}++;
    }
}
...
add_1_hash(\%table);
```

因为在函数中使用 `shift` 时，它默认使用 `@ARG`（或 `@_`）作为其操作数，所以在这些情况下，我们都可以使用 `shift` 而不是 `$ARG[0]` 来获取实际参数。（在函数定义之外，`shift` 的默认操作数是 `@ARGV`；参见第 4 章。）

考虑以下函数，它将其每个参数加 1 并返回一个新值的列表：

```
sub incrementor {
    my @list = @ARG;
    my $element;

    foreach $element (@list) {
        $element++;
    }

    return @list;
}
```

`incrementor` 函数可以用多种参数调用，如：

```
($count, $sum, @totals) = incrementor($count, $sum, @totals);
```

但是，你必须记住，返回值与形式参数 `@ARG` 一样，是一个单一的数组。因此，如果你将数组作为目标列表中的第一个元素，如：

```
(@totals, $count, $sum) = incrementor(@totals, $count, $sum);
```

所有结果值都返回到 `@totals` 中，而 `$count` 和 `$sum` 被设置为 `undef`。

如果你想调用一个函数并让它获取 `@ARG` 的当前版本（调用前的 `@ARG` 值），而不是一个新版本（调用后的值），可以通过在函数名前加上 `&` 并省略括号来实现，如：

```
&sub1;
```

### 6.5 一个示例

下一个示例函数说明了我们一直在讨论的一些内容。其目的可以描述如下：

**参数：**一个包含姓名和薪水的哈希表

**返回值：**一个包含薪水最高的五个人的姓名的数组，顺序不限

例如，对于实际参数：

```
%tst_data = ("Fred" => 200, "Mike" => 240, "Bob" => 220,
            "Darcie" => 190, "Jake" => 195, "Mary" => 215,
            "Louie" => 250, "Betsy" => 175, "Dusty" => 235);
```

程序应输出列表：
- Louie
- Bob
- Mike
- Dusty
- Mary

该函数（名为 `top_five`）使用的方法如下：一个 `while` 循环遍历参数哈希表的所有元素。对于每个元素，调用另一个函数 `insert_name`，传递两个数组的地址（一个用于存放薪水最高的五个人的姓名，另一个用于存放他们的薪水），以及新的姓名和薪水。在前五次调用时，`insert_name` 函数只是将给定的新数据插入到前五名数组中。之后，它在薪水最高的五人数组中找到最低的薪水。该函数将这个最低薪水与新薪水进行比较，以查看是否应替换前者。当第一个函数 `top_five` 发现给定的哈希表中没有更多数据时，它返回前五名的姓名数组。

代码如下：

```perl
# top_five (一个函数)
# 参数：
#     一个包含姓名和薪水的哈希
# 返回值：
#     一个包含薪水最高的五个人姓名的数组

use English;

sub top_five {
    my $ref_salaries = $ARG[0];
    my (@top_names, @top_salaries, $name, $salary);

    # 遍历输入的哈希，并对每个元素调用 insert_name
    while (($name, $salary) = each (%$ref_salaries)) {
        insert_name(\@top_names, \@top_salaries, $name, $salary);
    }

    return(@top_names);
} ##- 函数 top_five 结束

# insert_name (一个函数)
# 参数：
#     一个姓名数组的地址
#     一个薪水数组的地址
#     一个新姓名
#     一个新薪水
# 过程：将新姓名和薪水插入数组，但仅当新薪水高于
# 五薪水列表中的最小值时执行
sub insert_name {
    my($ref_names, $ref_salaries, $new_name, $new_salary) = @ARG;
    my $lowest_salary = 1.0;
    my $lowest_salary_index;

    # 检查数组中的姓名是否少于五个
    # 如果不是，将姓名放入数组
    if (@ref_names < 5) {
        push @ref_names, $new_name;
        push @ref_salaries, $new_salary;
    } else {
        # 如果姓名数组有五个，
        # 找出最小的薪水
        for ($index = 0; $index <= 4; $index++) {
            if ($lowest_salary > $ref_salaries[$index]) {
                $lowest_salary = $ref_salaries[$index];
                $lowest_salary_index = $index;
            }
        }

        # 现在将当前薪水与新薪水进行比较
        # 以确定新薪水应该替换它
        if ($new_salary > $lowest_salary) {
            $ref_names[$lowest_salary_index] = $new_name;
            $ref_salaries[$lowest_salary_index] = $new_salary;
        }
    }
} ##- 函数 insert_name 结束
```

### 6.6 间接调用

某些情况下，间接调用函数会方便。假设在程序的某个时刻，必须根据标量变量的值来调用不同函数。如果函数可以在 Perl 中那样间接调用，我们可以构建一个哈希，其键是字符串的可能值，值是相应函数的地址。通过哈希元素（该元素以字符串）来调用。使用操作符（`\`）设置为函数的地址，如：

```perl
$ref_fun = \&print_header;
```

显然，函数名前必须加 `&` 符号。可以使用函数的软引用。一个包含函数名的字符串赋值给引用。例如，考虑以下语句：

```perl
$ref_fun = "print_header";
```

通过引用变量调用函数时，无论是软引用还是硬引用，调用方式都相同。此类调用通过在引用名称前加上 `&` 来完成。以下两条语句都调用 `print_header`：

```perl
&$ref_fun();
&$ref_fun();
```

Perl 还支持匿名函数，当然必须通过引用来调用。匿名函数通过将无名函数定义给标量变量来创建。例如，考虑这个函数：

```perl
$ref_header = sub {
    print "\n Output \n";
}
```

匿名函数可以通过引用变量调用，就像它们是命名函数一样。对于定义的匿名函数，我们可以使用：

```perl
&$ref_header();
```

### 6.8 sort 函数

我们在第 4 章介绍了 `sort` 函数，但只介绍了其简单的形式。`sort` 函数现在更灵活。这种新形式中的附加参数指定了排序中使用的操作。这个新参数（如果使用）作为第一个参数。它可以采用函数名、代码块或包含函数名或函数引用的形式。在任何情况下，比较参数都指定了排序过程。比较代码必须返回一个小于数字（如果第一个值在第二个之前），返回零（如果两个值相等），返回一（如果左操作大于右操作数）。`sort` 的默认形式包含两个操作符，一个用于数字（`<=>`），一个用于字符串（`cmp`）。

两个值在比较代码中使用 `$a` 和 `$b`。这些变量是特殊的，因为它们在指定作用域（使用 `strict 'vars'`）时免于静态作用域的要求。变量充当参数。这种新形式 `sort` 可以通过 `<=>` 操作符用于数字列表，如：

```perl
sort { $a <=> $b } @list;
```

如果我们希望数组按降序排序，我们将使用

```perl
sort { $b <=> $a } @list;
```

同样，我们可以通过反转对 `$a` 和 `$b` 来将字符串列表按字母排序，如：

```perl
sort { $b cmp $a } @list;
```

`sort` 函数带两个参数常见的用途之一是按值（而不是键）对哈希进行排序。例如，假设我们有一个 `%top_five` 的哈希，它存储了公司薪水最高的五名员工的姓名和薪水。如果我们想查看按薪水排序的数据，我们可以在函数中使用代码：

```perl
print "Employees with the five highest salaries:\nPerson\t Salary\n";
```

### 6.9 pack 和 unpack 函数

偶尔，我们会遇到或处理非文本形式的文件或结构。因此，需要能够方便在文本和某种二进制形式之间转换这些。在许多情况下，从二进制到文本的转换可以通过 `sprintf` 完成，它与 `printf` 相同的功能，只是不将结果字符串发送到标准输出，而是将其放入 `sprintf` 第一个参数指定的标量变量中。`pack` 函数是 `sprintf` 的简单替代方案。`unpack` 函数执行相反的转换（从文本到二进制）。

`pack` 和 `unpack` 具有相同的参数形式：一个转换格式代码的字符串，以及一个指定要打包或解包数据的列表。返回值是操作的结果。第一个参数中可以使用大量的格式代码。格式代码参数通常称为模板。我们这里只描述两个常用的代码。你可以在 Perl 的 `perlf` 手册页中了解其他代码。

`C` 代码指定一个无符号字符值（任何无符号单字节数字）。如果有三个这样的值，可以指定 `CCC` 或 `C3`。当用作 `pack` 的参数时，`C` 代码指定给定列表中的每个值被打包成单字节。所有这些字节被组合成一个字符串。实际上，使用 `C` 代码的 `pack` 将值列表转换为 ASCII 码的标量字符串。例如，假设 `@code_word` 包含字母 'B'、y' 和 'e' 的十六进制 ASCII 码（0x42、0x79 和 0x65）。那么

```perl
$string = pack("C3", @code_word);
```

会在 `$string` 中构建字符串 "Bye"。在 CGI 编程中，我们将利用 `pack` 来解码从 HTML 表单发送到 CGI 程序的参数。

`unpack` 函数执行与 `pack` 相反的操作。在标量上下，它解包单个值。在列表上下文中，它将多值数据结构解包为一个列表。例如，我们可以使用以下方式解包我们刚刚用 `pack` 构建的字符串：

```
@code_word = unpack("C3", $string);
```

### 7.1 简介

系统管理员、系统程序员和应用程序程序员共同的常见编程任务之一是扫描字符串和文本文件以查找特定类型的子字符串。这种能力由各种实用程序和软件系统提供。例如，编辑器和文字处理器的搜索和替换操作、UNIX 的 `grep` 实用程序以及 Windows NT 的 `findstr` 实用程序。此外，编译器、解释器和静态程序分析器使用字符模式来识别词法和语法结构。虽然其中一些需求可以通过单独的实用程序来满足，但将此功能内置于编程语言中是很方便的，特别是像 Perl 这样经常用于系统管理的语言。

Perl 模式匹配操作的语法主要借鉴自 UNIX 的 `egrep` 实用程序。其他使用这种模式匹配的 UNIX 工具包括 `ed` 和 `sed` 文本编辑器、`awk` 以及 `grep` 家族的其他成员。

### 7.2 简单模式

我们从最简单的模式开始讨论模式匹配，这些模式仅匹配单个字符或字符类。模式是字符串集合的抽象表示。当被比较的字符串属于该集合时，模式即匹配成功。模式的复杂程度从极其简单到极其复杂不等。学习编写和理解复杂模式的唯一途径是了解其组成部分。

#### 7.2.1 匹配字符

模式中的字符分为三类：(1) 普通字符，匹配其自身；(2) 元字符，在模式中具有特殊含义；(3) 句点。转义序列，如 `\t`（制表符）和 `\cC`（Control-C），可以出现在模式中，此时它们匹配其自身。元字符本身也可以被匹配，但前提是它们在模式中被转义。元字符（在特定上下文中具有意义）包括：`.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `\` `|`。

虽然转义将元字符变为普通字符，但它也会匹配一些字符。默认，模式匹配字符。考虑以下语句：

```
if (/snow/) {
    print "There was snow somewhere\n";
} else {
    print "was snowless\n";
}
```

#### 7.2.2 字符类

字符类提供了一种在模式中轻松指定集合的方法。字符类是一个模式，它被指定为一个集合，其中任何字符都可以匹配。字符类通过将要包含的字符放在方括号内定义。例如，模式 `[a-z]` 匹配任何字母。模式 `[0-9]` 匹配任何进制数字。

有些字符类使用非常频繁，因此有预定义的缩写：

| 缩写 | 等效模式 | 匹配 |
|---|---|---|
| `\d` | `[0-9]` | 一个数字 |
| `\D` | `[^0-9]` | 一个非数字 |
| `\w` | `[A-Za-z_]` | 一个单词字符 |
| `\W` | `[^A-Za-z_]` | 一个非单词字符 |
| `\s` | `[ \t\n\f]` | 一个空白字符 |
| `\S` | `[^ \t\n\f]` | 一个空白字符 |

考虑以下示例：

```
/[A-Z]"\s/      匹配一个大写字母、一个双引号和一个空白字符
[\dA-Fa-f]/     匹配一个十六进制数字
/\w\w:\d\d/     匹配两个单词字符、一个冒号和两个数字
```

模式中的变量会被插值，就像模式是用双引号分隔的一样。例如，以下模式匹配一个被空白包围的十六进制数字：

```
$hexpat = "\\s[\dA-Fa-f]\\s";
```

注意，`\s` 必须前面加一个反斜杠，以使另一个斜杠成为字面量，而不是 's'。第二个反斜杠的替代方法是使用单引号来分隔字符串。模式 `$hexpat` 可以在以下语句中使用：

```
if (/$hexpat/) {
    print "$_ has a hex digit (or the word 'a') \n";
}
```

#### 7.2.3 量词

通过添加量词，字符和字符类模式可以变得更强大和灵活，量词允许模式重复指定的次数。量词像简单的字符序列一样，被视为一种运算符。Perl 有四种量词，用 `*`、`+`、`?` 和 `{m, n}` 指定。量词紧跟在字符、字符类或带括号的子模式之后指定。最通用的量词形式是 `{m, n}`，其中 `m` 和 `n` 是数字。它们的含义如下所示：

| 量词 | 含义 |
|---|---|
| `{n}` | 恰好重复 n 次 |
| `{m,}` | 至少重复 m 次 |
| `{m, n}` | 至少重复 m 次，但不超过 n 次 |

考虑以下示例：

```
/a{1,3}b/          匹配 ab, aab, aaab
/ab{3}             匹配 abbb, abbbb
/ab{2,}c           匹配 abbc, abbbcc
```

#### 7.2.4 交替

交替运算符在模式中用于可选的子模式。竖线 `|` 是逻辑或运算符。例如，可以有 `/a|e|i|o|u/` 匹配任何一个字母。

交替也可以在字符串之间使用，如：

```
/Fred|Mike|Dracula/ 匹配 字符串中的 Fred, Mike, 或 Dracula
```

圆括号可用于对交替进行分组，例如：

```
/(Bob|Tom|Pussy|Scaredy)cat    匹配 Bobcat, Tomcat, ...
/t(oo?|wo)/                      匹配 to, too, 和 two
```

匹配器尝试从左到右匹配模式。

#### 7.2.5 贪婪与最小模式

匹配器可以以两种几乎相反的模式处理量词：贪婪模式（默认模式，如前例所示）和最小模式。最小模式通过在量词后跟一个问号来指定。例如，在 `$_ = "Freddie's hot dogs";` 中，`/Fred+?/` 匹配结果是 "Fred"。在这种情况下，模式的最小版本是 "Fred"，因此匹配器无需进一步查看字符串。

再举一个例子，考虑 `$_ = "Freddie's hot hogs are really hot!";`。`/.*hot/` 在这个例子中，再次是贪婪模式，匹配器会为 `.*` 部分尝试尽可能多的字符，直到匹配到最后一个 "hot"。另一方面，在 `$_ = "Freddie's hot dogs are really hot!";` 中，`/.*?hot/` 匹配的是左侧的 "hot"，因为它首先尝试 `.*?` 不匹配任何字符，然后尝试一个字符，依此类推，直到模式的另一部分匹配，从而找到第一个 "hot"。

`.*` 展示了模式匹配器的贪性。它匹配尽可能多的字符。例如，假设我们有 `$_ = "Bob sat next to the Bobcat and listened to the Bobolink";` 那么 `/.*Bob/` 匹配的是 "Bobolink" 中的 "Bob"。实际上（但并非事实如此），匹配器首先将 `.*` 匹配到整个字符串，然后一次回退一个字符，直到找到模式其余部分 "Bob" 的匹配，从而找到最右侧的出现。

匹配过程对所有量化模式都以相同的方式运行。再举一个例子，考虑 `$_ = "Freddie's hot dogs";`。`/Fred+/` 这导致匹配 "Fredd"。匹配器开始此操作时，先匹配字符串的前三个字符 'F'、'r' 和 'e'。然后，它将模式中的 `d+` 与字符串中所有后续的 'd' 匹配，在本例中仅为 'dd'。匹配器将模式中的 `d` 与字符串中的字符匹配，直到失败为止。
```
```


匹配单个井号或一个或多个破折号，而不是一个或多个井号或破折号的出现。如果需要后一种解释，可以通过在适当位置包含圆括号来实现，如：`

`/(#|-)+/`

### 7.3 更复杂的模式

到目前为止，我们只讨论了相对简单的模式。更复杂的模式可以通过包含锚点和模式修饰符来设计。模式匹配器的操作可以通过在模式中包含锚点运算符来部分控制。模式修饰符改变了匹配器处理被修饰模式的方式。

#### 7.3.1 锚点

模式中的锚点要求模式的一部分在字符串中的特定位置进行匹配。这允许将模式中的特定位置与字符串的特定位置对齐。最简单的锚点是要求模式在字符串的开头 (`^`) 或结尾 (`$`) 匹配的锚点。例如，

`/^Shelley/`

匹配 "Shelley has red hair"，但不匹配 "What color is Shelley's hair?"。同样，

`/hair$/`

匹配第一个字符串，但不匹配第二个字符串（因为第二个字符串在 "hair" 和字符串末尾之间有一个问号）。脱字符（`^`）在模式中任何位置出现时都匹配自身，除了在左端或字符类内部。如果你想让脱字符匹配字符串的开头，请使用反斜杠转义它。脱字符的三种用法在模式中说明如下：

```
/^[^!]^/
```

该模式匹配任何不以 ! 开头，但第二个字符是脱字符的字符串。

模式中的锚点运算符不匹配字符串的字符；相反，它们匹配字符串中字符之间的位置。因此，锚点运算符有时被称为断言。例如，模式开头的 `^` 不匹配字符串中的任何字符。当这样的模式匹配时，脱字符匹配字符串第一个字符之前的位置。

`\b` 锚点匹配单词字符（`\w`）和非单词字符（`\W`）之间的位置。这可以用于单词模式的两侧，以匹配未嵌入另一个单词中的字符串。例如，

```
/\bwear\b/
```

匹配 "I wear old shoes"，但不匹配 "Swimwear for sale" 或 "Molly wears green sweaters"。

Perl 包含一些其他锚点运算符，但由于它们不太常用，我们不在本书中讨论它们。

匹配`$_` 中的字符串并不总是方便的。绑定运算符提供了一种匹配其他字符串的方法。

#### 7.3.2 绑定运算符

Perl 允许通过使用绑定运算符 `=~` 或 `!~` 将字符串连接到模式，从而将模式与任何字符串进行匹配。例如，

```
$string =~ /[,:;]/
```

尝试在 `$string` 中查找逗号、分号或冒号。

```
$string !~ /[,:;]/
```

执行与前一个表达式完全相同的模式匹配，但它反转了返回值的逻辑。因此，此模式仅在 `$string` 中查找逗号、分号或冒号失败时才返回 true。绑定运算符实际上是布尔运算符，因为它们返回布尔值。

绑定运算符的左操作数可以是任何产生字符串值的表达式。在标量上下文中使用时，输入运算符产生一个字符串值。因此，它可以用作绑定运算符的左操作数。例如，考虑以下语句：

```
if (<STDIN> =~ /^[Yy]/) { ... }
```

由于 `=~` 和 `!~` 运算符具有高优先级，当表达式用作左操作数时，必须用括号括起来。

#### 7.3.3 模式修饰符

模式后面可以跟一个修饰符，它要么改变模式的解释方式，要么改变模式匹配器在使用模式的工作方式。`i` 修饰符告诉模式匹配器忽略字符串中字母的大小写。例如，

```
/apples/i
```

匹配 "apples"、"Apples"、"APPLES"、"ApLlEs" 以及拼写该水果复数形式的所有大小写字母组合。

第 7.3.2 节中测试输入是否以大写或小写 `y` 开头的 `if` 语句可以重写为：

```
if (<STDIN> =~ /^y/i) { ... }
```

`m` 修饰符指定将字符串视为多行，假设它包含嵌入的换行符。这导致 `^` 匹配字符串中任何换行符之后的位置。同样，`$` 匹配字符串中任何换行符之前的位置。

`s` 修饰符指定将字符串视为单行，这改变了句点字符，使其在模式中也匹配换行符。当整个字符串被视为单行时使用此修饰符，无论是否包含嵌入的换行符。

如果同时指定了 `s` 和 `m` 修饰符，模式中的句点匹配字符串中的任何字符，包括换行符。然而，`^` 和 `$` 分别匹配换行符之前和之后的位置。

模式可以包含标量变量。当它们包含时，变量会被插值，就像它们出现在带引号的字符串字面量中一样。每次使用这样的模式时，它都会被重新编译，以防变量的值发生变化。这提供了动态模式，但使用起来代价高昂。如果模式包含标量变量，但该变量的值在模式的不同使用期间从未改变，则应在模式上包含 `o` 修饰符。此修饰符告诉 `perl` 在程序执行期间不要重新编译模式。

`x` 修饰符允许在模式的各部分之间包含空格，而不会改变模式匹配的内容。例如，

```
/\d+ \. \d+/x
```

等同于

```
/\d+\.\d+/
```

注释为空格，因此 `x` 修饰符在模式中非常有用。对于长模式，允许各部分出现在不同的行上。例如，考虑以下模式：

```
/\d+ # The digits before decimal point
\.  # decimal point
\d+ # The digits after decimal point
/x
```

### 7.4 记住

在某些情况下，我们希望能够直接在模式中引用匹配的字符串部分。这可以通过将感兴趣的部分用括号括起来来实现。匹配字符串部分通过隐式变量引用。第一个括号部分在 `$1` 中，第二个括号部分（如果存在）在 `$2` 中。例如：

```
/(?:Bob|Tom|Pussy|Scaredy) cat/
```

匹配像 "joanne" 和 "Duran" 这样的字符串。同样，

```
/(.)\1/
```

匹配它找到第一个字符，例如 "I like football!" 中的 "oo"。

如果模式包含普通括号，匹配的字符串部分在模式外部需要使用 `$1`、`$2` 等。在列表上下文中，模式运算符返回 `$1`、`$2` 等值。所以，

```
$_ = "305 today" =~ /(\d+) (\w+)/
print "$1 $2";
```

显示
305 today

做了正确的事情，尽管 `split` 对此更好。例如，考虑以下模式：

```
$_ = "17 May 1998"; /(\d+) (\w+)/;
print "$1 $2";
```

显示
17 May 1998

如果模式中有嵌套括号，匹配的字符串部分从左端计算，通过隐式变量 `$1`、`$2` 等相关联。例如：

```
$_ = "17 May 1998";/((\d+) (\w+))/;
print "$1 $2 $3";
```

显示
17 May 1998

### 7.5 正则表达式扩展

Perl 的正则表达式允许使用子字符串的上下文来指定模式的匹配。Perl 包含了对其正则表达式语法的先前版本的扩展，这些扩展在模式的括号内定义。这些扩展的一般形式是

```
(?xPattern)
```

其中 `x` 是定义特定扩展的一或两个字符。以下小节描述了一些最常用的扩展。

#### 7.5.1 非反向引用括号

使用括号对模式的部分进行分组通常很方便。如果你打算使用反向引用来引用括号部分的字符串部分，这很好。如果你打算使用反向引用，这些括号会不必要地减慢匹配过程。在这种情况下，可以使用 `?:` 扩展，它指定括号不提供反向引用，从而节省匹配器用于保存子字符串的时间。例如，

```
/(?:Bob|Tom|Pussy|Scaredy) cat/
```

比我们在第 7.2.4 节中介绍的版本更高效。

#### 7.5.2 前瞻

有时我们需要指定一个模式，该模式仅在紧随其后有某些内容时才匹配，但我们希望后续子字符串成为匹配的一部分。这在我们保存匹配的子字符串以及模式的下一部分必须匹配当前匹配之后的内容时很有用。这些被称为零宽度正向前瞻。它们由 `=` 扩展指定。例如，模式

```
/\d+(?=\.)/
```

匹配一串数字后紧跟一个小数点，但不会将小数点包含在 `$MATCH` 中，并且如果匹配器在同一模式中找到后续匹配，也会将其保留在字符串中。

前瞻也可以指定为负向，意味着我们只希望在子模式后面没有跟某些特定内容时才匹配。这些被称为零宽度负向前瞻。它们通过 `!` 扩展来指定。例如，

```
/\d+(?!\.)/
```

匹配一串后面没有紧跟小数点的数字。

#### 7.5.3 后顾

Perl 也允许零宽度后顾，行为类似于零宽度前瞻。`<=` 指定正向后顾；`<!` 指定负向后顾。例如，

```
/(?<=\.)\d+/
```

匹配一串前面点的数字。

```
/(?<!.)\d+/
```

匹配一串前面不是点的数字。

### 7.6 重新视 `split` 函数

回想一下，我们在第 4 章讨论了 `split` 函数，只使用空字符串或单个字符作为模式，例如：

```
@names = split /, "Betty,Bart,Bartholomew";
```

这会将 `@names` 设置为 "Betty", "Bart", "Bartholomew"。`split` 的第一个参数可以是模式。如果字符串中有空格，我们可以这样处理：

```
@names = split /, "Betty, Bart, Bartholomew";
```

这产生与示例相同的 `@names` 值。

### 7.7 替换

在字符串中查找特定字符串并替换为不同字符串是很常见的需求。Perl为此过程提供了一个强大的运算符：替换运算符。替换运算符的般形式是

```
s Pattern New_string Modifiers
```

其中 `s` 是分隔符。

### 7.8 示例

此示例是一个修改文件中给定文本的程序。具体来说:10 代表分号，:11 代表感叹号，:12 代表双引号，:13 代表问号。

必须对文件执行两个不同的过程：首先，必须将字符编码转换为它们所代表的字符。这可以通过全局替换运算符来完成。第二个过程更复杂。我们必须将文件中的大部分大写字母转换为小写。使用 `lc` 运算符可以轻松地将它们全部转换为小写。之后，我们必须将每个句子的第一个字母转换为大写。此外，我们必须将所有出现的人称代词 I 转换为大写。可能还有其他情况需要将字母转换为大写，但这些是我们这里将考虑的唯一转换。

因为我们必须能够找到句子的起始字符——而句子可能跨越文件中的行——所以最方便的方法是将整个文件视为一个字符串。Perl 的一个巨大优势是我们可以方便地做到这一点（因为字符串没有长度限制，除了计算机内存的大小）。

替换运算符与绑定运算符（`=~` 或 `!~`）一起使用，左操作数必须具有左值。替换运算符通过使用一个或多个可用的修符更加灵活。我们现在只讨论最常用的运算符。`i`、`m` 和 `x` 修饰符对替换运算符的影响相同。`g` 修饰符告诉 perl 在字符串中匹配的所有位置执行替换。考虑以下示例：

```
s/ +/g                     # 将多个空格缩减为单个空格
$_ = "1203405";
s/0//g;                       # 将 $_ 更改为 "12345"
s/mispelled/misspelled/g      # 修复 $_ 中的所有写错误
$_ = "Molly and Mary were molls";
s/(\w+)/"\1"/g;               # 现在 $_ 是 "Molly" "and" "Mary" "were" "molls"
$_ = "Is it Sum, sum, or suM?";
s/sum/ig;                      # 现在 $_ 是 "Is it sum, sum, or sum?"
```

替换运算符的返回值是进行的替换次数，如果没有进行替换，则返回假值。当然，只有在使用 `g` 修饰符时才可能有多次替换。`e` 修饰符可以在替换中指定，但它在该上下文中的含义与匹配运算符的含义无关。相反，它指定的新字符串部分应被视为 Perl 表达式并被解释以产生替换的值。第 7.8 节中有一个使用此修饰符的示例。


```markdown
# 格式化器
# 输入：命令行上指定的文本文件
# 输出：文件的列表，经过以下修改
#         1. 所有出现的 :10 转换为分号
#         2. 所有出现的 :11 转换为感叹号
#         3. 所有出现的 :12 转换为双引号
#         4. 所有出现的 :13 转换为问号
#         5. 所有字母转换为小写，除了每个句子的第一个字母
#            （句子以 ., !, 或 ? 结尾）和前面和后面都有空格的 i
# 通过首先将输入记录分隔符设置为无效字符，使用 `<>` 获取整个文件
$/ = 0777;
$file = <>;
# 执行编码字符转换
$file =~ s/:10/;/g;
$file =~ s/:11/!/g;
$file =~ s/:12/"/g;
$file =~ s/:13/?/g;
# 将文件中的所有字母转换为小写
$file = lc $file;
# 如果文件的第一个非空白字符是字母，
# 将其转换为大写
$file =~ s/\s*([a-z])/uc($1)/e;
# 找到每个句子终止符后的第一个字母并
# 将其转换为大写
$file =~ s/([.!?])(\s+)([a-z])/$1 . $2 . uc($3)/gem;
# 如果有任何小写 i 后面跟着空格，
# 将它们转换为大写
$file =~ s/ i /I /g;
print "修正后的文件是：\n\n$file \n";
```### 7.9 字符转换

在某些情况下，我们希望替换操作基于字符而非字符串。此时，可以使用转换操作符。转换操作符 `tr` 不使用模式，因此将其放在本章中介绍有些牵强。不过，它的外观确实与替换操作符相似，因此在此进行描述。转换操作符的一般形式为：

```
tr/Search_List/Replacement_List/
```

`Search_List` 和 `Replacement_List` 是字符的规范（而非模式或字符串）。当转换操作符在字符串中找到与 `Search_List` 中匹配的字符时，它会将字符串中的该字符替换为 `Replacement_List` 中对应位置的字符。转换操作符返回它在字符串中找到的 `Search_List` 中的字符数量。考虑以下示例：

```
tr/a-z/A-Z/; # 将 $_ 中所有小写字母转换为
# 大写
tr/\./\./; # 返回 $_ 中句点的数量，但
# 不改变它
tr/:/ /; # 删除 $_ 中所有冒号
```

转换操作符与匹配操作符一样，可以使用绑定操作符将其应用于任何指定的字符串。转换操作可以指定几个修饰符，但它们很少有用。然而，值得注意的是，它没有像匹配操作符那样的 `o` 修饰符。原因是 `Search_List` 和 `Replacement_List` 都不插值嵌入的变量。

### 7.10 总结

模式匹配操作符最常见的形式使用斜杠作为分隔符，并且不包含 `m` 操作符。当斜杠不方便时，会使用其他字符，并且 `m` 会出现。简单模式由字符组成，这些字符匹配自身；元字符在模式中具有特殊含义；以及句点，匹配除换行符外的任何字符。字符类指定一组字符，其中任何一个都可以用于匹配。在类中，可以使用连字符指定字符范围。字符类开头的脱字符表示除类中字符外的所有字符。一些字符类有缩写。例如，`\d` 表示任何数字，`\w` 表示任何单词字符，`\s` 表示任何空白字符。

三种不同的量词可以跟在模式中的任何字符或字符类后面：`*`、`+` 和 `{m, n}`。它们分别表示零个或多个、一个或多个，以及至少 `m` 个但不超过 `n` 个重复。量词也可以跟在字符的括号分组后面。

模式匹配器的默认操作是找到与整个模式匹配的最左边的子字符串。如果涉及量词，则量化的模式匹配导致匹配的最大重复次数。如果希望量词匹配最小重复次数，请在量词后附加问号。模式可以包含交替操作符，用于分隔替代模式。替代模式从左到右尝试，直到找到匹配或所有可能性都已尝试但未成功。模式操作符的优先级从高到低如下：括号、量词、字符序列和交替。

模式可以通过 `^`、`$` 和 `\b` 分别锚定在字符串的左端或右端，或单词/非单词边界。通过使用 `=~` 或 `!~` 将表达式绑定到模式，可以将指定为左值或右值的表达式作为模式匹配的目标。`!~` 操作符只是反转匹配值的逻辑。模式可以用 `i` 修改，指定字母的大小写不敏感匹配；`m` 指定字符串应被视为多行；`s` 指定句点也匹配换行符；`o` 指定模式在首次使用后不重新编译；`x` 指定匹配器应忽略模式中的空白和注释。

模式中的括号有一个副作用，即将隐式变量设置为它匹配的字符串的子字符串。最左边括号子模式的匹配结果放入 `\1`，从左数第二个括号子模式的匹配结果放入 `\2`，依此类推。如果需要在模式外使用匹配的子字符串，可以使用相应的隐式变量 `$1`、`$2` 等。

Perl 对正则表达式定义了几个扩展，这些扩展在括号子模式中指定。这些是 `?:`，防止括号匹配；前瞻（`=` 和 `!`）和后顾（`<=` 和 `<!`），允许模式在匹配部分的字符串端或另一端指定上下文。`split` 函数可以使用任何模式作为第一个参数。替换操作符使用模式查找子字符串，使用第二个参数作为替换字符串。`g` 修饰符用于指定替换字符串中的所有项。`e` 修饰符告诉 Perl 将第二个参数视为编译后的表达式。转换操作符将特定字符转换为其他字符。通常用于计算字符串中字符类的数量。

### 8.1 文件句柄和文件

文件是文本或数据的字节序列，通常存储在磁盘上。 Perl 与大多数起源于 UNIX 环境的语言一样，三个预定义的文件：一个用于键盘输入，一个用于屏幕输出，一个用于错误消息（通常也定向到屏幕）。所有文件在 Perl 程序中都通过文件句柄引用。一旦在程序中建立了句柄与实际文件之间的连接，文件就通过句柄引用。此连接通过 ` `open` 指定， ` `close` 毁，这将在节后面描述。

文件句柄的名称不特殊特殊开头开头——它们是裸名称。这很少成为问题，因为文件句柄的上下文通常会澄清其命名空间。为确保与当前或未来的保留字不冲突，按照惯例，文件句柄使用全大写拼写。我们已经通过 `STDIN`、`STDOUT` 和 `STDERR`（三个预定义 Perl 文件的句柄）看到了这一点。

### 8.2 打开和关闭文件

`open` 是用于指定文件与文件句柄之间连接的函数（或列表操作符）。其函数调用格式为

```
open (filehandle, filename)
```

其中，文件名可以用字符串表达式或简单的字符串字量指定。如果要打开的文件不仅用于读取，那么在 `open` 中，其文件名前必须加上一个或两个特殊字符来指定文件的用途。其中最常用的如下所示：

| 字符 | 含义 |
|---|---|
| > | 输出，从文件开头开始（覆盖之前的内容） |
| >> | 输出，从文件当前数据的末尾开始 |
| < | 输入（默认） |

例如，

```
open (INDAT, "scores");
open (RESULTS, ">grades");
```

第一次调用 `open` 将文件句柄 `INDAT` 与名为 `scores` 的文件连接，并将其打开用于输入。第二次调用 `open` 将文件句柄 `RESULTS` 与名为 `grades` 的文件连接，并将其打开用于输出，从文件开头开始（这会销毁之前写入文件的任何内容）。

`open` 函数可能因多种不同原因而失败；例如尝试打开不存在的文件。`open` 成功时返回真，失败返回假。检查 `open` 是否成功的方法是使用 `or` 运算符和 `die` 函数。例如：

```
open (INDAT, "scores") or die "Error--unable to open scores!";
```

如第 3 章所述，`die` 显示诊断消息并终止。`open` 返回的句柄包含行符，如果文件名中包含行符。`die` 消息来自系统的错误诊断。文件句柄是在重新打开（后续 `open` 调用）之前隐式关闭。但是，一些程序员喜欢显式关闭。这可以通过 `close` 函数完成，如

```
close (RESULTS) or die "Error--unable to close grades!";
```

`close` 可能会失败。`close` 失败的例子是磁盘空间不足。`close` 关闭时缓冲区内容会被磁盘。`open` 函数也可用于非文件的机制，例如管道。管道将在第 10 章中讨论。

### 8.3 读写文件

正如你看到的，文件读写在 Perl 中是操作。任何文本文件都可以读写一行。也可以读写多行。

#### 8.3.1 读写单行

在本书几乎示例中，我们都读写单行（从键盘读取并输出到屏幕），因此在程序中打开其他文件时，使用 `<>` 操作符。向程序中打开写入一行，使用 `print` 完成，句柄作为第一个参数，如

```
print RESULTS "Sum = \n";
```

注意，语句中的文件名没有行号。下面的示例说明了打开、读取、写入和关闭文本文件。它从文件中读取行，每行存储一个名字。它显示那些名字以结尾。

```
# new_file
# 输入：一个名为 names 的文件，其行格式为
#        姓, 名, 中间名
# 输出：一个名为 kids 的新文件，其中输入文件中
#         名字以 ie、y 或 i 结尾。

open(ALLNAMES, "names") or die "Error--cannot open names!";
open(KIDDIES, ">kids") or die "Error--cannot open kids!";

# 循环获取一个名字，如果是名字则显示它

while (<ALLNAMES>) {
    if (/,.*ie,|y,|i)/) { print KIDDIES; }
}

close(ALLNAMES) or die "Error--cannot close names!";
close(KIDDIES) or die "Error--cannot close kids!";
```

此程序中使用的模式查找逗号之间的单词，即名字，这些名字以 "ie"、y" 或 "i" 结尾。

#### 8.3.2 读取多行

`read` 函数用于从文件中读取长于一行的片段。对于长文件，可以减少读取操作次数并程序执行速度。`read` 读取的数据进入变量，该变量用作缓冲区。调用 `read` 的形式为

```
read(filehandle, buffer, length [, offset]);
```

其中方括号表示内容是可选的。`buffer` 参数是读取输入的变量，`length` 是此次 `read` 旨在读取的字节数，可选的 `offset` 是缓冲区中希望读取的字符的位置。如果省略，偏移量为零。`read` 函数返回其实际读入缓冲区的字节数。文件到达末尾返回零。如果在读取期间发生错误，它返回 `undef`。

下面的示例程序说明了 `read` 函数在与 `new_file` 程序类似的文件上的使用。在这种情况下，行长度为 19 个字符，算上行符为 20 个。程序一次读取三行，并显示那些在其初始文档中定义为名字的行。

```
# new_file_read

# 输入：一个名为 names 的文件，其行格式为
#        姓, 名, 中间名
#        每行长度为 19 个字符，不包括行符
# 输出：一个名为 kiddies 的新文件，其中包含
#         名字以 ie、y 或 i 结尾的行。
# 方法：此程序必须使用 read 一次读取三行

open(ALLNAMES, "names") or die "Error--cannot open names!";
open(KIDDIES, ">kids") or die "Error--cannot open kids!";

# 读取前三行
$return = read(ALLNAMES, $buf, 60);

# 循环处理三行
while ($return) {
    @lines = split /\n/, $buf;
    foreach $line (@lines) {
        # 如果是名字，将其和行符写入 kids 文件
        if ($line =~ /,.*(ie,|y,|i)/) {
            print KIDDIES $line . "\n";
        }
    }
    # 再读取三行
    $return = read(ALLNAMES, $buf, 60);
}

close(ALLNAMES) or die "Error--cannot close names!";
close(KIDDIES) or die "Error--cannot close kids!";
```


| 文件测试 | 返回值 |
| :--- | :--- |
| `-e` | 如果文件存在则为真 |
| `-r` | 如果文件可读则为真 |
| `-w` | 如果文件可写则为真 |
| `-x` | 如果文件可执行则为真 |

例如，你可能想检查当前目录下是否存在一个 `index.html` 文件。这可以通过以下方式完成：

同样，判断一个文件是否确实是常规文件且可读可能很重要，这可以通过以下方式完成：

### 8.6 删除和重命名文件

虽然文件通常通过操作系统命令进行删除和重命名，但这些相同的操作也可以在 Perl 程序中完成。在 Perl 程序中，可以使用 `unlink` 函数删除文件，例如：

```perl
unlink("temp");
```

`unlink` 可以接受一个参数列表，例如：

```perl
unlink("temp1", "temp2", "temp3");
```

可以使用星号通配符字符来指定文件集合，就像在许多操作系统命令语言中一样。在 Perl 中，这样的文件规范可以作为 `glob` 函数的参数给出，或者简单地放在尖括号运算符中。例如，以下两个对 `unlink` 的调用效果相同：

```perl
unlink(glob("\*.doc"));
unlink(<*.doc>);
```

注意这两者语法上的区别：`glob` 的参数是一个求值为字符串的表达式；尖括号运算符中的表达式是一个文件规范，可能包含星号通配符字符。

`glob` 函数在标量上下文中使用时返回一个文件名；在列表上下文中，它返回所有匹配文件名的列表。

`unlink` 函数返回它实际删除的文件数量，但在最后一种情况下，这个数字可能不足以说明操作情况。如果你需要知道它尝试删除但未能删除的哪个或哪些文件，请将 `unlink` 放在循环中，例如：

```perl
foreach $nextfile (<*.doc>) {
    unlink($nextfile) or warn "Could not delete $nextfile \n";
}
```

`unlink` 的默认参数是 `$_`，所以一个裸露的 `unlink`，例如：

```perl
unlink or warn "Could not delete $_ \n";
```

会尝试删除 `$_` 中指定的文件。

在 Perl 程序中，可以使用 `rename` 函数重命名文件。`rename` 的语法是：

```perl
rename(old_file, new_file);
```

`rename` 成功时返回真，否则返回假。如果目标文件已存在，旧版本将被销毁。这与某些操作系统的重命名操作不同，在那些操作中，这样的操作只会失败，不会销毁任何东西。一个或两个参数都可以是路径，以文件名结尾。因为目标文件名可以在另一个目录中，所以 `rename` 实际上是一个移动操作。由于存在失败的可能性，`die` 经常与 `rename` 调用一起使用。

### 8.7 格式

回想一下，Perl 是 *Practical extraction and report language*（实用提取和报告语言）的首字母缩写。报告部分由格式支持。顾名思义，格式用于对程序输出施加特定的形式。几乎所有的编程语言都包含某种格式化输出的能力。FORTRAN 有自己的 `FORMAT` 语句，C 语言的 `printf` 函数使用格式码，一些 BASIC 方言有 `PRINT USING` 语句来指定输出的特定格式。在 Perl 中，输出到特定文件的格式在非可执行的 `format` 语句中指定。格式通过使用文件的文件句柄名称作为格式名称与文件关联。这里没有冲突；名称相同，但同时它们是完全不同类型事物的名称。格式可以与程序中的函数同名而不会产生冲突。然而，那样做很愚蠢。因为格式与其关联的文件句柄同名，按照惯例，格式名称全部使用大写字母。除非你使用相同的惯例命名函数（这很奇怪），否则函数和格式的名称看起来会完全不同，无论它们的拼写如何。

`write` 函数用于使用格式创建输出。注意 `write` 与 `read` 没有任何关系。它专门与格式一起使用。`write` 的唯一参数是格式名称。如果输出到 `STDOUT`，则不需要参数。如果为该文件定义了格式，输出将被强制放入格式指定的模板中。在许多情况下，包括本节考虑的所有情况，就是这么简单。

因为 `format` 是一个非可执行语句，就像函数定义一样，它可以出现在程序中的任何位置。如果只有一个调用 `write` 使用特定格式，最好将格式放在 `write` 调用之后。然而，对于被多个 `write` 调用使用的格式，我们更喜欢将它们放在程序的开头。

格式的一般格式是：

```perl
format [name] =
Formlist
.
```

方括号表示名称是可选的；默认是 `STDOUT`。终止格式的句点必须单独占一行，除了终止该行的换符。Formlist 由一系列行组成，每行是三种不同类型之一：注释、模板或参数。

在深入探讨一个简单的通用网关接口（CGI）程序的细节之前，最好先了解一些关于CGI的通用背景信息。CGI被设计用来提供一种标准方式，使浏览器能够调用服务器上的程序、向其传递数据并接收响应。CGI允许浏览器间接访问服务器上——或互联网上任何其他服务器上——几乎任何软件。CGI是服务器程序与其他软件之间的接口。信息或处理请求通过CGI传递给其他软件。该计算的结果通过CGI返回给服务器。这些结果以HTML形式呈现，服务器将其返回给客户端的浏览器。CGI程序与其他程序类似，只是其输入具有特殊形式且来自Web服务器，输出为HTML形式，并且总是传递给调用它的Web服务器。

CGI允许网页与浏览器用户进行交互，这要求服务器能够从客户端收集输入，并动态创建响应这些输入的网页。显然，用通用编程语言编写的程序可以解码从服务器发送给它的任何合理编码的信息。此外，这样的程序可以轻松地创建`HTML` 文档作为输出。

通过分析CGI编程的需求，我们可以确定哪些编程语言最适合此类任务。CGI程序的任务之一是解码从客户端发送到服务器的编码文本值。因此，用于CGI编程的语言应具有方便且强大的文本处理能力。由于Web服务器使用环境变量¹将信息传递给CGI程序，CGI编程语言必须能够轻松访问这些环境变量。最后，CGI编程语言必须允许轻松访问服务器上的其他软件库和实用程序（例如，如果服务器平台是`UNIX`，则包括`UNIX shell` 命令）。Perl`可能比任何其他编程语言都更好地满足这些要求，这也是它迄今为止成为CGI编程最广泛使用的语言的原因之一。

CGI程序通常被放置在服务器上的特定位置，由Web服务器管理员选择。在许多情况下，这个位置是一个名为`cgi-bin`的子目录。如果在服务器的常规子目录（例如`cgi-bin`）中放置了指向它的链接，CGI程序也可以位于其他位置。无论哪种情况，程序文件必须具有允许服务器执行的访问保护代码。在`UNIX`上，这意味着文件必须对所有人可执行。此外，如第2章所述，`perl`只能通过指定`perl`位置的特殊注释行来调用此类程序。

¹环境变量存储有关其所在计算机的各种信息，通常是关于其操作系统的信息。它们为操作系统提供全局变量。

### 9.3 与CGI程序的简单链接

这里`Call hello`是链接。当用户在客户端点击`Call hello`链接时，Perl CGI程序`hello.pl`将被执行。

CGI程序必须创建其想要传达回客户端的内容的`HTML`版本。返回客户端的连接通过标准输出进行，标准输出传递到服务器，然后返回给客户端。因此，CGI程序只需使用`print`函数调用来创建描述其输出给客户端浏览器的`HTML`。

```perl
print "Content-type: text/html\n\n";

### 9.4 处理表单

许多网页会收集访问它们的客户端信息。本节描述了浏览器与 CGI 程序之间一种更强大的交互方式，它可以将数据从浏览器用户传递给 CGI 程序。要传输的数据通过表单提供。表单是网页中一组控件的集合，旨在通过用户的浏览器收集其响应。表单必须包含一个“提交”按钮，点击该按钮会将其控件值的字符串表示形式发送到服务器。该字符串采用一系列`name = value`对的形式，其中`name`是控件名称，`value`是该控件在表单中的值，且始终为文本形式。无法发送浮点数或整数等其他数据类型。客户端无法测试从表单发送的值的有效性；这必须由 CGI 程序完成。

有两种方式可以将表单中控件的值传递给 CGI 程序：`GET`和`POST`。`GET`是默认方法，`POST`是可选方法。`GET`通过环境变量将数据字符串从服务器传递给CGI 程序；使用`POST`方法时，数据字符串通过标准输入发送，因此 CGI 程序可以直接读取。`UNIX`和`Windows`系统都已有环境变量，但一些新的变量用于 CGI 输入，稍后我们将讨论`GET`和`POST`方法的相对缺点。

`<FORM>`标签用于开始表单，其必需的属性是`ACTION`，它指定处理表单的程序的URL。使用`POST`（回想一下，`GET`是默认技术）。例如，我们可能有

```html
<FORM ACTION="http://www.cs.ucp.edu/cgi-bin/survey.pl"
METHOD="POST">
```

我们现在非常要描述表单中出现的控件。HTML中控件都以`<INPUT>`标签开头。`<INPUT>`标签中的`TYPE`属性指定特定类型。这些类型包括`text`、`checkbox`或`radio`。控件旁边有一个标签，用于从那里收集信息，例如其姓名和地址。文本控件默认大小为20个字符。可以使用`SIZE`属性指定。如果用户输入的文本超过大小，文本将显示。如果你希望文本滚动，可以指定`MAXLENGTH`。文本控件的值是用户输入。多行文本字段使用`<TEXTAREA>`标签指定，标签包含一个`ROWS`属性和一个`COLS`属性来指定文本区域的大小。多行文本字段隐式带有滚动条。还可以包含一些文本，这些文本出现在`<TEXTAREA>`及其结束标签之间。文本区域中的换符被忽略。

选框控件是一个独立的按钮，其行为类似于开关：要么打开，要么关闭。选中的选框按钮的值是"on"，除非你使用`VALUE`属性改为"yes"。未选中的选框在表单的值中没有条目。单选按钮是一组密相关的按钮。在任何时刻，恰好有一个单选按钮处于“打开”状态。特定中的单选按钮具有相同的名称，但每个按钮指定不同的`VALUE`。一组单选按钮的初始值是当前处于“打开”状态的按钮的`VALUE`属性。菜单控件在`<SELECT>`子句中指定。菜单可以是下拉菜单或滚动列表。此由`SIZE`属性指定，其中1表示下拉菜单，任何正数表示一个滚动列表。菜单的项目使用`<OPTION>`标签指定。其中一个项目可以包含`SELECTED`属性，使其成为菜单的默认值。表单中的控件通常通过将它们放置在表格中来对齐，表格在HTML中使用`<TABLE>`、`<TR>`（表格行）、`<TH>`（表格列标题）和`<TD>`（表格数据）标签指定。表单有一个提交按钮，还包含一个重置按钮。它们的类型分别是`submit`和`reset`。这些按钮的值是你希望显示在其中的标签。提交按钮会触发两个操作：(1) 表单的值发送到服务器，(2) `<FORM>`的`ACTION`属性指定的 CGI 程序被执行。重置按钮会清除表单中控件的值。

### 9.6 CGI.PM基础

CGI程序的某些部分在大多数 CGI 程序中都会出现。因此，让这些部分是易用的CGI.pm 是一个 Perl 函数模块，它完成了 CGI 程序中许多任务。其中许多函数的名称与 HTML标签相同，并使用参数提供值，以及嵌入标签来生成闭标签之间的内容。这些函数被称为快捷方式。我们将在第9.8 节中实际在程序中使用的 CGI.pm 部分专门导入。这是通过`use`语句完成的。部分通常按类别或集合导入，而不是导入单个函数。对 CGI 编程普遍用的函数类别命名为`standard` 和 `html3`。我们可以在 CGI 程序顶部包含以下语句来导入这些集合：

```perl
use CGI(:standard :html3);
```

CGI.pm 中的一些内容实际上只是 CGI 程序中完成的标准写法。例如，`header` 函数生成标准的 HTML 内容类型和必需的空行。具体来说，

```perl
print header();
print "Content-type: text/html\n\n";
```

`header` 函数可以接受一个参数，该参数用于指定 "text/html" 的替代项。`start_html` 函数接受一个字符串参数，创建`<HEAD>`标签、使用其参数作为标题的`<TITLE>`标签、闭标题标签、闭头部标签和`<BODY>`标签。例如，

```perl
print start_html('Sebesta's Home Page');
print "<HEAD> \n";
print "<TITLE> Sebest's Home Page </TITLE> \n";
print "</HEAD> \n";
print "<BODY> \n";
```

获取服务器发送给 CGI 参数值的整个过程可以使用`param` 函数一步完成。例如，考虑以下查询字符串：

```
name=Max Marks&fruit=apples!
```

这将被浏览器转换为查询字符串：

```
name=Max%20Marks&fruit=apples%21
```

以下语句将局部变量设置为正确的查询值：

```perl
my($name, $fruit) = (param("name"), param("fruit"));
```

百分号 (%)后跟一个两位十六进制数，该数字是字符的 ASCII 码。例如，空格编码为 %20（十六进制 20 是空格的 ASCII 码）。进行此编码是因为某些浏览器可能对某些字符附加特殊含义。如果表单有一个名为`name`的文本小部件（其值为 "Max Marks"）和一个名为`fruit`的单选按钮集合（其值为 "apples!"），则表单的编码值（称为查询字符串）将是

```
name=Max%20Marks&fruit=apples%21
```

回想一下，表单的查询字符串可以通过两种不同的方法（`GET`和`POST`）传输到 CGI 程序。在`GET` 的情况下，查询字符串只是附加到指定处理表单的 CGI程序的 URL 上，URL 和查询字符串之间有一个问号 (?)。当用户按下提交按钮时，会发生此附加。当服务器收到请求时，服务器从 URL 中删除查询字符串并将其分配给环境变量`QUERY_STRING`，CGI 程序可以访问该变量。当不涉及表单时，此机制也可将参数传递给 CGI 程序。`GET` 方法的缺点是某些浏览器和服务器可能对 URL 的长度施加限制，并简单地截断超出限制的任何字符。

content]
如果指定表单由 POST 方法处理，则 CGI 程序将查询字符串作为标准输入读取。查询字符串的长度在 `CONTENT_LENGTH` 环境变量中可用。POST 方法的优点是查询字符串没有长度限制。

在某些编程语言中，将表单输入转换为 CGI 程序使用的方便格式很复杂，但 Perl 非常适合这项任务。我们现在考虑该过程中的步骤。首先，查询字符串必须放入 Perl 字符串变量中。最好编写 CGI 程序以同时处理 GET 和 POST 输入。因此，程序应首先确定使用了哪种方法。这可以通过检查环境变量 `REQUEST_METHOD` 的值来完成，其值是技术名称的字符串值。如果是 GET，则查询字符串直接从环境变量 `QUERY_STRING` 中获取。如果是 POST，则查询字符串从标准输入读取。以下代码获取输入字符串：

```perl
$request_method = $ENV{'REQUEST_METHOD'};
if ($request_method eq "GET") {
    $query_string = $ENV{'QUERY_STRING'};
}
elsif ($request_method eq "POST") {
    read(STDIN, $query_string, $ENV{'CONTENT_LENGTH'});
}
```

接下来，我们按 `&` 分割输入查询，以获取一个字符串数组，其中每个元素都是一个名称-值对。这可以通过以下方式完成：

```perl
@name_value_pairs = split(/&/, $query_string);
```

然后，该数组的每个元素再次被分割，这次是按 `=` 分割，分成一个包含名称及其对应值的两元素数组，如：

```perl
($name, $value) = split (/=/, $name_value);
```

接下来，值中的任何加号都通过 `tr` 运算符转换为空格。最后，我们来到最复杂的部分：将编码的特殊字符转换为普通字符。这是通过替换运算符完成的。找到编码字符很容易；我们使用一个以百分号开头，后跟两个十六进制数字的模式。如果我们对模式的十六进制数字部分加括号，则匹配操作会将两个十六进制数字保存在 `$1` 中。然后替换部分必须将十六进制版本转换为十进制 ASCII 码。这可以通过首先对其使用 `hex` 函数，然后使用 `pack` 将其打包成一个字节来完成，使用 "C" 作为第一个参数。替换第二部分中的这些操作显然必须通过使用求值选项来指定。因为值中可能有多个特殊字符，所以我们还必须包含全局选项。因此，适当的替换是：

```perl
s/%([\dA-Fa-f][\dA-Fa-f])/pack("C",hex($1))/eg
```

我们这里的 CGI 程序的目标是从浏览器获取表单数据，计算各种订购项目的成本，将这些成本求和以获得订单的总账单，并将总额以 HTML 页面的形式发送回浏览器。以下是执行这些操作的完整 Perl 程序：

```perl

# This is nuts.pl
# It is a CGI program to process the Nut Sales form
# First produce the header part of the HTML return value

print "Content-type: text/html\n\n";
print "<HTML><HEAD>\n";
print "<TITLE> CGI-Perl Nuts Form </TITLE></HEAD> \n";
print "<BODY>\n";
print "Thank you for your order. <BR> <BR>\n";

# Determine the request method and get the query string

$request_method = $ENV{'REQUEST_METHOD'};
if ($request_method eq "GET") {
    $query_string = $ENV{'QUERY_STRING'};
}
elsif ($request_method eq "POST") {
    read(STDIN, $query_string, $ENV{'CONTENT_LENGTH'});
}

# Split the query string into the name/value pairs

@name_value_pairs = split(/&/, $query_string);

# Split the pairs into names and values and translate the values
# into text (decode hex characters and translate +'s to spaces)
# Also compute the cost of the item and add it to the total and
#  count the cans sold

$total_price = 0;
$total_nuts = 0;

    $value =~ tr/+/ /;
    $value =~ s/%([\dA-Fa-f][\dA-Fa-f])/pack("C", hex($1))/eg;
    if ($name eq "mixed") {
        $cost = 4.0 * $value;
        $total_price += $cost;
        $total_nuts += $value;
    } elsif ($name eq "Spanish") {
        $cost = 3.5 * $value;
        $total_price += $cost;
        $total_nuts += $value;
    } elsif ($name eq "cashews") {
        $cost = 4.5 * $value;
        $total_price += $cost;
        $total_nuts += $value;
    } elsif ($name eq "toffee") {
        $cost = 4.0 * $value;
        $total_price += $cost;
        $total_nuts += $value;
    } elsif ($name eq "chocolate") {
        $cost = 4.25 * $value;
        $total_price += $cost;
        $total_nuts += $value;
    } ##- end of if
} ##- end of foreach

# Produce the result information to the browser and finish the page
print "You ordered $total_nuts cans of nuts <BR> <BR>";
print "Your total bill is: \$total_price <BR> \n";

### 9.9 总结

网页文档的格式通过标记语言HTML来描述。URL是网页上文档的地址。CGI是一种协议，Web服务器通过它根据连接的Web客户端浏览器的请求来运行软件。来自浏览器的输入以文本形式通过服务器传递给CGI程序。CGI程序的输出以HTML格式编写，发送到服务器，服务器再将其转发给客户端浏览器，由浏览器为用户显示。Web文档可以通过将程序的URL放置在锚标签的HREF属性中来使CGI程序可用。这样的标签包含一个链接，点击该链接会触发CGI程序的执行。

HTML表单在网页中呈现，用于收集用户的输入。表单中的信息作为称为查询字符串的编码字符字符串发送到服务器，使用`GET`或`POST`技术。编码很简单：特殊字符将字符串分隔成单独的信息片段。原始查询字符串中的特殊字符被编码为十六进制数字，这些数字是字符的ASCII码。表单可以包含各种小部件，从文本窗口、复选框到菜单。

`GET`方法通过环境变量`QUERY_STRING`将查询字符串发送给CGI程序；`POST`方法通过标准输入发送。`GET`方法的缺点是某些服务器和浏览器会对查询字符串的长度设置任意限制。Perl的`split`、`tr`和`s///`操作符在CGI程序中解码查询字符串时非常方便。CGI程序的输出通过`print`函数创建，并发送回服务器。

`CGI.pm`是一个函数模块，它极大地简化和缩短了CGI程序中所需的一些典型操作。其中一些只是样板HTML的简写，但其他一些提供了更复杂的功能。

### 10.1 目录

Perl 处理目录的函数与处理文件的类似。当然，目录是一种特殊的文件，所以目录使用`opendir`来打开，该函数返回其操作状态：成功为真，失败为假。因此`opendir`经常与`die`一起使用，就像文件输入一样。`opendir`的第一个参数是目录句柄，第二个参数是名称。考虑以下表达式：

```
opendir(MYPERL, "perl_pgms") || die "not open $!";
```

目录成功打开后，可以使用`readdir`读取。此函数接受目录句柄作为参数，返回目录中下一个文件的。例如，当使用`readdir`时：

```
$filename = readdir(MYPERL);
```

第一次调用`readdir`返回目录中的第一个名称。第二次调用时返回第二个名称。如果调用`readdir`时目录中的所有文件已被读取，它将返回`undef`。可以使用`rewinddir`将内部指针重回到目录中的第一个文件，如：

```
rewinddir(MYPERL);
```

可以使用简单的循环列出目录中的文件：

```
while(($filename = readdir(MYPERL)) && length($filename) > 0) {
    print "$filename \n";
}
```

一次读取目录中的所有文件比循环更快。可以通过将`readdir`放在列表上下来实现：

```
@files = readdir(MYPERL);
```

如果你想对文件进行排序，可以使用`sort`强制列表上下文，如：

```
foreach $filename (sort readdir(MYPERL)) {
    print "$filename \n";
}
```

注意，`readdir`返回的文件名不包含任何路径信息。这说明了它可能带来的问题。当你的程序处理完一个目录后，可以使用`closedir`关闭目录，如：

```
closedir(MYPERL);
```

可以使用`mkdir`创建一个新目录，其参数是目录的名称和权限模式。在 UNIX 下，权限模式是用于文件和目录的标准值。`mkdir`的一个示例是：

```
mkdir("new_perl", 0777) || die "Could not make directory: $!";
```

实际上，这并不完全简单，因为 Perl 有一个系统值用来防止某些权限的保护。该值会传递给`mkdir`的值中减去，结果用于新目录的权限。在某些 UNIX 系统上，此值初始化为 077。例如，可以通过`umask`函数设置和确定这个值。当给定参数时，`umask`返回新值。当不带参数调用`umask`时，它返回当前值。

通配符（Globbing）是一种通过使用简写符号来指定相关文件集合的方法。文件的通配符使用星号（`*`）指定。可以通过将表达式放在尖括号中或将其作为参数传递给`glob`函数来实现。例如，使用`glob`函数获取当前目录中所有以`.c`结尾的文件，我们可以：

```
@c_programs = glob("*.c");
```

这也可以通过以下方式完成：

```
@c_programs = <*.c>;
```

目录的模式可以使用`chmod`更改，其第一个参数是新模式。其他参数是要更改模式的文件名称，如：

```
chmod 0777, "perl1.pl", "perl27.pl";
```

如果你是一名 UNIX 程序员，并且这一切听起来很熟悉，那很好！

考虑示例程序`too_big.pl`。它在命令行上接受一个目录名和一个最大文件长度作为参数。此程序的目标是打开给定的目录，读取其所有文件，并显示它找到的、大于最大大小的文件名。请注意，在程序中，在使用`-f`和`-s`测试运算符检查文件之前，需要将目录名和一个斜杠连接到文件名的开头。这是我们之前提到的关于`readdir`只返回文件名而不是完整路径描述的一个例子。考虑以下程序：

```perl
# too_big.pl - 生成所有过大的文件列表
# 输入：    (1) 一个目录，来自命令行
#           (2) 可接受的最大文件大小，来自命令行
# 输出：给定目录中所有大于限制的文件

# 获取参数

if ($#ARGV >= 1) {
    $dir = $ARGV[0];
    $max = $ARGV[1];
}
else {
    print "Usage: $0 <dir> <size>\n";
    exit;
}

# 打开目录
opendir(DIRDIR, $dir) or die "Could not open $dir: $!";

while ($filename = readdir(DIRDIR)) {
    next if ($filename =~ /^\./;
    $path = "$dir/$filename";
    if (-f $path && -s $path > $max) {
        print "$path\n";
    }
}
closedir(DIRDIR);
```

### 10.3 启动程序

在 Perl 中启动外部程序非常简单。可以使用`()`运算符或`system`函数来执行命令。

```perl
$output = `ls -l`;
print "Output:\n$output";

system("date");
```


Perl 有多种方式可以启动或请求执行另一个程序。这些方式通常用于在用户的 Perl 程序运行时执行系统程序。也许最简单的方法是将程序名放在反引号（`` ` ``）中。¹例如，UNIX 和 Windows 都有一个可以从命令行执行并返回当前日期的程序（都名为 `date`）。因此，在 UNIX 或 Windows 下，我们可以这样写：

```perl
$date = 'date';
print "$date \n";
```

请注意，通过此机制执行的程序的输出就是返回值。当我们在 Windows 下运行此程序时，其输出为：

```
Current date is Sat 01-30-1999
Enter new date (mm-dd-yy):
```

当使用反引号方法启动程序时，启动它的程序会等待被启动的程序完成执行后，才继续自身的执行。这称为*同步*执行。

从 Perl 程序启动程序的另一种方法是将程序名作为参数传递给 `system` 函数。此函数返回所请求执行的程序的执行状态。被执行程序的输出照常的定向到 `STDOUT`。通过 `system` 运行的程序是同步运行的。`system` 函数在 UNIX 和 Windows 下都可用。例如，要获取日期，我们可以使用（同时忽略返回的状态值）：

```perl
system("date");
```

此调用产生的结果与使用反引号执行 `date` 相同。

Perl 的 UNIX 实现包含了 `fork` 和 `exec` 函数，它们模仿了同名的 UNIX 命令。这些函数用于通用的进程²创建和控制。请记住，本书的标题宣称自己是“小”书。因此，我们现在声明，描述 UNIX 进程模型以及 `fork` 和 `exec` 的用法显然超出了本书的范围。

在 Windows 下运行的 Perl 程序也可以创建和控制进程。这些功能由 `Win32::Process` 模块提供，但同样超出了任何“小”书的范围。

## 10.4 通过套接字通信

计算机通信是一个庞大而复杂的话题。在本节中，我们将严格限制自己只讨论该话题的一个小角落：在 UNIX 系统上使用套接字和 TCP/IP（传输控制协议/互联网协议）的 Perl 客户端和服务器程序。套接字在其他系统中也可用，但我们不会讨论它们在那些环境中的使用。

*客户端*是计算机上的一个程序，它寻求另一个称为*服务器*的程序的服务，该服务器可能位于地球上其他地方的另一台计算机上（或者可能在太空中的某个地方）。现在，很大一部分计算都是在客户端/服务器模式下使用 TCP/IP 完成的。

套接字是一种通信连接，在 Perl 程序中看起来非常像一个文件。Perl 程序可以向套接字写入数据，也可以从套接字读取数据。套接字起源于加州大学伯克利分校版本的 UNIX。它们由 Perl 的 `Socket` 模块支持。

构建客户端或服务器的第一步是创建一个套接字，这是通过调用 `Socket` 模块中的 `socket` 函数完成的。`socket` 函数接受四个参数，第一个是套接字文件句柄。它的作用与文件的文件句柄相同：它是程序为套接字指定的名称。第二个参数指示协议，对我们来说，它始终是一个互联网套接字。这通过 `Socket` 模块中定义的常量 `PF_INET` 来指定。第三个参数指示套接字类型，对我们来说，它始终是 TCP。这通过 `Socket` 模块中定义的常量 `SOCK_STREAM` 来指定。最后一个参数指示系统上的协议编号，这是通过调用 `Socket` 中的 `getprotobyname` 函数获得的，参数为 "tcp"。因为 `socket` 在失败时返回 false，所以对 `socket` 的调用通常与 `die` 一起使用。因此，要创建一个使用 TCP/IP 的套接字，可以使用以下代码：

```perl
use Socket;
$proto = getprotobyname("tcp");
socket(MY_SOCKET, PF_INET, SOCK_STREAM, $proto) ||
    die "无法创建套接字 $!";
```

我们现在描述构建基于套接字的服务器的过程。第一步是使用 `bind` 函数将之前创建的套接字连接到一个网络地址。然而，在描述 `bind` 之前，我们必须讨论其一个参数的计算，即潜在客户端的互联网地址。它由所选的端口号、地址类型和客户端的互联网地址组合而成。最简单的服务器允许连接到任何客户端，为此在 `Socket` 中定义了一个常量 `INADDR_ANY`，它结合了互联网的地址类型和“任何客户端”的代码。这又通过 `sockaddr_in` 与端口号组合，如：

```perl
sockaddr_in($port, INADDR_ANY);
```

通常将此调用用作 `bind` 的第二个参数。与 `socket` 一样，`bind` 在失败时返回 false，因此通常与 `die` 一起使用。例如，考虑以下代码：

```perl
bind(MY_SOCKET, sockaddr_in($port, INADDR_ANY)) ||
    die "无法绑定套接字 $!";
```

接下来，我们调用 `listen` 函数，让程序关注该端口，“监视”传入的连接。与 `Socket` 中的许多其他函数一样，`listen` 函数在失败时返回 false，因此我们使用 `die` 调用它。`listen` 的一个示例调用是：

```perl
listen(MY_SOCKET, 1) || die "无法监听 $!";
```

`listen` 的第二个参数是等待向该端口发送消息的进程的队列大小。对于我们的简单示例，1 就足够了。

## 10.5 使用 UNIX DBM 数据库

大多数 UNIX 版本都包含一个简单的数据库管理系统，用于处理轻级数据库应用程序。该系统由数据库管理（DBM）函数库支持，这些函数易于使用，并且可以在 Perl 程序中访问。Perl 版本 5 引入了一种新的数据库访问方式，即使用 `tie` 和 `untie` 函数。由于这些函数的复杂性以及本书的简洁性，我们描述的是数据库使用的原始方法，而不是 `tie`/`untie`。

DBM 数据库的结构是键/值对的列表。由于这与哈希的结构相同，因此在 Perl 中通过将数据库连接到哈希来使用 DBM 数据库。对哈希的所有存储操作都会镜像到数据库上。访问先前构建的数据库的程序将该数据库连接到一个哈希并访问该哈希。DBM 数据库实际上存储为两个文件，一个文件名具有 `.dir` 扩展名，另一个文件名具有 `.pag` 扩展名。`.dir` 文件是 `.pag` 文件的索引，数据存储在 `.pag` 文件中。

DBM 在 Perl 程序中最常见的用途之一是提供持久化哈希；即一种在程序或使用它的程序集合的多次运行之间持续存在的哈希存储结构。

`dbmopen` 函数用于创建新的 DBM 数据库和打开现有的 DBM 数据库。它的第一个参数是哈希的名称。第二个参数是数据库的名称，它实际上是存储数据库的两个文件的非扩展名。第三个参数是数据库的 UNIX 访问模式，其含义与文件和目录的访问模式相同。例如，要创建一个新的 DBM 数据库来存储员工姓名及其薪水，这些数据将在程序中存储在 `%salaries` 哈希中，我们可以使用：

```
dbmopen(%salaries, salary_db, 0666) ||
    die "Could not open salary_db!";
```

`dbmopen` 创建的两个文件 `salary_db.dir` 和 `salary_db.pag`。如果在调用 `dbmopen` 时，`%salaries` 中有任何值，它们将不会放入数据库。访问 DBM 数据库后，应该使用 `dbclose` 关闭它。

以下是一个示例：

```perl
# update.pl
dbmopen(%salaries, salary_db, 0666) || die "Could not open salary_db!";
$salaries{"John"} = 50000;
$salaries{"Mary"} = 60000;
dbclose(%salaries);
```

如果需要列出数据库，你可以使用：

```perl
foreach $name (keys %salaries) {
    print "$name: $salaries{$name}\n";
}
```

这是一种相当慢的方式，因为它需要读取磁盘文件两次（一次获取键，一次获取的值）。使用 `each` 获取元素只需要遍历一次：

```perl
while (($name, $salary) = each(%salaries)) {
    print "$name: $salary\n";
}
```

## 10.6 使用 Tk 的图形界面

Tk 是脚本语言 tcl 相关的图形界面（GUI）。由于 Tk 的简单性和强大功能，已经构建了一个模块 Tk.pm，为 Perl 程序提供 Tk 功能。Perl/Tk 提供了常见的 GUI 部件，如按钮、复选按钮、菜单和滚动条。与本章其他主题一样，我们将只讨论 Perl/Tk 的一些功能。Perl/Tk 不是标准 Perl发行版的一部分，但可以从 CPAN 轻松获取。最重要的是，与其他 Perl 模块一样，它是免费的。就像第 9 章中的 CGI.pm 一样，Tk 是一个面向对象的模块，但这次我们将使用它。

构建 Perl/Tk GUI 的第一步是创建一个主窗口，程序的所有部件都出现在该窗口中。该窗口对象在 `MainWindow` 上调用 `new` 来创建，它返回指向新 `MainWindow` 对象的引用，如：

```perl
$big_window = new MainWindow;
```

主窗口是 GUI 中所有部件的父部件。所有部件都出现在主窗口中，并通过调用引用（`$big_window`）到 `$MainWindow` 对象的函数来创建。因此，在主窗口中创建 GUI 函数以如下形式调用：

```perl
$big_window -> Function_Name;
```

最简单的部件是按钮。按钮为用户提供开关，用于输入简单信息或请求程序操作。按钮对象通过调用 `Button` 函数创建，该函数可以接受多个参数。回一下，我们将 CGI.pm 视为一个简单的函数集合。Perl/Tk 中函数的参数通常与 CGI.pm 函数相同的形式传递。它们以关键字形式指定，参数名称首先出现，并带有一个连字符（`-`）。其后是一个隐含符号 `=>`，然后是实际参数的值。所有按钮都需要一个名称或标题，这通过 `text` 参数指定。如果一个按钮在按下时要触发某个程序操作，则该操作在一个称为*回调*函数的函数中描述。按钮的特定回调函数通过 `command` 参数指定。例如，考虑：

```perl
$quit_button = $big_window -> Button(-text => "Quit",
                                -command => \&quit);
```

其中 `Quit` 是标题，`quit` 是回调函数的名称。我们现在创建了一个按钮部件，但它尚未显示在屏幕上。这通过在按钮对象上调用 `pack` 函数来实现，如：

```perl
$quit_button -> pack;
```

`pack` 函数可以接受多个不同的参数，允许用户指定部件在主窗口中的位置，但我们不会讨论它们。使按钮工作所需的最后一步是创建一个循环来监视按钮的用户操作。这是通过调用 `MainLoop` 来完成的。在我们的 `$quit_button` 的简单情况下，我们可以使用：

```perl
MainLoop;
sub quit {
    exit;
}
```

所有这些组合在一起如下：

```
# quit.pl - 一个简单的退出按钮

use Tk;

# 创建主窗口
$big_window = new MainWindow;

# 创建并打包退出按钮
$quit_button = $big_window -> Button(-text => "Quit",
                                -command => \&quit);

$quit_button -> pack;

# 循环监视按钮
MainLoop;

# 回调函数
sub quit {
    print "The quit button was pressed \n";
    exit;
}
```

回想一下，单选按钮是组中的按钮，其相关特征是同一时间只能处于按下状态或状态。如果你按下其中一个，而当前有另一个按钮被按下，那么你的操作将使该按钮变为未按下状态。一组单选按钮的值存储在一个程序变量中，该变量在创建单选按钮时命名。可以通过检查此变量的值来确定具体哪个单选按钮被按下。单选按钮通过调用 `Radiobutton` 创建，它可以接受多个参数。值变量通过 `Radiobutton` 的 `value` 参数指定。单选按钮组的初始值通过将该值分配给单选按钮组的值变量来指定。显然，组中的所有单选按钮都使用相同的值变量。要一起创建一组按钮，我们首先在主窗口中创建一个框架来放置它们。接下来将解释这一点。

`Radiobutton` 函数的一些可能参数如下：

- `text`：为单选按钮提供名称。

- `background`：指定单选按钮的背景颜色。

- `foreground`：指定用于显示按钮名称的颜色。

- `variable`：指定存储单选按钮组值的变量。

- `command`：指定单选按钮的回调函数。

框架对象通过窗口对象调用 `Frame` 创建，如

```bash
$frame = $big_window -> Frame;
```

框架的特性可以通过调用 `configure` 函数来设置，该函数可以接受多个参数。在下一个示例中，我们调用 `configure` 来使用 `background` 参数设置框架的背景颜色。我们使用 `borderwidth` 参数设置框架边框的宽度。边框宽度是框架边框与其部件之间的像素距离。

打包我们创建的按钮后，我们还必须打包框架。

下面的示例说明了这些想法。它创建了三个按钮，可用于更改框架的背景颜色。

```
# tstradio.pl - 一个说明 Tk 单选按钮的程序

use Tk;

# 创建主窗口和用于放置按钮的框架

$big_window = new MainWindow;
$frame = $big_window -> Frame;
$frame -> configure(-background => "red",
                   -borderwidth => 60);

# 设置单选按钮组的默认颜色

$color = "red";

# 创建三个单选按钮，一个用于蓝色，一个用于红色，
# 一个用于绿色框架背景颜色

$blue = $frame -> Radiobutton (-text => "Blue",
                              -background => "yellow",
                              -foreground => "blue",
                              -variable => \$color,
                              -value => "blue",
                              -command => \&bluebk);

$red = $frame -> Radiobutton (-text => "Red",
                             -background => "yellow",
                             -foreground => "red",
                             -variable => \$color,
                             -value => "red",
                             -command => \&redbk);

$green = $frame -> Radiobutton (-text => "Green",
                               -background => "yellow",
                               -foreground => "green",
                               -variable => \$color,
                               -value => "green",
                               -command => \&greenbk);

# 创建退出按钮

$quit = $frame -> Button (-text => "Quit",
-foreground => "white",
-background => "purple",
-command => \&quit);

# 打包按钮和框架

$blue -> pack;
$red -> pack;
$green -> pack;
$quit -> pack;
$frame -> pack;

# 创建循环监视按钮

MainLoop;

# 回调函数

sub bluebk {
    $frame -> configure(-background => "blue");
}

sub redbk {
    $frame -> configure(-background => "red");
}

sub greenbk {
    $frame -> configure(-background => "green");
}

sub quit {
    exit;
}

### 10.7 总结

在 Perl 中可以创建、删除和遍历目录。通配符可用于指定目录中的文件类别或文件组。

可以使用 `getpwent` 检索 UNIX 帐户信息。在 Windows 中，可以使用 `Win32` 模块中的函数检索有关系统和一些帐户的信息。

Perl 提供了两种不同的方式来启动其他程序：反引号和 `system` 函数。这些通常用于执行可以直接从命令行运行的程序。

套接字为可能分布式的进程之间的通信提供了一种简单的标准方法。套接字和 TCP/IP 协议是提供 Internet 处理的主要方法。Perl 的 `Socket` 模块提供了创建和使用套接字的软件。`Socket` 的功能类似于 C 中可用的功能。TCP/IP 服务器通信通过创建套接字、将其绑定到 Internet 地址，然后监听套接字以获取消息来实现。客户端通过创建套接字并将其绑定到服务器的 Internet 地址来构建。

UNIX 简单数据库管理系统 DBM 可通过哈希提供给 Perl 程序。程序中的哈希变量通过调用 `dbmopen` 连接到数据库。建立此连接后，对哈希的任何操作都会反映在数据库中。本质上，DBM 数据库是一个持久化的哈希。

Tk 的图形用户界面功能通过模块 `Tk.pm` 提供给 Perl 程序。Tk 工具功能强大且易于使用。
