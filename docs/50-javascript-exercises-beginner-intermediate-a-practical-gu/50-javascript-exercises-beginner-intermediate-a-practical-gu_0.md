1-5. 输出一个数除以零的结果。

### 第 2 节：基本运算符

2-2. 使用取模运算符求两个数的余数。

### 第 3 节：字符串

3-2. 将字符串转换为大写。
3-3. 检查字符串是否包含单词"apple"。
3-4. 将一个逗号分隔的字符串拆分为数组。
3-5. 将字符串中所有的"apple"替换为"orange"。

### 第 4 节：条件语句
4-1. 编写一个条件语句，如果数字大于 0，则输出"positive"。
4-2. 扩展上述条件，对于小于 0 的数字输出"negative"，否则输出"zero"。
4-3. 使用`switch`语句处理一周中多天的不同情况。
4-4. 检查字符串长度是否大于 5。如果是，输出"Long string"，否则输出"Short string"。
4-5. 使用三元运算符判断一个数是奇数还是偶数。

### 第 5 节：循环
5-1. 使用`for`循环输出数字 1 到 10。
5-2. 使用`while`循环输出数字 5 到 15。

```javascript
function callbackFunction(data, callback) {
  if (data) {
    callback(null, "Data processed successfully");
  } else {
    callback("Error processing data", null);
  }
}

function promiseFunction(data) {
  return new Promise((resolve, reject) => {
    callbackFunction(data, (error, result) => {
      if (error) {
        reject(error);
      } else {
        resolve(result);
      }
    });
  });
}
promiseFunction(true).then(console.log).catch(console.error);
```
