Whenever a RESTful API is called, the server will transfer to the client a representation of the state of the requested resource. In fact, we use this just about every day! They operate independently of each other and both are replaceable.Cache: Data from the server can be cached on the client, which can improve performance speed.URL Composition: We use a standardized approach to the composition of base URLs.
