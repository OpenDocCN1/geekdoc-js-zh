# JavaScript 简介

JavaScript 是一种解释型编程语言，基于 ECMAScript 标准构建。该语言的定义非常广泛，因为它可以被定义为基于原型的、命令式的、弱类型的和动态的语言。

JavaScript 主要作为客户端编程语言使用，作为 浏览器的一部分实现，允许开发者以更改进的方式实现网页中的用户界面和动态功能；尽管也存在服务器端的 JavaScript 实现（SSJS），但该语言的流行完全归功于客户端的实现。JavaScript 也可以用于 Web 之外，例如为 PDF 文档和桌面小组件添加交互功能。

JavaScript 的语法与 C 语言相似，尽管它借鉴了 Java 编程语言的名称和约定。然而，尽管名字相似，但 Java 和 JavaScript 之间并没有关系，并且具有不同的语义和目的。

JavaScript 最初由 Netscape 的 Brendan Eich 以 Mocha 的命名开发，后来被重命名为 LiveScript，最后称为 JavaScript。名称的更改恰好赶上 1995 年底 Netscape 在其网页浏览器 Netscape Navigator 2.0B3 版本中增加对 Java 技术支持的时刻。JavaScript 这一名称引起了误解，给人一种该语言是 Java 扩展的印象，许多人将其描述为 Netscape 为了获得声誉并在新的 Web 编程语言中进行创新而采取的营销策略。

第二年，微软在其 Internet Explorer 3.0 浏览器中实现了类似的客户端编程语言。微软将其客户端语言称为“jscript”，以避免与品牌相关的问题。Jscript 这个词看起来非常相似，以至于 "javascript" 和 "jscript" 经常被通用，但 JScript 的规范并非 100% 兼容 ECMA 规范。

为了避免这些不兼容性，世界网联盟（W3C）设计了标准的文档对象模型（DOM，或 document object model），它被包含在 Internet Explorer 6 版、Netscape Navigator、Opera 7 版、Mozilla Firefox 自首次发布起及之后的所有现代版本中。

1997 年，有一项建议将 JavaScript 提交给欧洲计算机制造商协会 ECMA 的标准，尽管其名为欧洲，但它并不是欧洲的，而是国际性的，总部位于日内瓦。1997 年 6 月，它以 ECMAScript 的名称被采用 ECMA 标准。JavaScript 也成为了 ISO 标准。

由于其标准化和互联网的广泛采用，JavaScript 已成为地球上最常用的编程语言。


# JavaScript 的用途

今天的大多数网页中都存在 JavaScript。很有可能你现在正在查看的页面包含了 JavaScript 代码。尝试一下这个活动：在网页上点击右键，然后点击“查看源代码”。你应该能在页面代码的某处找到“JavaScript”这个词。

虽然 HTML 标记语言允许 Web 开发人员格式化内容，但 JavaScript 允许他们让页面动态化。例如，HTML 允许将文本加粗、创建文本框和创建按钮，而 JavaScript 允许更改页面上的文本、创建弹出窗口消息，并对文本框中的文本进行验证，以确保必填字段已填写。JavaScript 通过允许用户与网页进行交互、点击元素并更改页面，使 Web 页面变得更加动态。

# JavaScript 能为你做什么

让我们退一步，数一数 JavaScript 的优点：

- JavaScript 非常容易实现。你只需要将代码放在 HTML 文档中并告诉浏览器它是 JavaScript 即可。
- JavaScript 在用户的计算机上运行——即使在他们离线时也是如此！
- JavaScript 允许你创建高度响应的界面，提高用户体验并提供动态功能，而无需等待服务器响应并显示另一个页面。
- JavaScript 可以在用户需要将内容加载到文档中，而无需重新加载整个页面——这通常被称为 Ajax。
- JavaScript 可以测试浏览器中可能的功能并做出相应反应——这被称为非侵入性 JavaScript 原则，有时被称为防御性脚本。
- JavaScript 可以帮助修复浏览器问题或修补浏览器支持的漏洞——例如修复某些浏览器中的 CSS 布局问题。

对于一种直到最近还被“高级编程语言”程序员所嘲笑的语言来说，这已经非常多了。JavaScript 复兴的一个原因是，我们现在正在构建越来越复杂的 Web 应用程序，而高交互性需要 Flash（或其他插件）或脚本。JavaScript 无疑是最佳选择，因为它是 Web 标准，或者被跨浏览器原生支持（在某种程度上——某些东西在浏览器之间有所不同，这些差异将在后续文章的相关位置讨论），并且与其他开放的 Web 标准兼容。

# JavaScript 的其他现代用途

这基本上就是我们现在使用 JavaScript 所做的。我们增强了旧的、经典的 Web 界面——点击链接、输入信息和提交表单等——使其对终端用户产生响应。例如：

注册表单可以在你输入用户名时检查其是否可用，防止你不得不忍受令人沮丧的页面刷新。

搜索框可以在你打字时根据你目前输入的内容提供建议结果（例如，输入“bi”可以调出包含该字符串的建议，如“bird”、“big”和“bicycle”）。这种使用模式被称为自动补全。

不断变化的信息可以定期加载而无需用户交互，例如体育比赛结果或股市行情。

对于那些“锦上添花”但对某些用户来说可能冗余的信息，可以在用户选择访问时再加载。例如，一个网站的导航菜单可能有 6 个链接，但当用户激活菜单项时，可以按需显示更深层页面的链接。

JavaScript 可以修复布局问题。使用 JavaScript，你可以找到页面上任何元素的位置和区域，以及浏览器窗口的尺寸。利用这些信息你可以防止元素重叠和其他问题。例如，假设你有一个多级菜单；在显示子菜单之前检查是否有足够的空间让其出现，你可以防止滚动条或菜单项重叠。

JavaScript 可以增强 HTML 为我们提供的界面。虽然有一个文本输入框很不错，但你可能想要一个组合框（combo box），允许你从预设值列表中选择或输入自己的值。使用 JavaScript，你可以增强普通的输入框来实现这一功能。

你可以使用 JavaScript 制作页面元素的动画——例如显示和隐藏信息，或高亮页面的特定部分——这可以带来更好用、更丰富的用户体验。

# 明智且负责任地使用 JavaScript

没有什么是 JavaScript 办不到的——尤其是当你将其与 Canvas 或 SVG 等技术结合时。然而，能力越大责任越大，在使用 JavaScript 时你应该始终记住以下几点：

- JavaScript 可能不可——这很容易测试，并不是真正的问题。然而，依赖 JavaScript 的东西在创建时应该考虑到这一点，你应该确保当 JavaScript 不可用时，你的网站不会崩溃（即核心功能不可用）。
- 如果使用 JavaScript 没有帮助用户快速、高效地实现目标，你可能用错方法了。

# 开始使用 JavaScript

## 入门：设置你的代码

JavaScript 代码放在哪里？嗯，在页面的 `html` 标签内的任何地方。你的代码以 `<script type="text/javascript">` 开始，以 `</script>` 结束。

<html>
<head><title>This is an example page</title></head>
<body>
Welcome to the JavaScript course!
<!--
document.write("Hi here. This text is written using JavaScript!")
-->
</script>
</body>
</html>

输出：Hi here. This text is written using JavaScript!

所示，我们用 `<script type="text/javascript">` 开始了脚本。红色部分是完全可选的，因为浏览器默认认为 `<script>` 标签是 JavaScript，尽管出于验证原因，你仍然应该包含它。上述示例中的第二和第三行是 `<!--` 和 `-->`，它们是为 JavaScript 定制的 HTML 注释标签。建议包含它们，以防止不支持 JavaScript 的非常旧的浏览器显示你的代码。如果你不包含它们且有人在使用这种浏览器，浏览器会将你的所有代码作为文本倾倒到屏幕上，换句话说，并不好看！这个脚本唯一的“功能部分”是 `document.write("......")` 部分。它基本上会将你引号内的任何内容写入页面。现在不要太担心为什么这样做，我们稍后会详细讨论。我们用 `</script>` 结束整个代码，这终止了脚本并回到 html。

像 HTML 一样，你可以在 JavaScript 代码中插入注释。JavaScript 注释与 HTML 注释不同，后者是注释掉脚本中的行，使其不被解释。JavaScript 注释的语法是：

//注释内容

用于单行注释，或者

/*
注释内容
*/

用于多行注释：



//this script does nothing and is useless!
/*
Hay, don't involve me in this!
*/

好了，我们现在准备好开始真正的编程了！

JavaScript 与许多编程语言一样，依赖于对象、函数和事件处理器来创建可运行程序。如果你对这些术语以及如何使用它们一无所知，不要担心。在我们完成本教程时，你将掌握它们。

## JavaScript 与 HTML

你可以将 JavaScript 视为 HTML 的扩展；即一个插件。以下是它的工作原理：HTML 标签创建对象；JavaScript 允许你操作这些对象。例如，为了像表 1 所示创建一个网页，在创建文档之后，你可以使用 JavaScript 与其进行交互。例如，你可以使用一个名为 `onload` 句器的特殊结构来触发动作——也许当文档加载到浏览器中时。你通过 JavaScript 交互的其他 HTML 对象还包括窗口、文本字段、图像和应用程序。

表 1：创建和操作对象

| 对象 | HTML 标签 | JavaScript |
| :--- | :--- | :--- |
| 网页 | `<body>...</body>` | document |
| 图像 | `<img name="myimage">` | document.myimage |
| HTML 表单 | `<form name="myForm">...</form>` | document.myForm |
| 按钮 | `<input type='button' name="myButton">` | document.myButton |

要在网页中添加 JavaScript，你需要做的只是将 JavaScript 代码嵌入到 HTML 文件中。在你嵌入代码的行下方，你可以响应事件处理器的要求引用或调用该 JavaScript 代码。在向 HTML 文件中嵌入 JavaScript 代码时，你有两个选择：

你可以使用 `<script>` 标签将 JavaScript 代码直接包含在 HTML 文件中。在下面的示例中，一个名为 `myFunction` 的 JavaScript 函数定义在 HTML 文件的顶部。在 HTML 文件的下方，该函数与一个事件处理器关联——具体是 `onclick` 事件。（换句话说，当用户点击按钮时，`myFunction` 函数中包含的 JavaScript 代码就会运行。）

<html>
<head>
<script language="JavaScript">
// JavaScript 语句放在这里
function myFunction() {
// 更多 JavaScript 语句放在这里
}
</script>
<body>
<form name="myForm">
<input type="button" name="myButton" value="Click to order" onclick="myFunction();">
</form>
</body>
</html>

你可以使用 `<script>` 标签将一个独立的外部 JavaScript 文件（仅包含 .js 扩展名的 JavaScript 语句的文件）包含到 HTML 文件中。在示例中，JavaScript 函数定义在 `myfile.js` 中。当用户点击链接时，该函数会被触发或调用。

<html>
<head>
<script language="JavaScript" src="myfile.js"></script>
</head>
<body>
<a href="javascript:myFunction();">点击这里</a>
</body>
</html>

因为网页不仅仅由 HTML 组成，所以 JavaScript 提供的不仅仅是 HTML 对象。JavaScript 还提供了对浏览器特定对象的访问。浏览器插件（如 RealPlayer 和 Adobe Acrobat）、特定查看器的名称和版本以及当前日期，都是你可以使用 JavaScript 处理的非 HTML 对象示例。

构成网站的所有对象——HTML 对象、浏览器相关对象以及内置在语言中的特殊对象——统称为文档对象模型 (DOM)。

## HTML 基础

如果你对 HTML 一无所知，你绝对应该从基础开始，并在网上进行彻底的阅读。一旦你掌握了基础，其余部分应该非常简单。然而，像每个学科一样，HTML 基础必须细心学习。你不能跳过任何步骤。建议一次只关注 HTML 基础的一个方面，只有在理解了较简单内容后，再进入高级阶段。再给一个建议——不要气馁，因为 HTML 基础看起来可能需要很长时间才能学习；这一切都是值得的。

首先，你必须知道 HTML 是什么以及为什么要用它。嗯，HTML 代表 HyperText Markup Language（超文本标记语言），它是一种脚本语言。简单来说，HTML 是一个纯文本文件，除了标记标签外什么都没有。当浏览器收到打开网页的指令时，它会查找页面中的 HTML 代码。然后浏览器会将这些代码转换为布局、图像和指向其他网站的链接。你必须记住的其他基础之一是，HTML 文件是文本文件，因此可以使用最简单的文本编辑器编写。一些流行的文本编辑器，如 FrontPage 和 Dreamweaver 将允许你使用 Word 创建页面。现在，这有多容易呢？

为了让事情变得更简单，这里有一些你无疑非常有吸引力的更多 HTML 基础。一旦你通过一个简单的文本编辑器完成了页面布局，你可以让专业的编辑器来完成 HTML 部分。这会花费你很少的费用。此外，如果你仍在自己进行 HTML 编码，还有其他有用资源可以参考。例如，如果你觉得某个效果很酷，你甚至可以从其他页面借鉴代码。你只需要编写代码、保存它，并给文件加上 .html 扩展名。

在 HTML 基础方面，你必须知道的另一个重要点是标签。标签告诉浏览器如何解码文本。然后你当然必须关注页面结构。页面结构由头部 `<head>`（不可见的文本和标签）和主体 `<body>`（可见的）组成。你必须对每个部分以及高级结构进行深入研究。一旦你掌握了窍门，一切都应该是有趣且简单的，并且你会喜欢最终的结果。

## 你知道 HTML 是什么吗？

HTML 代表 Hyper Text Markup Language（超文本标记语言）。

它本质上是人们在万维网上交流和认可彼此的方式，因为它是核心标记语言。超文本标记语言的最新版本 HTML5 最近发布，并带有值得自豪的新功能和元素。它非常容易使用；它就是这样设计的。你不需要成为程序员就可以使用它。它是一种为了创建网站而设计的语言。

它是浏览器用于显示内容的标记语言。它控制格式、字体、边距和其他项目。它不是，因为它是一种功能性标记语言（主要指定文档结构），而不是页面布局。它的确切渲染并不是由发布的文档指定的，而是某种程度上留给浏览器的裁量权。

它是为了构建文档而设计的。关键在于：如果你按照预期用途使用每个元素，你将拥有一个更漂亮、更有语义化的网络，而且它终于停止被滥用来构建并非其设计初衷的复杂应用程序。

它通常以不可编辑的方式由浏览器显示——它迫使用户使用外部软件编辑原始内容。它是一种非常稳定的标记语言格式。命令在任何地方含义都相同。它经常被人们指责是一种糟糕的语言。习惯于 XML 的人会抱怨缺乏标记作者和日期等的良好元素。

它是最为人知的标记语言。尽管该库是用编写的



多种语言绑定使得它可以在其他环境中可用。它是一种非交互式布局语言。它可以对文本和图形进行布局，并提供颜色、**粗体**、闪烁字体等。HTML 也是一种超文本标记语言。超文本是指任何格式的文本，但增加了一个功能：文本的部分链接到文本的其他部分，使得可以很容易地从文本的一个部分跳转到另一部分。

它的目的不仅仅是包含内容，它还包含了描述自身和引用更多内容的数据。网络上的文本不仅仅是线性的，它是超文本。它的目的并不是重现艺术家梦想中视觉效果的精确外观。相反，它是为了让信息以结构化的方式组织，以便从设计的宽屏专业工作站到文本模式 VT100 终端，再到盲人的语音文本阅读器，都能以易理解的方式进行渲染。它就是代码，仅此而已。

它不是一种编程语言——它是一种“标记”语言，通过将简单的代码嵌入到描述文档结构、布局和格式的叙述中来实现功能。这些代码由网络浏览器进行“解释”或“解析”，并希望页面能按照设计的意图进行显示。它通常在 Firefox 或 Internet Explorer 等网络浏览器中读取，并作为网页显示在用户的屏幕上。由于许多网页的默认属性未定义，由相同 HTML 代码编写的网页在不同的浏览器中可能看起来不同。它本质上是人们在万维网上进行通信和认可彼此的方式，因为它是核心标记语言。最新版本的超文本标记语言 HTML5 最近发布，并带有值得自豪的新功能和元素。

它本身并不是一种语言。它由放置在元素周围的标签组成，这些标签会改变这些被包围元素的属性。HTML 是一种复杂的脚本语言，而这个免费文本编辑器可能就是轻松创建网站的关键。它由一系列标签组成，类似于命令，告诉网络浏览器要做什么。这些标签可以输入到任何普通的文本编辑器（如记事本或 Simple text）中，并且在顺序正确的情况下，就能形成网页。

让我们快速回顾一下这段代码的作用。首先，你需要理解 jQuery 是一个扩展了 JavaScript 语言的库。在创建任何 jQuery 插件时，你本质上是在扩展你的插件扩展 jQuery 库的方式，而这又是在扩展 JavaScript。真正理解你的插件如何扩展 jQuery 库，需要理解 JavaScript 的 `prototype`（原型）属性。虽然它没有被直接使用，但 JavaScript `prototype` 属性通过 jQuery 属性 `fn` 在后台使用，`fn` 是原生 JavaScript `prototype` 属性的 jQuery 别名。

简单来说，你通过 `fn."your-plugin-name"` 从 jQuery 扩展你的插件。

此外，我们还可以添加选项来传递给我们的插件。一个 jQuery 插件可以包含默认值和选项。选项（options）是你传递给插件的参数。与其发送多个参数，不如使用一个选项对象，你可以发送多个属性，这是 jQuery 的标准做法。在插件中允许选项时，最佳实践是使用 `defaults` 对象设置默认选项。与选项一样，`defaults` 是一个对象字面量，它应该包含你允许传递给插件的属性。

让我们快速为插件添加选项，以展示它是有多简单。我们将传递一个选项参数，在插件初次加载时打开折风琴的第一部分。

(function($) {
  $fn.simpleAccordion = function(options) {
    var state = $.extend({}, {open: false}, options);

    return this.each(function() {
      var dts = $(this).children('dt');

      dts.click(accordionClick);

      dts.each(reset);

      if(state.open)
        $(this).children('dt:first-child').next().show();
    });

    function accordionClick() {
      $(this).siblings('dt').each(hide);
      $(this).next().slideDown('fast');

      return false;
    }

    function hide() {
    }

    function reset() {
      $(this).next().hide();
    }
  });
})(jQuery);
```

如果你注意到，我们使用了 `open:false` 的默认值，所以如果没有传递任何选项，插件将假设你希望在初次加载时关闭折风琴。当插件接收到选项时，你可以依赖 `$.extend` 方法执行实际的覆盖。`$.extend` 方法的作用是合并两个或多个对象。

## 为什么 JavaScript 对大小写敏感如此重要？

这是由本质决定的。首先，脚本是用纯文本编写的，但它不仅仅是 HTML（HTML 在很大程度上不区分大小写）那样的标记，它是代码，因此受到浏览器内部机制（DOM APIs）更严格的审查。

var names, Names;

这两个变量看起来几乎一样，但对 JS 来说，它们之间是天壤之别。重要的是我们要意识到这一点，不是因为它的重要性，而是因为它的本质。它就是它本该的样子。

function Person(name, age){
  this.name = name;
  this.age = age;
}
var person = new Person("Zach", 29);

我们可以忽略这段代码的构成，因为可能还没有介绍对象。这里的重点是展示 `person` 和 `Person` 是两个完全不同的对象。`Person` 是一个对象构造函数，而 `person` 是该构造类的实例。

console.log(person);
// { name: 'Zach', age: 29 }

以及，

console.log(Person);
// [Function]

目前，我们都必须检查自己的大小写，否则可能会遇到负面后果，如语法错误、引用错误和其他异常。培养敏锐的眼力，并记住 JS 是区分大小写的。对此我们无能为力。

## 信誉循环

时而时地

在旧世界，我们去学校获取信息，我们信任法律和其他权威，并将广告当作娱乐。大多数 30 岁以上的人还记得，每个人在电影开始前几分钟到达电影院，只为了看广告。今天，我们几乎随处都能获得信息。我们质疑权威，因为他们服务的是系统而不是人民，而广告已经或很快将成为最不可信的信息。今天的广告是单向交流，而消费者想要并要求互动。

我们变得越来越具有批判性、见多识广，并希望自己搜索和发现信息。经常向朋友或小社区/亚文化寻求参考，多或是一个规则；我们绝不相信第 3 页的广告。广告业长期以来产生精良但价格过高的材料，这在未来将是不可能的。我们都知道，在如今的媒体喧嚣中，很难让自己的声音被听到，增加一次广告活动并不是让你穿过噪音的最佳解决方案。

我们质疑的是广告本身的现象，以及所有（在所有其他意义上）将昨天的广告文化护在手中的聪明男/女人们。有很多例子表明广告并没有提高销量。那么为什么我们仍然有这种“广告景观”文化，拥有那些没有产生预期效果的昂贵广告呢？

恐惧

哪些基本要素被用于设定媒体预算？我们只能推测，但我们完全可以说，心理影响是巨大的。对安全的渴望和对失败的恐惧比质疑以前做过的事情及其结果更强大。

一个昂贵且失败的广告活动无法从财务或理性角度合理化。但从情感和心理原因来说，这种情况经常发生。我们看到的是一种全球性的精神幻觉，一群成功的公司（广告代理商）正在销售被被夸大的产品。这怎么会发生？广告已经变成了一种保险费吗？

## 感知

接收者的感知已经发生了。随着互联网以及某些地区的全球化（从积极角度），人们有了评估广告能力的独特可能。过去传播信息需要几天或几个月，而今天只需要几秒钟。如今人们更倾向于直接从网络上的搜索引擎、朋友、有影响的小群体或编辑媒体中获取他们的价值观、影响和建议。例如：如果你去纽约并想住一家非常特别酒店，你会查看酒店广告吗？不太可能。你更倾向于问朋友或阅读酒店评论。很少有人会信任酒店广告：它们是主观的，只传递酒店的信息。这有多可信？

## 线条之前 (Before the line)

在当今市场上，你需要一套卫生因素才能立足。所有的竞争对手都有良好的质量、良好的服务、良好的渠道、良好的人员、良好的价格、良好的沟通以及等方面……在索尼有句说法，所有产品的功能、性能、技术和价格都是相同的。他们的产品与竞争对手的唯一区别就是设计。为什么不把大部分精力放在开发良好的设计上呢？

创意行业内部有大量关于线上广告（ATL）和线下广告（BTL）沟通的讨论。红角坐着的是 ATL，它涉及杂志、广播、电视和户外印刷等传统广告。在蓝色区域我们将找到 BTL，它涉及公关（PR）、网络、直邮营销（DM）、零售沟通等。如果你问我们，ATL 已经被击倒了。但我们又向前了一步，引入了自己的 BTL：线条之前（Before the Line）。我们的 BTL 像蝴蝶一样飞舞，又像蜜蜂一样刺人……

## 更快的马 (Faster horses)

直到今天，营销人员一直负责将新产品引入市场，这（仅仅）是因为他们的工作是了解人们喜欢和想要什么。但他们真的知道人们需要什么吗？观察人们在做什么比听他们说什么更有趣。看看你的孩子；他们喜欢你，但他们不喜欢你让他们做的事。如果让亨利·福特（Henry Ford）在直接询问人们的需求时，他可能得到的答案是“更快的马”，而不是“四四轮汽车”。

我们认为营销人员经常具有同样的狭隘思维。他们中的许多人看不透现有类别，往往追求已经存在且可能的东西。

所以，让一种创意设计文化席卷组织，将研发部门的创新思维与营销部门外向的随者相结合。只有通过结合不同的技能和思维，你才能创造出真正的创新，获得改变未来的可能。

既然你无法赢得广告战，不如在“信誉环路”中兜一圈吧！

让产品自己说话。给它们一个存在的理由（raison d'être）、个性和灵魂！这可能是差异化产品供应的最佳方式。从纯粹的财务角度来看：为什么不生产那些能够进行高效沟通的产品呢？

为什么不将资金和精力从产品周期的末端（广告）转移到开始（研发）？通过这样做，公司可以更具创新性，并使其能够从开始就将沟通特性融入到产品中。通过赋予产品和服务更好的意义，目标群体自发寻找它们的机会会大得多。

一个很好的例子：当苹果在2001年推出 iPod时，他们耗费了2450万美元来发布该产品。这是一笔巨款，但可能只是使用一个不那么吸引力的产品来达到同样的全球成功所需成本的十分之一。良好的设计和口碑完成了大部分工作。

正如伟大的瑞典平面设计师奥莱·埃克斯塞尔（Ole Eksksell）在1964年描述的那样：设计 = 经济。最后：这一切关乎掌控局面。

## 设计策略触无处不在 (A design strategy has its tentacles everywhere)

我们坚信，公司将通过良好的设计和创新策略建立更具信誉的品牌，而不是在最后只用广告包装产品。广告资金应该更好地用于那些能产生影响并造福业务和社会的创新。谁不想通过开发更具吸引力和可持续性的产品或服务来让人们的生活变得更好、更平等、更快乐呢？

有些人可能会认为一切都会被复制：产品或服务。当然会，如果它足够成功。当每个人都拥有相同的技术时，复制永远存在。因此，你必须差异化并保持独特性，你需要更聪明、更主动。前进的良好方法是少技术官僚主义而多关注文化，因为企业的价值观是抄袭者最难复制的蓝图。通过在公司战略中整合设计策略（与营销、人力资源、研发、财务等一起），你会走得非常远。

我们每天都使用数组

一袋 M&M 糖是 M&M 类型的数组。它是一个糖果的集合。

如何声明一个数组？

声明数组与声明其他变量非常相似。唯一的区别在于你正在声明一个包含多个值的变量。让我们比较一下这两个声明。

```

在这种情况下，我们将数组的大小设置为 6，因为我们添加了 6 个值。

# JavaScript 和 Ajax

JavaScript 是一种客户端脚本语言。当你打开网页时，浏览器首先从服务器下载正确显示该页面所需的所有必要文件。这些必要文件包括 HTML、CSS、图像、视频等，以及 JavaScript 文件。下载完成后，浏览器会在窗口中显示该页面，任何与其关联的脚本将从下载的脚本文件中运行。

在 Ajax 技术中，用户输入和其他数据通过 JavaScript 发送到网络服务器。JavaScript 创建 XML_REQUEST_OBJECT 来连接服务器、提交数据并请求服务器响应。当响应返回时，会触发 JavaScript 事件，然后执行与该事件相关的函数。因此在 Ajax 技术中，JavaScript 只用于在客户端和服务器之间传输数据，而主程序（即数据处理）在服务器端使用 PHP 或或其他服务器语言执行。

由于 JavaScript 从客户端计算机运行，它的执行时间非常短，几乎是瞬时的。View 可以在不连接服务器的情况下运行 JavaScript。在 Ajax 中，查看器必须连接服务器。此处的执行时间要长得多，取决于它们的互联网连接速度、服务器硬件以及客户端与服务器之间传输的字节数。

在服务器安全方面，JavaScript 是绝对安全的，因为它不从客户端向服务器传输任何用户输入。但在 Ajax 中，你必须特别小心，以防止来自恶意用户的恶意数据。

在 JavaScript 中，你无法隐藏源代码。用户可以从运行在他们计算机上的源代码视图轻松读取你的源码。但在 Ajax 中，数据处理发生在服务器端，因此用户无法看到程序源码。

在 Ajax 中，你可以用服务器数据库支持你的程序。

对于一个长程序，如果你使用 JavaScript 实现它，网页的大小将变得更大。这将花费更长的时间，这是一个糟糕的 SEO 特性。但在 Ajax 中，你可以运行长程序处理数据库中的数千条数据，你的页面大小仍然保持很小。

由于并非所有浏览器都严格遵循任何特定标准，因此编写浏览器无关 JavaScript 程序并不容易。

JavaScript 只用于某些数据安全不是重要考虑因素特定应用程序，而 Ajax 技术的应用范围是无限的。

# 什么是 CSS？

CSS 代表级联样式表（Cascading Style Sheets）。CSS 是一组控制网页外观的指令。

XHTML 是扩展超文本标记语言（Extensible HyperText Markup Language）。它比 HTML 更强大。

你可以用 CSS 做？

你可以构建布局，调整大小和颜色。

# 如何让搜索引擎看到

据说搜索引擎在理解 CSS 方面存在一些问题。如果你的网页有很多垃圾内容，爬虫将会很困难。因此，CSS 可以让你的网页保持整洁，无需为每个元素编写冗余代码。这里有一个编写标题的示例：

示例：
```css
h1 {font-family: Arial; size: 18px; font: bold;}
```

# CSS 语法

首先，CSS 可以在任何文本编辑器中编写。但文本文件必须以 CSS 扩展名保存。

CSS 语法由选择器（selector）和声明（declaration）组成。选择器是网页主体内的标识符；声明是标识你要应用的样式的代码。假设你想让所有的标题都是绿色的，字体为 Arial。CSS 的代码如下：

注意：代码周围不要包含引号。

```css
H1 {color: green; font-family: Arial;}
```

注意：注意属性和规则必须封装在 `{}` 中。

# CSS 的放置位置

你的 CSS 代码可以放在三个地方：

- 在 Head 内部（内部，Internal）：用于具有独特样式的单个网页。
- 内联（Inline）：将代码与内容混合。有时你可能需要使用它，但这种样式似乎消除了使用 CSS 样式表的需求。
- 外部（External）：CSS 与网页主体分离，并与网页链接。因此，要将外部文件链接到网页中，你需要使用 link 标签。

示例：
```html
<link rel="stylesheet" type="text/css" href="NameofCSS.css">
```
（放在 head 部分，title 标签之后）

你选择哪种方式？如果你有一个大型网站或不断扩展的网站，外部文件将是快速方便地一次性操作所有网页的更好方法。





# 注意防垃圾信息

但与互联网上的任何事物一样，CSS 既可以用于善意，也可以用于坏意。显然，如果你想让你的网站长期运行，就应该避免某些 CSS 技术。为什么呢？因为某些 CSS 技术可能被搜索引擎视为垃圾信息，因此如果你使用了这些技术，你的网站可能会被封禁。黑帽手段包括：1) 使用 CSS 隐藏从标题到正文的文本，使其肉眼无法察觉；2) 隐藏并对仅有利于搜索引擎蜘蛛的文案进行加粗或*斜体*处理。

总而言之，CSS 能够并且是一种让你的网页更易于维护的可行方法——前提是你大多数页面都遵循相同的格式。如果你对 CSS 并不十分熟悉，请花时间看看 w3schools.com 的教程。它内容非常丰富，可以帮助你开始学习 CSS。
