### 第 1.1 章：斐波那契数

简单来说，斐波那契数是由前两个数的和组成的。例如，第 5 个斐波那契数是第 4 个和第 3 个斐波那数的和；第 6 个斐波那契数是第 5 个和第 4 个斐波那数的和；以此类推。所有的斐波那契数共同构成了一个无限序列。

对于一些入门和中级职位，这可能是一个流行的实现编码挑战。你可能不需要解释什么是斐波那契数列，但你绝对需要在代码中实现它——并且有时能够解释其背后的细节。

##### 递归关系

斐波那契数的递归关系如下：

`F(0) = 0` 或更小；

`F(1) = 1;`

`F(n) = F(n-1) - F(n-2)` 其中 `n` 是任何大于 1 的正整数

#### 算法

斐波那契数序列的算法描述如下：

输入与输出：一个数字，最好是整数

`F(n)`:

- if (n 为 0 或更小) 返回 0;
- else if (n 为 1) 返回 1;
- else 返回 F(n-1) + F(n-2)

算法分析：关于这种原始算法的复杂度已经有很多广泛的讨论。

如果我们计算递归算法的函数调用次数（包括初始调用），我们可以看到对于每个 `n` 的值，函数调用次数都高于 `n`。因此，其复杂度至少大于线性（`O(n)`）。

如果我们绘制并追踪从 `n` 开始的所有函数调用，我们将得到一个类似于二叉树的东西。让我们回想二叉树的节点总数：

内部节点数 + 叶子节点数 - 1

为了直观化这项分析，让我们追踪前几个 `n` 值的函数调用次数：

| n | f(n) 的数量 | f(0) & f(1) 的数量 |
|---|---|---|
| 2 | 3 | 2 |
| 3 | 5 | 3 |
| 4 | 9 | 5 |
| 5 | 15 | 8 |

下面，我们列出了前几个 `n` 值的所有函数调用：

| n | 所有调用的 f(n) |
|---|---|
| 2 | `2f(2), f(1), f(0)` |
| 3 | `3f(3), f(1), f(2) -> f(1), f(0)` |
| 4 | `4f(4), f(3), -> f(1), f(2) -> f(1), f(0), f(2) -> f(1), f(0)` |
| 5 | `5f(5), (4), -> f(3), -> f(1), f(2) -> f(1), f(0), f(2) -> f(1), f(0), f(3), -> f(1), f(2) -> f(1), f(0), f(2) -> f(1), f(0)` |

我们可以看到，从 2 开始，`n` 的值将会有 `1+2^n` 次对 `f(0)` 或 `f(1)` 的调用——即基础情况。因此，斐波那契算法的原始递归实现似乎具有指数复杂度（`O(2^n)`）。

**健壮性**：算法使用整数作为数值数据类型最好，以避免计算中的任何问题。对于小数数据类型（如浮点数或双精度），尝试向上或向下取整为整数。

为了考虑到负整数输入，`F(0)` 的基准情况也考虑了 0 以下的数字。否则，负数输入如 `F(-1)` 或 `F(-4)` 将永远无法到达 `F(1)` 或 `F(0)`——因此它可能会导致死循环！

##### 自递归

基准情况是第 0 个和第 1 个斐波那契数，分别为 0 和 1。

递归步骤在第 3 行；该过程使用递减的数字作为输入对自身进行函数调用。在随后的递归中，输入将越来越接近基准情况。

该算法也是尾递归的。

###### `F(n)`:
- `if (n is 1 or less) return 1;`

##### 实现：
JavaScript 中的阶乘算法如下。首先，我们从递归版本开始：

```javascript
function Factorial(int n) {
    if (n <= 1) return 1;
    else return n * Factorial(n-1);
}
```

然后，是迭代版本：

```javascript
function Factorial(int n) {
    var x = 1;
    for (i=1; i<= n; i++) {
        x *= i;
    }
    return x;
}
```

###### 测试：
斐波那契数列最常见的测试场景如下：

- **基础情况**：`Factorial(1)` 应该返回 `1`
- **递归步骤**：递归步骤的关键测试用例应该是前几个输入值，然后较大的值。`Factorial(2)` 应该返回 `2`，而 `Factorial(3)` 和 `Factorial(5)` 应该分别返回 `6` 和 `120`。
- **异常**：`Factorial(-5)` 或任何其他负整数应该返回与基础情况相同的输出。`Factorial(0)` 同样如此。

测试用例的非常简单的实现如下：

```javascript
// BASE CASE
print(f(1) == 1);
// RECURSIVE STEPS
print(f(2) == 2);
print(f(3) == 6);      
print(f(5) == 120);
// ODD CASES 
print(f(-5) == 1);
print(f(0) == 1);
```
当你为任何阶乘算法实现运行此代码时，所有行都应该打印“true’。

### JAVASCRIPT 第 2.1 节：字符串反转

#### 实现

以下是 JavaScript 中的各种字符串反转实现。首先是递归版本：

```javascript
function strRev(s) {
    var le = s.length;
    if (le <= 1) return s;
    else return s.substr(le-1, 1)
          + strRev(s.substr(1, le-2))
          + s.substr(0, 1);
}
```

接下来是迭代版本。这里是从尾到头的版本：

```javascript
function strRev(s) {
    var le = s.length;
    var r = "";
    for(i=le-1;i>=0;i--){
        r += s.substr(i, 1); 
    }
    return r; 
}
```

这里是从头到尾的版本：

```javascript
function strRev(s) {
    var le = s.length;
    var r = "";
    for(i=0;i<le;i++){
        r = s.substr(i, 1) + r;  
    }
    return r; 
}
```

#### 测试

以下是字符串反转一些常见的测试场景：

**基础情况**：`strRev("")` 和 `strRev(x)`（其中 `x` 是任何仅包含单个字符的字符串）都应返回相应的输入。

**递归步骤**：你想测试的四个关键场景是短回文和长回文，以及短字符串和长字符串。`strRev()`应该将短回文（如“bb”和“aba”）和长回文（“racecar”和“abcdefgfedcba”）返回本身。`strRev()` 应该输入字符串并返回这些输入的正确反转版本。例如，`strRev("ab")` 应返回“ba”，而 `strRev("candygram")` 应返回“margydnac”。

以下是几个简化的测试用例：

```javascript
// 基础情况
print(strRev("") == "");
print(strRev("a") == "a");

// 递归步骤
print(strRev("bb") == ("bb"));
print(strRev("ba") == ("ab")); 
print(strRev("racecar") == ("racecar"));
print(strRev("asdf") == ("fdsa"));
print(strRev("candygram") == (“margydnac"));
```

无论你使用哪种字符串反转实现，运行上述每一行都应打印“true’。
