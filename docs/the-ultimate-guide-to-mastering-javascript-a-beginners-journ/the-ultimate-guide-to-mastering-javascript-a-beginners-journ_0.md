## 1.1 设置你的开发环境

在开始编码之前，你需要设置一个开发环境。幸运的是，JavaScript 对初学者非常友好，你不需要任何复杂的软件即可开始。你只需要文本编辑器和一个浏览器。JavaScript 直接在浏览器中运行，所以你可以立即测试你的代码。

### 1.1.1 选择文本编辑器

文本编辑器是你编写 JavaScript 代码的地方。一些 JavaScript 最流行的文本编辑器有：

● Visual Studio Code (VSCode)：一个免费的开源编辑器，对 JavaScript 有极佳的支持。它带有语法高亮、代码建议和用于扩展功能的插件等特性。

考虑到本书，我们将使用 Visual Studio Code (VSCode)，因为它在行业内被广泛使用，并为 JavaScript 开发提供了许多实用的功能。

一旦安装了文本编辑器，打开它并创建一个新文件。以 `.html` 扩展保存文件，例如 `index.html`。该文件将同时包含你的 HTML（用于构建页面）和 JavaScript（用于添加交互性）。

### 1.1.2 编写你的第一个 HTML 文件

现在你已经设置好了文本编辑器，让我们创建一个简单的 HTML 文件来嵌入 JavaScript。以下是设置方法：

1. 打开你的编辑器并创建一个新文件。
2. 将其保存为 `index.html`。
3. 添加以下基础结构：

```html
<!DOCTYPE html>

// 你的 JavaScript 代码将在这里

```

`<script>` 标签是你编写 JavaScript 代码的地方。`console.log()` 函数是 JavaScript 中基础的命令之一——它将消息打印到控制台。

## 1.2 语法和结构

现在你已经设置好了环境，让我们深入学习 JavaScript 的语法基础。在开始编写代码之前，理解结构至关重要。

### 1.2.1 变量

在 JavaScript 中，变量用于存储数据。你可以将变量看作存储不同类型数据的容器。声明变量有三种：

● `var`：声明变量的老方法（现代开发中不常用）。
● `let`：声明变量的现代方式，允许块作用域变量。
● `const`：用于声明不可重新赋值的变量。

你可以这样声明变量：

```javascript
let myVariable = 10;
const myConstant = "Hello!";
```

### 1.2.2 数据类型

JavaScript 支持多种数据类型。常见的有：

● Number（数字）：表示数值。
● String（字符串）：表示文本。
● Boolean（布尔）：表示真或假的值。
● Object（对象）：用于以键值对的形式存储数据。
● Array（数组）：有序的值集合。
● null：表示值的缺失。
● undefined（未定义）：表示未赋值的变量。

例如：

```javascript
let age = 25; // Number
let name = "John"; // String
let isActive = true; // Boolean
let user = { name: "John", age: 25 }; // Object
let colors = ["red", "green", "blue"]; // Array
```

## 1.3 JavaScript 中的运算符

操作符用于对变量和值进行操作。在 JavaScript 中，有几种类型的运算符：

### 1.3.1 算术运算符

这些运算符用于执行数学计算。基础算术运算符包括：

● `+`（加法）：将两个值相加。
● `-`（减法）：从一个值中减去另一个。
● `*`（乘法）：将两个值相乘。
● `/`（除法）：用一个值除以另一个值。





- `%` (取模运算符): 返回一个数值除以另一个数值后的余。
- `++` (自增运算符): 将一个值增加一。
- `—` (自减运算符): 将一个值减一。

示例：

```javascript
let x = 10;
let y = 5;
let sum = x + y; // 15
let difference = x - y; // 5
let product = x * y; // 50
let quotient = x / y; // 2
let remainder = x % y; // 0
```

### 1.3.2 比较运算符

这些运算符用于比较两个值并返回一个布尔值（true 或 false）。

- `==` (等于): 如果两个值相等，则返回 true。
- `===` (严格相等): 如果两个值及其类型相等，返回 true。
- `!=` (不等于): 如果两个值不相等，则返回 true。
- `!==` (严格不等于): 如果两个值或它们的类型不相等，则返回 true。
- `>` (大于): 如果左侧的值大于右侧，则返回 true。
- `<` (小于): 如果左侧的值小于右侧，则返回 true。
- `>=` (大于等于): 如果左侧的值大于或等于右侧，则返回 true。
- `<=` (小于等于): 如果左侧的值小于或等于右侧，则返回 true。

示例：

```javascript
let a = 10;
let b = 5;
let isEqual = a == b; // false
let isStrictEqual = a === b; // false
let isGreater = a > b; // true
```

### 1.3.3 逻辑运算符

逻辑运算符用于组合多个条件或表达式：

- `&&` (逻辑与): 如果两个条件都为真，则返回 true。
- `||` (逻辑或): 如果至少有一个条件为真，则返回 true。
- `!` (逻辑非): 反转布尔值。

示例：

```javascript
let x = true;
let y = false;
let result1 = x && y; // false (两者都为真)
let result2 = x || y; // true (至少有一个为真)
let result3 = !x; // false (反转值)
```

## 1.4 控制流：条件语句

条件语句允许你根据特定条件执行某些代码块。在 JavaScript 中，有几种类型的条件语句：

### 1.4.1 If-Else 语句

`if` 语句评估一个条件，如果条件为真，则执行相应的代码块。如果条件为假，则可以使用 `else` 语句执行另一块代码。

```javascript
let age = 18;
if (age >= 18) {
  console.log("You are an adult.");
} else {
  console.log("You are a minor.");
}
```

### 1.4.2 Else If 语句

你可以使用多个 `else if` 块来测试多个条件。

```javascript
let score = 85;
if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 80) {
  console.log("Grade: B");
} else {
  console.log("Grade: C");
}
```

### 1.4.3 Switch 语句

`switch` 语句是测试多个条件的更高效的方法。当你对一个变量有多个可能的值时，它特别有用。

```javascript
let day = "Monday";
switch (day) {
  case "Monday":
    console.log("Start of the work week!");
    break;
  case "Friday":
    console.log("End of the work week!");
    break;
  default:
    console.log("It's just another day.");
}
```

## 1.5 JavaScript 中的函数

函数是执行特定任务的可重用代码块。函数可以接收参数（输入）并返回一个值（输出）。

### 1.5.1 定义函数

你可以使用 `function` 关键字定义函数，后面跟上函数名称、参数以及在调用函数时将执行的代码块。

```javascript
function greet(name) {
  console.log("Hello, " + name + "!");
}
greet("John"); // 输出: Hello, John!
```

### 1.5.2 函数返回值

函数可以使用 `return` 关键字返回一个值。该值随后可以在程序的其他地方使用。

```javascript
function add(a, b) {
  return a + b;
}
let result = add(5, 3); // result = 8
```

### 1.5.3 箭头函数

在现代 JavaScript 中，你可以使用箭头函数定义更短的函数。这种语法更简洁，但行为与普通函数相似。

```javascript
const multiply = (a, b) => a * b;
let result = multiply(4, 3); // result = 12
```

## 2.1 循环

循环允许你多次执行代码块。JavaScript 提供了几种类型的循环：

### 2.1.1 for 循环

`for` 循环是用于遍历数据的最常用方式之一。这是 `for` 循环的基本语法：

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

在此示例中，循环将运行五次，打印 0 到 4。for 循环由三部分组成：
- 初始化：`let i = 0` —— 设置循环的起点。
- 条件：`i < 5` —— 决定循环何时停止。
- 递增：`i++` —— 迭代后更新变量 `i`。

### 2.1.2 while 循环

`while` 循环用于在条件为真时重复代码。与 `for` 循环不同，`while` 循环没有固定的迭代次数——它会持续直到条件为假。这是 `while` 循环的语法：

```javascript
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
```

此示例的结果与 `for` 循环相同，打印 0 到 4。关键区别在于循环条件在每次迭代之前进行检查。

### 2.1.3 do-while 循环

`do-while` 循环与 `while` 循环相似，但有一个关键区别：循环内部的代码在检查条件之前至少执行一次。当你需要确保循环无论如何都至少运行一次时，这非常有用。这是一个 `do-while` 循环的示例：

```javascript
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 5);
```

在这种情况下，循环也会打印 0 到 4，但它保证即使初始条件为假，代码也会执行一次。

## 2.2 JavaScript 中的数组

数组用于在变量中存储多个值。它可以包含不同类型的数据，对于处理相似项目的集合非常有用。

### 2.2.1 创建数组

你可以使用方括号 `[]` 并用逗号分隔元素来创建一个数组。这是一个示例：

```javascript
let fruits = ["apple", "banana", "cherry"];
```

该数组包含三个元素：“apple”、“banana”和“cherry”。你可以通过使用索引（从 0 开始）来访问数组的单个元素。

```javascript
console.log(fruits[0]); // 输出: apple
console.log(fruits[1]); // 输出: banana
```

### 2.2.2 数组方法




JavaScript 提供了几个内置方法来操作数组。一些最常用的方法包括：

`push()` – 向数组末尾添加一个元素。

```javascript

console.log(fruits); // ["apple", "banana", "cherry", "orange"]
```

`pop()` – 从数组中移除最后一个元素。

```javascript

```

`shift()` – 从数组中移除第一个元素。

```javascript
fruits.shift();

```

`unshift()` – 向数组开头添加一个元素。

```javascript
fruits.unshift("grape");

```

`length` – 返回数组中的元素个数。

```javascript
console.log(fruits.length); // 3
```

你可以使用循环来遍历数组的元素。以下是使用 `for` 循环遍历数组的方法：

```javascript
  console.log(colors[i]);
}
```

## 2.3 JavaScript 中的对象

```javascript
const multiply = function(a, b) {
```

在上面的示例中，`applyOperation` 是一个高阶函数，因为它接收另一个函数。

## 3.2 JavaScript 中的作用域

作用域是指变量定义的上下文以及决定可以在哪里访问它的规则。JavaScript 有两种作用域：全局作用域和局部作用域。

### 3.2.1 全局作用域

在函数外部定义的变量具有全局作用域。这意味着可以在代码的任何地方访问。

```javascript
let globalVar = "I am a global variable";
```

### 3.2.2 局部作用域

```javascript
function myFunction() {
  let localVar = "I am a local variable";
  console.log(localVar); // 可以访问局部变量
}
myFunction(); // 输出: I am a local variable
console.log(localVar); // 错误: localVar is not defined
```

### 3.2.3 块作用域

JavaScript 使用 `let` 和 `const` 关键字引入了块作用域变量。在块（一对大括号 `{}`）内部定义的变量在块外部不可用。

```javascript
if (true) {

```

这与使用 `var` 定义的不同，`var` 没有块作用域，而是具有函数作用域。

## 3.3 JavaScript 中的闭包
闭包是一个在外部函数执行完毕后仍保留访问其词法作用域变量的函数。闭包是 JavaScript 中一个强大的特性，能够实现高级编程模式，如数据封装和函数工厂。

### 3.3.1 理解闭包
当函数被创建时，它可以访问其自身作用域、外部函数作用域以及全局作用域的变量。这就形成了闭包。这是一个示例：

```javascript
function outer() {
let outerVar = "I am from the outer function";
return function inner() {
console.log(outerVar); // 访问外部函数的变量
};
}

const closureFunc = outer();
closureFunc(); // 输出: I am from the outer function
```
在这个示例中，即使在 `outer` 执行完成后，`inner` 函数仍然可以访问 `outerVar`。这就是闭包的精髓。

### 3.3.2 闭包的实际应用
闭包通常用于创建私有变量或模拟数据封装，这有助于防止外部意外访问变量。

示例：

```javascript
function counter() {

return {
increment: function() {
count++;
console.log(count);
},
decrement: function() {
count--;
console.log(count);
}
};
}

const myCounter = counter();

myCounter.increment(); // 输出: 2
myCounter.decrement(); // 输出: 1
```
在这个示例中，`count` 变量是私有的，只能通过 `increment` 和 `decrement` 方法进行访问和修改。这是使用闭包在 JavaScript 中创建私有状态的示例。

# 第 4 章：在 JavaScript 中操作 DOM（文档对象模型）

![image](img/chapter_title_below.png)

文档对象模型 (DOM) 是一个强大的 API，允许 JavaScript 与 HTML 文档交互并操作其内容。它提供了一种结构化的方式，将网页表示为对象树。本章将重点关注如何使用 JavaScript 访问、操作和修改 DOM，以便创建动态、交互式的 Web 应用。

## 4.1 理解 DOM

在深入操作 DOM 之前，理解 DOM 是什么以及它如何表示 HTML 文档是非常重要的。DOM 是网页上 HTML 元素的层次模型。每个元素都表示为一个节点，整个页面结构像一棵树。例如，树的根是 `document`，每个 HTML 标签（例如 `<html>`、`<body>`、`<div>`、`<p>`）都是树中的节点。

这是一个简单的 HTML 文档如何在 DOM 中表示的示例：

```html
<!DOCTYPE html>
<html>
<head>
<title>DOM Example</title>
</head>
<body>
  <div id="content">
    <h1>Welcome to JavaScript DOM!</h1>
    <p>This is an example of working with the DOM.</p>
  </div>
</body>
</html>
```

在 DOM 中，此文档看起来如下：

```less
document
├── html
│   ├── head
│      └── title
└── body
    └── div#content
        ├── h1
        └── p
```

这种层次结构允许 JavaScript 通过遍历树轻松访问和操作页面上的任何元素。

***

## 4.2 访问 DOM 中的元素

要操作 DOM 中的元素，首先需要访问它们。JavaScript 提供了多种方法来选择 DOM 元素，例如 `getElementById`、`getElementsByClassName`、`querySelector` 和 `querySelectorAll`。

### 4.2.1 getElementById

`getElementById` 方法通过 `id` 属性选择元素。它返回单个元素，因为 ID 在页面内预期是唯一的。

```javascript
const element = document.getElementById("content");
console.log(element); // Output: <div id="content">...</div>
```

### 4.2.2 getElementsByClassName

`getElementsByClassName` 方法通过类名选择元素。它返回一个实时的元素 `HTMLCollection`，这意味着如果 DOM 更新了（例如添加了元素），该集合也会更新。

```javascript
const paragraphs = document.getElementsByClassName("text");
```

### 4.2.3 querySelector 和 querySelectorAll

`querySelector` 方法允许你使用 CSS 选择器选择元素。它返回第一个匹配的元素。`querySelectorAll` 在 `NodeList` 中返回所有匹配的元素。

```javascript
const firstParagraph = document.querySelector("p");
console.log(firstParagraph); // Output: <p>...</p>

const allParagraphs = document.querySelectorAll("p");
```

***

## 4.3 操作 DOM 中的元素

一旦访问了元素，你就可以各种方式对其进行操作，例如更改其内容、样式或属性。JavaScript 提供了各种属性和方法来实现此目的。

### 4.3.1 修改内容

要更改元素的内容，可以使用 `innerHTML` 或 `textContent` 属性。`innerHTML` 允许你设置 HTML 内容，而 `textContent` 只修改元素的文本内容。

```javascript
const title = document.querySelector("h1");
title.textContent = "New Title"; // 修改 <h1> 的文本内容
```

要向元素添加 HTML 内容，请使用 `innerHTML`：

```javascript
const content = document.getElementById("content");
content.innerHTML = "<h2>Updated Content</h2><p>This is new content.</p>";
```

### 4.3.2 修改样式

你可以使用 `style` 属性更改元素的样式，该属性允许你修改内联 CSS。每个 CSS 属性都可以单独设置。

```javascript
const paragraph = document.querySelector("p");
paragraph.style.color = "blue"; // 将文字颜色改为蓝色
paragraph.style.fontSize = "18px"; // 将字体大小改为 18px
```

### 4.3.3 修改属性

`setAttribute` 方法允许你更改元素的属性，例如图片的 `src`、链接的 `href` 或任何其他属性。

```javascript
const link = document.querySelector("a");
link.setAttribute("href", "https://www.example.com");
link.textContent = "Go to Example";
```

你还可以使用 `getAttribute` 获取属性值。

```javascript
const srcValue = document.querySelector("img").getAttribute("src");
console.log(srcValue); // 输出: 图片当前的 src 值
```

## 4.4 创建和删除元素

JavaScript 允许在 DOM 中动态创建和删除元素。

### 4.4.1 创建元素

要创建新元素，可以使用 `createElement` 方法。创建元素后，可以使用 `appendChild` 将其追加到现有元素中。

```javascript
const newDiv = document.createElement("div");
```




```javascript

document.body.appendChild(newDiv); // Adds the new div to the body
```

### 4.4.2 移除元素

要从 DOM 中移除元素，你可以使用 `removeChild` 方法。首先，你必须访问想要移除的元素的父元素。

```javascript
const divToRemove = document.querySelector("#content");
divToRemove.parentNode.removeChild(divToRemove); // Removes the #content div
```

或者，你也可以直接在元素上使用 `remove` 方法。

# 第 5 章：异步 JavaScript 与 Promises

异步编程是 JavaScript 中的一个核心概念，特别是在处理需要时间才能完成的任务时，例如发送 HTTP 请求、读取文件或等待用户输入。在�本章中，我们将探索异步编程的概念，重点关注 promises、async/await 以及如何在 JavaScript 中处理异步操作。

## 5.1 什么是异步编程？

在同步编程中，每个任务都是一个接一个地执行的。如果一个任务需要很长时间才能完成，它就会阻塞下一个任务的执行。例如，如果你从服务器获取数据，程序将等待数据返回后才继续执行下一行代码。这会导致性能效率低下，特别是在等待外部资源时。

异步编程通过允许任务独立于主程序流执行来解决这一问题。这意味着在等待一个任务完成的同时，程序可以继续执行其他任务。

## 5.2 JavaScript 回调函数简介

在理解 promises 和 async/await 之前，了解 JavaScript 如何处理异步操作是非常重要的。处理异步操作的最常见技术之一是通过回调函数（callbacks）。

回调函数作为一个参数传递给另一个函数的函数，它会在稍后的时间执行，通常在异步任务完成后执行。以下是回调工作原理的示例：

### 示例：使用回调函数

```javascript
function fetchData(callback) {
  setTimeout(() => {
    console.log("Data fetched");
    callback(); // 当数据获取时调用回调函数
  }, 2000);
}

function processData() {
  console.log("Processing data...");
}
fetchData(processData); // 获取数据，然后在 2 秒后进行处理
```

在这个示例中，`fetchData` 模拟异步获取数据（使用 `setTimeout`），一旦数据获取完成，它就会调用 `processData` 函数。

虽然回调函数运行良好，但在更复杂的应用程序中它们可能会变得难以管理。这就是 Promises 大显用场的地方

## 5.3 理解 Promises

Promise 是 JavaScript 中处理异步操作的现代方式。Promise 代表异步操作的最终完成（或失败），并允许你附加 `.then()` 和 `.catch()` 处理程序来分别处理结果或处理错误。

### 创建 Promise

你可以使用 `Promise` 构造函数来创建一个 promise。`Promise` 构造函数接受一个带有两个参数的函数：`resolve` 和 `reject`。当异步操作成功完成时，你调用 `resolve` 表示成功。如果失败了，你调用 `reject` 表示失败。

### 示例：使用 Promises

```javascript
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const success = true; // 将此改为 false 以模拟错误
      if (success) {
        resolve("Data fetched successfully");
      } else {
        reject("Error fetching data");
      }
    }, 2000);
  });
}

fetchData()
  .then((message) => {
    console.log(message); // "Data fetched successfully"
  })
  .catch((error) => {
    console.log(error); // "Error fetching data"
  });
```

在这个示例中，`fetchData` 返回一个两秒后 resolve 的 promise。如果操作成功，将记录消息 "Data fetched successfully"。如果发生错误，将记录消息 "Error fetching data"。

## 5.4 链式调用 Promises

Promise 最强大的功能之一是可以使用 `.then()` 将多个异步操作链式连接。每个 `.then()` 块都会返回一个新的 promise，允许你按顺序链式执行多个操作。

### 示例：链式调用 Promises

```javascript
fetchData()
  .then((message) => {
    console.log(message); // "Data fetched successfully"
    return "Processing data..."; // 返回一个新值
  })
  .then((processMessage) => {
    console.log(processMessage); // "Processing data..."
    return "Data processed successfully"; // 返回另一个值
  })
  .then((result) => {
    console.log(result); // "Data processed successfully"
  })
  .catch((error) => {
    console.log(error);
  });
```

在这个示例中，获取数据后，程序继续处理数据并最终记录结果。每个 `then()` 块都会接收上一个块的返回值并可以链接后续操作。

## 5.5 Async/Await

async 和 await 是现代 JavaScript 特性，它们简化了异步代码的处理，使其看起来更像同步代码，但仍然是非阻塞的。这些功能与 promise 配合使用，通常被认为比传统的回调或 promise 语法更简洁、更易理解。

### 5.5.1 async 函数

`async` 函数总是返回一个 promise。在函数内部，你可以使用 `await` 关键字暂停函数的执行，直到 promise resolve 或 reject。





### 示例：使用 async 和 await

```javascript
async function fetchData() {
  const data = await new Promise((resolve, reject) => {
    setTimeout(() => {
      const success = true;
      if (success) {
        resolve("Data fetched successfully");
      } else {
        reject("Error fetching data");
      }
    }, 2000);
  });
  console.log(data); // "Data fetched successfully"
}

fetchData();
```

在这个示例中，`fetchData` 函数被标记为 `async`，并使用 `await` 关键字来等待 `promise` 解析后再记录结果。这使得异步代码在看起来和行为上都更像同步代码。

***

## 5.6 使用 try 和 catch 处理错误

在使用 `async` 和 `await` 时，你可以使用 `try...catch` 块来处理错误，这与你在同步代码中处理错误的方式类似。如果在等待 promise 时发生错误，执行将将跳转到 `catch` 块。

### 示例：使用 try 和 catch 处理错误

```javascript
async function fetchData() {
  try {
    const data = await new Promise((resolve, reject) => {
      setTimeout(() => {
        const success = false;
        if (success) {
          resolve("Data fetched successfully");
        } else {
          reject("Error fetching data");
        }
      }, 2000);
    });
    console.log(data); // 如果发生错误，此处不会执行
  } catch (error) {
    console.log(error); // "Error fetching data"
  }
}

fetchData();
```

在这个示例中，`promise` 被拒绝（rejected），错误消息在 `catch` 块中被捕获。

## 5.7 处理多个 Promise

JavaScript 提供了 `Promise.all()` 和 `Promise.race()` 等方法来并发处理多个 promise。

### 5.7.1 Promise.all()

`Promise.all()` 接收一个 promise 数组并返回一个新的 promise，当数组中的所有 promise 都解析后，该 promise 就会解析。如果任何一个 promise 被拒绝，整个 promise 都将被拒绝。

```javascript
const promise1 = Promise.resolve("Data 1");
const promise2 = Promise.resolve("Data 2");
const promise3 = Promise.resolve("Data 3");
Promise.all([promise1, promise2, promise3])
  .then((values) => {
    console.log(values); // ["Data 1", "Data 2", "Data 3"]
  })
  .catch((error) => {
    console.log(error);
  });
```

### 5.7.2 Promise.race()

`Promise.race()` 接收一个 promise 数组并返回一个新的 promise，一旦其中任何一个 promise 解析或拒绝，该 promise 就会立即解析或拒绝。

```javascript
const promise1 = new Promise((resolve) => setTimeout(resolve, 1000, "Data 1");
const promise2 = new Promise((resolve) => setTimeout(resolve, 500, "Data 2"));
Promise.race([promise1, promise2])
  .then((value) => {
    console.log(value); // "Data 2"
  })
  .catch((error) => {
    console.log(error);
  });
```

在这个示例中，第二个 promise 先解析，因此 `Promise.race()` 的结果是 "Data 2"。

## 6.5 封装与私有属性

```javascript
cat.speak(); // Output: Cat meows.
dog.speak(); // Output: Dog barks.
```

在此例中，`Cat` 和 `Dog` 类都重写了 `Animal` 类的 `speak()` 方法，以提供它们特定的行为。多态允许你在不同对象类型中使用相同的方法名但具有不同的行为，提供了灵活性并简化了代码结构。

# 第 7 章：异步 JavaScript 与 Promises

![image](img/chapter_title_below.png)

在现代 Web 开发中，异步编程是一个至关重要的概念。JavaScript 是单线程的，这意味着一次只能执行一个操作。然而，许多任务（如从 API 获取数据、读取文件或等待用户输入）需要更多的时间来完成。异步编程允许 JavaScript 执行非阻塞操作，确保用户体验顺畅，且任务得到高效处理。

在本章中，我们将探索异步 JavaScript 的工作原理，包括回调（callbacks）、Promises 和 async/await 等概念。理解这些概念对于处理需要时间的任务（如网络请求和大型计算）至关重要。

***

## 7.1 什么是异步 JavaScript？

异步编程允许程序在等待耗时操作完成的同时继续执行其他任务。这在与外部资源（如 API、数据库或文件）交互时特别有用，因为延迟在那里很常见。

如果没有异步编程，JavaScript 将阻塞代码的执行，导致应用程序无响应。通过使用异步操作，JavaScript 可以同时处理多个任务，提高性能和响应能力。

### 事件循环（Event Loop）

事件循环是允许 JavaScript 执行非阻塞操作的机制。当启动一个任务（例如网络请求）时，事件循环会将任务移交给浏览器的 Web APIs（如 `fetch()`、`setTimeout()` 等）。任务在后台执行，而 JavaScript 引擎继续执行其他代码。一旦任务完成，事件循环会将回调或 Promise 的解析（resolution）放入队列中，当 JavaScript 引擎准备就绪时就会执行它。

***

## 7.2 回调（Callbacks）

回调是一个作为参数传递给另一个函数并在该函数完成任务后执行函数函数回调是 JavaScript 中处理异步代码的最早形式。

### 示例：使用回调

```javascript
function fetchData(callback) {
  setTimeout(() => {
    const data = "Some data from an API";
    callback(data);
  }, 2000);
}

fetchData(function(data) {
  console.log(data); // Output: Some data from an API
});
```

在此例中，`fetchData()` 模拟从 API 获取数据，并在 2 秒延迟后通过回调函数处理数据。

#### 回调地狱（Callback Hell）

虽然回调很有用，但当你有多个相互依赖的异步操作时，它们会导致被称为“回调地狱”的情况。这发生在将回调嵌套在其他回调中，导致代码难以阅读。

```javascript
fetchData(function(data) {
  processData(data, function(result) {
    saveResult(result, function(response) {
      console.log(response);
    });
  });
});
```

在这种情况下，代码难以追踪且容易出错。这就是 promises 和 async/await 发挥作用的地方，提供了更整洁的替代方案。

***

## 7.3 Promises

Promise 是一个代表异步操作最终完成（或失败）及其结果的 get。Promise 是回调更整洁的替代方案，并允许对多个异步操作进行链。

### Promise 的状态

Promise 可以处于以下三种状态之一：

1. **等待中（Pending）**：异步操作完成之前的状态。
2. **已解决（Resolved/Fulfilled）**：操作成功完成，Promise 拥有结果。
3. **已拒绝（Rejected）**：操作失败，Promise 拥有错误原因。

### 示例：使用 Promises

```javascript
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const data = "Some data from an API";
      resolve(data); // Promise 成功解决
    }, 2000);
  });
}

fetchData()
  .then(data => {
    console.log(data); // Output: Some data from an API
  })
  .catch(error => {
    console.error(error);
  });
```

在此例中，`fetchData()` 返回一个 promise。`then()` 方法用于处理 promise 的成功解析，而 `catch()` 用于处理发生的任何错误。

### Promise 链（Chaining Promises）

Promises 允许链式，这意味着你可以顺序执行多个异步操作，将上一个操作的结果传递给下一个。

```javascript
fetchData()
  .then(data => {
    console.log(data);
    return "New data";
  })
  .then(newData => {
    console.log(newData); // Output: New data
  })
  .catch(error => {
    console.error(error);
  });
```





```javascript
console.error(error);

});
```

与上一个示例中的嵌套回调相比，这种 promise 链式使得代码更具可读性和可维护性。

***

## 7.4 Async/Await

Async/await 是 JavaScript 较新引入的特性，发布于 `ECMAScript 2017`。它构建在 promise 之上，提供了一种更简洁、更直观的方式来处理异步代码。

- **Async**: `async` 关键字放在函数之前，表示该函数返回一个 promise 并且包含异步操作。
- **Await**: `await` 关键字只能在 `async` 函数内部使用。它会暂停函数的执行，直到 promise 解析完成并返回结果。

### 示例：使用 Async/Await

```javascript
async function fetchData() {
  const response = await new Promise(resolve => {
    setTimeout(() => resolve("Data fetched from API"), 2000);
  });
  console.log(response); // 输出: Data fetched from API
}

fetchData();
```

在这个示例中，`fetchData()` 是一个异步函数。`await` 关键字会等待 promise 解析完成后，再继续执行下一行代码。

### 使用 Async/Await 处理错误

你可以使用 `try...catch` 块来处理异步函数中的错误，这使得捕获和处理异常变得更加容易。

```javascript
async function fetchData() {
  try {
    const response = await new Promise((resolve, reject) => {
      setTimeout(() => reject("Error fetching data"), 2000);
    });
    console.log(response);
  } catch (error) {
    console.error(error); // 输出: Error fetching data
  }
}

fetchData();
```

这种方法比使用 `.then()` 和 `.catch()` 要清晰得多且易于阅读。

***

## 7.5 将 Async/Await 与其他函数结合

Async/await 可以与其他 JavaScript 函数结合使用，包括 `setTimeout()`、`fetch()`，甚至可以在循环中使用。这种灵活性使得 async/await 成为管理异步操作的最强大的工具之一。

### 示例：结合 Async/Await 使用 fetch()

`fetch()` API 通常用于在 JavaScript 中发送网络请求。它返回一个 promise，该 promise 解析的结果为请求的响应。

```javascript
async function getUserData() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/users');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

getUserData();
```

在这个示例中，使用 `fetch()` 从 API 获取用户数据。`await` 关键字等待响应的返回，然后使用 `.json()` 方法解析响应。

### 示例：在循环中使用 Async/Await

你也可以在循环内部使用 async/await 来按顺序处理异步任务。

```javascript
async function fetchMultipleData() {
  const urls = [
    'https://jsonplaceholder.typicode.com/posts',
    'https://jsonplaceholder.typicode.com/comments'
  ];
  for (let url of urls) {
    const response = await fetch(url);
    const data = await response.json();
    console.log(data);
  }
}

fetchMultipleData();
```

在这种情况下，循环会顺序地从多个 URL 获取数据，在移动到下一个请求之前会等待每个请求完成。

***

## 7.6 结论

异步编程是 JavaScript 的一个至关重要的方面，它允许你处理原本会阻塞程序执行的操作。通过掌握回调、promise 和 async/await，你可以编写出更高效、更可维护的代码。

在本章中，我们学习了事件循环、回调、promise 和 async/await。这些工具和技术对于构建现代的非阻塞应用程序至关重要。异步编程将成为你 JavaScript 开发之旅中的基础性部分，特别是在处理 API、数据库以及任何需要等待结果的任务时。

# 第 8 章：使用 API 和 Fetch

在现代 Web 开发中，API（应用程序编程接口）在实现不同软件系统之间的通信方面起着核心作用。API 允许开发者与数据库、第三方平台甚至外部应用程序等服务交互。在 JavaScript 中与 API 通 通常用方法之一是通过 `fetch()` API。在本章中，我们将探索如何使用 `fetch()` 与 API 交互、如何处理响应以及如何处理 JSON 数据。在本章结束时，你将掌握将 API 集成到 Web 应用程序中的知识。

## 8.1 什么是 API？

API 是一套协议和工具，允许不同的软件应用程序相互进行通信。在 Web 开发背景下，API 通常用于允许客户端应用程序（如网站）与服务器、数据库或第三方服务（如社交媒体平台、支付网关等）交互。

API 可以分为不同的类型：

1. **RESTful APIs（表述状态转移）**：REST 是一种使用标准 HTTP 方法（如 `GET`、`POST`、`PUT` 和 `DELETE`）的架构风格。REST API 是无状态，允许客户端和服务器之间进行通信。
2. **GraphQL APIs**：与 REST 不同，GraphQL 允许客户端请求特定的数据字段而不是获取整组数据，提供了更高的灵活性效率。
3. **WebSocket APIs**：WebSockets 实现了客户端与服务器之间的双向通信，允许实时更新。

为了本章的演示，我们将关注常用于 Web 开发的 REST APIs。

***

## 8.2 fetch() API

`fetch()` 函数是 JavaScript 中发送 HTTP 请求的现代方式。它内置于浏览器中，与 `XMLHttpRequest` 等旧方法相比，它更易访问且更易使用。`fetch()` 返回一个 promise，该 promise 解析的结果为请求的响应。

### fetch() 的基本用法

`fetch()` 最基本的用法是从 URL 请求数据。这里有一个如何从 API 获取数据的示例：

```javascript
fetch('https://jsonplaceholder.typicode.com/posts')
  .then(response => response.json()) // 从响应中解析 JSON 数据
  .then(data => console.log(data)) // 处理数据
  .catch(error => console.error('Error:', error)); // 处理任何错误
```

在这个示例中，使用 `fetch()` 函数从 `jsonplaceholder` API 获取数据，这是一个用于测试和原型设计的虚虚拟在线 REST API。`response.json()` 方法用于解析响应。

### 处理响应

###fetch()` 函数返回一个 promise，该 promise 解析为一个 `Response` 对象。`Response` 对象包含了多个与响应数据交互的属性和方法，例如 `status`、`statusText` 和 `json()`（将体解析为 JSON）。

#### 示例：检查响应状态

```javascript
fetch('https://jsonplaceholder.typicode.com/posts')
  .then(response => {
    if (!response.ok) {
      throw new Error('Network response was not ok');
    }
    return response.json();
  })
  .then(data => console.log(data))
```





```javascript
.catch(error => console.error('There was a problem with the fetch operation:', error));
```

在这个示例中，我们检查了 `response.ok` 属性，这是一个布尔值，用于表示响应是否成功（状态码 200–299）。如果响应未成功，我们会抛出一个错误。

***

## 8.3 发送 POST 请求

虽然 `fetch()` 通常用于获取数据（GET 请求），但它也可以用于向服务器发送数据。要做到这一点，你需要指定请求方法并在请求正体（body）中包含数据。

### 示例：使用 POST 请求发送数据

```javascript
const data = {

title: 'New Post',

body: 'This is the content of the post.',

userId: 11};

fetch('https://jsonplaceholder.typicode.com/posts', {

method: 'POST',

headers: {

'Content-Type': 'application/json'

},

body: JSON.stringify(data)

})
.then(response => response.json())

.then(data => console.log('Post created:', data))
.catch(error => console.error('Error:', error));
```

在这个示例中，我们发送了一个 POST 请求来创建一个新帖子。数据包含在请求正文中，并且我们指定了内容类型为 JSON。服务器将返回创建的帖子，我们将其打印到控制台。

## 8.4 处理 API 请求中的错误

在处理 API 工作时，可能会由于许多原因发生错误，例如网络问题、无效请求或服务器错误。为了优雅地处理这些错误，你应该始终在代码中包含错误处理逻辑。

`async/await` 语法可以与 `fetch()` 使用，让异步代码看起来更像同步代码，从而更容易阅读和维护。`await` 关键字会暂停代码的执行，直到 promise 解决（resolved）。

# 9 处理异步 JavaScript

异步编程是现代 JavaScript 开发中的一个核心概念。它允许应用程序执行诸如从 API 获取数据、处理用户交互和操作文件而不会阻塞主线程。异步代码可以与其他操作并发运行，确保应用程序保持响应。在本章中，我们将深入探讨异步 JavaScript 的概念，重点关注回调、promise 和 async/await 语法。

## 9.1 什么是异步 JavaScript？

JavaScript 是一种单线程编程语言，这意味着一次只能执行一个操作。然而，许多操作（如从服务器获取数据或读取文件）需要时间完成。如果没有异步编程，浏览器在执行这些任务期间将冻结或无响应。

异步编程允许你在后台执行耗时操作，同时主线程继续执行其他代码。操作完成后，浏览器就可以处理结果。这带来了更流畅的用户体验和更高效的应用程序。

JavaScript 有几种处理异步任务的关键技术：

1. 回调 (Callbacks)
2. Promise (Promises)
3. Async/Await

每种技术都有自己的优点和适用场景，它们都助于更有效地管理异步操作。

## 9.2 理解回调

回调是一个作为参数传递给另一个函数，并在另一个函数的内部任务完成后执行的函数。回调是 JavaScript 中处理异步操作的基础方式。

### 示例：基础回调用法

```javascript
function fetchData(callback) {

setTimeout(() => {

const data = 'Data fetched from server';

callback(data);

}, 2000); // 模拟 2 秒的延迟

}

function displayData(data) {

console.log(data);

}

fetchData(displayData); // 将 displayData 函数作为回调传递
```




在这个示例中，`fetchData` 使用 `setTimeout` 模拟了一个异步操作（例如从服务器获取数据）。一旦获取到数据，它就会调用 `displayData` 函数并将数据作为参数传递。。

### 回调地狱 (Callback Hell)

虽然回调函数非常有用，但它们可能会导致“回调地狱”，即回调嵌套在其他回调中，使得代码难以阅读和维护。这在需要将多个异步操作链联的场景中尤为常见。

```javascript
fetchData(function(data1) {
  fetchData(function(data2) {
    fetchData(function(data3) {
      console.log(data1, data2, data3);
    });
  });
});
```

这种方法很容易出错并且让代码更难调试。幸运的是，JavaScript 提供了更好的处理异步操作的方法，例如 promises。

* * *

## 9.3 理解 Promises

`Promise` 是一个代表异步操作最终完成（或失败）的对象。与回调函数相比，`Promises` 提供了一种更简洁、更易管理的方法来处理异步代码。一个 promise 可以处于三种状态之一：

1. `Pending`：初始状态，操作完成之前的状态。
2. `Fulfilled`：操作成功完成。
3. `Rejected`：操作失败。

### 创建一个 Promise

你可以使用 `new Promise()` 构造函数创建一个 promise。在构造函数内部，你提供一个函数（称为执行器），它带有两个参数：`resolve` 和 `reject`。当操作成功时调用 `resolve`，操作失败时调用 `reject`。

```javascript
let myPromise = new Promise((resolve, reject) => {
  let success = true; // 模拟操作的结果
  if (success) {
    resolve('Operation successful!');
  } else {
    reject('Operation failed!');
  }
});
```

### 处理 Promises

你可以使用 `.then()` 方法处理 promise 的成功结果，使用 `.catch()` 处理错误。这两个方法都会返回一个新的 promise，从而允许链式调用。

```javascript
myPromise
  .then(result => {
    console.log(result); // 'Operation successful!'
  })
  .catch(error => {
    console.log(error); // 'Operation failed!'
  });
```

### 链式调用 Promises

Promises 可以链式连接起来，使得按顺序执行多个异步操作变得更容易。

```javascript
fetchData()
  .then(data => {
    console.log(data);
    return fetchData(); // 返回另一个 promise
  })
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.log('Error:', error);
  });
```

在这个示例中，第二个 `fetchData` 操作只有在第一个操作成功完成后后才会运行。

* * *

## 9.4 Async/Await 语法

虽然 promises 大大改进了异步代码，但在处理多个操作时它们仍然可能很繁琐。ES2017 引入的 `async` 和 `await` 关键字通过允许以类似于同步的方式编写异步代码，简化了对 promises 的操作。

### async 关键字

`async` 关键字用于定义异步函数。一个 `async` 函数总是返回一个 promise。如果函数返回一个值，则 promise 将以该值解析。如果函数抛出错误，则 promise 将拒绝。

```javascript
async function myAsyncFunction() {
  return 'Hello, world!';
}
myAsyncFunction().then(result => console.log(result)); // 'Hello, world!'
```

### await 关键字

`await` 关键字用于 `async` 函数内部，暂停函数的执行，直到 promise 解析完成。它简化了对 promises 的操作，使得异步代码更易阅读和理解。

```javascript
async function fetchData() {
  let data = await fetch('https://jsonplaceholder.typicode.com/posts');
  let jsonData = await data.json();
  console.log(jsonData);
}
fetchData();
```

在这个示例中，`await` 等待 `fetch()` promise 解析完成后，再继续将响应解析为 JSON。

### 使用 async/await 处理错误

你可以使用 `try/catch` 块在 `async/await` 函数中处理错误，这比使用 promises 的 `.catch()` 使错误处理更加简洁。

```javascript
async function fetchData() {
  try {
    let data = await fetch('https://jsonplaceholder.typicode.com/posts');
    let jsonData = await data.json();
    console.log(jsonData);
  } catch (error) {
    console.log('Error:', error);
  }
}
fetchData();
```

在这个示例中，`try` 块包含了异步代码，`catch` 块捕获了执行 `async` 函数期间发生的任何错误。

## 9.5 实际示例：从多个 API 获取数据

现在我们已经理解了异步 JavaScript 的基本概念，让我们在一个实际示例中将它们结合起来。假设我们想从多个 API 获取数据并在应用程序中显示结果。

### 示例：使用 async/await 从多个 API 获取数据

```javascript
async function fetchDataFromApis() {
  try {
    let postsResponse = await fetch('https://jsonplaceholder.typicode.com/posts');
    let usersResponse = await fetch('https://jsonplaceholder.typicode.com/users');
    let posts = await postsResponse.json();
    let users = await usersResponse.json();
    console.log('Posts:', posts);
    console.log('Users:', users);
  } catch (error) {
    console.log('Error fetching data:', error);
  }
}
fetchDataFromApis();
```

在这个示例中，第二个 `fetchData` 操作只有在第一个操作成功完成后后才会运行。

## 附录 D：JavaScript 最佳实践

随着你 JavaScript 经验的增加，采用最佳实践以确保你的代码整洁、高效且易于维护。以下是需要遵循的一些关键最佳实践：

### 1. 使用一致的命名规范

- **驼峰命名法 (CamelCase)**：变量和函数名使用 `camelCase`。这意味着以小字母开头，后续单词的首字母大写。
示例：`let myVariableName = "Hello";`

- **帕斯驼命名法 (PascalCase)**：类名和构造函数使用 `PascalCase`。
示例：`class MyClass {}`

### 2. 避免全局变量

全局变量会导致不可预测的行为，特别是当你的代码库变得时。使用 `let` 或 `const` 在块或函数内部声明变量以避免污染全局作用域。

### 3. 保持函数短小专注

函数应该执行单一且定义良好的任务。如果一个函数执行过多，将难以理解和维护。将较大的函数拆分为较小的函数，使代码更具模块化。

### 4. 使用描述性的变量名

为变量和函数选择有意义的名字。避免使用如 `x` 或 `temp` 等模糊的名称。相反，使用描述变量内容的名称。
示例：`let userAge = 30;`

### 5. 为你的代码注释

使用注释来解释复杂或非直观代码的作用。这将帮助你和其他开发人员以后理解代码。

```javascript
// 计算矩形的面积
function calculateArea(width, height) {
  return width * height;
}
```
