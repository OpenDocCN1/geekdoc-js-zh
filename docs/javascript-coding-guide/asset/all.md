Question1: JavaScript: What are the mathematical assignment operators?

+=

-+

*=

/=

%=

**=

Question 2:  JavaScript: What is the exponentiation operator?

**

Example:

let answer = 3 ** 2;

The above code assigns the variable answer a value of 9.

Question 3:  JavaScript: What Math method returns a random decimal value between 0 and 1?

Random

Question 4:  JavaScript: How are template literals formatted?

Using backticks `` instead of quotation marks ''.

Question 5:  JavaScript: What Number method returns a boolean value based on whether or not a given number is an integer?

isInteger(number)

Question 6:  JavaScript: What is the use of template literals?

To insert variables into strings without escaping quotation marks.

Question 7: JavaScript: What keyword declares a variable that can have its value changed?

Let

Question 8:  JavaScript: How are variables inserted into template literals?

Inside the curly braces of ${}.

Example:

console.log(`The number is equal to ${valueOfNumber}`);

Question 9:  JavaScript: How are single line comments formatted?

Using //.

Question 10:  JavaScript: What operator returns the type of the variable to its right as a string?

typeof

Example:

let valueType = typeof 42;

The valueType variable would be assigned the value 'number'.
