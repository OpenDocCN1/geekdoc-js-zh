## 前言：谁、什么以及为什么选择 JavaScript？

如果你正在阅读这本书，你可能刚刚开始学习前端开发。自网页早期以来，前端开发已经取得了巨大的进步，现在不再局限于基础的 HTML。如今，无法想象没有 JavaScript 的前端编码，JavaScript 无处不在，几乎是所有 Web 应用程序的基石。

简单的 HTML 就能开始构建引人入胜的网站的时代已经过去了。静态 HTML 已出淘汰，现在的需求是功能丰富的内容，而如果不引入有效的 JavaScript，这是无法实现的。

这本书是给谁看的？这本书做了一些假设，即你对 HTML 以及静态 HTML 网页的编码有基本的了解。我们还假设你懂一点 CSS，并且对于 JavaScript 来说是新手。即使你对 JavaScript 编程有一定的基础知识，这本书也将作为一次欢迎的复习，强化核心概念，并介绍你可能熟悉的概念，这无疑会提升你的编程技能。

这本书不会让你一夜之间成为 JavaScript 专家，即使你读了十遍并完成其中所有的练习，我们甚至没有打算这样做。定义大师、忍者与新手之间的编程边界每天都在被重新定义。这本书将为你提供使用 JavaScript 所需的核心概念，此后学习这些概念将成为你的本能。

什么是 JavaScript？

让我们从头开始，JavaScript 到底是什么？JavaScript 是一种客户端脚本语言。在 Web 开发领域，你有客户端语言和服务器端语言。服务器语言是用于编写在服务器上解析和执行页面的语言，包括 Php、ASP、ASP.NET 和 Ruby 等语言。

客户端语言是在浏览器中执行或运行的——因此被称为“客户端”。在这种情况下，“客户端”（即浏览器）向服务器发送请求，服务器随后返回显示给你的 HTML。每当你在浏览器的 URL 框中输入 Web URL 时，你都在向服务器发送一个请求，服务器随后返回一组 HTML 并在你的浏览器中显示。你的


浏览器解析 HTML 并将其展示给您。

JavaScript 能做什么？
正如所述，JavaScript 被设计为在客户端运行，因此它运行在您的浏览器中。正因为有了 JavaScript，网页才不再是静态的。JavaScript 让网页能够展现出比仅仅点击链接打开新页面多得多的交互性。这种现象你显然在访问过的几乎每个网站中都注意到了。例如：

- 那些要求你提供手机号码和电子邮件的烦人弹窗
- 页面上的时间似乎与你的时钟同步计时
- 当你输入错误时，那些变红的表单字段
- 那些酷炫的淡入和滑入动画
- 那些似乎记得你上次访问时的偏好的网站
- 那些在你点击提交按钮时，无需刷新页面就能自动更新的列表

这一切以及更多，都归功于 JavaScript。JavaScript 客户端脚本的另一个关键方面也是减少发送到服务器的请求数量或体积。例如，考虑以下情况：

你需要在网站的访客簿表单中收集访问者的姓名、电子邮件和消息。为了确保用户输入正确的信息，你在服务器端脚本（假设是 php）中编写了一个基础验证模块，用于检查提交的每个访客簿条目是否填写正确，即电子邮件是有效的邮箱，姓名是真实的姓名。如果有人输入了错误，你的服务器必须运行验证，然后返回带有错误消息的相同页面，要求他重新输入。如果你在服务器端代码的同时，也在页面本身使用 JavaScript 编写了一个类似的验证脚本，在表单提交**之前**检查输入内容——你不仅减少了发送到服务器的 HTTP 请求次数，还让终端用户无需等到填写并提交表单后才发现自己犯了错。

这只是非常简单的例子——想象一下，如果表单异常巨大而用户正处于慢速连接，你会让终端用户有多抓狂。

## 易于学习和使用
说真的，JavaScript 学习非常简单，而且用起来很愉快。你不需要准备很多就可以开始学习 JavaScript，而且作为代码，你可以立即看到工作的结果。这与使用 Php & ASP 等服务器端脚本编码完全不同，后者你绝对需要服务器来执行你的脚本。有了 JavaScript，你只需要一个浏览器就可以就绪了。

JavaScript 可以做到 HTML 做不到的任何事情。JavaScript 赋予你权力和灵活性，允许终端用户操作你网页上的内容。通过 JavaScript，你可以验证表单中输入的内容，允许终端用户更改页面内容，甚至与页面上的元素进行交互。你还可以设置代码在不同事件上执行，例如有人点击按钮、悬停在图片上、离开页面甚至尝试关闭页面时会发生什么。简而言之，你对用户如何以及与什么交互有着大量的控制权，为你的网页增添了全新的维度。

人们使用 JavaScript 多久了？
JavaScript 已经存在很长时间了。它最初由 Brendan Eich 在 90 年代初在 Netscape 开发，专为 Netscape Communicator 浏览器设计。他开发这种语言的目标是让网页更具动态和交互性。有趣的是，JavaScript 与 Java 语言之间没有任何关联，除了它们共享了 "java" 这个词。

在此期间，微软为 Internet Explorer 浏览器推出了他们自己的名为 JavaScript 的客户端语言。JavaScript 基于 Netscape 的 JavaScript，为了避免版权问题被命名为 JavaScript。

这导致了所谓的“浏览器大战”，领先的浏览器提供了该客户端语言的各种实现。这产生了严重的后果，你现在拥有基于浏览器的私有代码，导致在 Netscape 浏览器中编写的脚本在 Internet Explorer 中失败。

简而言之，JavaScript 经历了重大的演变，并在近二十年的历史中在很大程度上实现了标准化。

它是魔法吗？取决于你用它来做什么。尽管 JavaScript 允许你对 HTML 页面以及用户的浏览器有很大的控制权，但它不会导致电脑崩溃，所以它是相当安全的。

然而，自诞生以来，JavaScript 出现了许多安全漏洞，例如跨站脚本攻击（XSS），它允许黑客向用户返回恶意脚本，这些脚本会在用户的浏览器中执行。就像那些被反复警告不要点击的横幅广告一样，脚本能做的最坏事情就是访问存储在浏览器中的信息，包括存储在 cookie 中的身份验证详细信息以及你不希望别人获取的其他类型数据。

在这方面，保护的责任在于用户，而我们所有正直的人所能做的做的，就是永远不要利用 JavaScript 的力量去做邪恶的行径——就像任何超级力量一样，在错误的人手中，它可能会导致灾难！

### 内联与 外部 JavaScript
上面是一个内联编写的 JavaScript 示例。即你在同一个 HTML 页面中在 <script> 标签内编写了 JavaScript。虽然这在测试简单代码时很方便——但并不是一个好的做法，而且当你的页面和代码变得复杂时，它并不易扩展。

出于这个原因，最好从外部运行 JavaScript，将所有的 JavaScript 放在一个单独的文件或一组文件中，并使用相同的 <script> 标签将其引入。首先，在与 index.html 相同的文件夹中创建一个文件并将其命名为 main.js。

保存文件并在文本编辑器中打开它，将 script 标签之间的代码（不包括 script 标签）复制到 main.js 文件中并保存。

从你的 HTML 文档中删除 script 标签和代码，并在 <head> 标签内添加以下版本的 <script> 标签：

```html
<script language="JavaScript" src="main.js"></script>
```

保存并刷新你的浏览器——你应该看到与内联时完全相同的输出。我们把所有的 JavaScript 移动到了单独的 JavaScript 文件中，并通过在上面的 <script> 标签中引用它来包含该文件。<script> 标签的 src 属性指向要加载的文件的位置。

更好的做法是将所有的 JavaScript 代码放在一个单独的 js 文件夹中。随着你的项目变得越来越复杂，你会发现将 JavaScript 分在不同的文件中是有意义的。





注意：*你也可以将 JavaScript 文件包含在 <body> 标签内，尽管按照惯例它们通常加载在 <head> 标签中。*

# 第 2 章：基础知识

JavaScript 的独特之处在于它是一种解释型语言，而不是编译语言。在编程中，你有解释型语言和编译语言。在解释型语言中，程序是逐语句执行的而在编译语言中——整个程序首先被编译成可以执行的格式然后然后运行。解释型语言的一个特点是，如果程序中存在错误语句，错误语句之前的语句仍然会被运行和执行，但程序会在遇到错误代码时停止。

你将在书的后续部分理解为什么知道这一点很重要。

将语法想象成计算机的语法和词汇。如果你没有足够的词汇，你就无法进行交流；如果你没有语法感，你完全无法表达意思。计算机编程也是如此。和所有计算机编程语言一样，JavaScript 有它自己的语法，即你在编写有效代码时必须遵守的一套规则。

JavaScript 语法由：

在我们之前的代码中，我们学习了 JavaScript 的一条基本规则，即：

> 每条语句都必须以分号结尾

注意，当我们说语句时，并不一定意味着语句是单行上的所有代码。当你在 JavaScript 中写一条语句时，它都必须以分号结尾。即使你在同一行上写了多个语句，每条语句也都要以分号结尾。例如：

```
var t = 1;var x = 1;
```

这与写以下代码是一样的：

```
var t = 1;
var x = 1;
```

JavaScript 代码中的另一个有用功能是可以为代码添加注释。添加注释是为了对代码的实际作用进行简要说明。它们仅供程序员参考，不会作为 JavaScript 代码运行。在 JavaScript 中，通过在注释前加上两个反斜杠来添加注释。这将把该行上的所有内容标记为注释，例如：

```
// 这是一个注释 - 它什么都不做
var t; // 之后的所有内容都是注释
```

或者，注释可以包含在 `/*` 和 `*/` 之间。这种注释方式仅会将字符之间的内容排除为注释。例如：

```
// 整行都被注释了
/*这段文字全部被注释了 */
var t = 1; /* 这被注释掉了 */ var x = 2;
```

给代码注释是非常好的习惯，有助于理解复杂代码的作用，特别是当你需要回来查看它，或者当其他人必须处理你的代码时。保持注释简短，但要足够全面，让别人能理解下面的代码块应该做什么。

### 条件运算符

JavaScript 了一个了一个条件运算符，可以根据简单的判断进行赋值。这就是 `? :` 运算符。为了理解它，请查看以下示例：

```javascript
var a = 10;
var b = (a == 10 ? 12 : 0); // b 被赋值为 12
```

上述语句的意思是如果 a 等于 10，则返回值 12，否则返回值 0。由于 a 等于 10，因此变量 b 被赋值为值 12。这是一个根据单个语句进行赋值的非常方便的快捷方法。你可以根据需要让语句变得复杂，例如：

```javascript
var a = 10, b = 12;
var c = (a == 10) && (b > 10) ? 12 : 0; // c 被赋值为 12
```

在上面的语句中，我们在条件语句内部使用逻辑与运算符对两个表达式进行检查。一点建议是，每当你使用条件运算符时，请保持简单，否则你可能会陷入非常难以处理的局面：

```javascript
var c = !((a == 10) && (b > 10)) || !((b < 15) && ((c/2) < b)) ? 12 : 0; // 请不要这样做
```

```javascript
var name = '';
if(name == '') {
  document.write('Name cannot be blank!');
}else if (name == 'Bob') { // 名字不是空的，是 Bob

}else{ // 名字既不为空也不是 Bob
  document.write('Your name is not Bob but ' + name);
}
```

上面的语句在第一个 `if` 语句失败时会运行第二个 `if` 语句。你可以这样链式地连续调用 `if` 语句，根据你的需求检查特定的条件。

### 嵌套条件

```javascript

```javascript

  // 执行一些事情
}

这虽然可以运行，但编写四个不同的条件语句来检查每一种可能性似乎有点疯狂。实现此点的简单方法是在彼此内部嵌套 `if - else` 语句。就像任何代码都可以一样，你也可以嵌套 `if - else` 语句。例如，上面的代码可以重写为：

### for 循环
JavaScript 中最基础且多功能的循环语句是 `for` 循环。`for` 循环的语法如下：

```javascript
for (statement 1; statement 2; statement 3) {
  // 要运行的代码
}
```

语句 1 是在循环实际开始之前执行的表达式。这通常是一个初始化表达式，用于初始化一个用作计数器的变量。

语句 2 是一个定义代码运行条件的表达式，也就是说，只要语句 2 中的表达式求值为 `true`，代码就会持续运行。

语句 3 是在循环每次迭代时运行的表达式。

`for` 循环中的这三个语句定义了将进行多少迭代，这意味着 `for` 循环块中的代码将运行多少次。因此如果我们输出上面的例子，假设输出 10 次，我们会这样写 `for` 循环：

```javascript
for( i = 0; i < 10; i++){
  document.write('I will not drive in a no driving zone.<br/>');
}
```

结果是语句“我不会在禁区开车”被打印了 10 次。让我们稍微解构一下循环。我们可以看到语句 1 是 `i = 0`，我们将变量 `i` 初始化为零。语句 2 概述了一个条件 `i < 10`，这意味着只要变量 `i` 小于 10 就继续迭代。因此我们知道变量 `i` 已初始化了一个起始值为零，循环将一直运行到变量 `i` 不再小于 10（即等于或大于 10）为止。第三个语句 `i++` 在循环每次迭代时运行，在循环的每次迭代中，我们都将变量 `i` 加了 1。

你可能会奇怪为什么我们将 `i` 初始化为 0 而不是 1。我们可以这样做，但我们必须将语句 2 调整为 `i<=10`，否则该语句只会执行 9 次。这是因为 `i++` 语句在迭代后增加 `i` 的值。

所以如果我们重复 `for` 语句中的代码块 20 次，只需将语句 2 改为 `i < 20` 即可。由于 `for` 循环非常通用，只要这些语句能有效地作为循环工作，你可以使用任何语句组合。例如，下面的 `for` 循环将完全不会运行：

```javascript
for( i=0; i==0; i++){
  // 做些什么
}
```

这是因为第二个语句的条件在循环开始之前就已经满足了。而下面的循环将永远不会结束：

```javascript
for( i=0 ; i<0; i++){
  // 永远不会的循环
}
```

因为在上面的循环中，迭代语句 `i++` 在任何时候都会给 `i` 分配一个小于零的值，因为 `i++` 在每次迭代中都会将 `i` 的值增加 1。因此在处理循环时需要非常小心。在 JavaScript 中工作的大忌之一是在有限或无限循环中放置 `alert` 命令，后者仍然会让你赢得全球网页用户的蔑视，所以请永远不要在循环中使用任何会触发弹出窗口的命令。

### do -- while - 再给你一个循环

`do while` 循环是 `while` 循环的一种变体，在 `while` 循环甚至 `for` 循环中，条件是在循环运行之前测试的；而在 `do while` 循环中，执行循环的条件是在迭代之后测试的。这意味着即使循环求值结果为假，`do while` 循环也会至少运行一次。

`do while` 循环的基本语法如下：

```javascript
do{
  // 要执行的代码
}while(expression)
```

就像 `while` 循环一样，你需要在代码块内部初始化用于迭代循环的变量。否则，你将导致一段要么在变量未初始化时不运行的代码，要么在崩溃你的浏览器之前永远不会停止的代码（这前提是你没有定义迭代器）。上面的示例可以重写为 `do while` 循环，如下：

```javascript
var i = 0;
do{
  document.write('I will not drive in a no driving zone.<br/>');
  i++;
}while(i < 10 )
```

`do while` 语句与 `while` 语句唯一的区别可以通过下面的示例看到。

```javascript
var i = 0;
while(i != 0 ) {
  document.write('While loop runs.<br/>');
  i++;
}
```

```javascript
var i = 0;
do{
  document.write('Do while runs.<br/>');
  i++;
}while(i !== 0 )
```

我们为两个循环设置的条件都是当变量 `i` 等于零时停止递增——在这种情况下，变量已经初始化为零，因此在循环运行之前条件就已经满足了。然而，对于 `while` 循环来说是这样，但在 `do` 循环的情况下——显而易见，在测试条件之前已经执行了代码块。因此结果是，`while` 循环将完全不运行，但 `do` 循环在测试条件之前至少运行一次。

### 嵌套循环

就像嵌套条件语句一样，我们也可以在 JavaScript 中嵌套循环。嵌套循环是指你在一个循环内部包含另一个循环。为了演示这一点，我们将使用 JavaScript 使用两个循环语句创建一个具有特定行数和单元格的表格。为了让它更有趣，我们顺便还会打印一个乘法表。让我们来看下面的代码：

```javascript
var tbl = '';
tbl = '<table>';
tbl = tbl + '</table>';
document.write(tbl);
```

这没什么用，但让我们看看上面的代码，我们引入了一种输出大量文本的更简单的方法。与其为每个需要写入屏幕的内容都使用 `document.write` 语句，不如将我们的字符串数据赋值给变量。注意，对于字符串，`+` 运算符充当连接符，从而拼接字符串形成一个新的字符串。在上面的代码中，我们只是创建了一个没有行和单元格的简单 `<table>` 元素。让我们使用循环为我们的表格添加 10 行。

```javascript
var tbl = '';
tbl = '<table>';
for( i = 1; i <= 10; i++) {
  tbl = tbl + 'tr>';
  tbl = tbl + '</tr>';
}
tbl = tbl + '</table>';
document.write(tbl);
```

不错，现在让我们创建一些单元格。记住我们需要为每一行创建十个单元格。这可以通过在创建行的循环内部嵌套另一个循环来实现。

```javascript
var tbl = '';
tbl = '<table>';
for( i = 1; i <= 10; i++) {
  tbl = tbl + '<tr>';
  for( j = 1; j <= 10; j++) {
    tbl = tbl + '<td>';
    tbl = tbl + ( i * j );
    tbl = tbl + '</td>';
  }
  tbl = tbl + '</tr>';
}
tbl = tbl + '</table>';
document.write(tbl);
```

注意，在嵌套循环中，我们有被称为循环的代码块，用于重复。我们在上一节中检查了循环，唯一的区别是，在 `while` 循环中，你需要手动递增变量并在之前初始化它。

百分比、在不同的数值格式之间转换——你会发现自己一直在重复大量的代码。这为错误的产生提供了很多可能，并会让你的代码变得非常长且高度重复。

函数是代码块，你只需要编写一次，以后每当需要时，就可以调用所需的函数。事实上，到目前为止，你甚至在不知道的情况下已经使用了一些函数。

## 基础函数
函数通过 `function` 关键字声明，后面跟着函数名、圆括号以及括在在大括号中的代码。函数的命名方式与变量几乎完全相同，即它们只由字母、数字和下划线组成，且不能以数字开头。下面的示例是一个返回消息的函数。

```javascript
function greet(name) {
  return 'Hello ' + name;
}
```

函数可以接受参数并返回结果。在上面的示例中，名为 `greet` 的函数接受一个名为 `name` 的参数。`return` 关键字做了两件事：首先它跳出函数，其次每当函数被调用时返回一个值。上面的函数可以如下所示被调用：

```javascript
greet('Bob');
```

运行这段代码似乎没有产生任何结果，因为函数返回了一个值，而我们没有对其进行任何处理。让我们把函数返回的值存储在一个变量中。

```javascript
var greeting = greet('Bob');
document.write(greeting);
```

在上面的示例中，`greeting` 变量被赋值为 `greet()` 函数返回的值，在这种情况下，我们向函数传递了字符串 `'bob'`。函数返回了 `'Hello Bob'`，由于我们使用 `document.write` 将其打印到屏幕上——你会在页面上看到它。这就是函数的工作原理。在此之前，我们实际上已经使用了一些原生 JavaScript 函数，它们的作用与上面定义的函数相同。

## 几个原生 JavaScript 函数
在之前的章节中，我们介绍了一些核心原生 JavaScript 函数，例如 `alert`、`confirm` 和 `prompt` 函数。所有这些函数都接受参数并返回结果，与我们的简单示例类似。例如，在调用 `confirm` 时：

```javascript
var a = confirm('Are you sure?');
```

我们传递了一个参数，即要在 `confirm` 弹出框中显示的消息，而函数会显示该框、捕获用户的选择，并根据用户的选择返回 `true` 或 `false` 值。`prompt` 函数也是如此。

## 将函数赋值给变量
在 JavaScript 中，有多种声明函数的方法。函数也可以赋值给变量——从技术上讲，它仍然是一个函数声明。例如，上面的函数完全可以重写如下：

```javascript
var greet = function(name){ return 'Hello ' + name};
```

在调用函数时，请记住它后面总是紧跟着 `()`。如果你尝试在不带后续括号的情况下调用函数——它会返回整个函数的定义。在上面的示例中：

```javascript
var greet = function(name){ return 'Hello ' + name};

document.write(greet('Bob')); // 打印 'Hello Bob'
document.write(greet); // 打印 function(name){ return 'Hello ' + name};
```

一旦声明了函数，就可以将其赋值给另一个变量。例如：

```javascript
var greet = function(name){ return 'Hello ' + name};
var g = greet;
```

```javascript
g('Bob'); // 等同于 greet('Bob');
```

这是 `()` 括号在处理函数时产生的细微但巨大的区别。函数允许你使用不同的变量复用相同的代码。如果你有一段代码显然会被再次使用，或者它能独立完成一组功能——将其放入函数并进行函数调用是一个好主意。

## 向函数传递参数
如果不能从函数获取自定义结果，函数将没有太大用处。传递给函数的参数可以通过声明参数时给定的参数名在函数内部访问。在 JavaScript 中，你可以选择声明要传递的参数或不声明。在上面的示例中，我们显式地提到了在函数作用范围内使用的第一个参数名称，即在这种情况下。因此你可以向函数传递任何变量，但在函数内部它将通过函数声明时的名称进行引用。

你可以向函数传递与声明数量数量的参数。例如：

```javascript
function add(num1, num2) {
  return num1 + num2;
}
add(2,3); // 返回 5
```

你在函数声明中声明的任何参数都可以通过其声明时的名称进行引用，如上面的示例所示，传递给函数的两个参数分别是 `num1` 和 `num2`。如果由于原因没有传递所有的函数参数：

```javascript
function add(num1, num2) {
  return num1 + num2;
}
add(10) //
```

上述代码会导致错误，因为 `num2` 没有被传递值，因此是 `undefined`。另一种，你也可以传递比声明数量更多的参数，例如：

```javascript
function add(num1, num2){
  return num1 + num2;
}
add(10, 20, 30)
```

变量名和变量 `i` 可以被函数内部的代码访问。这被定义为**局部作用域 (Local scope)**——我们说函数内部定义的变量具有局部作用域，因为它们只能被函数内部的代码访问。因此，在下面的示例中：

```javascript

```

局部变量只能在函数内部访问，不能在函数外部访问。局部变量在函数被调用时存在，在函数执行完毕时销毁。

然而，让我们考虑以下示例：

```javascript
var stuff = 12;

function foo(name) {
  var i = 0;

}
```

函数如何访问在函数外部声明的变量 `stuff` 呢？在页面函数外部声明的变量具有所谓的**全局作用域 (Global scope)**。此类变量可以在任何函数中访问。变量不仅可以被函数访问，还可以被函数修改，甚至无需显式地传递它。

```javascript
var stuff = 12;

function foo(){
  // 执行某些操作
  stuff = 15;
}

foo();
document.write(stuff); // 打印 15
```

同时，你也可以从函数内部声明全局变量。要做到这一点，你只需要给变量赋值而不需要显式使用 `var` 命令声明它。例如：

```javascript
function foo(){
  // 执行某些操作
  stuff = 15;
}

foo();
document.write(stuff); // 打印 15
```

在上面的示例中，声明 `stuff` 变量会自动使其成为全局变量，可以在脚本的任何地方访问。这种方法的缺点是，你可能会在不知情的情况下修改了一个变量。因此，尽量确保你使用的任何变量都已初始化，并且你的变量具有描述性的名称。

## 数组的概念

## 创建数组

```javascript

```

在上面的示例中，我们使用方括号声明了一个名为 `gender` 的数组，并在数组中存储了两个值，即 `'male'` 和 `'female'`。如果没有数组，我们必须像这样使用变量：

```javascript
var male_gender = 'male';

如果我们需要更复杂的示例，情况就会变得非常复杂。例如，如果我们必须列出不同的宠物：

var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];

### 推入/弹出 (Push/Popping)
在处理数组时，我们知道数组是按顺序方式存储值的变量。从数组中添加元素和移除元素分别被称为推入（Push）和弹出（pop）。数组对象为我们两个命名恰当的 `push` 和 `pop` 方法来执行这些功能。

`push` 方法将新元素推入或添加到数组末尾。在上面的示例中，我们向数组末尾添加了一个元素，可以将其重写为：

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.push('turtle'); // 返回 5
pets[5]; // 等于 'turtle'
```

同样，如果我们需要从数组移除最后一个元素，就会使用 `pop` 方法。

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.pop(); // 返回 'bird'
pets; // 等于 ['dog', 'cat', 'rabbit', 'hamster']
```

与函数一样，`push` 方法返回数组的新长度，而 `pop` 方法返回被“弹出”的数组元素。

### 移位/插入 (Shift/Unshift) - 这些不是齿轮
与 `push` 和 `pop` 方法类似，我们还有 `shift` 和 `unshift` 方法，它们在 JavaScript 数组中的作用几乎相同。上面的两个示例可以使用 `shift` 和 `unshift` 重写：

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.unshift('turtle'); // 返回 5
pets[5]; // 等于 'turtle'
```

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.shift(); // 移除最后一个元素 'bird' 并返回它
pets; // 等于 ['dog', 'cat', 'rabbit', 'hamster'];
```

### 从数组中移除元素
提到从数组中移除元素，我们已经知道了 `shift` 和 `pop` 函数，但这些函数只能通过移除数组末尾的元素来工作。你需要移除那些并不位于你操作数组极端的元素。

从数组中移除元素与修改和读取元素非常相似，即你会通过元素所在的索引来引用它们。要从数组中删除元素，我们使用 `delete` 命令：

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
delete(pets[1]);
pets; // 等于 ['dog', undefined, 'rabbit', 'hamster', 'bird']
```

虽然 `delete` 确实删除了数组中的值，但同一个数组中会留下一个 `undefined` 值。使用 `delete` 会在数组中留下空隙，这并不符合我们想要从数组中移除元素并缩短它的预期。这样做，我们引用一个名为 `splice` 的多功能函数。`splice` 是所有数组都拥有的功能方法，可以用于删除也可以添加数组元素。让我们来看看它移除元素：

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.splice(1,1);
pets; // 等于 ['dog', 'rabbit', 'hamster', 'bird'];
```

这里到底发生了什么？你可能在好奇。在上面的示例中，`splice` 接收两个参数。第一个参数是你想在数组中添加或移除元素的位置。第二个参数是要移除的元素数量。在上面的示例中，我们从数组索引为 1 的位置移除了一个元素，从而使数组缩短了一个元素。`splice` 函数也可以使用相同的参数删除多个一个元素。

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.splice(2,2);
pets; // 等于 ['dog', 'cat', 'bird'];
```

这些都很有用，但 `splice` 如何在删除元素的同时向数组添加元素呢？为了添加元素，我们可以向 `splice` 传递更多的参数。

```javascript
var pets = ['dog', 'cat', 'rabbit', 'hamster', 'bird'];
pets.splice(2,0, 'turtle', 'goldfish');
pets; // 等于 ['dog', 'cat', 'rabbit', 'turtle', 'goldfish', 'hamster', 'bird'];
```

`splice` 方法是 JavaScript 函数可以在不需要显式声明的情况下接收多个参数的示例。在上面的示例中，第一个参数指定了添加元素的位置，第二个参数是要移除的元素个数，其余参数是要待添加到数组中的元素。你可以根据意愿传递任何一组参数，甚至可以传递数组数组和对象。数组几乎可以携带任何类型的信息。同时，你也可以使用单个 `splice` 函数从数组中移除和添加元素：

```javascript
var pets = ['dog', 'cat', 'hamster', 'bird'];
pets.splice(2,1, 'turtle', 'goldfish');
pets; // 等于 ['dog', 'cat', 'turtle', 'goldfish', 'hamster', 'bird'];
```

### 合并数组
合并多个数组如何？你有两个或多个不同的数组，并想像蜈蚣一样将它们连接以得到更大的超级数组。JavaScript 中的数组提供了 `concat` 方法，它正可以实现这一点：将若干个数组添加到原始数组中。

### 遍历数组
由于我们知道数组有数字索引，我们可以使用循环遍历数组。以下是使用循环遍历上述数组的几个示例：

```javascript
var pets = ['dog', 'cat', 'hamster', 'bird'];
for(var i = 0; i < pets.length; i++) {
  document.write(pets[i] + '<br/>');
}
```

```javascript
var i = 0;
while( i < pets.length ) {
  document.write(pets[i] + '<br/>');
  i++;
}
```

```javascript
var i = 0;
do{
  document.write(pets[i] + '<br/>');
  i++;
}while( i < pets.length );
```

在上面的示例中，JavaScript 还提供了所有不同的循环。JavaScript 还提供了另一种用于遍历数组的特殊循环，叫做 `for...in` 循环。它的工作方式与其他循环相似，你你不需要使用变量来遍历，而是完全依赖数组或对象来知道何时停止。

pets = ['dog', 'cat', 'hamster', 'bird', 'rabbit', 'turtle', 'goldfish'];

### 数组排序
你经常想要对数组中的元素进行排序。这就像在学校游行期间让孩子们从矮到高排队一样自然。对于数组排序，JavaScript 提供了 `sort` 函数，它在处理带有文本数据的数组时表现良好。



数值值：

```javascript
var a = [10, 3, 2];
a.sort() // 现在等于 [10, 2, 3]; 咦？
```

这是怎么发生的？`sort` 函数不知道如何计数吗？`sort` 函数实际上是按字母顺序排序，将数组中的所有元素视为字符串而不是数字。因此，作为字符串，'10' 排在 '2' 之前，因为数字 '1' 被视为 '2' 的前置字符——在这种语境下，'10' 的数值被忽略了。为了解决这个问题，`sort` 函数接受一个完整的函数作为参数进行比较（是的，你也可以将函数作为参数 - JavaScript 是不奇妙吗？）。

这个比较函数将接受两个参数，这两个参数对应于要相互比较的值。简单来说，`sort` 函数会在每次比较数组中的两个值时调用此函数。通过这个函数，你可以定义实际上如何对数组进行排序，只要该函数返回负值、正值或零即可。让我们来看一个进行数值比较的例子：

```javascript
var a = [10, 3, 2];
a.sort(function(x, y){return x-y});
```

在上面的示例中，我们传递了一个函数，它用第二个传入的元素减去第一个传入的元素。如果第一个元素大于第二个元素，如下——返回值将是正数，因此该元素的位置将被较小的元素替换。这会将元素按数值从低到高进行排序。对该函数进行稍微修改，就可以实现从高到低的排序：

```javascript
var a = [10, 1, 2];
a.sort(function(x, y){return y-x});
```

### 搜索

当数组有多个元素时，我们需要一种找到特定元素的方法。我们可以始终遍历数组并检查特定元素是否存在。这里有一个使用函数说明这一点的例子。

```javascript
function findInArray(needle, haystack) {
  for (var i = 0; i < haystack.length; i++) {
    if(haystack[i]==needle){
      return i;
    }
  }
  return -1;
}

var a = [10, 3, 2];
findInArray(a, 3); // 等于 1
findInArray(a, 13); // 等于 -1
```

上面的示例简单地遍历数组，并在找到元素时返回数组的索引。数组永远不会有负索引，这就是为什么如果循环完成且没有返回值（即没有找到元素），上面的函数会返回负值。然而，你真的不需要在 JavaScript 中创建自己的函数来搜索元素，因为 JavaScript 已经提供了数组方法来查找元素的索引，它的功能方式与上面的函数几乎相同。认识 `indexOf` 函数。

```javascript
var pets = ['dog', 'cat', 'hamster', 'bird', 'dog', 'goldfish'];
pets.indexOf('cat'); // 返回 1
pets.indexOf('dog'); // 返回 0
pets.indexOf('snail'); // 返回 -1
```

在上面的示例中，我们看到 `indexOf` 返回所求元素第一次出现的索引。这就是为什么它没有返回 'dog' 最后一次出现的索引。要从末尾搜索数组——我们使用 `lastIndexOf` 函数，它是 `indexOf` 函数的反向变体。

```javascript
var pets = ['dog', 'cat', 'hamster', 'bird', 'dog', 'goldfish'];
pets.indexOf('dog'); // 返回 0
pets.lastIndexOf('dog'); // 返回 4
```

`indexOf` 函数还接受第二个参数，用于从该位置开始搜索。默认情况下是零，因为函数的搜索从数组中的第一个元素开始。让我们看看它是如何工作的：

```javascript
var pets = ['dog', 'cat', 'hamster', 'bird', 'dog', 'goldfish'];
pets.indexOf('dog'); // 返回 0
pets.indexOf('dog', 2); // 返回 4
```

在上面的示例中，我们告诉 `indexOf` 函数从索引 '2' 开始开始搜索 'dog'。

## 什么是对象？

从字面上说，存在于几乎每一个事物都是对象。我们在这里不要考虑编程，让我们想想周围的一切。汽车是一个对象，它有特定的属性和某些功能。同样，你的电脑也是一个对象，它有某些属性并可以执行特定的功能。同样的，你的手机、烤面包机、明治机、电视等。用直白的话说，这些都是对象。

如何转化为编程逻辑？到目前为止我们一直使用函数和变量进行开发。然而，就像现实生活中一样，事实是所有对象都执行与其直接相关的功能。汽车有电机并移动，它不是用来烤三明治的。在编程术语中，将对象看作具有属性和方法（在本例中为变量和函数）的特殊代码块。

在运行对象之前，我们需要创建一个对象。为了创建一个对象，我们需要定义所谓的类。

类和对象。区别是什么？在非常坦率的话中，对象是类的实例。类可以被看作是制造对象的蓝图。它是一个带有函数和属性的代码块。当你定义一个类并从该类创建一个对象时，对象拥有了自己的属性和方法。这就像一个制造汽车的工厂。制造汽车的蓝图可以假设为类，产出的每一辆汽车都是该类的实例。别担心，创建对象不需要你建立一个制造工厂，但你需要一个蓝图。

即类（class）。

有趣的是，我们直一直在使用许多对象（Objects）和类，而完全没有意识到。回想上一章关于数组的内容，我们使用以下语句创建了一个数组：

```
var a = new Array();
```

在上面的示例中，`Array` 是一个 JavaScript 类，它定义了数组对象（Object）。`new` 关键字创建了 `Array` 类的一个实例。因此，在上面的示例中，变量 `a` 是 `Array` 类的一个对象，因此它拥有 `Array` 类的所有方法和属性。就像每一辆按照蓝图制造的汽车都有自己的一套四个轮子和引擎一样。

我们在上一个章节中也使用了数组对象的方法。我们使用的一些方法有：

```
var a = new Array();
a.sort();
a.join(',');
a.shift();
```

不仅如此，我们还使用了数组对象的一个属性，即：

```
var a = new Array();
a.length // length 属性
```

方法和属性定义在类内部，并可以从类的对象访问。这正是我们在之前的章节中所做的。甚至在此之前，我们已经使用了从第一章就开始提供给我们的对象。即 `document` 对象：

```
document.write('hi');
```

注意，`document` 对象是 JavaScript 中提供的一个对象，它不是一个类而是一个对象，它指向浏览器中的页面。我们使用的 `write` 方法是 `document` 对象的一个方法。事情开始变得清晰了。我们已经略微体验了如何使用对象，以及我们长期以来一直在使用对象。现在，让我们开始理解它们是如何工作的，以及我们如何创建自己的对象。

## 一个简单的对象

让我们创建我们的第一个对象（Object）。在 JavaScript 中，创建一个对象非常简单。

```
var dog = { name:'Fido', breed:'Bulldog', age:2};
```

这看起来和声明数组有点像。主要的区别在于，在最简单的形式下，对象技术上是一个非数值索引的数组。数组只有数值索引，而对象不是数值索引的。看起来像索引的部分实际上被称为属性行（properties lines）——上面的示例也可以分几行写——换行符不会影响对象。

```
var dog = {
    name:'Fido',
    breed:'Bulldog',
    age:2
};

dog.name; // 等于 Fido
dog.breed; // 等于 Bulldog
```

使用 JavaScript 的 `new` 关键字来创建一个新对象的另一种替代方法。

```
var dog = new Object();
dog.name ='Fido';
dog.breed ='Bulldog';
dog.age = 2;
```

上面的代码与之前的示例相同。虽然对于更简单的对象，之前的示例更易读，并且是声明简单对象的首选方法。

声明对象的另一种方法是使用 JavaScript 中称为“对象构造函数”（Object constructor）的东西，这在面向对象的术语中等同于类（class）。这是一种特殊的声明，允许你定义一个蓝图，该蓝图将定义从它创建的所有对象。例如，在上面的示例中，我们为单只狗声明了一个对象。如果我们想对多只狗进行同样的操作呢？我们可以显式地为每一个狗对象使用相同的声明。

```
var dog1 = { name:'Fido', breed:'Bulldog', age:2};
var dog2 = { name:'Rover', breed:'Wolfhound', age:3};
var dog3 = { name:'Butch', breed:'Dashund', age:2};
var dog4 = { name:'Mitch', breed:'Sheepdog', age:2};
var dog5 = { name:'Bowerser', breed:'Alsatian', age:2};
```

这是非常冗余且极易出错的。我们在这里创建同一种对象——所以使用对象构造函数或定义对象蓝图的类是合理的。在这种情况下，类构造函数（class constructor）将定义属性，即 `name`、`breed` 和 `age`，这样我们就不需要在每次创建狗对象时显式地定义它们。让我们来看演示。

```
function dog(name, breed, age) {
  this.name = name;
  this.breed = breed;
  this.age = age;
}

var fido = new dog("Fido", "Bulldog", 3);
var rover = new dog("Rover", "Wolfhound", 2);
```

这里发生了很多事情，但我们可以清楚地看到，使用我们名为 `dog` 的对象构造函数来创建一个新的狗对象要容易得多。这种函数被称为构造函数（constructor），因为它在“构造”对象时创建并初始化了对象的属性。你还注意到了名为 `this` 的 `new` 关键字的使用。`this` 关键字在对象的上下文中使用。它只在类定义内部使用，并引用对象本身。

它在对象创建时产生。因此，`this.name` 是使用上述类构造函数创建的对象的 `name` 变量。在上面的示例中，你可以看到 `this.name` 和传递给构造函数的 `name` 之间的区别，其中 `this.name` 指向对象的 `name` 变量实例。以这种方式创建对象时，我们可以像访问之前创建的对象的属性一样访问这些属性。

```
var fido = new dog("Fido", "Bulldog", 3);
fido.name; // 等于 'Fido'
```

通过对象构造函数，你可以根据对象构造函数定义的相同类型创建任意数量的实例。你甚至在创建对象后还可以创建一个对象属性。

```javascript
var fido = new dog("Fido", "Bulldog", 3);
fido.name; // 等于 'Fido'
```

```

```

### 对象添加方法

不仅仅是属性，你还可以为对象赋值函数，这些被称为方法（methods）。方法的声明方式与属性相同。看这个简单的例子：

```javascript
function dog(name, breed, age) {
  this.name = name;
  this.breed = breed;
  this.age = age;
  this.feed = function(food) {
    document.write(this.name + ' likes ' + food);
  }
}
```

```javascript
var fido = new dog("Fido", "Bulldog", 3);
fido.feed('kibbles'); // 输出 'Fido likes kibbles'
```

在上面的示例中，我们声明了一个方法 `feed`，传递了参数并从创建的对象中调用了它。上面的示例还展示了在函数内部使用 `this` 关键字引用对象的属性。同时，我们还可以在函数内部引用外部对象，就像我们调用 `document` 对象的 `write` 方法一样。通过方法，我们还可以编辑对象的底层属性。这是一个例子：

```javascript
function dog(name, breed, age) {
  this.name = name;
  this.breed = breed;
  this.age = age;
  this.addAge = function(years) {
    this.age+=years;
  }
}

var fido = new dog("Fido", "Bulldog", 3);
var rover = new dog("Rover", "Sheepdog", 4);
```

fido.addAge(3);
rover.addAge(5);

fido.age; // 等于 6
rover.age; // 等于 9

我们创建了两个对象并修改了每个对象的 `age` 属性。你可以看到，从同一个构造类创建的两个对象都有自己的属性和方法。属性和方法对于每个创建的对象都是唯一的。你已经可以看到使用对象的灵活性以及面向对象开发实际上是如何运作的。所有相关的代码和属性都汇总在同一个对象中。如果没有对象，你的代码将是变量和函数的混乱，你将苦于尝试将相互关联的值组合在一起。考虑一下如果没有对象完成上述操作将会是怎样的噩梦：

```
var fido_name = 'Fido';
var fido_breed = 'Bulldog';
var fido_age = 3;
```




```javascript
var rover_name = 'Rover';var rover_breed = 'Sheepdog';
var rover_age = 5;
// Please no more
```

### 对象让编程再次变得意义

万物皆对象
在 JavaScript 中，几乎一切都是对象（Object）。JavaScript 提供了一系列默认的 Object 类型，我们在日常编程中使用这些类型。当我们说“万物”时，意思实际上是指几乎一切。你创建的变量、函数和数组——一切都是对象，并且像对象一样对待。当我们说“像对象一样对待”时，意味着所有此类对象都有自己的属性和方法。我们并没有定义它们——因为 JavaScript 已经为我们预定义了大部分内容（JavaScript 这样做真是太贴了，不是吗）。

### JavaScript 原生对象
就像 Array 对象和 Object 对象一样，JavaScript 为许多对象定义了构造函数。我们这段时间一直都在使用其中大多数对象，例如：

- 数字 (Numbers)
- 字符串 (Strings)
- 日期 (Dates)
- 对象 (Objects)
- 数组 (Arrays)
- 函数 (Functions)
- 日期 (Dates)

这些对象中的某些映射到了我们这段时间一直在使用的原始数据类型（primitive datatypes）。例如，让我们看看数字。下面的代码的作用：

```javascript
var a = 10;
```

如果你说它给变量 `a` 赋值为数字 10，你是完全正确的。然而，你也可以使用 JavaScript 的 Number 构造函数将其声明为数字对象：

```javascript
var a = new Number(10);
```

这与声明原始变量的区别在于，当你声明一个变量时，你只是声明了一个变量；但当你像上面示例那样将其声明为 Number 构造函数的对象时，你随之获得了一系列属性和方法。在 JavaScript 中，你可以将原始变量和值像对象一样对待。

**提示：** 使用原始变量，它们速度更快——只有在真的需要时才使用 JavaScript 构造函数。

让我们看看 Number 对象提供的一些方法和属性。

```javascript
var a = new Number(10);
a.NaN(); // 检查 a 是否为数字，返回 true 或 false
a.toString(); // a 现在等于 '10'，这与 10 不同
```

`NaN` 方法检查该值是否为数字（NaN = Not A Number，不是数字）。注意，此函数仅在对象是 Number 对象时实际有效，并针对存储的值进行检查。或者，你可以使用全局函数 `isNaN` 来检查变量是否具有数值。

```javascript
var a = 10;
a.NaN(); // 返回 undefined
isNaN(a); // 返回 false，因为它是一个数字
```

同样，`.toString()` 函数将数字对象转换为字符串值。所以我们知道 '10' 不等于 10，因为后者是数字，而前者是字符串。

接下来让我们看看字符串对象。我们在大多数文本示例中都使用了字符串，并且对字符串是文本数据这一事实非常熟悉。在之前的章节中我们也使用了与字符串相关的函数。JavaScript String 对象将在下一章节中进行详细地介绍，其他主要的 JavaScript 对象也是如此。

在 JavaScript 中声明字符串时，你可以通过两种方式之一来实现：

```javascript
var str = 'Hello';
var str = new String('Hello');
```

两种方法大体相同，但第一种方法更快更高效。一旦你创建了字符串，就会获得了一系列方法和属性。例如，这里是使用字符串时获得的一些属性和方法的示例：

```javascript
var str = 'Hello';
str.length; // 返回 5，字符串的长度
str.trim(); // 字符串两端的末尾空格
str.concat(' there'); // 将传入的字符串连接到字符串上——就像数组的 concat 工作方式一样
```

我们将在下一章节中详细讨论各种字符串方法和属性。

# 第 8 章：字符串对象

JavaScript 字符串不仅仅是文本数据。当你在 JavaScript 中创建一个字符串时，你会获得一系列属性和方法，通过它们与字符串交互并对其处理。深入了解 JavaScript 中字符串对象包含的内容将帮助你完成最基础的编程任务，节省你编写函数的时间，否则这些功能可以通过 JavaScript 字符串对象的现有方法来处理。

## 概述

我们将讨论 JavaScript 字符串对象，并介绍字符串对象可用的各种属性和方法。我们还将理解字符串对象方法的影响，并介绍几个说明其用法的真实世界示例。

## 所有字符串都是对象
如你所知，字符串是文本数据。它们可以包含字母、数字、运算符、带符号字符等。字符串始终包含在双引号或单引号内。当字符串包含单引号或双引号时，通常会使用反斜杠进行转义。字符串像其他对象一样是可以创建的。

```javascript
var str = 'This is a string';
var str = new String('This is a string');
```

在上面的示例中，我们通过两种方式创建了字符串：隐式地声明一个字符串值，以及创建一个 String 实例。这两种方式都会获得一个系列方法和属性。让我们看看字符串自带的一些属性和方法。

## 字符串长度以及关于字符串的其他事实
字符串对象为我们提供了一些操作属性。最常用的属性是 `length` 属性。它的工作方式与数组类似，即返回字符串的长度。

```javascript
var str = 'This is a string';
str.length; // 等于 16——空格也被计数
```

```javascript
var str = ' ';
str.length; // 等于 1——空格也被计数
```

```javascript
var str = '';
str.length; // 等于 0——空字符串
```

单用 `length` 属性可以判断字符串是否为空，但它通常与循环或其他用于搜索或提取字符串的方法配合使用。字符串在某些方面与数组具有相似特性。例如，字符串中的单个字符可以通过索引引用，就像引用数组的单个元素一样。

```javascript
var str = 'This is a string';
str[0]; // 等于 'T'
str[1]; // 等于 'h'
```

正如上面的示例所示，字符串可以像数组一样被拆解。让我们在简单的循环中使用 `length` 属性吧：

```javascript
var str = 'This is a string';
for(var i = 0; i<str.length; i++){
    document.write(str[i] + '<br/>');
}
```

我们刚刚在不同的行输出了字符串中所有的字母。就像数组一样，字符串的起始索引也是 0，这就是为什么循环字符串和循环数组的操作是一样的。

## 搜索/切片——你可以对字符串做什么
就像其他对象一样，字符串也拥有一系列方法，允许你根据需要操作和处理字符串。这在你需要验证任何类型的字符串输入、检查某个特定关键词的出现时特别有用。虽然以后你还会接触到一些可以简化过程的库，但请尽量使用 JavaScript 为对象提供的原生函数。这是因为通过使用原生 JavaScript 函数，你的代码将变得高效得多，从而带来更好的用户体验。

如果它是 JavaScript 原生的，那就是你的最佳选择




字符串与数组（Arrays）有很多许多相似的功能。例如，我们在数组的章节中查看过 `indexOf` 函数。对于数组来说，该函数会返回传递的元素在数组中第一次出现的位置索引。对于字符串，我们有相同的函数，其执行逻辑几乎完全相同。

```
var s = "Macaroni and Cheese";
s.indexOf('Cheese');// // 返回 13
```

你可以在字符串中搜索另一个字符串的出现情况，它将返回被搜索字符串首次出现的数值索引。将其视为一种基础搜索功能。如果没有找到该字符串，它将返回一个负值。

注意：此函数区分大小写。

```
var s = "Macaroni and Cheese"
s.indexOf('Cheese');// // 返回 13
s.indexOf('CHEEESE');// // 返回 -1
```

它的姊妹函数是 `lastIndexOf` 函数，它的作用与 `indexOf` 相反，返回传递的搜索字符串最后一次出现的位置。这与搜索数组时使用的函数完全相同，就像 `indexOf` 方法一样。该函数也区分大小写。

```
var s = "Cheddar Cheese and Gouda Cheese"
s.indexOf('Cheese');// // 返回 8
s.indexOf('CHEEESE');// // 返回 -1
```

```
s.lastIndexOf('Cheese');// // 返回 24
s.lastIndexOf('CHEEESE');// // 返回 -1
```

另一个常用功能是组合字符串的能力。我们在早的示例中已经使用了加号 `+` 来拼接字符串。

```
var s = "Cheddar Cheese";
var b = "Fried Onions";
var d = s + ' and ' + b;
d; // 现在等于 'Cheddar Cheese and Fried Onions'
```

或者，你也可以使用字符串的 `concat` 方法在在其后追加尽可能多的其他字符串。这与数组的 `concat` 函数完全一样。因此，上面的代码可以重写如下：

```
var s = "Cheddar Cheese";
var b = "Fried Onions";
var d = '';
d.concat(s, ' ', b);
d; // 现在等于 'Cheddar Cheese and Fried Onions'
```

注意，即使是使用数组，你也需要将变量声明为字符串才能使用其函数。

```
var s = "Cheddar Cheese";
var b = "Fried Onions";
d.concat(s, ' ', b); // 这将不起，因为我们还没有声明 d
```

字符串还允许你操作内部的内容。你可以使用两个方便的函数 `toLowerCase` 和 `toUpperCase` 分别更改字符串中所有字母的大小。其中一个函数你绝对会经常用到。

```
var s = "Cheddar Cheese";
s.toUpperCase(); // s 现在是 'CHEDDAR CHEESE'

```

s.toLowerCase(); // s 现在是 'cheddar cheese'
```

有时，特别是在从用户处获取输入时，你可能希望确保输入的任何数据都没有尾随空格。这看起来很难看，并且当你想要排序字符串数据时会导致问题。此外，假设你正在获取一个密码，某人不小心多加几个空格（这是可能发生的！），你可能会导致用户感到沮丧，因为密码不起而他不记得加过空格（反正空格也不是好密码）。JavaScript 提供了 `trim` 函数，可以去除任何多余的尾随或领先空格。

```
var name = " George Glass ";
s.trim(); // s 现在是 'George Glass'
```

### 分割中的字符串 (Strings in Splits)

记得在数组中，我们有一个 `join` 函数，它技术上可以用分隔符将数组的所有元素胶合在一起给你一个字符串。相反，字符串提供了该函数的反义词，即 `split` 函数。`split` 函数不是连接内容，而是根据分隔符将字符串拆分为一个子字符串数组。它的工作方式与数组的 `join` 函数仅是相反。

```
var s = "Cheese,Onions,Pickles,Tomatoes";
s.split('/'); s; // 等于 ['Cheese','Onions','Pickles','Tomatoes']
```

```
var s = "Dogs and Cats and Mice";
```

```
s.split(' ');
s; // 等于 ['Dogs','Cats','Mice']
```

请注意，即使使用 `split` 函数，搜索的分符也是区分大小写的。默认情况下，所有的字符串函数都区分大小写。

```
var s = "Cheese and Onions and Tomatos";
s.split(' And ');
s; // 等于 ["Cheese and Onions and Tomatos"]
```

### 搜索 - 正则表达式，我的天 (Search - Regular Expressions Oh My)

此时，我们想介绍 JavaScript 在字符串搜索方面的一个非常强大的功能。有时你需要进行搜索，你的查询将比仅仅查找字符串中区分大小写的子串出现要复杂得多。你想要确保一个邮箱是有效的邮箱吗？你可以搜索 `@` 符号的出现情况——但你如何确保没有其他错误的符号呢，你如何检查以确保它是正确的格式？你需要使用大量的嵌套 `if` 语句才能完成此任务。如果你需要检查输入的电话号码是否有效，或者社会安全号码呢？显然，在这里查找第一次和最后一次出现的位置是不行的。

现在引入正则表达式（Regular Expressions）。正则表达式是一组特殊的字符序列，用于形成搜索模式。它们起初可能相当困惑，但如果操作正确，它们非常强大。通过正则表达式，你使用字符的混合定义要搜索的模式。在正则表达式中，不同的字符和运算符在形成模式时具有不同的含义。

正则表达式通过在 JavaScript 中创建一个显式的 `RegExp` 对象或通过在两个斜杠 `/ /` 之间声明模式本身来实现。

这是一个执行非常简单搜索的正则表达式示例。

```
var s = 'Cheese and Onions';
var r = /cheese/i; // 我们的正则表达式
```

我们声明了一个简单的正则表达式。它本身没做什么，但当我们当我们将其与一个接收正则表达式的方法一起使用时，例如字符串的 `search` 方法。

```
var s = 'Some Cheese and Onions';
var r = /cheese/i; // 我们的正则表达式
s.search(r); // 返回 5
```

上面的正则表达式由两个元素组成——斜杠内部是待搜索的字符串。末尾的字母 `i` 被用作“修饰符”（modifier）。字母 `i` 在反斜杠后使用时表示不区分大小写的搜索，因此正则表达式在搜索时将无论其大小写如何都返回出现的情况。这比使用一堆混乱的 `if` 语句有效得多！

此外，我们用于斜杠之间使用的不仅仅是文本。记得我们还可以使用特殊字符编写模式来创建搜索模式。让我们看看正则表达式制作的一些模式。

方括号 `[]` 在斜杠内使用时，意味着搜索括号内的任何字符。

```
var r = /[ce]/i; // 我们的正则表达式
```

上面的正则表达式将匹配 `c` 和 `e` 的所有出现情况（区分大小写），当用于搜索操作时（等等，后文提到了替换）。让我们在另一个你会经常使用的有用函数中使用正则表达式，即 `replace` 函数。`replace` 函数接受两个参数，第一个是要搜索的正则表达式，第二个参数是用于替换匹配值的字符串。

```
var s = 'Cheese and Onions';
var r = /cheese/i; // 我们的正则表达式
```

s.replace(r, 'Thyme'); // r 现在是 'Thyme and Onions'

```
var s = 'Cheese and Onions';
var r = /[ce]/i; // 我们的正则表达式
s.replace(r, 'x'); // s 现在是 `hese and Onions`
```

这应该是理解的，但在上面的带有方括号的示例中，只有第一个出现的 `c` 被替换了。这是因为默认情况下正则表达式只匹配第一次出现。如果我们想匹配所有出现的情况，我们必须使用一个新的修饰符，即 `g` 修饰符。`g` 是全局修饰符，并将模式应用于字符串中所有可能的出现情况。

注意，修饰符可以共同工作

```
var s = 'Cheese and Onions';
var r = /[ce]/g; // 我们的正则表达式
```




```javascript
s.replace(r, 'x'); // s is now `Chxxsx and Onions`
var s = 'Cheese and Onions';
var r = /[ce]/ig; // our regular expression
s.replace(r, 'x'); // s is now `Xhxxsx and Onions`
```

```javascript
var s = 'Cheese and Onions';
var r = /[ce]/gi; // our regular expression
s.replace(r, 'x'); // s is now `Xhxxsx and Onions`
```

正则表达式本身是一个非常复杂的话题，即使是涵盖其基本用法至少也需要用一整本书才能说清楚。我们已经简略触及了正则表达式，但你已经可以看到它的可能性，以及在正则表达式的帮助下可以进行多么通用的搜索。

另一个可以考虑用于搜索的有趣函数是 `match` 函数。该函数正如其名，会搜索字符串并返回可能的匹配项（如果有）。此函数与 `search` 的不同之处在于 `search` 函数只返回第一次出现的位置索引。

```javascript
var s = 'Some Cheese, cheeses and Onions';
var r = /cheese/i; // our regular expression
s.match(r); // returns ["Cheese"]
```

```javascript
var s = 'Some Cheese, cheeses and Onions';
var r = /cheese/gi; // our regular expression
s.match(r); // returns ["Cheese", "cheese"]
```

如何对一些字符串进行切片和处理呢？
我们已经了一些字符串的原生函数来搜索它们，并根据搜索字符串以及正则表达式进行替换。除此之外，你还可以像专业的寿司厨师一样切分和分割字符串。

JavaScript 提供了 `substring` 和 `substr` 函数。这两个函数的功能相同，但有细微的差别。它们接受两个参数：第一个是提取开始的字符串索引，第二个参数是可选的。对于 `substr`，它接收的是要提取的字符串长度；对于 `substring`，它接收的是要提取的下一个索引。如果省略第二个参数，则提取从索引开始的整个长度的字符串。

```javascript
var s = "Cheese and onions pizza";
s.substring(0, 1); // returns C
s.substr(0, 1); // returns C
```

```javascript
s.substring(2, 4); // returns ees
s.substr(2, 4); // returns eese
```

在 `substring` 函数中，如果传入的第二个值小于第一个值，这两个值会交换，因为提取的第二个索引不能小于提取的起始索引。

```javascript
var s = "Cheese and onions pizza";
s.substring(7, 5) == s.substring(5, 7);
```

这些函数在与搜索函数以及正则表达式配合使用，可以帮助开发基于复杂字符串处理的应用。

## 总结

- 我们知道字符串可以显式创建，也可以通过给变量赋值字符串值来创建。
- 字符串类似于数组，因为它们有索引并共享类似的函数。
- 字符串也可以使用正则表达式搜索。
- 正则表达式是顺序字符，有助于定义用于字符串函数的搜索模式。
- `substring` 和 `substr` 函数用于根据起始索引和长度/结束索引来提取字符串的部分。

# 第 9 章：Date 对象

你可以用 JavaScript 创建并使用的有用对象之一是 `Date` 对象。它几乎被应用于每一个应用程序中。了解日期不仅仅是知道今天是星期几，你很快就会学到。

## 概述

在本章中，我们将触及 `Date` 对象以及如何创建和实例化它。我们将理解 JavaScript 如何处理日期，以及 `Date` 对象为我们提供的许多可用函数。在本章过程中，我们将理解 `Date` 对象可以很好的实际场景，并澄清如果忽略可能会引起混淆的微妙问题。

日期——我们在这里指的是日历！JavaScript 提供了一个内置的 `Date` 类构造函数来创建日期对象，不，这些不是可食用的类型，也不涉及浪漫的约会。`Date` 对象用于处理日期和时间。它还允许你处理和操作日期的组成部分，即年、月、日、秒、分、小时和毫秒。`Date` 对象带有很多方法和属性。在编程中，日期本身是一种特殊的数据类型，它们在所有数据库中都被特殊地表示为数据类型，而且几乎每个编程语言都有处理日期的规定。

创建一个 `Date` 对象非常简单，你只需要对日期对象进行显式声明：

```javascript
var dt = new Date();
```

上面的 `dt` 变量是一个日期对象。如果你使用 `document.write` 输出它，你会得到精确到最近毫秒的当前日期时间，甚至是你所在的时区。类似于：

Wed Dec 31 2014 11:49:31 GMT+0400 (Arabian Standard Time)

`Date` 对象获取你运行网站的机器上设置的当前日期。记住，JavaScript 是一种客户端语言，意味着它在浏览器中运行，因此获取的日期将是你计算机上设置的日期。要尝试一下，只需更改计算机中的日期和时间即可。



```javascript
var dt = new Date(2012,11,31); // dt 现在等同于
Wed Dec 31 2012 00:00:00 GMT+0400 (Arabian Standard
Time)
var dt = new Date(2012,11); // dt 现在等同于 Wed
Dec 1 2012 00:00:00 GMT+0400 (Arabian Standard Time)
```

顺便提到，如果你使用的月份数字大于 11，日期将按超过 11 的月数增加。

```javascript
var dt = new Date(2012,11,31); // dt 现在等同于
Dec 31 2012 00:00:00 GMT+0400 // dt 现在等同于
var dt = new Date(2012,12,31); // dt 现在等同于
January 2013 - 12 是 12 月再加一个月
var dt = new Date(2012,13,10); // dt 现在等同于
February 2013 - 13 是 12 月再加两个月
在下一年
var dt = new Date(2012,13,40); // dt 现在等同于
March 2013 - 13 是 12 月再加两个月在
下一年
```

当你想要创建一个特定日期而不需要过多担心格式正确时，这非常有用；此外，如果你需要在循环中处理日期，这也非常有用。

得于 `toString` 方法，日期会自动显示。默认情况下，当你创建一个日期对象时，你本质上创建了一个 Object，但当你使用 `document.write` 它时，正如我们看到的，它会完美地打印为字符串。否则，如果你创建一个自定义 Object并尝试直接打印，它只会打印 Object。这是由于 `toString` 方法，每当日期对象需要被视为字符串时，JavaScript 都会自动调用此方法。

```javascript
var dt = new Date(2012,11,31);
document.write(dt) == document.write(dt.toString()); //
两者是相同的
```

## 日期由什么组成？

JavaScript Date 对象为你提供了许多方法来操作日期。虽然我们已经看到了如何使用字符串、参数集和毫秒来创建一个自定义的 Date 对象，但在获取 Date 对象后，你所能的操作真正展现了该对象的威力。我们需要理解并显然知道，日期是由年、月、日组成的。由于 JavaScript Date 对象还考虑了时间，因此日期也包含了小时、分钟、秒和毫秒。我们有一系列函数，允许我们获取和修改日期对象的任何部分。这非常有用，特别是当你想要比较两个日期时。

```javascript
var dt = new Date(2012,11,31, 10, 30, 20); // 它是 2012 年的最后一天，世界还没有毁灭！呼！
dt.getFullYear(); // 返回 2012
dt.getMonth(); // 返回 11，日期的月份！
dt.getDate(); // 返回 31 - 月中的几号
dt.getDay(); // 获取 1，即周一 - 周日是 0，周一是 1，一直到周六是 6
dt.getHours(); // 返回 10
dt.getMinutes(); // 返回 30 分钟
dt.getSeconds(); // 自显自懂
dt.getMilliseconds(); // 自显自懂
```

JavaScript 还提供了 `getTime` 方法，它可以获取从零时间开始的指定日期的毫秒数。如果你想检查一个日期是否比另一个晚或更早，这非常有用，特别是当你想要根据日期对数组进行排序时。

注意，在上述所有方法中，获取的细节是相对于你计算机上的时区的。除了上述方法外，JavaScript 还提供了类似的方法，仅相对于 UTC 获取相同的细节，并考虑了你 PC 上的时区。它们的命名如下：

```javascript
var dt = new Date(2012,11,31, 10, 30, 20); // 几分钟或几小时就能完全改变一个日期
dt.getUTCFullYear(); // 返回根据 UTC 调整的年份
dt.getUTCMonth(); // 返回根据 UTC 调整的月份
dt.getUTUTCDate(); // 返回根据 UTC 调整的日期
dt.getUTCDay(); // 返回根据 UTC 调整的星期几
dt.getUTCHours(); // 返回根据 UTC 调整的小时
dt.getUTCMinutes(); // 返回根据 UTC 调整的分钟
dt.getUTCSeconds(); // 再次自显自懂
dt.getUTCMilliseconds(); // 自显自懂
dt.getUTCDatetime(); // 返回根据 UTC 调整的整个日期 - 即 getDate() 的 UTC 等效值
```

在处理日期时，考虑时区差异是非常重要的。你必须意识到用户的时区以及他可能进行交易的时间。通常，日期是基于世界标准时间（UTC）存储的，然后转换为匹配用户的时区，以便在网页中显示。

你可能注意到上述所有方法中的一个共同模式，即它们都以 `get` 前缀开头。对象拥有属性，与其直接访问属性，面向对象编程的常见做法是拥有简单的函数来获取这些单独属性的值。这些函数被称为获取器（getter），通常通过在属性名称前加上 `get` 来命名。正如你有获取器一样，你也有设置器（setter）来设置这些单独属性。它们遵循类似的命名规则，因此以 `set` 为前缀。所以所有方法都有一个接收一个变量的替代方法。

```javascript
var dt.setFullYear(2013); // 年份

..set((2); //  0  11 的数字
..setDate(23 // //  1  31之间的数字
dt.setHours(12); //  0  23数字
dt..set((4); // // 0 到 59 的数字
dt.setSeconds(45); // 自显自懂
dt.setMilliseconds(0); // 自显自懂
```

在处理日期时，考虑时区差异是非常重要的。你必须意识到用户的时区以及他可能进行交易的时间。通常，日期是基于世界标准时间存储的，然后转换为匹配用户的时区，以便在网页中显示。





```javascript
var dt = new Date();
dt.toString(); // Thu Jan 01 2015 17:07:17 GMT+0400
(GST)
dt.toDateString(); // Thu Jan 01 2015
dt.toUTCString(); // Thu, 01 Jan 2015 13:05:59 GMT
dt.toLocaleTimeString(); // 17:05:56 GMT+0400 (GST)
```

除了 `toString` 函数外，你还可以使用 `toDateString` 输出部分日期，或者使用 `toString` 函数仅输出日期的部分部分。别忘了，这些函数也有 UTC 版本，用于打印 UTC 等效内容。

## 总结
我们知道 JavaScript 提供了一个复杂的日期对象来处理日期。日期可以通过四种不同的方式实例化。零时间指的是 1970 年 1 月 1 日午夜。JavaScript 中的日期是以相对于零时间的毫秒数形式存储的。可以使用原生 `Date` 对象的 getter 和 setter 函数来获取和设置日期的各个组成部分。

# 第 10 章：文档是一个对象

当我们谈论面向对象编程时，也要知道在开发网页时——面向对象起着非常重要的作用。不仅仅是变量和日期被视为对象，HTML 页面上的几乎所有内容包括页面本身也被视为对象，并且像所有对象一样，它们拥有自己的方法和属性可以被访问和操作。

## 概述
在本章中，我们将学习文档对象模型（DOM），它定义了构成网页的不同元素，以及每个元素是如何作为一个对象的。我们还将学习页面上的每个元素都是一个节点（node），包括页面本身，以及用于与它们交互的不同属性和方法。

## 一切都是对象
HTML DOM 或文档对象模型是用于定义和访问网页内容（即 document）的 W3 标准。HTML DOM 是一个标准约定接口，它将所有元素定义为对象，以及每个元素固有的属性以及每个元素可用的方法和事件。

网页中的每个元素（包括网页本身）被称为节点。这些节点以树结构排列，以文档节点为根节点，其他节点随其后，例如：

```html
<html>
  <head></head>
  <body></body>
</html>
```

文档节点中的第一个节点是 `html` 节点，它分别分支为 `head` 元素节点和 `body` 元素节点，依此类推。

当网页被渲染时，会创建一个该页面的文档对象模型，其中每一个元素都加载为树上的一个节点。这是理解 DOM 的非常重要的方式，为了能够对其进行交互和操作，我们将使用 DOM 提供的许多方法来实现。

页面上的每个元素（包括页面本身）都是 `node` 类的对象。`node` 是基类，定义了页面上的每个元素以及页面本身。正因如此，几乎所有对象都有相似的方法和属性，以及它们自己的特殊属性。

让我们从创建一个基础 HTML 页面开始，我们将在接下来的练习中使用它。你可以将所有 JavaScript 代码放在页面 `head` 中的 `script` 标签中，也可以放在外部 `.js` 文件中并作为外部脚本链接该文件。

```html
<html>
  <head>
    <title>Hello World</title>
  </head>
  <body>
    <h1>The Page</h1>
    <p id="sub" class="base">This is some text on the page</p>
    <table class="base">
      <tr>
        <td>Item</td>
        <td>A</td>

## 再次强调：一切都是对象

有趣的是，正如文档模型（DOM）拥有自己的一set属性和方法，页面上的元素也是如此。由于包括 `document` 在内的所有元素都继承自 `Node` 对象，它们共享许多相似的函数，但同时某些元素拥有自己独立的方法和属性。

例如，某些元素会有 `href` 属性，而显然 `p` 或 `table` 则不会。同样，某些元素默认显示为块级（block），而某些显示为行内（inline）。这些内容在学习 HTML 和 CSS 时会有更好的讲解，因此我们现在涵盖这些可用方法。

上面的示例返回一个元素数组，与之前一样。但如果你在控制台中输出它，你会发现之前的示例返回了三个元素，而这个示例只返回了两个。原因是这些检索元素是相对于调用的对象工作的。`document` 对象包含了每个 HTML 元素，因此 `getElementsByClassName` 或 `getElementsByTagName` 会搜索所有包含的元素。当与单个父元素配合时，它会搜索所有的子节点或元素。

var el = document.getElementsByName('list') [0];
var ch = el.children;
console.log(ch); // 以数组形式获取所有子元素

var el = document.getElementsByName('list') [0];

var ch =

console.log(ch); // ????
```

等一下，获取到的第一个节点是一个空字符串吗？因为和 `childNodes` 属性一样，这个属性也将空格视为单独的元素。从技术上讲，修剪所有空格可以让页面加载更快。因此，在不带空格的 HTML 上使用相同的代码，你应该就能得到第一个元素了。

或者我们在这里使用 `firstElementChild` 属性，因为它方便地忽略了空格和注释。所以，保留你那易读的 HTML 代码并使用以下 JavaScript：

```javascript
var ch =

等一下，我们如何获取第二个元素呢？在这种情况下，我们想要获取当前选定的 `firstChild` 的下一个元素。请注意，同一层级的所有元素被称为兄弟元素（siblings），包含其他元素的元素被称为被包含元素的父元素（parent element），而被包含的元素被称为父元素的子元素（child elements）。JavaScript 提供了两个有趣的函数来遍历兄弟元素，就像我们之前使用 `firstChild` 属性移动到子元素一样。

```javascript
// 注意：在无空格的 HTML 中使用
var ch =
document.getElementsByName('list') [0].firstChild;
ch2 = ch.nextSibling
ch == ch2.previousSibling
```

```javascript
// 注意：在普通 HTML 中使用
var ch =
document.getElementsByName('list') [0].firstElementChild;
ch2 = ch.nextElementSibling
ch == ch2.previousElementSibling
```

这两个函数及其变体 `previousSibling`、`nextSibling` 通过访问同一层级上的相邻元素来遍历 DOM。我们首先获取了第一个元素，然后遍历并移动到与第一个元素相邻第二个元素。

让我们把这些操作推得更远 - 如果我们想删除第二个元素怎么办？或者在这里添加另一个元素。我们可以用 JavaScript 实现这一点。

```javascript
// 注意：在无空格的 HTML 中使用
var list = document.getElementsByClassName('list') [0];
var ch = list.firstChild;
list.removeChild(ch); // 我们移除了第一个子节点
```

`removeChild` 方法接收要从父元素中删除的实际节点。是父元素执行了删除操作。同样，我们也可以使用 `appendChild` 和 `insertBefore` 函数类似地添加子元素。

在插入元素之前，你需要创建它，或者使用一个已有的元素。让我们创建一个新的列表元素并将其添加到列表中。

```javascript
// 注意：在无空格的 HTML 中使用
var list = document.getElementsByClassName('list') [0];
var li = document.createElement("li");
li.innerHTML = 'This was added';
list.appendChild(li);
list.lastChild(); // 返回 li
```

文档模型中的 `createElement` 函数根据传递的标签创建元素。一旦你创建了元素，你就拥有了所有元素都拥有的属性和方法。在上面的代码中，我们设置了新创建的列表项目的 `innerHTML` 属性，并使用列表元素的 `appendChild` 方法将其添加到列表中。该方法由所有元素拥有。`appendChild` 将传递的元素作为父元素的最后一个孩子添加，正如我们在 `lastChild` 属性中看到的那样。你也可以使用 `insertBefore` 方法将元素插入到你喜欢的任何位置。它接收要插入的节点以及在其之前添加的节点。因此，你可以在文档的任何位置添加节点。

```javascript
// 注意：在无空格的 HTML 中使用
var list = document.getElementsByName('list')[0];
var li = document.createElement("li");
li.innerHTML = 'This was added';
list.insertBefore(li, list.lastChild); // 在最后一个元素之前
list.insertBefore(li, list.firstChild); // 在第一个元素之前
```

正如 `firstChild` 一样，`nextSibling`、`previousSibling`、`lastChild` 也有对应的忽略文本节点的版本 `nextElementSibling`、`previousElementSibling`、`lastElementChild`。

## 事件 - 别乱鼠标乱晃！

HTML 中最基础的交互形式是 `a` 标签。它是一个指向不同页面或资源的简单链接。然而，所有的 DOM 元素都能响应几乎任何类型的事件。预期的所有事件肯定是通过鼠标或光标完成。因此，所有与 DOM 元素相关的事件都是基于用户对鼠标的操作。

让我们在 HTML 内部本身创建一个简单的事件处理器示例：

```html
<a href="http://www.yahoo.com" onclick="return false;">Click</a>
```

将该代码放入你的 HTML 文件中并尝试点击链接。出于某种原因，它不起作用。如果你查看代码，你会发现我们为该元素添加了 `onclick` 属性。`onclick` 实际上对应用户的点击动作，而该属性的内容是纯 JavaScript。这部分代码仅仅返回布尔值 `false`。向点击处理程序返回 `false` 基本上意味着什么都不做。而正是我们所做的。让我们修改一下部分：

```html
<a href="http://www.yahoo.com" onclick="return confirm('Are you sure?');">Click</a>
```

运行它并现在点击，你会得到一个确认框，如果你回答肯定，它就会跳转，因为你传递了一个 true 值；如果你选择其他，它就不会跳转，因为你传递给它的是 false。这是在事件处理器中编写代码的一种非常简单的方法。但如果我们我们需要对多个链接执行此操作呢？

```html
<a href="http://www.yahoo.com" onclick="return confirm('Are you sure?');">Click</a>
<a href="http://www.google.com" onclick="return confirm('Are you sure?');">Click</a>
<a href="http://www.bing.com" onclick="return confirm('Are you sure?');">Click</a>
```

这非常单调。我们可以做的是将 JavaScript 放入函数中并调用该函数。

```javascript
function doConfirm() {
  return confirm('Are you sure?');
}
```

<a href="http://www.yahoo.com" onclick="doConfirm()">Click</a>
<a href="http://www.google.com" onclick="doConfirm()">Click</a>
<a href="http://www.bing.com" onclick="doConfirm()">Click</a>

好多了，但我们仍然需要对每个函数进行调用——让我们把处理事件的所有代码都放在这里的 JavaScript 中。

```javascript
var a = document.getElementsByTagName('a');
for(var i = 0; i < a.length; i++){
  a[i].onclick = function() {
    return confirm('Are you sure?');
  }
}
```

```html

```

var el = document.getElementById('foo');

```javascript
el.onkeydown = function(e) {
  counter = document.getElementById('counter');
  counter.innerHTML = e.keyCode;
}
```

现在在输入框中输入会显示你点击的每个按键的代码。这太棒了，但如果我们想告诉[我们]该代码代表什么呢？幸运的是，`String` 对象带有一个名为 `String.fromCharCode` 的方法，它可以将 Unicode 值转换为对应的字符。让我们再次修改上面的示例：

```javascript

  counter = document.getElementById('counter');
  code = e.keyCode;
  counter.innerHTML = String.fromCharCode(code);
}
```

尽管尝试一下吧——计数器现在填充了你一定按下的按键。你可能会发现，它对于基础字母数字字符运行良好，但对于其他键（如回车键、Esc 键和某些字符）则无效。

var frm = document.getElementById('theForm');

因此请进行以下调整：

```javascript
var frm = document.getElementById('theForm');
frm.onsubmit = function() {
  if(document.getElementById('name').value == '') {
    alert('表单无效，名称不能为空！');
    return false;
  } else {
    return true;
  }
}
```

现在你就可以就绪了，现在如果名称字段为空，表单就不会提交。

注意，上述示例中的 `else` 语句并不是真的需要的，没有它也可以正常工作。

## 你想要一个 cookie 吗？

我们说的不是和牛奶和奶油很搭配的食物，cookie（饼干）是网站在你的浏览器上创建的存储数据的文件。每当你使用网站时，你都会向服务器发送请求，服务器返回 html。然而，网站实际上没有办法将你识别为唯一用户。Cookie 帮助通过在用户的浏览器上存储关于用户的信息来识别用户。例如，在一个你进入时需要输入名字的网站上，如果不使用 cookie，那么在会话期间，你每次访问该网站都必须输入你的名字；但当名字被网站存储在 cookie 中时，它就能识别你并知道你的名字。

Cookie 以分号隔开的值和属性对的形式存储，例如：

```
'name=Bob; Age=32;'
```

Cookie 还可以附带一个过期日期，这允许浏览器清除旧 cookie，同时保留存储了大量数据的 cookie。
示例：

```
'name=Bob; Age=32; expires=Thu, 1 Feb 2015 12:00:00 UTC'
```

默认情况下，cookie 在浏览器关闭时会被删除，只有带有过期日期的 cookie 会保留到该日期。创建一个 cookie 非常简单，只需使用 `document.cookie`。

```javascript
document.cookie = 'name=Bob; Age=32; expires=Thu, 1 Feb 2015 12:00:00 UTC';
```

Cookie 也可以被修改，你只需要更改传递给原始 cookie 的属性即可：

```javascript
document.cookie = 'name=Jimmy; Age=16; expires=Fri, 2 Feb 2015 12:00:00 UTC';
```

删除 cookie 很简单，只需传入一个过去的过期日期，cookie 就会被删除。

```javascript
document.cookie = 'name=; Age=; expires=Thu, 01 Jan 1970 00:00:00 UTC';
```

要访问 cookie，你可以使用 `document.cookie` 属性来检索所有存储的 cookie。注意，检索 cookie 将返回上述字符串形式的字符串，你需要进行一些字符串处理。

## 移除用户。

我们有了一个功能完整的表单，可以添加并显示已添加的用户。但是，我们需要添加删除现有用户的功能。考虑在每个添加的元素上添加一个显示为删除（remove）的链接。点击此链接将从列表中删除该元素。这意味着我们需要创建一个元素并为其绑定一个点击 事件处理器，该处理器从数组中删除该元素。为了这一点，让我们稍微重写一下用户的 `getHTML` 函数。目前它返回一段 HTML 代码，让我们修复它使其返回一个节点（node）。

```javascript
this.getHTML = function() {
  node = document.createElement('p');
  node.setAttribute('style', 'padding:5px; border:1px #ccc');
  span = document.createElement('span');
  span.innerHTML = 'Name : ' + this.getName() + '<br/>';
  span.innerHTML += 'Date of Birth : ' + this.getDob().toString() + '<br/>';
  span.innerHTML += 'Address : ' + this.getAddress() + '<br/>';
  span.innerHTML += 'City : ' + this.getCity();
  node.appendChild(span);
  return node;
}
```

如你所示，我们使用 `document.createElement` 函数创建了几个元素。然后我们将每个单独的元素视为一个节点。通过这样做，我们可以分配事件处理器和代码，而这些在仅传递 HTML 对象时是无法实现的。现在我们还需要调整 `html` 属性，它接收一个 HTML 字符串。让我们修复它，这样我们就不一致地存储大量的 HTML 或节点，而是重写列表的 `getHTML` 函数，使其返回传递给它的单个元素的节点。我们还将重写列表的 `add` 函数，以便同时传递要添加的元素和要追加的 DOM 无序列表元素（unordered list element）。

我们还需要调整表单处理器中的代码，以便列表填充的是节点而不是纯 HTML：

```javascript

```javascript

运行上面的代码，现在点击删除链接。在这个示例中，元素已从无序列表中移除了。如果你注意到删除链接的处理器，我们使用了列表元素父节点的 `removeChild` 方法。在这种情况下，删除链接的父级是列表元素，而 `li` 元素的父级是 `ul` 元素。父元素可以移除子元素。

这一切都很好，但我们在这里有一个问题。我们只从 HTML 的无序列表中删除了元素，它仍然存在于列表对象的 `list` 属性中。要从中删除它，我们需要知道对应元素在列表中的索引。我们可以通过在 `getHTML` 方法中传递元素的索引来实现。记住，我们在添加节点时调用了 `getHTML` 方法，所以很容易获取最新的索引传递给函数。

```javascript
this.getHTML = function(elem, index){

  li.appendChild(usr);

  rm.setAttribute('href', '#');

    this.parentNode.parentNode.removeChild(this.parentNode);
    this.remove(index);

# 验证验证再验证

这是一个你刚刚构建的非常实用的应用程序。但它非常容易出错，我们需要确保输入的信息最初是有效的。首先我们


需要确保名称、城市和地址字段不为空。我们可以将所有这些验证逻辑放在表单的处理程序（handler）中，但那违背了面向对象编程的思想。难道用户对象不应该是由来告诉我们提供给它的信息是否有效的吗？现在回想，这很有道理。那么，让我们在用户对象的声明中添加一个简单的函数，来检查上述三个字段是否都不为空。它返回一个布尔值，表示所创建的用户对象是否有效。如果对象有效，我们就将其添加到列表中；如果无效，我们将弹出错误消息进行提示。

在你的用户对象中添加以下内容：

```
this.isValid = function() {
  errors = [];
  if(this.name.trim() == '') {
    errors.push('Name is required');
  }
  if(this.city.trim() == '') {
    errors.push('City is required');
  }
  if(this.address.trim() == '') {
    errors.push('Address is required');
  }

  if(errors.length > 0) {
    alert(errors.join(','));
    return false;
  } else {
    return true;
  }
}
```

这是一个检查列出属性是否为空的简单函数。无效元素将导致布尔值 `false` 和一个糟糕的警告消息。请对你的表单处理程序进行以下调整：
