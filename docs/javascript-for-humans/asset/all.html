What is the onload event?

<body onload = "ourMessage();"> The onload event triggers when everything is done loading on the page.

Thus, the function that we made, named

ourMessage()

will be activated the moment that the page is finished loading.

The onload event, is one of many

events that we can choose from

to activate our functions.
