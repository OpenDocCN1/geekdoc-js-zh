# 序言

这是《黑客手册》（`THP`）系列的第三版。以下是将要讨论的所有新漏洞和攻击的概述。除了新内容之外，还包含了一些来自先前书籍（至今仍相关）的攻击和技术，从而无需回头查阅旧书。那么，有什么新内容？过去几年更新的一些主题包括：

- 滥用 Active Directory
- 滥用 Kerberos
- 高级 Web 攻击
- 更好的横向移动方式
- 云漏洞
- 更快/更聪明的密码破解
- “白利用”（Living Off the Land）
- 横向移动攻击
- 多个自定义实验室
- 更新的语言 Web 漏洞
- 物理攻击
- 权限提升
- PowerShell 攻击
- 勒索软件攻击
- 红队与渗透测试
- 搭建你的红队基础设施
- 可用的红队指标
- 编写恶意软件并绕过 `AV`
- 以及更多内容

此外，我尝试整合了来自第一和第二版书籍读者的所有评论和建议。我想重申，我并非职业作家。我只是热爱安全领域，热爱教授安全知识，这是我最热衷的项目之一。我希望你会喜欢它。

本书还将更深入地介绍如何搭建实验室环境以测试你的攻击，并提供最新的渗透测试技巧。最后，我试图使这个版本更易于理解，因为许多学校已将我的书纳入课程。在可能的情况下，我添加了实验部分，以帮助提供测试漏洞或漏洞利用的方法。

与其他两本书一样，我尽量保持内容尽可能真实或“贴近现实”。我也尽量避免理论上的攻击，专注于我在个人经验中见过且确实有效的方法。我认为行业已经从渗透测试人员向红队人员发生了重大转变，我想向你展示为什么会有这种变化，而不是仅仅告诉你。如前所述，我的热情在于教学和激励他人。因此，通过这本书，我对你的目标有两方面：首先，我希望你进入攻击者的思维模式，理解攻击的“如何”；其次，我希望你利用所学的工具和技术进行扩展。阅读和重复实验只是其中一部分——我教给学生的主要课程是让你的作品证明你的才华。比起专注于简历（当然，你应该有简历），我认为拥有一个强大的公共 `Github` 仓库/技术博客在安全领域比一份优秀的简历更有说服力。无论你在蓝队防御还是红队进攻领域，参与其中并与我们的安全社区分享都是至关重要的。

对于那些没有读过我前两部书的人，你可能会想知道我的经验背景。我的背景包括在主要金融机构、大型公用事业公司、《财富》500 强娱乐公司和政府机构从事超过 `12` 年的渗透测试/红队工作。我还曾在大学教授进攻性网络安全多年，在多个安全会议上发表演讲，被许多安全出版物引用，在全国各地授课，组织了多次公共 `CTF` 竞赛，并创办了自己的安全学校。我的另一个热衷项目是在南加州建立了一个免费且开放的安全社区，名为 `LETHAL`（`meetup.com/lethal`）。现在，它拥有超过 `800+` 名成员，每月举行会议、`CTF` 竞赛等，已成为人们交流、学习和成长的绝佳平台。

需要注意的是，我同时使用了商业工具和开源工具。对于讨论的每一个商业工具，我都尝试提供相应的开源替代品。我偶尔会遇到声称只使用开源工具的渗透测试人员。作为一名渗透测试员，我发现这种说法难以接受。如果你应该模拟“现实世界”的攻击，那么“坏人”并没有这些限制；因此，你需要使用任何能完成任务的工具（无论是商业还是开源）。

我经常收到这样一个问题：“本书的目标读者是谁？” 很难确切说明本书具体面向哪类人群，因为我坚信任何安全从业者都能从中获益。 书中的部分内容对初学者来说可能过于艰深，有些部分对高级黑客来说又过于简单，而还有其他部分甚至可能不属于你的安全领域。

对于那些刚入门安全领域的新人，我从读者那里听到的一个最常见的问题是：他们往往在阅读第二或第三次（并确保阅读之间留有充足时间）时才能获得最大的收益。 本书中涉及了大量材料，有时需要时间去充分吸收。 所以，请放松心态，认真阅读，完成实验室练习和示例，搭建你的实验环境，将你的脚本或代码推送到公共的 `GitHub` 仓库，并开始撰写博客。

最后，作为一名红队成员，其能力一半取决于技术水平，另一半则取决于自信心。 许多社会工程学练习要求你克服紧张情绪，走出舒适区。 大卫·莱特曼曾说得最好：“假装不害怕实际上与真正不害怕效果一样好。” 虽然这句话需要打个折扣来理解，但有时候你确实需要信心，付诸行动，并且不要回头。
